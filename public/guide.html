살아있는 정보책 사용 가이드

이 가이드는 전자책을 편하게 읽는 방법을 알려줍니다.

📱 두 가지 읽기 모드

전자책은 두 가지 방식으로 읽을 수 있습니다. 상단 컨트롤 바에서 자유롭게 전환할 수 있어요.

📜 스크롤 모드 (기본)

위아래로 스크롤하며 읽는 방식입니다. 웹페이지를 읽듯이 자연스럽게 내려가면 됩니다.

📖 페이지 모드

종이책처럼 한 페이지씩 넘기며 읽는 방식입니다. 집중해서 읽을 때 좋습니다.

모드 전환 방법: 상단 컨트롤 바의 📖 또는 📜 버튼을 클릭하면 바로 전환됩니다.

📖 페이지 모드 사용법

페이지 모드에서는 여러 가지 방법으로 페이지를 넘길 수 있습니다.

페이지 넘기기

‹

(전자책 내용)

← 이전
왼쪽 화살표
다음 →
오른쪽 화살표
›
화면 양쪽에 ‹ › 화살표 버튼이 있습니다. 클릭하면 페이지가 넘어갑니다.
  • 다음 페이지: 오른쪽 › 화살표 버튼 또는 화면 오른쪽 아무 곳을 클릭
  • 이전 페이지: 왼쪽 ‹ 화살표 버튼 또는 화면 왼쪽 아무 곳을 클릭
  • 모바일: 손가락으로 좌우로 스와이프
  • PC: 키보드의 ← → 화살표 키

현재 위치 확인

화면 하단에 현재 페이지 / 전체 페이지가 표시됩니다. 예를 들어 "3 / 12"이면 전체 12페이지 중 3페이지를 읽고 있다는 뜻입니다.

상단 컨트롤 바

페이지 모드에서는 읽기에 집중할 수 있도록 상단 컨트롤 바(글자 크기, 다크 모드 버튼 등)가 자동으로 숨겨집니다.

⚠️ 스크롤 모드로 돌아가는 방법 (꼭 기억하세요!)

페이지 모드에서 스크롤 모드로 돌아가려면:

1단계: 상단 빈 영역을 터치하세요

컨트롤 바 (숨겨진 상태)
👆 여기를 터치!
(전자책 내용 영역)

2단계: 컨트롤 바가 나타납니다 (3초간)

가- 가 가+ 🌙 📜 이것을 클릭!
(전자책 내용 영역)

3단계: 스크롤 모드로 돌아왔습니다! ✅

위아래로 자유롭게 스크롤하며 읽을 수 있습니다.

💡 컨트롤 바가 3초 안에 사라졌다면, 다시 상단 빈 영역을 터치하면 다시 나타납니다.

정리하면:

📜 → 📖스크롤 → 페이지 모드 전환
📖 → 📜페이지 → 스크롤 모드 전환
두 버튼 모두 상단 컨트롤 바에 있습니다

🔤 글자 크기 조절

상단 컨트롤 바에서 세 가지 글자 크기 중 원하는 것을 선택할 수 있습니다.

가- 작은 글자 (15px)

가 기본 글자 (17px) — 처음 열면 이 크기입니다

가+ 큰 글자 (20px)

페이지 모드에서 글자 크기를 바꾸면, 한 페이지에 들어가는 내용이 달라지기 때문에 페이지가 자동으로 다시 계산됩니다.

🌙 다크 모드

상단 컨트롤 바의 🌙 버튼을 누르면 다크 모드가 켜지고, 다시 누르면 꺼집니다.

  • 어두운 환경(밤, 이불 속 등)에서 눈이 훨씬 편합니다.
  • 모든 텍스트, 인용문, 표가 다크 모드에 맞게 자동으로 변환됩니다.
  • 배경은 진한 남색(#1a1a2e), 글자는 밝은 회색으로 바뀝니다.

📋 목차 이동

전자책의 원하는 챕터로 바로 이동할 수 있습니다. 읽기 모드에 따라 방법이 다릅니다.

스크롤 모드에서

  • 전자책 상단에 있는 목차에서 원하는 챕터를 클릭하면 해당 위치로 스크롤됩니다.
  • 아래로 내려가서 목차가 보이지 않을 때는, 화면 오른쪽 아래에 📋 목차 플로팅 버튼이 나타납니다. 이 버튼을 누르면 맨 위 목차로 이동합니다.

페이지 모드에서

  • 화면 하단의 📋 목차 버튼을 누르면 목차 오버레이가 나타납니다.
  • 원하는 챕터를 클릭하면 해당 페이지로 바로 이동합니다.

❓ 자주 묻는 질문 (FAQ)

Q. 스크롤 모드와 페이지 모드 중 뭐가 좋은가요?

A. 취향에 따라 다릅니다. 스크롤 모드는 빠르게 훑어볼 때 좋고, 페이지 모드는 집중해서 차분히 읽을 때 좋습니다.

Q. 글자 크기를 바꾸면 저장되나요?

A. 아니요, 페이지를 새로고침하면 기본(가) 크기로 돌아갑니다.

Q. 페이지 모드에서 읽던 위치가 기억되나요?

A. 같은 세션(탭을 닫지 않은 상태) 내에서는 유지되지만, 페이지를 닫으면 처음부터 시작합니다.

Q. 모바일에서도 잘 되나요?

A. 네, 모바일에 최적화되어 있습니다. 스와이프로 페이지를 넘길 수 있고, 화면 크기에 맞게 자동으로 조절됩니다.
