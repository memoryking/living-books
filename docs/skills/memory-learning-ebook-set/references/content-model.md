# 공통 원고와 주제 확장

## 데이터 원칙

책 메타데이터(id/title/version/updated), 단원, 항목, 비교 세트를 하나의 정규 모델에 둔다. 항목에는 stable ID, 원문, 학습 표기, 뜻·읽기, 기억 장면, 암기 문장, 실제 설명, 활용 예시, 그림 참조, 교정 메모와 출처를 보관한다.

한자 기준 필드는 `id, char, reading, originalChar, originalReading, scene, memory, examples, englishScene, chapter, image, imageColumn, imageRow, note, source, kind, corrected`이다. 다른 주제는 `term, pronunciation, meaning, explanation` 등으로 일반화하고 렌더러를 맞춘다. 이름만 다른 원고 두 개를 만들지 않는다.

변경 전파 테스트는 격리된 사본에서 기억 문장·예시·교정·그림 참조를 수정하고 두 출력에 같은 값이 나타나는지 확인한다. 두 번째 수정 후 오래된 설명이 남지 않아야 한다. 생성 Markdown을 직접 고쳤다가 빌드에서 사라지는 편집 흐름을 만들지 않는다.

## 영단어 어원

영단어·발음·품사·한국어 뜻, 접두사·어근·접미사 분해, 각 요소의 뜻, 실제 어원과 출처, 창작 연상, 대표 예문 두 개와 자연스러운 번역을 공통 원고에 둔다. 실제 어원은 신뢰할 수 있는 사전·학술 출처로 확인한다. 철자가 비슷하다는 이유로 어근을 꾸며내지 않는다. 단순 분해가 불가능하면 그 사실을 설명한다.

- 어원 설명과 그림 암기 이야기를 별도 필드·레이블로 표시한다.
- 접두사·어근·접미사의 색상 구분은 텍스트 UI에서 조판한다.
- 순방향은 영단어 → 뜻·핵심 어근, 역방향은 뜻·단서 → 영단어 입력/쓰기.
- 허용 정답은 대소문자·공백 등을 정규화하되 다른 동의어를 임의로 정답 처리하지 않는다.
- 파생어·유사 어근·혼동 단어를 비교하고 현대 의미가 달라진 경우 설명한다.
- 어린이·성인 대상에 따라 표현과 그림 스타일을 조정하되 뜻을 왜곡하지 않는다.

학습자가 그림을 가려도 용어를 떠올리도록 철자·글자 모양의 연결점을 둔다. 예시는 자연스러운 실제 쓰임을 우선한다. 드문 구성 요소는 희귀함을 밝혀 가짜 일상 단어를 만들지 않는다. 출처 없는 연상을 역사적 사실로 표현하지 않는다.
