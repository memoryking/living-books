# 메모리학습 세트 전자책

사용자가 승인한 《그림으로 기억하는 한자 453》 세트를 재사용한다. 단순 PDF나 프롬프트 목록으로 대체하지 않는다. 사용자가 다른 형식이나 범위를 지정하면 그 지시를 우선한다.

## 유지할 사용자 선택

- **오늘 학습 완료:** 오답 직접 선택·즉시 재도전으로 선택 학습에 넘기지 않는다. 예정 시각 전이면 지금 복습할 한자가 없다는 안내와 다음 시각을 표시한다. 오답은 평가 시점부터 10분 뒤이며 일반 복습도 날짜뿐 아니라 정확한 시각을 기준으로 한다. 기한이 된 나머지 항목만 오늘 복습으로 이어간다. 지금 학습 가능한 한자과 오늘 남은 예정(아직 시각 전)을 구분하고 기한 도달·창 복귀 시 갱신한다. 선택 학습의 자발적 연습은 별도다.

- **자율/메타 학습:** 한자→뜻과 음에서 자율(무제한 자기평가)과 메타(기본 5초, 3/5/7/10/15/20/30초)를 선택·저장한다. 메타는 첫 문제 전에 시작 준비 창, 훈음 첫 글자와 중복 없는 오답 한 글자를 무작위로 표시한다. 시간 내 정답은 맞힘, 오답/시간 초과는 다시 연습으로 한 번만 저장하고, 정답 화면에는 다음 버튼만 둔다. 다음 클릭 시 다음 타이머를 시작한다. 선택 학습 정답은 기존 일정 유지, 오늘 예정 복습 정답은 단계 상승, 첫 정답은 1일, 실패는 10분이다. 화면 이탈 시 일시정지 후 계속하기로 재개한다. 그림 사전 학습은 무제한이며 시험 전 준비 창을 띄운다. 뜻→쓰기는 이 모드를 사용하지 않는다. 첫 글자 선택은 훈음 전체 회상과 다른 단서형 문제임을 안내한다.

- **전체 항목 대기 화면:** 중앙 한자·시험 카드와 글자 선택창의 한자를 숨기고 중앙에 학습 목록 선택 안내를 표시한다. 학습 목록 선택창은 천천히 반짝이며 초점 상태와 움직임 줄이기 설정에서는 고정 강조한다. 다른 목록을 선택하면 강조를 해제하고 학습 화면을 표시한다.

- **학습 이름·시작 조건 최신 기준:** ‘골라 학습’의 현재 이름은 ‘선택 학습’이다. 전체 항목에서는 정답 보기 대신 ‘학습 목록을 선택해 주세요’를 표시하고 정답 공개·평가를 차단한다. 단원·직접 글자 선택·쓰기 방향으로 우회하지 못하도록 한다. 책갈피/다시 볼 항목/통과한 항목/새 항목 중 하나를 고르면 테스트한다. 오늘 학습은 이 조건과 독립적으로 동작한다.

- **골라 학습 목록/색상 최신 기준:** 다시 볼 항목은 마지막 평가가 다시 연습인 글자, 통과한 항목은 맞혔어요인 글자다. 기존 복습할 항목 필터는 없애고 예정 시간이 지난 모든 항목은 오늘 학습으로 모은다. 글자 선택은 훈음 없이 번호·한자·단계를 표시하며 10분 빨강/1일 자주/3일 주황/7일 노랑/14일 연두/30일 초록, 새 항목 회색이다. 색은 남은 시간이 아닌 stage이며 기한이 지난 글자는 복습 시간 됨을 표시한다. 모바일에서도 색을 유지하는 선택창을 사용한다. 통과 여부와 예정 단계는 독립적이며 골라 학습의 기존 날짜 보존 규칙은 유지한다.

- **기능 변경과 안내 동시 갱신은 필수:** 별도 요청 없이 변경된 버튼·필터·출제·복습 일정·저장/백업·쓰기 동작에 맞춰 학습 안내의 설명·예시·FAQ를 같은 작업에서 수정한다. 안내 화면이 바뀌면 조작 영역만 다시 캡처하여 R2 새 경로와 매니페스트를 갱신한다. PC는 이미지 왼쪽/설명 오른쪽, 모바일은 이미지 위/설명 아래이며 별도 화면 보기 링크를 쓰지 않는다. 기능·안내·캡처 검증 후 함께 커밋하고 GitHub 푸시로 Vercel 자동 배포를 확인한다. 프로젝트의 `docs/LEARNING_GUIDE_MAINTENANCE.md`를 따른다. 이는 담당 에이전트의 자동 포함 작업 규칙이며 앱 자체의 자동 집필 기능은 아니다.

- **최신 학습 구분(이전 책 읽기 UI 설명보다 우선):** 책 읽기는 ‘골라 학습’으로 바꾼다. 단원·학습 목록·글자 선택으로 범위를 정하고 정답을 가려 출제한다. 글자 선택에는 번호·한자만 표시한다. 책갈피는 추가한 순서(기존 bookmarks 배열 순서)이며 해제 후 다시 담으면 뒤로 간다. 골라 학습에서 맞히면 기존 stage/due를 그대로 유지하고, 모르면 10분 뒤로 예약한다. 기록 없는 글자를 맞히면 다음 날로 시작한다. 오늘 학습은 예정 복습 최대 10개와 별도 ‘새 글자 배우기 · 5개’ 버튼을 제공한다. 쓰기 테스트는 정답 확인 후 기존 캔버스 획을 보존하며 붉은 정답 한자를 뒤에 겹쳐 비교한다. 자동 채점으로 표현하지 않는다. 최신 검증은 `scripts/qa-hanja-practice.mjs`이며 이전 읽기 탭 전용 QA는 과거 UI 기준이다.

- **한자 그림 학습형의 최신 화면:** 검색·상단 책 소개 영역·훈음/연상 듣기를 제거한다. 읽기와 회상은 스크롤 없이 한 화면에 배치하고 단원·학습 목록·글자 선택창을 둔다. 암기법·예시·메모·쓰기·표기 안내는 탭으로 전환한다. 긴 설명은 화면 높이에 맞춰 ‘다음 설명’으로 넘겨 모든 내용을 유지한다. 이는 기존 전자책형 페이지/스크롤 규칙과 별개다. 아래 일반 기능 설명에 검색이 있어도 이 한자책에는 다시 넣지 않는다.

- **하나의 원고, 두 화면.** 용어·뜻·읽기·암기법·예시·그림·교정·비교는 동일한 안정적 ID의 공통 데이터에서 나온다. 어느 화면의 수정 요청이든 원본을 수정하고 모든 출력을 재생성한다. 출력별 복사본을 별도 원고로 편집하지 않는다.
- **그림 학습형:** 오늘의 학습 시작을 기본 진입으로 둔다. 예정 복습을 먼저 최대 10개, 없으면 새 항목 최대 5개를 그림으로 먼저 배운 뒤 가리고 확인한다. 정답 보기 후 ‘다시 연습 / 맞혔어요’ 두 버튼으로 평가한다. 책 읽기의 단원 선택, 양방향 회상, 책갈피, 개인 메모, 기록 가져오기·내보내기를 유지한다. 쓰기가 의미 있는 주제에는 손글씨 연습판을 둔다. 한자 앱의 검색·책 소개·음성 재생은 제거한 상태를 유지한다.
- **기존 전자책형:** 목차와 전체 본문을 처음부터 보여주고 스크롤·페이지 넘김을 지원한다. ‘꼭 알아야 할 10가지’ 탭은 사용하지 않는다.
- 기존형에는 ‘전체 목록으로’ 링크를 표시하지 않는다. 페이지형·스크롤형 전환 버튼과 오른쪽 아래 고정 ‘목차로 가기’를 제공한다. 페이지 모드의 목차는 오버레이로 연다. 전체 본문 URL과 관리자 내보내기가 같은 뷰어를 사용하도록 하고, 단순 본문 화면을 페이지형 뷰어라고 안내하지 않는다.
- 관리자 내보내기에 **① 그림 학습형 / ② 기존 전자책형**을 구분하여 각각 미리보기와 iframe 코드 복사를 둔다. 그림 학습 화면 상단에 ‘기존 방식으로 읽기’ 버튼을 다시 넣지 않는다.
- 모바일에서 현재 학습형을 검증한 뒤 기본으로 사용한다. 사용하기 어려우면 검증된 기존형을 제공한다. 기기 이름만으로 임의 자동 전환시키지 않는다.

## 제작 순서

1. 기존 프로젝트·원고를 확인하고 [구현 위치와 검증](references/implementation.md)을 읽는다. 새 책 ID·경로·저장소 키를 정한다. 항목 수와 단원 수는 현재 목록에 맞춘다. 453개·29단원을 다른 책에 고정하지 않는다.
2. 원문을 보존하고 뜻·독음·어원 오류를 확인한다. 교정에는 원문과 이유·출처를 남긴다. 같은 표기의 다른 의미는 별도 ID로 유지한다. [공통 원고와 어원 학습](references/content-model.md)을 사용한다.
3. 항목마다 ‘용어 → 선명한 장면 → 정확한 뜻’을 연결한다. 과장된 특징 하나, 짧은 연상 문장, 활용 예시 두 가지를 작성한다. 실제 글자·접사·어근과 그림의 연결점을 설명한다.
4. 사용 가능한 imagegen 스킬을 읽고 실제 삽화를 제작한다. 단순 배경·선명한 색과 질감·한 장면 중심으로 생성하고 모든 장면을 확인한다. 정답 텍스트는 이미지 생성에 맡기지 않고 UI에서 정확히 조판한다.
5. 공통 데이터에서 두 화면과 관리자 내보내기를 생성한다. 생성 절차를 빌드에 자동 연결하고 변경 전파 테스트를 둔다. 다운로드한 HTML은 재생성해야 하며 원격으로 자동 갱신된다고 말하지 않는다.
6. PC·모바일 기능과 내용을 확인한다. 배포는 현재 대화의 허가 범위에서 수행하며 실제 주소의 양쪽 화면·내보내기·이미지까지 확인한다.

## 학습 설계

- 상단 도구의 재표시는 **화면 상단 60px 영역을 누를 때만** 작동한다. 본문·그림·정답 펼치기·페이지 이동을 누르거나 모바일 주소창 변화로 화면 크기가 바뀌어도 도구가 나타나면 안 된다. 아래의 일반적인 ‘터치하면 표시’ 표현은 이 제한을 따른다. 도구 내부 조작과 키보드 초점은 접근성을 위해 표시 상태를 유지한다.

- 상단 도구 자동 숨김은 모바일 너비 조건으로 제한하지 않는다. PC·태블릿·모바일 모두 3초 후 숨고 클릭/터치로 다시 표시된다. 특히 640px보다 넓은 화면에서도 동작을 검사한다.

- 모바일 기존형의 상단 글자 크기·읽기 방식 버튼은 한 줄로 배치하고, 약 3초 후 숨기며 터치하면 다시 표시한다. 도구 표시만으로 페이지가 넘어가면 안 된다. 키보드로 도구에 초점을 둔 동안은 숨기지 않는다. 페이지형 목차는 화면 높이 안에서 마지막 항목까지만 스크롤되고, 뒤쪽 본문이나 iframe 높이로 스크롤이 이어지지 않아야 한다.

- 기존 전자책의 페이지형은 `001 · 日 — 날 일`처럼 세 자리 번호로 시작하는 학습 제목을 경계로 한 항목을 한 페이지에 묶는다. 그림·설명·예시·가리고 꺼내기를 분리하지 않는다. 글자 확대나 정답 펼치기는 같은 항목 안에서 세로 스크롤만 늘리고 페이지를 넘기지 않는다. 본문 클릭으로 페이지를 넘기지 않으며 이전/다음 버튼을 사용한다. 들어가며 등 일반 글은 기존 흐름형 페이지 나눔을 유지한다.

- 답을 가린 회상, 반대 방향 회상, 유사 항목 비교를 넣는다. 오답 후 그림과 정확한 해설을 다시 보여준다.
- 새 항목의 그림을 읽는 것만으로 정답 기록을 만들지 않는다. 유한한 묶음을 완료하면 헷갈린 항목만 재도전할 수 있게 한다. ‘넘기기’처럼 평가 의미가 불명확한 버튼은 기본 회상 흐름에서 제외한다. 다음 복습 시각을 표시하며 모바일의 학습 본문은 한 화면 안에서 유지한다. 긴 설명은 내부 설명 페이지로 넘기되 글자 자체는 바꾸지 않는다.
- 기본 복습은 1·3·7·14·30일, 실패는 약 10분 후로 시작할 수 있다. 운영 기본값이며 모두에게 최적인 과학 법칙이라고 주장하지 않는다. 예정 시각 전 연속 성공으로 단계를 계속 올리지 않는다.
- 창작 암기 이야기와 검증된 역사적 어원을 구분한다. 기억 효과나 ‘절대 안 잊음’을 보장하지 않는다.
- 한국어 UI, 크림색 배경·짙은 초록·황금색 강조, 큰 용어와 독립 삽화가 승인된 시각적 기준이다. 주제에 맞게 조정한다.

## 완료 기준

원문 누락 없음, 두 화면의 ID·핵심 내용 일치, 그림 연결 정확, 회상 전 정답 숨김, 터치 쓰기·지우기, 다음 항목 이동, 저장·복원, 내보내기 분리, 모바일 가로 넘침 없음. 실기기와 재현 환경을 구분해 보고한다. 원고 개정으로 기존 학습 기록의 ID를 망가뜨리지 않는다.
