# 전자책 제작 프롬프트 변경 비교·이력

현재 버전: **2.0.0** · 최종 개정일: **2026-10-02 (Asia/Seoul)**

**무엇이 달라졌나:** 화면·원고 동기화·홍보카드 중심으로 흩어져 있던 지침에, 실제 독자 조사부터 결과물 중심 목차·집필·근거 검증·홍보·운영까지 이어지는 공통 제작 절차를 추가했다. 웹 전자책과 메모리학습 세트의 기존 제작 방식은 유지한다.

**사용자 확인 사항(2026-10-02):** 기존 프롬프트가 기본이며 새 자료는 기획·목차·본문·부록·상세페이지 모두의 내용 보강에 적용한다. HTML 전자책·아임웹 임베딩·뷰어·내보내기 방식은 절대 바꾸지 않는다. PDF 전자책 전환 지시는 채택하지 않는다. 이미 운영 중인 인쇄 홍보카드 PDF와 구분한다. 같은 개정 작업 중 받은 명시적 지시로, 아래 v2.0.0 최종 기준에 반영했다.

현재 기준은 [통합 제작 프롬프트](EBOOK_CREATION_PROMPT.md), 실제 작업용 문장은 [단계별 실행 프롬프트](EBOOK_PROMPT_MODULES.md)에 있다. 이 문서는 이후 개정 때도 같은 파일에 기록을 누적한다.

## 이 문서를 갱신하는 규칙

1. 제작 프롬프트·출력 기준·전문 스킬의 의미를 바꾸는 작업에 이력 갱신을 포함한다. 별도 요청을 기다리지 않는다.
2. 날짜는 실제 작업일과 시간대를 쓴다. 바꾸지 않은 과거 기록의 날짜를 오늘로 갱신하지 않는다.
3. 새 기록을 위에 추가하고 과거 기록은 보존한다. 과거 설명의 오류는 정정 기록으로 연결한다.
4. `major`: 기존 제작/출력 계약을 바꾸는 변경, `minor`: 호환되는 절차·모듈 추가, `patch`: 의미를 바꾸지 않는 교정·링크 수정으로 구분한다.
5. 상단 현재 버전과 개정한 공통 문서의 버전을 함께 갱신한다. 전문 스킬의 고유 기능 변경 날짜는 별도로 유지한다.
6. 사용자 요청·근거 자료·변경 전후·영향 파일·기존 책 소급 여부·검증·남은 문제를 기록한다.
7. 프로젝트 지침과 관련 스킬의 참조 링크를 확인한다. 프로젝트 사본과 개인 전역 사본은 구분해서 보고한다.
8. 기능 변경은 [학습 안내 유지보수](LEARNING_GUIDE_MAINTENANCE.md)도 함께 적용한다. 제작 지침만 바뀌면 변경되지 않은 UI 캡처를 다시 만들지 않는다.

이는 **담당 에이전트가 수행할 필수 작업 절차**다. 실행 중인 앱이 임의의 기능 변경이나 외부 자료를 감지해 이 문서를 자동 집필한다는 뜻이 아니다.

## 2026-10-02 · v2.0.0 · 공통 제작 체계 통합

### 개정 이유와 기준점

사용자가 제공한 AI노마드 PDF 3권과 강의·프롬프트를 분석하여 우리 전자책 제작 프롬프트를 전면 보강하고, 전후 비교와 향후 변경 이력을 남기도록 요청했다.

이전 기준은 `AGENTS.md`, 메모리학습 세트 스킬, 홍보카드 스킬, `PROMOTIONAL_CARDS.md`, `public/promo/PROMPT.md`, 학습 안내 유지보수 문서에 분산되어 있었다. 이 작업 전 단일 공통 제작 프롬프트 파일은 없었다. **v2.0.0은 통합 개정판의 시작 번호**이며 존재하지 않았던 v1.0.0 파일이나 과거 검증 기록을 소급 생성하지 않는다. 비교 기준 소스는 이번 작업 전 Git 커밋 `22d2f5c`와 당시 프로젝트 지침이다.

### 유지한 것

- 웹 전자책 기본, 목차·스크롤·페이지형과 관리자 내보내기.
- 메모리 세트의 공통 항목 원고, 안정적인 ID, 기존 학습 기록, 전자책 전용 부록 분리.
- 오늘 학습과 미리 복습의 최신 동작, 기능 변경 시 학습 안내·부분 캡처 동시 갱신.
- 한자 암기앱 `hanja-memory`, 전자책 `hanja`, `vipup.site/상품ID` 주소 원칙.
- A5 양면, A4 가로 앞면2→뒷면2, 실제 QR·폰트·전체 PDF 검수.
- 사용자 지시가 자료나 제작 기본값보다 우선한다는 원칙.

### 자료에서 그대로 채택하지 않은 것

가상 후기·입금·합격·검진 화면을 실제 증거로 제시하기, 수익·감량·전환율 보장, 허위 희소성, 임의 가격 앵커, 검증되지 않은 명언, 구매를 거절한 독자 비난, 특정 엔진의 완벽한 한글 생성 보장, 모든 책의 PDF/15쪽/50쪽 고정화는 제외했다. 자세한 번호·쪽과 대체 규칙은 [전체 분석서](EBOOK_SOURCE_ANALYSIS_2026-10-02.md)에 남겼다.

### 적용 범위

신규 제작 및 이후 개정 작업부터 적용한다. 기존 34종 상품의 원고·마케팅·PDF를 일괄 재생성하거나 재배포하지 않았다. 외부 개인 전역 스킬은 수정하지 않고 **프로젝트 지침과 프로젝트 스킬**을 기준으로 연결했다. 런타임 코드·상품 가격·환불 조건·학습 데이터는 변경하지 않는다.

### 검증 기록

- PDF 3권의 페이지별 텍스트를 검토하고, 추출 누락 여부와 원본 해시를 기록했다.
- 카피 번호 001–1000이 각 한 번씩 존재함을 검사했다.
- 이미지50선의 8개 스타일과 사업100선의 전 구간을 반영표로 대조했다.
- 대화의 중복 집필 모듈을 통합하고 20×2의 분량 계산을 수정했다.
- 공통 문서·전문 스킬의 링크, 버전, 모듈 번호, 사본 동기화를 최종 검사 대상으로 삼는다. 실제 최종 결과는 아래 완료 기록에 남긴다.
- 문서 변경이므로 앱 기능 테스트·이미지 재생성·PDF 재출력은 이 작업의 검사 대상이 아니다.

완료 기록(2026-10-02): 공통 문서 4개 내부의 로컬 링크 18개, P01–P16 모듈 순서, 전문 스킬 사본 2쌍의 바이트 일치 검사를 통과했다. `git diff --check` 오류 없음. 변경 목록은 문서·지침·홍보카드 프롬프트로 한정되며 앱 런타임 코드·HTML/iframe 구현·원고 데이터·인쇄 PDF는 변경하지 않았다. 프로젝트 파일에 저장했으며 이번 문서 개정으로 운영 배포는 수행하지 않았다.
