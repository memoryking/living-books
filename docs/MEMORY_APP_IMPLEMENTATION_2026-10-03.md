# 한자 암기앱 구현 기록 — 2026-10-03

## 상태와 범위

한자 앱 코드·안내·상세페이지를 수정했다. FSRS 기본 설정과 앱 보호 규칙을 사용하며 개인별 모델 학습/최적화는 구현하지 않았다. 실제 콘텐츠는 453개다. 1,000개·30일 계획은 확장 기준이며 영어 앱 신규 제작은 이번 범위에 포함하지 않는다. HTML 전자책과 아임웹 임베딩 구조·공통 원고·전자책 전용 부록은 유지한다.

## 구현 선택

- `ts-fsrs@5.4.2` 고정. 유지율 0.9, fuzz 비활성화, 학습/재학습 10분. 라이브러리 기본 매개변수. 선택형 이력의 예측 정확도나 완전 암기를 보장하지 않는다.
- 주 학습은 첫 글자 메타 학습만 제공한다. 보기의 전체 훈음 대신 첫 글자를 주는 방식이며 직접 회상보다 정확하다는 뜻이 아니다. 기본 5초, 3/5/7/10/15/20/30초, 시작 준비·일시정지·숫자 없는 막대·1초 이하 빨강 유지.
- 평가 시각으로 due 여부를 판정한다. 조기 정답은 이벤트에만 저장하고 S/D/모델 last_review/due를 유지한다. 모델 갱신에서 제외된 성공도 전체 이벤트에서는 보존한다. 이 비대칭 정책의 모델 편향은 향후 검증 대상이다.
- 오답/시간 초과는 별도 결과로 기록하고 실패 평가 후 10분 due. 이미 미래 재학습 due가 있으면 더 뒤로 밀지 않는다. due 후 재실패면 그 시점부터 10분. due 후 성공은 실제 경과를 반영한다.
- 세 색 초기 경계는 S<1 빨강, 1≤S<7 노랑, S≥7 초록. 재학습 대기와 독립이며 오답 무조건 빨강 리셋을 하지 않는다. 임계값은 운영 초기값이지 보편적 숙달 기준이 아니다.
- 회차 범위·최초 결과·날짜·순서·진행을 저장한다. 정규 평가가 활성 회차의 미확인 항목이면 한 번 인정한다. 중복 이벤트 키는 무시하며 회차 최초 결과를 재학습 성공으로 덮어쓰지 않는다.
- 10개 묶음·이어하기·새 회차·약한 순/무작위/최근 평가 오래된 순. 중간 변경은 현재 문제를 유지하고 미출제 항목에만 적용한다. 회차 오답 별도 즉시 재도전 버튼 없음.
- 마지막 10일 별도 시험 없음. 오늘 학습과 회차 복습을 계속한다. +1/−1 점수 없음.
- 모든 항목 첫 학습 이후 보조 쓰기 제공. 자동 필기 채점 없음. 보조 쓰기는 주 기록·회차 평가에 영향 없음. 전체 통과 제한 대신 첫 학습 완료를 진입 기준으로 선택했다.
- 하루 60분, 기본 신규 50개, 20일 진도+10일 반복. 실제 453개면 일찍 첫 학습을 마칠 수 있다. 남은 항목/날짜로 신규 목표 재분배, 복습 20초·신규 40초 초기 추정치로 시간 배분. 학습 화면에서 초점을 유지한 시간은 기록하되 개인별 시간 추정 학습·FSRS workload 시뮬레이션은 미구현이다.
- 복습을 감추는 강제 일일 상한 없음. 시간 부담을 표시하고 30/40/50/60/90일로 목표 기간을 사용자가 연장한다. 연장 시 마지막 10일을 남기고 신규 기간을 조정하며 기존 due는 바꾸지 않는다.

## 기록 보호

저장소 주소는 기존 `living-books-hanja-memory-v1` 유지, 내부 스키마 v2·appId 명시. 최초 v1 이전 시 원본을 별도 legacy-backup 키에 보존한다. 단계·due·횟수·책갈피·메모를 유지하며 실제 과거 로그를 만들지 않는다. 첫 모델 평가 시 기존 단계에서 추정 초기화하고 migration 표시를 남긴다. 잘못된 저장 데이터는 자동 덮어쓰기를 중지한다. JSON 가져오기는 확인 후 교체이며 v1/v2를 검증한다. 계정/기기 자동 동기화 없음.
