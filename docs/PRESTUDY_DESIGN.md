# 예정 복습과 미리 복습의 분리

사용자 승인: 시험 전, 아직 예정일이 오지 않은 학습한 한자를 즉시 확인한다. 설정을 늘리지 않고 원래 일정과 추가 연습을 분리한다.

## 미리 복습 — 2026-09-26 현재 기준

- 메뉴는 오늘 학습 → 미리 복습 → 학습 안내이며 오늘 학습으로 진입한다. 선택 학습/골라 학습은 이전 명칭이다.
- 미리 복습은 예정일 전 시험 대비를 위한 추가 연습이다. 이미 한 번 이상 평가한 한자만 대상으로 한다. 범위는 학습한 한자 전체(기본), 단원 선택, 책갈피 세 가지이며 범위 선택 후 시작을 누른다. 전체 항목 대기/선택 강제/반짝임과 다시 볼·통과·새 항목 필터는 제거했다.
- 미리 복습의 정답·오답·시간 초과·쓰기·반복 재도전은 records 전체(stage/due/last/attempts/misses/needsReview)를 변경하지 않는다. gradeRecord는 오늘 학습에만 사용한다. 예전 practice=true 옵션은 삭제했다. 기존 v1 기록과 백업 형식은 그대로 읽는다.
- 연습 결과는 현재 React 세션에만 둔다. 틀린 한자 다시 확인으로 오답만 즉시 반복하며, 맞힌 것은 빠지고 남은 오답만 이어진다. 원래 범위의 총수와 누적 통과수를 유지한다. 마지막은 ‘선택한 N개를 이번 연습에서 모두 맞혔어요’이며 완전 암기로 표현하지 않는다.
- 범위·방식 변경, 메뉴 이동, 새로고침은 임시 연습 결과를 종료한다. 장기 이어하기/백업 대상이라고 설명하지 않는다. 책갈피와 메모의 편집은 기존처럼 저장한다.
- 책갈피는 학습한 한자 중 추가 순서로 제공한다. 단원 범위와 중첩하지 않는다. 한자 직접 고르기는 체크박스 목록을 바로 펼치고 훈음은 숨긴다.
- 오늘 학습은 그대로다. 기한이 지난 글자를 최대 10개, 새 글자는 별도 최대 5개. 예정 복습 정답은 단계 상승, 첫 정답 1일, 오답 10분. 완료 시 아직 시간이 되지 않은 글자를 즉시 재도전으로 넘기지 않는다.
- 메타 학습은 기본 5초, 준비 창·막대 타이머·1초 이하 빨강·이탈 일시정지를 유지한다. 미리 복습에서는 ‘이번 연습에 반영’, 오늘 학습에서는 ‘저장 완료’라고 구분한다. 쓰기는 타이머 없이 손글씨와 정답을 겹쳐 비교한다.
- 현행 검증은 scripts/qa-hanja-prestudy.mjs(자율/메타/쓰기·일정 불변·반복·필터·신규 제외·오늘 승급·반응형), qa-hanja-completion.mjs(오늘 완료), qa-hanja-guide.mjs(안내)다. 기존 qa-hanja-practice/meta/stages의 이전 필터·일정 주장은 과거 UI 기준이다.
- 기능 변경 시 안내 설명·부분 캡처·R2 매니페스트·프로젝트 문서를 함께 갱신하고 GitHub 푸시 → Vercel 자동 배포를 확인한다.

개별 앱의 전체 기능을 복제하지 않고, 현재 사용자가 승인한 독립 연습 방식을 적용했다.

## 검증 기록

- 운영 빌드·TypeScript·변경 코드 ESLint·453개 원고/906개 예시/복습 간격/백업 검사 통과.
- Chrome 1920×1080, 1280×800, 768×1024, 390×844, 320×568, 844×390에서 미리 복습의 자율/메타/쓰기와 records 전체 불변을 확인. 반복 오답 후 누적 통과, 첫 문제 준비, 일시정지, 시간 초과도 확인했다.
- 단원 필터/책갈피 순서/미학습 제외, 직접 연결, 새 사용자 빈 범위를 검사했다. 작은 화면의 단원 선택과 가로 화면 질문 배치를 보완했다.
- 오늘 학습 완료·10분 대기·기한 도달 시 버튼 갱신을 네 화면 크기에서 확인했다. 오늘 학습은 계속 기록하고 단계를 올린다.
- 안내 10개 항목과 인라인 이미지 15개, PC 좌우/모바일 세로 배치를 검사했다. 변경된 부분 이미지 8장을 R2 새 경로에 업로드하고 공개 응답을 확인했다.
- 이는 Chrome 화면 크기 재현 검사이며 실제 iOS/Android 기기 검사는 아니다.

### 체크박스 선택과 10개 묶음 (최신)

한자 직접 고르기는 한 번 펼치면 체크박스 목록이 바로 나온다. 훈음은 숨기며 번호·한자·기존 단계 색을 유지한다. 미체크는 현재 범위 전체이며 선택 여부와 대상 개수를 항상 안내한다. 체크해도 자동 출제하지 않고 선택 완료 후 시작한다. 모두 체크/체크 해제를 제공한다. 범위·단원 변경 시 체크를 초기화한다. 출제 순서는 체크 순서가 아닌 범위 순서다.

미리 복습은 최대 10개씩 끊는다. 23개면 10→10→3. 각 묶음의 오답을 먼저 다시 확인하고 모두 통과하면 다음 묶음 버튼이 나온다. 재도전은 남은 본 묶음을 덮어쓰지 않는다. 다음 묶음과 재도전의 메타 타이머는 준비 창을 거친다. 누적 맞힘/전체 대상/남은 항목을 표시하며 여기서 마치기는 임시 진행을 버린다. 마지막에만 선택한 전체를 이번 연습에서 모두 맞혔다고 표시한다. 원래 records 전체는 계속 불변이며 오늘 학습 동작은 유지한다.

검증: `qa-hanja-batches.mjs`로 1280×800, 768×1024, 390×844, 320×568, 844×390의 단일 펼침/체크·해제/훈음 숨김/목록 순서/범위 변경 초기화/23개를 10+10+3으로 완주/오답 반복 중 대기 묶음 보존/메타 11개를 10+1로 분리/쓰기/records 불변을 확인했다. `qa-hanja-prestudy.mjs`의 기존 메타·쓰기·오늘 학습 회귀 검사도 새 선택 UI에 맞춰 갱신했다.

## 공통 학습 원고와 전자책 전용 부록

앱 메뉴는 오늘 학습 → 미리 복습 → 학습 안내다. 헷갈림 비교 메뉴는 앱에서 제거한다. 연동 범위는 안정적 ID를 가진 한자별 학습 본문(한자·훈음·그림·암기법·예시·표기 안내)이며 book.json이 공통 원본이다. 단원 구조는 이 항목을 묶는 공통 메타데이터다.

헷갈림 비교 18개는 전자책 전용 부록이다. 편집 원본은 ebook-appendix.json이며 앱은 가져오지 않는다. comparisons.json 및 content/31-comparisons.md는 이 파일로부터 생성하는 사본이다. 비교 부록의 한자·훈음 표시는 공통 항목 ID를 참조해 정확성을 유지하지만, 비교 설명 자체를 앱 기능이나 공통 학습 내용으로 전파하지 않는다. 웹 전체 읽기·관리자 내보내기·다운로드 전자책에는 부록을 유지한다.

한자 내용 변경은 두 형식에 반영하고, 부록 변경은 전자책에만 반영하는 것을 동기화 검사로 확인한다. 기존의 모든 내용/비교까지 두 형식에서 동일하다는 규칙보다 이 구분이 우선한다.
