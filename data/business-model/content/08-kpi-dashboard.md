# 8장: 핵심 지표 대시보드 — CAC, LTV, MRR로 사업 건강 체크

## 숫자가 말해주는 진실

**피터 드러커**는 "측정할 수 없으면 관리할 수 없다"고 했습니다. 비즈니스도 마찬가지입니다. 감에 의존하는 경영은 눈을 가리고 운전하는 것과 같습니다.

이 장에서는 사업의 건강 상태를 한눈에 파악할 수 있는 **핵심 지표(KPI) 대시보드**를 설계합니다. 병원에서 혈압, 혈당, 콜레스테롤 수치로 건강을 진단하듯, 비즈니스도 **CAC, LTV, MRR** 같은 지표로 진단할 수 있습니다.

## 반드시 알아야 할 핵심 지표 8가지

### 1. CAC (Customer Acquisition Cost) — 고객 획득 비용

**정의**: 신규 고객 1명을 확보하는 데 드는 총 비용

```
CAC = 마케팅 + 영업 총 비용 / 신규 고객 수

예시:
월 마케팅비: 1,000만 원
월 신규 고객: 200명
CAC = 1,000만 / 200 = 50,000원
```

**건강한 기준**: 업종에 따라 다르지만, LTV의 1/3 이하가 이상적

**한국 시장 CAC 벤치마크**:
| 업종 | 평균 CAC |
|------|----------|
| 이커머스 | 15,000~30,000원 |
| SaaS (B2B) | 200,000~500,000원 |
| 구독 서비스 | 30,000~80,000원 |
| 앱 설치 | 2,000~10,000원 |

### 2. LTV (Lifetime Value) — 고객 생애 가치

**정의**: 한 고객이 전체 거래 기간 동안 가져다주는 총 수익

```
LTV = 고객당 월 평균 매출 × 평균 거래 기간(월) × 매출총이익률

예시 (구독 서비스):
월 구독료: 9,900원
평균 유지 기간: 18개월
매출총이익률: 70%
LTV = 9,900 × 18 × 0.7 = 124,740원
```

### 3. LTV/CAC 비율 — 사업의 건강도 핵심 지표

| LTV/CAC | 의미 | 상태 |
|---------|------|------|
| 1:1 미만 | 고객을 확보할수록 손해 | 위험 |
| 1:1 ~ 3:1 | 수익이 나지만 여유 없음 | 주의 |
| **3:1** | **건강한 비즈니스** | **이상적** |
| 5:1 이상 | 성장에 더 투자할 여지 있음 | 기회 |

**토스의 LTV 전략**: 무료 송금으로 고객을 획득(낮은 CAC)한 후, 투자·보험·대출 등 고마진 서비스로 LTV를 극대화. LTV/CAC 비율이 매우 높은 구조입니다.

### 4. MRR (Monthly Recurring Revenue) — 월간 반복 매출

**정의**: 매월 반복적으로 발생하는 매출

```
MRR 구성 요소:
+ 신규 MRR (New): 새 고객의 구독료
+ 확장 MRR (Expansion): 기존 고객의 업그레이드
- 이탈 MRR (Churned): 해지 고객의 구독료
- 축소 MRR (Contraction): 다운그레이드한 고객
= 순 MRR 증가 (Net New MRR)
```

**MRR 추적이 중요한 이유**: 일회성 매출과 달리, MRR은 **미래 매출을 예측**할 수 있게 해줍니다. 투자자들이 가장 먼저 보는 지표이기도 합니다.

### 5. Churn Rate — 이탈률

**정의**: 특정 기간 동안 서비스를 떠나는 고객의 비율

```
월간 이탈률 = 해당 월 이탈 고객 수 / 월초 총 고객 수 × 100

예시:
월초 고객: 1,000명
해지 고객: 50명
이탈률: 5%
```

**이탈률의 복리 효과**:
| 월간 이탈률 | 연간 고객 유지율 |
|-------------|------------------|
| 1% | 88.6% |
| 3% | 69.4% |
| **5%** | **54.0%** |
| 10% | 28.2% |

월간 5%가 별것 아닌 것 같지만, 1년이면 **고객의 절반**이 사라집니다.

### 6. NRR (Net Revenue Retention) — 순 매출 유지율

**정의**: 기존 고객에서 발생하는 매출의 변화율 (신규 제외)

```
NRR = (시작 MRR + 확장 - 축소 - 이탈) / 시작 MRR × 100

예시:
시작 MRR: 1억 원
확장: +2,000만 원
축소: -500만 원
이탈: -1,000만 원
NRR = (1억 + 2,000만 - 500만 - 1,000만) / 1억 = 105%
```

**NRR 100% 이상**이면, 신규 고객 없이도 매출이 성장하는 꿈같은 구조입니다. 최고 수준의 SaaS 기업들(Slack, Datadog 등)은 NRR 120~140%를 달성합니다.

### 7. 매출총이익률 (Gross Margin)

```
매출총이익률 = (매출 - 매출원가) / 매출 × 100

업종별 벤치마크:
SaaS: 70~85%
이커머스: 20~40%
마켓플레이스: 60~80%
제조업: 25~45%
```

### 8. CAC Payback Period — 투자 회수 기간

**정의**: CAC를 회수하는 데 걸리는 기간

```
CAC Payback = CAC / (월 매출 × 매출총이익률)

예시:
CAC: 100,000원
월 구독료: 20,000원
매출총이익률: 70%
Payback = 100,000 / (20,000 × 0.7) = 7.1개월
```

**건강한 기준**: 12개월 이하 (B2B SaaS는 18개월까지 허용)

## A/B 테스팅으로 지표 개선하기

### A/B 테스트 6단계 프로세스

**Step 1: 가설 수립**
```
"결제 페이지의 CTA 버튼을 '무료로 시작하기'로 바꾸면
전환율이 10% 이상 개선될 것이다."
```

**Step 2: 실험 설계**
- 대조군(A): 현재 버전
- 실험군(B): 변경 버전
- 샘플 크기 계산 (통계적 유의성 확보)

**Step 3: 트래픽 분배**
- 50:50 균등 분배
- 최소 2주 이상 운영

**Step 4: 데이터 수집**
- 핵심 지표: 전환율, 클릭률, 체류 시간
- 보조 지표: 이탈률, 스크롤 깊이

**Step 5: 결과 분석**
- 통계적 유의성 확인 (p-value < 0.05)
- 실질적 영향도 평가

**Step 6: 의사결정 & 반복**
- 승자 적용 후 다음 실험 설계
- 지속적 개선 사이클

### 한국에서의 A/B 테스트 사례

**배달의민족**: 앱 내 음식점 정렬 순서, 리뷰 표시 방식, 배달비 표시 형태 등을 지속적으로 A/B 테스트하여 주문 전환율을 최적화합니다.

**무신사**: 상품 상세 페이지의 사이즈 가이드 위치, 리뷰 사진 배치, 쿠폰 노출 타이밍을 테스트하여 구매 전환율을 개선했습니다.

## 대시보드 설계 가이드

### CEO/창업자용 주간 대시보드

```
┌────────────────────────────────────────┐
│         주간 핵심 지표 대시보드          │
├────────────┬───────────┬───────────────┤
│  MRR       │  신규고객  │  이탈률       │
│  5,200만원 │  45명     │  3.2%         │
│  ↑ 8%     │  ↑ 12%   │  ↓ 0.5%p     │
├────────────┼───────────┼───────────────┤
│  CAC       │  LTV      │  LTV/CAC      │
│  52,000원  │  189,000원│  3.6:1        │
│  ↓ 5%     │  ↑ 3%    │  개선 중      │
├────────────┼───────────┼───────────────┤
│  매출총이익 │  번레이트  │  런웨이       │
│  68%       │  2,800만원│  14개월       │
│  유지       │  ↓ 200만 │  개선 중      │
└────────────┴───────────┴───────────────┘
```

### 지표 간 인과 관계 이해하기

```
CAC 감소 → LTV/CAC 개선 → 더 많은 마케팅 투자 가능
                              ↓
이탈률 감소 → LTV 증가 → 수익성 개선
                              ↓
업셀링 증가 → NRR 개선 → 성장 가속
```

**핵심**: 지표는 개별적으로 보는 것이 아니라, **인과 관계의 시스템**으로 이해해야 합니다.

## 위험 신호와 대응 전략

| 위험 신호 | 가능한 원인 | 대응 전략 |
|-----------|-------------|-----------|
| CAC 지속 상승 | 시장 포화, 경쟁 심화 | 채널 다변화, 바이럴 강화 |
| LTV 하락 | 제품 만족도 저하 | 고객 피드백 분석, 제품 개선 |
| 이탈률 급증 | 경쟁사 등장, 품질 이슈 | 리텐션 캠페인, 로열티 프로그램 |
| MRR 성장 둔화 | PMF 약화, 시장 한계 | 신규 세그먼트, 제품 확장 |
| 번레이트 증가 | 비효율적 지출 | 비용 감사, 린 운영 (5장) |

## Spotify의 지표 관리

Spotify는 **프리미엄 전환율**을 핵심 지표로 관리합니다:

```
무료 사용자 6억+ → 유료 전환율 약 37% → 유료 2.2억+

핵심 전환 지표:
- 무료 → 유료 전환까지 평균 소요 시간
- 전환 트리거 (어떤 기능이 전환을 유도하는가)
- 이탈 예측 모델 (머신러닝 기반)
```

Spotify는 사용자가 **개인화 플레이리스트(Discover Weekly)**를 사용할수록 유료 전환율이 높아진다는 데이터를 발견하고, 이 기능에 집중 투자했습니다.

### 핵심 정리

> **숫자를 보지 않고 사업을 하는 것은, 계기판 없이 비행기를 조종하는 것과 같습니다.** CAC, LTV, MRR, 이탈률 — 이 4가지만 제대로 추적해도 사업의 건강 상태를 정확히 진단할 수 있습니다. 다음 장에서는 이 지표들이 미래에 어떻게 변할지, AI와 플랫폼 시대의 비즈니스 모델 전략을 다루겠습니다.
