# 10장: 90일 비즈니스 모델 설계 로드맵

## 왜 90일인가

비즈니스 모델 설계는 영원히 고민만 할 수도, 하루아침에 완성할 수도 없습니다. **90일(약 3개월)**은 가설을 세우고, 검증하고, 첫 번째 결과를 확인하기에 충분한 기간입니다.

이 장에서는 1장부터 9장까지 배운 모든 프레임워크를 **실행 가능한 90일 로드맵**으로 통합합니다. 각 주차별로 무엇을 하고, 어떤 산출물을 만들어야 하는지 구체적으로 안내합니다.

## 90일 전체 구조

```
Phase 1: 설계 (1~4주) — "무엇을 할 것인가"
Phase 2: 검증 (5~8주) — "고객이 원하는가"
Phase 3: 최적화 (9~12주) — "수익성이 있는가"
```

| Phase | 기간 | 핵심 활동 | 산출물 |
|-------|------|-----------|--------|
| 설계 | 1~4주 | 모델 설계, 가치 제안, 가격 | BMC, VPC, 가격표 |
| 검증 | 5~8주 | MVP 제작, 시장 테스트 | MVP, 피드백 데이터 |
| 최적화 | 9~12주 | 지표 분석, 개선, 스케일 판단 | KPI 대시보드, 피벗/스케일 결정 |

## Phase 1: 설계 (Week 1~4)

### Week 1: 비즈니스 모델 캔버스 작성

**목표**: 비즈니스 모델의 전체 그림을 한 장에 완성

**Day 1~2: 고객 리서치**
- 타겟 고객 5~10명 인터뷰
- 핵심 질문: "가장 불편한 점은?", "현재 어떻게 해결하고 있나?"
- 결과물: 고객 프로필 정리

**Day 3~4: BMC 초안 작성**
```
[비즈니스 모델 캔버스]
┌──────────┬──────────┬──────────┐
│ 핵심파트너 │ 핵심활동  │ 가치제안  │
│          │          │          │
│          ├──────────┤          │
│          │ 핵심자원  │          │
│          │          │          │
├──────────┼──────────┼──────────┤
│          │  채널     │ 고객관계  │
│ 비용구조  │          │          │
│          ├──────────┤──────────┤
│          │          │ 고객세그먼트│
│          │ 수익원    │          │
└──────────┴──────────┴──────────┘
```

**Day 5: 팀 리뷰 & 수정**
- 동료, 멘토, 또는 신뢰할 수 있는 사람에게 피드백 요청
- "이 모델에서 가장 약한 부분은?"이라는 질문으로 핵심 리스크 파악

### Week 2: 가치 제안 캔버스 & 경쟁 분석

**목표**: 고객이 돈을 내는 진짜 이유를 명확히 정의

**Day 1~2: 가치 제안 캔버스 작성** (3장 워크시트 활용)
- 고객의 할 일, 고통, 이득 정리
- 우리의 고통 해결제, 이득 창출제 매핑

**Day 3~4: 경쟁 분석 매트릭스** (3장 참고)
- 직접 경쟁사 3개, 간접 경쟁사 2개 분석
- 차별화 포인트 도출

**Day 5: 한 문장 가치 제안 확정**
```
"우리는 _____(타겟)에게 _____(핵심 가치)를 제공하여
_____(고객의 고통)을 해결합니다.
_____(경쟁사)와 달리 _____(차별점)입니다."
```

### Week 3: 수익 모델 & 가격 전략

**목표**: 어떻게 돈을 벌 것인지 구체적으로 설계

**Day 1~2: 수익 모델 선택** (2장 참고)
- 7가지 모델 중 핵심 모델 1개 선택
- 보조 수익원 1~2개 추가 검토

**Day 3~4: 가격 전략 설계** (4장 워크시트 활용)
- 원가 기반 가격 산출
- 가치 기반 가격 산출
- 경쟁 기반 포지셔닝 결정
- 심리적 가격 적용

**Day 5: 재무 시뮬레이션**
```
[3개월 재무 시뮬레이션]

월 고정비: _______________원
변동비(건당): _______________원
판매 가격: _______________원
건당 마진: _______________원

손익분기점 판매량: 고정비 / 건당 마진 = ___건/월

시나리오 A (보수적): 월 ___건 → 영업이익 ___원
시나리오 B (목표): 월 ___건 → 영업이익 ___원
시나리오 C (낙관적): 월 ___건 → 영업이익 ___원
```

### Week 4: 운영 체계 설계

**목표**: 실행을 위한 인프라와 프로세스 구축

**Day 1~2: 핵심 프로세스 설계** (5장 참고)
- 고객 획득 프로세스
- 제품/서비스 전달 프로세스
- 고객 지원 프로세스

**Day 3~4: 기술 인프라 구축**
- 필요한 도구 목록 작성 (SaaS, 노코드 도구 등)
- 최소 비용으로 시작 가능한 스택 결정

**Day 5: Phase 1 종합 리뷰**
```
[Phase 1 체크리스트]
□ BMC 완성
□ 가치 제안 캔버스 완성
□ 경쟁 분석 매트릭스 완성
□ 수익 모델 결정
□ 가격 전략 확정
□ 재무 시뮬레이션 완료
□ 운영 프로세스 설계 완료
□ 기술 인프라 준비 완료
```

## Phase 2: 검증 (Week 5~8)

### Week 5: MVP 제작

**목표**: 핵심 가설을 검증할 수 있는 최소 제품 제작

**MVP 유형 선택** (6장 참고):
- 예산 50만 원 이하: 랜딩 페이지 MVP
- 예산 100만 원 이하: 오즈의 마법사 / 컨시어지 MVP
- 예산 300만 원 이하: 기능 축소 MVP

**한국에서 활용 가능한 노코드 도구**:

| 목적 | 도구 | 비용 |
|------|------|------|
| 랜딩 페이지 | 아임웹, 식스샵 | 무료~월 3만 원 |
| 앱/웹 서비스 | 버블, 노코드AI | 무료~월 5만 원 |
| 결제 연동 | 토스페이먼츠, 포트원 | 건당 수수료 |
| 이메일 마케팅 | 스티비 | 무료~월 3만 원 |
| 고객 관리 | 노션, 시트 | 무료 |

### Week 6~7: 시장 테스트

**목표**: 실제 고객에게 MVP를 노출하고 반응 수집

**Week 6: 초기 고객 확보**
```
[채널별 테스트 예산 배분]
네이버 검색 광고: 30% (키워드 타겟팅)
인스타그램 광고: 30% (관심사 타겟팅)
커뮤니티 직접 홍보: 20% (관련 카페, 오픈채팅)
지인 네트워크: 20% (바이럴, 추천)
총 테스트 예산: 50~100만 원
```

**Week 7: 데이터 수집 & 분석**
- 핵심 지표 추적 시작 (8장 참고)
- 최소 50명 이상의 사용자 피드백 수집
- 주간 피드백 루프 운영

### Week 8: 검증 결과 판단

**목표**: PMF 존재 여부 판단, 다음 방향 결정

**PMF 검증 질문** (숀 엘리스 테스트):
> "이 제품/서비스를 더 이상 사용할 수 없다면 어떤 기분이 드시겠습니까?"
> - 매우 실망: ___%
> - 약간 실망: ___%
> - 실망하지 않음: ___%
> - 해당 없음(사용하지 않음): ___%

**40% 이상이 "매우 실망"**이면 PMF가 있다고 판단합니다.

**판단 매트릭스**:

| PMF 수준 | 다음 단계 |
|----------|-----------|
| 40% 이상 (강한 PMF) | Phase 3로 → 스케일업 준비 |
| 25~40% (약한 PMF) | 제품 개선 후 재테스트 |
| 25% 미만 (PMF 없음) | 피벗 검토 (7장 참고) |

## Phase 3: 최적화 (Week 9~12)

### Week 9: KPI 대시보드 구축

**목표**: 핵심 지표를 실시간 추적하는 체계 구축

8장의 대시보드 설계를 실제로 구현합니다:

```
[최소 대시보드 (구글 시트로 시작)]

매일 업데이트:
- 방문자 수
- 신규 가입/구매

주간 업데이트:
- CAC
- 전환율
- 이탈률

월간 업데이트:
- MRR
- LTV
- LTV/CAC
```

### Week 10~11: 최적화 사이클

**목표**: 데이터 기반으로 핵심 지표 개선

**주간 최적화 루틴**:
```
월요일: 지난주 지표 리뷰
화요일: 개선 가설 수립 (가장 약한 지표 1개 선택)
수~목요일: A/B 테스트 또는 개선 실행
금요일: 결과 측정 & 다음 주 계획
```

**최적화 우선순위 판단**:

| 지표 | 현재 | 목표 | 갭 | 우선순위 |
|------|------|------|-----|----------|
| 전환율 | 1.5% | 3% | -1.5%p | ★★★★★ |
| CAC | 80,000 | 50,000 | -30,000 | ★★★★ |
| 이탈률 | 8% | 5% | -3%p | ★★★ |

**갭이 가장 큰 것, 또는 개선 시 전체 수익에 가장 큰 영향을 미치는 것**부터 시작합니다.

### Week 12: 90일 회고 & 다음 단계 결정

**목표**: 전체 여정을 돌아보고 다음 90일 계획 수립

**90일 회고 템플릿**:
```
[90일 회고]

1. 원래 가설: _______________
2. 실제 결과: _______________
3. 예상과 달랐던 점: _______________

4. 핵심 지표 결산:
   - 총 고객 수: ___명
   - MRR: ___원
   - CAC: ___원
   - LTV: ___원
   - 전환율: ___%

5. 가장 큰 배움: _______________
6. 가장 큰 실수: _______________
7. 다음 90일 핵심 목표: _______________
```

**다음 단계 의사결정**:

| 90일 결과 | 다음 90일 방향 |
|-----------|----------------|
| PMF 확인 + 수익성 | 스케일업 (6장 Stage 2~3) |
| PMF 확인 + 수익성 부족 | 가격/비용 구조 최적화 (4~5장) |
| PMF 불확실 | 추가 검증 또는 소규모 피벗 (7장) |
| PMF 없음 | 대규모 피벗 또는 새로운 아이디어 (7장) |

## 흔한 실수와 예방법

| 주차 | 흔한 실수 | 예방법 |
|------|-----------|--------|
| 1~4 | 설계에 너무 오래 머무름 | 완벽보다 속도, 4주 안에 반드시 마감 |
| 5 | MVP에 기능을 과다 투입 | Must Have만, 나머지는 과감히 제외 |
| 6~7 | 충분한 데이터 없이 결론 | 최소 50명 이상 확보 후 판단 |
| 8 | 감정적으로 PMF 판단 | 숫자(40% 기준)로만 판단 |
| 9~12 | 여러 지표 동시 개선 시도 | 한 번에 1개 지표만 집중 |

### 핵심 정리

> **90일은 아이디어를 비즈니스 모델로 전환하기에 충분한 시간입니다.** 설계 4주, 검증 4주, 최적화 4주. 이 로드맵을 따라가면, 90일 후에는 데이터에 기반한 사업 판단을 내릴 수 있습니다. 완벽한 계획보다 빠른 실행이 더 중요합니다. 오늘 바로 Week 1을 시작하세요.
