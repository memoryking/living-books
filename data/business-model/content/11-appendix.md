## 도구 1: 비즈니스 모델 캔버스 (BMC)

알렉산더 오스터왈더의 9개 블록 캔버스입니다. 사업의 전체 구조를 한 장으로 표현합니다. (1장 참고)

```
┌─────────────────────────────────────────────────────────┐
│                   비즈니스 모델 캔버스                     │
│                                                         │
│  작성자: ___________  작성일: ___________  버전: _____   │
├──────────┬──────────┬──────────┬──────────┬──────────────┤
│          │          │          │          │              │
│ 핵심     │ 핵심     │          │ 고객     │ 고객         │
│ 파트너십 │ 활동     │ 가치     │ 관계     │ 세그먼트     │
│          │          │ 제안     │          │              │
│          ├──────────┤          ├──────────┤              │
│          │          │          │          │              │
│          │ 핵심     │          │ 채널     │              │
│          │ 자원     │          │          │              │
│          │          │          │          │              │
├──────────┴──────────┴──────────┴──────────┴──────────────┤
│                    │                                     │
│    비용 구조       │           수익원                     │
│                    │                                     │
└────────────────────┴─────────────────────────────────────┘
```

### 각 블록 작성 가이드

**1. 고객 세그먼트 (Customer Segments)**
```
주요 고객: _______________
2차 고객: _______________
고객 특성:
- 연령/성별: _______________
- 직업/소득: _______________
- 핵심 니즈: _______________
- 행동 패턴: _______________
```

**2. 가치 제안 (Value Propositions)**
```
핵심 가치: _______________
해결하는 문제: _______________
차별화 포인트: _______________
한 문장 가치 제안: "_______________"
```

**3. 채널 (Channels)**
```
인지 채널: _______________
평가 채널: _______________
구매 채널: _______________
전달 채널: _______________
사후 관리 채널: _______________
```

**4. 고객 관계 (Customer Relationships)**
```
관계 유형: □ 셀프서비스  □ 자동화  □ 커뮤니티
          □ 전담 지원   □ 공동 창작
목표: □ 신규 확보  □ 유지  □ 업셀링
```

**5. 수익원 (Revenue Streams)**
```
주요 수익원: _______________
보조 수익원: _______________
가격 모델: □ 정가  □ 구독  □ 사용량  □ 수수료
월 예상 매출: _______________원
```

**6. 핵심 자원 (Key Resources)**
```
인적 자원: _______________
기술 자원: _______________
재무 자원: _______________
지적 재산: _______________
```

**7. 핵심 활동 (Key Activities)**
```
제품 개발: _______________
마케팅/영업: _______________
운영/배송: _______________
고객 지원: _______________
```

**8. 핵심 파트너십 (Key Partnerships)**
```
공급 파트너: _______________
기술 파트너: _______________
유통 파트너: _______________
전략적 제휴: _______________
```

**9. 비용 구조 (Cost Structure)**
```
주요 고정비: _______________
주요 변동비: _______________
월 총 비용: _______________원
손익분기점: _______________
```

## 도구 2: 가치 제안 캔버스 (VPC)

고객 프로필과 가치 맵을 매칭하는 도구입니다. (3장 참고)

```
┌─────────────────────────┐    ┌─────────────────────────┐
│     [가치 맵]            │    │     [고객 프로필]        │
│                         │    │                         │
│  제품/서비스:            │    │  고객의 할 일:           │
│  1. _______________     │    │  1. _______________     │
│  2. _______________     │    │  2. _______________     │
│  3. _______________     │    │  3. _______________     │
│                         │    │                         │
│  고통 해결제:            │    │  고통(Pains):           │
│  1. _______________ →   │←──→│  1. _______________     │
│  2. _______________ →   │←──→│  2. _______________     │
│  3. _______________ →   │←──→│  3. _______________     │
│                         │    │                         │
│  이득 창출제:            │    │  이득(Gains):           │
│  1. _______________ →   │←──→│  1. _______________     │
│  2. _______________ →   │←──→│  2. _______________     │
│  3. _______________ →   │←──→│  3. _______________     │
│                         │    │                         │
└─────────────────────────┘    └─────────────────────────┘

핏(Fit) 확인:
□ 모든 핵심 고통에 대응하는 해결제가 있는가?
□ 모든 핵심 이득에 대응하는 창출제가 있는가?
□ 경쟁사보다 뛰어난 해결/창출이 1개 이상 있는가?
```
