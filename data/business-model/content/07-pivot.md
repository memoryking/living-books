# 7장: 피벗의 기술 — 방향 전환으로 살아남은 기업들의 비밀

## 피벗이란 무엇인가

**피벗(Pivot)**은 농구에서 한 발을 축으로 방향을 바꾸는 동작에서 유래한 용어입니다. 비즈니스에서 피벗은 **핵심 가설이 틀렸음을 인정하고, 새로운 방향으로 전환하는 전략적 결정**을 의미합니다.

에릭 리스(Eric Ries)는 이렇게 말했습니다:

> "피벗은 실패가 아니다. 학습의 결과물이다."

실제로 현재 가장 성공한 기업들 중 상당수가 피벗을 거쳤습니다. **피벗은 포기가 아니라, 데이터에 기반한 진화**입니다.

## 피벗의 10가지 유형

에릭 리스가 분류한 피벗 유형을 한국 사례와 함께 정리합니다:

| 유형 | 설명 | 사례 |
|------|------|------|
| **고객 세그먼트 피벗** | 다른 고객층으로 전환 | 슬랙: 게임 회사 내부 도구 → 기업용 메신저 |
| **고객 니즈 피벗** | 다른 문제를 해결 | 유튜브: 데이팅 사이트 → 동영상 플랫폼 |
| **플랫폼 피벗** | 앱 → 플랫폼, 또는 반대 | 당근마켓: 중고거래 → 지역 커뮤니티 플랫폼 |
| **비즈니스 구조 피벗** | B2C → B2B, 또는 반대 | 토스: 소비자 앱 → 금융 인프라(B2B 겸용) |
| **수익 모델 피벗** | 수익 방식 변경 | Adobe: 패키지 판매 → SaaS 구독 |
| **채널 피벗** | 유통 채널 변경 | 무신사: 온라인 잡지 → 이커머스 |
| **기술 피벗** | 핵심 기술 변경 | Netflix: DVD 우편 → 스트리밍 |
| **가치 포착 피벗** | 가격 모델 변경 | 카카오: 무료 메신저 → 이모티콘·광고 수익 |
| **성장 엔진 피벗** | 성장 방식 변경 | 바이럴 → 유료 마케팅, 또는 반대 |
| **확장/축소 피벗** | 범위 조정 | 크래프톤: 다양한 게임 → 배틀그라운드 집중 |

## Slack: 역대 최고의 피벗 사례

### 피벗 전: Glitch (온라인 게임)

Slack의 창업자 스튜어트 버터필드는 원래 **Glitch**라는 온라인 게임을 만들고 있었습니다. 게임은 실패했지만, 개발팀이 내부 소통에 사용하던 도구가 있었습니다.

### 피벗의 순간

```
[피벗 타임라인]
2009: Glitch 게임 개발 시작
2012: 게임 사용자 부족 → 서비스 종료 결정
2013: 내부 커뮤니케이션 도구를 별도 제품으로 분리 → Slack 탄생
2014: 출시 24시간 만에 8,000명 가입
2019: 뉴욕증권거래소 상장 (기업가치 약 23조 원)
2021: Salesforce에 약 32조 원에 인수
```

### 핵심 교훈

1. 실패한 프로젝트에서도 **재활용 가능한 자산**이 있다
2. **내부에서 자연스럽게 사용하는 것**이 최고의 PMF 신호
3. 피벗은 **핵심 역량(기술력)은 유지**한 채 방향만 바꾸는 것

## Netflix: 생존을 위한 연속 피벗

Netflix는 한 번이 아니라 **여러 번의 피벗**을 거쳤습니다:

### 피벗 1: DVD 대여점 → DVD 우편 배송 (1997)
- **계기**: 블록버스터 연체료에 대한 불만
- **전환**: 우편으로 DVD를 보내고, 반납도 우편으로
- **성과**: 연체료 0원이라는 가치 제안

### 피벗 2: 건당 대여 → 월정액 구독 (1999)
- **계기**: 건당 대여 모델의 한계 (수요 변동 큼)
- **전환**: 월 $15.95에 무제한 대여
- **성과**: 예측 가능한 반복 매출(MRR) 확보

### 피벗 3: DVD 우편 → 스트리밍 (2007)
- **계기**: 인터넷 속도 향상, 디지털 콘텐츠 소비 증가
- **전환**: 온라인 스트리밍 서비스 시작
- **리스크**: 기존 DVD 사업 잠식 가능성
- **결정**: 자기 잠식(Cannibalization)을 감수하고 전환

### 피벗 4: 라이선스 콘텐츠 → 오리지널 콘텐츠 (2013)
- **계기**: 콘텐츠 라이선스 비용 급증, 경쟁사 증가
- **전환**: 하우스 오브 카드 등 자체 제작
- **성과**: 콘텐츠 경쟁력과 독점 가치 확보

> **Netflix의 교훈: 지금 잘하고 있더라도, 미래를 위해 스스로 파괴할 수 있는 용기가 필요합니다.**

## 한국 기업의 피벗 사례

### 당근마켓: 중고거래 → 하이퍼로컬 플랫폼

| 시기 | 모델 | 핵심 변화 |
|------|------|-----------|
| 2015 | 판교장터 | 판교 지역 한정 중고거래 |
| 2018 | 당근마켓 | 전국 동네 기반 중고거래 |
| 2021 | 지역 플랫폼 | 중고거래 + 동네 커뮤니티 + 지역 광고 |
| 2023 | 당근 (리브랜딩) | 중고거래를 넘어선 지역 생활 슈퍼앱 |

피벗 포인트: **중고거래 수수료 0원**이라는 파격적 결정. 수익은 지역 광고에서 만들겠다는 전략적 판단.

### 무신사: 패션 매거진 → 패션 커머스

```
2001: 무진장 신발을 사랑하는 모임 (온라인 커뮤니티)
2009: 무신사 스토어 오픈 (커뮤니티 → 커머스 피벗)
2019: 무신사 스탠다드 (PB 브랜드 런칭)
2022: 기업가치 3조 원 돌파

피벗의 핵심: 커뮤니티에서 축적한 '패션 취향 데이터'를
커머스 추천에 활용 → 전환율 극대화
```

## 피벗 타이밍을 결정하는 신호

### 피벗해야 할 때 (Red Flags)

- [ ] 3개월 이상 핵심 지표가 정체되어 있다
- [ ] 고객 획득 비용(CAC)이 지속적으로 증가한다
- [ ] 고객 피드백에서 반복적으로 같은 불만이 나온다
- [ ] 팀원들이 제품에 대한 확신을 잃고 있다
- [ ] 경쟁사가 동일 시장에서 압도적 우위를 보인다

### 피벗하지 말아야 할 때

- [ ] 아직 충분한 데이터가 쌓이지 않았다 (최소 3개월)
- [ ] 단순 실행 문제(마케팅 부족, 버그 등)인데 모델 문제로 오인
- [ ] 감정적 판단(지루함, 새로운 것에 대한 유혹)
- [ ] 한두 명의 고객 피드백에 과잉 반응

## 피벗 실행 프레임워크

### Step 1: 현재 상태 진단

```
현재 비즈니스 모델:
- 고객: _______________
- 가치 제안: _______________
- 수익 모델: _______________
- 핵심 지표: _______________

문제 진단:
- 무엇이 작동하지 않는가? _______________
- 무엇은 작동하는가? _______________
- 데이터가 말하는 것은? _______________
```

### Step 2: 피벗 옵션 탐색

보존해야 할 핵심 자산을 식별합니다:
- **기술**: 재활용 가능한 기술 역량
- **고객**: 이미 확보한 사용자 베이스
- **데이터**: 축적된 고객/시장 데이터
- **브랜드**: 쌓아올린 인지도와 신뢰

### Step 3: 린 방식으로 검증

새로운 방향을 **다시 MVP로 검증**합니다. 피벗은 처음부터 다시 시작하는 것이 아니라, 기존 자산 위에서 방향을 바꾸는 것입니다.

### Step 4: 결단과 실행

피벗을 결정했다면 **빠르고 단호하게** 실행합니다. 반쯤 피벗한 상태(한 발은 기존, 한 발은 새 방향)가 가장 위험합니다.

### 핵심 정리

> **피벗은 실패의 인정이 아니라, 학습에 기반한 전략적 방향 전환입니다.** Slack, Netflix, 당근마켓 모두 피벗을 통해 더 큰 시장을 찾았습니다. 핵심은 보존할 자산을 지키면서, 데이터에 기반해 빠르게 전환하는 것입니다. 다음 장에서는 이 모든 의사결정의 기반이 되는 핵심 지표 대시보드를 설계해보겠습니다.
