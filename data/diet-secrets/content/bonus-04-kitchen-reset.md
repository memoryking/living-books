# 보너스 4: 주방 리셋 체크리스트

## 환경 설계를 위한 냉장고·찬장 정리 + 필수 구매 리스트

챕터 3에서 "환경을 바꾸면 의지력이 필요 없다"고 했습니다. 이 체크리스트는 그것을 실행하는 구체적 가이드입니다.

**소요 시간:** 약 1~2시간
**필요한 것:** 쓰레기 봉투, 마커펜, 장보기 목록

---

## Step 1: 찬장 정리 (30분)

### 버릴 것 (또는 다 먹고 재구매하지 않을 것)

**즉시 처리:**
- [ ] 유통기한 지난 것 전부
- [ ] 먹다 남은 오래된 과자/스낵 봉지

**다 먹고 재구매 안 할 것:**
- [ ] 과자/칩 류 (포카칩, 프링글스 등)
- [ ] 초콜릿/캔디/젤리
- [ ] 컵라면/봉지라면 (2~3개만 남기고)
- [ ] 설탕이 첫 번째 성분인 시리얼
- [ ] 크래커/비스킷
- [ ] 믹스 커피 (설탕+크림)

### 남길 것
- [ ] 통조림 (참치, 닭가슴살, 콩)
- [ ] 견과류 (소포장이면 더 좋음)
- [ ] 오트밀/귀리
- [ ] 통밀 파스타/현미
- [ ] 향신료/양념 (후추, 마늘가루, 고춧가루 등)
- [ ] 올리브유 (소량 사용)
- [ ] 간장, 식초, 겨자

### 재배치
- [ ] 건강한 간식(견과류, 건과일)을 눈높이에
- [ ] 라면/과자가 남아있다면 높은 선반 + 불투명 용기에

---

## Step 2: 냉장고 정리 (30분)

### 버릴 것

**즉시:**
- [ ] 유통기한 지난 것 전부
- [ ] 정체불명의 반찬/용기
- [ ] 말라비틀어진 채소

**다 먹고 재구매 안 할 것:**
- [ ] 탄산음료/주스
- [ ] 초콜릿 우유
- [ ] 아이스크림 (가장 강력한 유발 음식 1위)
- [ ] 케이크/빵류
- [ ] 고칼로리 소스 (마요네즈는 소량 OK)

### 남길 것
- [ ] 계란
- [ ] 두부
- [ ] 그릭 요거트
- [ ] 채소류 전부
- [ ] 과일
- [ ] 닭가슴살/생선
- [ ] 김치/피클 (발효식품)
- [ ] 물/탄산수

### 냉장고 구역 설정

```
┌──────────────────────────────┐
│     눈높이 (가장 먼저 보이는 곳)    │
│  → 삶은 계란, 방울토마토, 과일,    │
│    그릭 요거트, 당근 스틱         │
├──────────────────────────────┤
│     중간                        │
│  → 반찬, 두부, Meal Prep 용기    │
├──────────────────────────────┤
│     아래                        │
│  → 생고기, 생선, 채소 서랍        │
├──────────────────────────────┤
│     문쪽 선반                    │
│  → 물, 탄산수, 소스류            │
└──────────────────────────────┘

냉동실:
→ 냉동 닭가슴살, 냉동 채소, 냉동밥 소분
```

**핵심 원칙:** 문을 열었을 때 **가장 먼저 보이는 것이 건강한 음식**이어야 합니다.

---

## Step 3: 필수 구매 리스트

주방 리셋 후 채워야 할 것들:

### 단백질 (포만감의 핵심)
- [ ] 계란 (1판)
- [ ] 닭가슴살 (냉동 OK)
- [ ] 두부 (2~3모)
- [ ] 그릭 요거트 (무가당)
- [ ] 참치캔 (3~5개)
- [ ] 콩/렌틸 (통조림 또는 마른 것)

### 채소 (볼륨 이팅)
- [ ] 브로콜리
- [ ] 방울토마토
- [ ] 오이
- [ ] 양배추
- [ ] 시금치/상추
- [ ] 당근
- [ ] 파프리카
- [ ] 양파, 마늘

### 탄수화물 (적정량)
- [ ] 현미 또는 잡곡밥 (소분 냉동 추천)
- [ ] 통밀빵 (또는 통밀 래핑)
- [ ] 오트밀
- [ ] 고구마

### 과일
- [ ] 바나나 (간식/스무디)
- [ ] 사과 (포만감 높음)
- [ ] 베리류 (블루베리, 딸기)
- [ ] 제철 과일

### 간식 (건강한 것)
- [ ] 견과류 소포장 (하루 1봉지)
- [ ] 삶은 계란 (미리 삶아두기)
- [ ] 방울토마토 + 당근 스틱 (씻어서 용기에)
- [ ] 다크 초콜릿 85% (2~3조각/일)

### 음료
- [ ] 물/탄산수
- [ ] 녹차/허브티
- [ ] 블랙커피 (또는 아메리카노)

### 필수 양념/향신료
- [ ] 소금, 후추
- [ ] 간장
- [ ] 식초 (발사믹 또는 사과식초)
- [ ] 고춧가루/고추장
- [ ] 마늘 (다진 마늘 OK)
- [ ] 생강
- [ ] 레몬즙
- [ ] 핫소스/고추냉이
- [ ] 올리브유
- [ ] 참기름 (소량)

---

## Step 4: Meal Prep 초보자 1주일 가이드

### 일요일 준비 (약 1시간)

**만들 것:**

1. **단백질 베이스** — 닭가슴살 500g 구워두기 (소금, 후추, 마늘)
2. **탄수화물 베이스** — 잡곡밥 4공기 소분 냉동
3. **채소 베이스** — 브로콜리/당근 데쳐두기
4. **삶은 계란** — 6개 삶아서 냉장
5. **간식 소분** — 견과류 5봉지 소분, 방울토마토 씻어서 용기에

### 월~금 조합

| | 아침 | 점심 | 저녁 |
|---|------|------|------|
| 월 | 계란 2개 + 통밀빵 | 닭가슴살 + 잡곡밥 + 브로콜리 | 자유 (외식 OK) |
| 화 | 그릭 요거트 + 바나나 | 닭가슴살 + 잡곡밥 + 당근 | 자유 |
| 수 | 계란 2개 + 통밀빵 | 참치 + 잡곡밥 + 샐러드 | 자유 |
| 목 | 그릭 요거트 + 베리 | 닭가슴살 + 잡곡밥 + 브로콜리 | 자유 |
| 금 | 계란 2개 + 통밀빵 | 두부 볶음 + 잡곡밥 + 채소 | 계획된 유연성 |

**핵심:** 아침과 점심을 자동화하면 저녁에 자유를 누릴 수 있습니다.

---

## 가족이 있는 경우

"가족은 과자를 먹는데 나만 안 먹을 순 없잖아요?"

현실적 대안:

1. **분리 보관** — 가족 간식은 특정 찬장에, 나의 간식은 다른 곳에
2. **불투명 용기** — 가족 과자가 보이지 않게
3. **나의 간식을 매력적으로** — 견과류, 다크 초콜릿, 과일을 예쁜 용기에
4. **가족도 함께** — Meal Prep은 가족 식사에도 도움. 의외로 환영받을 수 있음

---

## 유지 관리

주방 리셋은 한 번으로 끝나지 않습니다.

**주간:** 장보기 전에 냉장고 체크. 유발 음식이 다시 들어오지 않았는지.
**월간:** 찬장 재점검. 유통기한 확인. 사용하지 않는 것 정리.
**시즌:** 명절/연말 후 리셋. 선물로 받은 과자/초콜릿 처리.

환경은 계속 관리해야 합니다. 하지만 처음이 가장 힘들고, 그 이후는 유지만 하면 됩니다.
