# 5장. 나트륨과 DASH 식단: 먹는 것이 혈압을 바꾼다

## 식단이 약만큼 중요한 이유

"약사님, 먹는 것으로 혈압이 진짜 내려가요?"

네, 내려갑니다. 그것도 상당히 많이요.

DASH 식단(Dietary Approaches to Stop Hypertension)은 **고혈압을 멈추기 위한 식이 요법**이라는 뜻으로, 미국 국립보건원(NIH)이 개발하고 대규모 임상 연구로 효과를 입증한 식단입니다.

DASH 식단을 제대로 실천하면 수축기 혈압이 **8~14mmHg** 내려갈 수 있습니다. 이것은 혈압약 한 알의 효과에 버금가는 수준입니다. 약물 치료와 병행하면 효과가 더 커집니다.

## DASH 식단의 핵심 원칙

DASH 식단은 특별한 음식을 먹는 것이 아니라, **균형 잡힌 식사**를 하는 것입니다.

| 식품군 | 하루 권장량 | 구체적 예시 |
|--------|-----------|-----------|
| 통곡물 | 6~8회 | 현미, 잡곡밥, 통밀빵, 오트밀 |
| 채소 | 4~5회 | 시금치, 브로콜리, 당근, 토마토 |
| 과일 | 4~5회 | 바나나, 사과, 오렌지, 키위 |
| 저지방 유제품 | 2~3회 | 저지방 우유, 요거트, 치즈 |
| 살코기/생선 | 2회 이하 | 닭가슴살, 등푸른 생선 |
| 견과류/콩류 | 주 4~5회 | 호두, 아몬드, 렌틸콩 |
| 건강한 지방 | 2~3회 | 올리브유, 들기름 |

**줄여야 할 것:** 나트륨(소금), 붉은 고기, 단 음료, 과자류, 포화지방

DASH 식단의 핵심을 한마디로 요약하면, **"채소와 과일을 많이, 소금은 적게, 가공식품은 멀리"**입니다.

## 한국인의 나트륨 문제

한국인의 하루 평균 나트륨 섭취량은 약 **3,500mg**입니다. WHO 권장량인 2,000mg의 거의 2배입니다.

### 나트륨이 많은 한국 음식

| 음식 | 1인분 나트륨 함량 | 하루 권장량 대비 |
|------|-----------------|----------------|
| 김치찌개 | 약 2,500mg | 125% |
| 된장찌개 | 약 2,200mg | 110% |
| 라면 (국물 포함) | 약 1,800mg | 90% |
| 김치 1인분 (40g) | 약 300mg | 15% |
| 젓갈 1큰술 | 약 800mg | 40% |
| 짜장면 | 약 2,300mg | 115% |
| 비빔밥 (간장 포함) | 약 1,200mg | 60% |

이 표를 보면 충격적일 수 있습니다. 김치찌개 한 그릇이면 하루 나트륨 권장량을 초과합니다. 한국 음식 문화에서 나트륨을 줄이는 것이 쉽지 않은 이유가 여기에 있습니다.

## 나트륨 줄이기 실천 전략

갑자기 싱겁게 먹으면 음식이 맛이 없어서 오래 지속하기 어렵습니다. **단계적으로 줄이는 것**이 핵심입니다.

### 1단계: 현재 섭취량 파악하기

3일간 먹은 음식을 기록하고, 대략적인 나트륨 섭취량을 계산해봅니다. 식품의약품안전처의 나트륨 줄이기 앱이나 영양 정보 앱을 활용하면 편리합니다.

### 2단계: 가장 쉬운 것부터 줄이기

| 전략 | 구체적 방법 | 절감 효과 |
|------|-----------|----------|
| 국물 섭취 줄이기 | 찌개·국의 국물은 절반만 | 나트륨 30~50% 절감 |
| 간장·소스 줄이기 | 찍어 먹기, 덜어 먹기 | 나트륨 20~30% 절감 |
| 라면 국물 남기기 | 면만 건져 먹기 | 나트륨 40~50% 절감 |
| 가공식품 줄이기 | 햄, 소시지, 통조림 줄이기 | 나트륨 상당량 절감 |
| 외식 줄이기 | 주 2회 이하로 | 전체 나트륨 20% 절감 |

### 3단계: 대체 양념 활용하기

소금 대신 다른 양념으로 맛을 낼 수 있습니다. 마늘, 생강, 양파, 후추, 레몬즙, 식초, 카레가루, 허브류는 나트륨 없이도 풍미를 더해줍니다.

**저나트륨 간장과 소금에 대해:** 저나트륨 소금은 나트륨을 줄이고 칼륨을 넣은 제품입니다. 혈압 관리에 도움이 되지만, **신장 기능이 나쁜 분이나 칼륨 보존형 이뇨제를 복용하는 분은 주의**해야 합니다. 칼륨이 과도하게 쌓일 수 있기 때문입니다. 사용 전에 약사에게 확인하세요.

## 칼륨이 풍부한 음식: 나트륨의 천적

칼륨은 나트륨을 몸 밖으로 배출하는 것을 도와줍니다. 칼륨 섭취를 늘리면 나트륨을 줄이는 효과를 증폭시킬 수 있습니다.

| 음식 | 칼륨 함량 (100g당) |
|------|-------------------|
| 바나나 | 358mg |
| 시금치 | 558mg |
| 고구마 | 337mg |
| 아보카도 | 485mg |
| 토마토 | 237mg |
| 감자 | 421mg |
| 오렌지 | 181mg |
| 키위 | 312mg |

**주의:** 신장 기능이 저하된 분(만성 신장병 3기 이상)은 칼륨 섭취를 오히려 제한해야 할 수 있습니다. 반드시 의사와 상의하세요.

## 외식 시 나트륨 줄이기

완벽하게 외식을 피할 수는 없습니다. 현실적인 외식 전략을 알려드립니다.

**외식 전:** 메뉴를 미리 확인하고, 나트륨이 적은 메뉴를 선택합니다.

**주문할 때:** "소스를 따로 주세요", "덜 짜게 해주세요"라고 요청합니다.

**먹을 때:** 국물은 남기고, 반찬은 골라 먹고, 추가 소스나 간장은 최소화합니다.

| 외식 종류 | 저나트륨 선택 | 피해야 할 선택 |
|----------|-------------|--------------|
| 한식 | 생선구이 정식, 비빔밥(소스 별도) | 찌개류, 탕류 |
| 중식 | 잡채밥, 울면(국물 남기기) | 짬뽕, 짜장면 |
| 일식 | 회, 초밥(간장 최소) | 우동, 라멘 |
| 양식 | 그릴 스테이크, 샐러드 | 피자, 파스타(크림) |
| 분식 | 김밥(간장 없이) | 떡볶이, 라면 |

## 한국형 저나트륨 DASH 식단 1주일 플랜

한국인의 입맛에 맞으면서도 나트륨을 줄인 실천 가능한 식단입니다.

### 월요일

- **아침:** 잡곡밥 + 달걀 프라이 + 무염 김 + 채소 샐러드
- **점심:** 비빔밥(간장 반으로 줄이기) + 미역국(국물 절반만)
- **저녁:** 현미밥 + 고등어구이 + 시금치 무침(소금 절반) + 두부

### 화요일

- **아침:** 오트밀 + 바나나 + 호두 + 저지방 우유
- **점심:** 닭가슴살 샐러드 + 잡곡밥 + 된장국(된장 절반)
- **저녁:** 현미밥 + 삼치구이 + 브로콜리 + 콩나물무침

### 수요일

- **아침:** 통밀 토스트 + 아보카도 + 토마토 + 저지방 요거트
- **점심:** 잡곡밥 + 불고기(소스 줄이기) + 상추쌈 + 깍두기 소량
- **저녁:** 현미밥 + 두부조림(간장 줄이기) + 나물 3종

### 목요일

- **아침:** 잡곡밥 + 계란찜 + 오이무침 + 김
- **점심:** 콩나물국밥(국물 절반) + 김치 소량
- **저녁:** 현미밥 + 연어구이 + 파프리카 + 미역무침

### 금요일

- **아침:** 그래놀라 + 저지방 우유 + 키위
- **점심:** 잡곡밥 + 제육볶음(소스 줄이기) + 양배추 샐러드
- **저녁:** 현미밥 + 닭가슴살 스테이크 + 채소볶음

### 토요일

- **아침:** 통밀 팬케이크 + 과일 + 저지방 요거트
- **점심:** 비빔국수(소스 줄이기) + 삶은 계란
- **저녁:** 잡곡밥 + 갈치구이 + 무나물 + 가지무침

### 일요일

- **아침:** 잡곡밥 + 된장국(된장 절반, 채소 듬뿍) + 계란말이
- **점심:** 닭가슴살 덮밥 + 샐러드
- **저녁:** 현미밥 + 새우볶음 + 버섯볶음 + 토마토 샐러드

## DASH 식단 성공을 위한 실전 팁

1. **한 번에 다 바꾸려 하지 마세요.** 첫째 주는 국물 줄이기, 둘째 주는 가공식품 줄이기, 이런 식으로 단계적으로 접근합니다.
2. **영양 성분표를 확인하세요.** 가공식품을 살 때 나트륨 함량을 확인하는 습관을 들이세요.
3. **집에서 요리하세요.** 직접 만들면 나트륨 양을 조절할 수 있습니다.
4. **허브와 향신료를 활용하세요.** 마늘, 후추, 레몬, 허브로 맛을 내면 소금이 적어도 맛있습니다.
5. **가족과 함께하세요.** 혼자만 싱겁게 먹으면 지속하기 어렵습니다. 가족 전체의 건강을 위한 것임을 공유하세요.

## 이 장의 핵심 정리

1. DASH 식단으로 수축기 혈압을 8~14mmHg 낮출 수 있습니다
2. 한국인의 나트륨 섭취량은 WHO 권장량의 2배에 달합니다
3. 국물 줄이기가 가장 효과적인 첫 번째 단계입니다
4. 칼륨이 풍부한 채소와 과일은 나트륨 배출을 도와줍니다
5. 갑자기가 아니라 단계적으로 줄이는 것이 지속 가능합니다

> **약사의 한마디:** "싱거우면 맛이 없잖아요"라고 하시는 분이 많습니다. 맞습니다, 처음에는 그렇습니다. 하지만 2~3주만 지나면 미각이 적응하면서 오히려 짠 음식이 불편해지기 시작합니다. 3주만 참아보세요. 여러분의 미각이, 그리고 혈압이 바뀌기 시작할 것입니다.
