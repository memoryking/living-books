## 부록 B: 5대 혈압약 비교 카드

### ARB (안지오텐신 II 수용체 차단제)

| 항목 | 내용 |
|------|------|
| 대표 약물 | 로사르탄, 발사르탄, 올메사르탄, 텔미사르탄 |
| 작용 원리 | 안지오텐신 II 수용체 차단 → 혈관 이완 |
| 주요 장점 | 부작용 적음, 신장/심장 보호 |
| 주요 부작용 | 드물게 어지러움, 고칼륨혈증 |

| 복용 시간 | 보통 1일 1회 (아침 또는 저녁) |

| 항목 | 내용 |

## 부록 E: 응급 상황 대처 카드

### 혈압 위기 (180/120 이상)

**즉시 확인할 사항:**
- 가만히 앉아서 5분 후 다시 측정합니다
- 그래도 180/120 이상인지 확인합니다

**동반 증상이 없는 경우:**
- 침착하게 안정을 취합니다
- 혈압약을 빼먹었다면 복용합니다
- 1시간 후 다시 측정합니다
- 당일 병원이나 약국에 전화 상담합니다

**다음 증상이 동반되면 즉시 119에 전화:**
- 심한 두통 (지금까지 경험 못 한 두통)
- 가슴 통증 또는 호흡곤란
- 한쪽 얼굴/팔/다리 마비 또는 저림
- 말이 어눌해짐
- 시야 장애
- 심한 코피가 멈추지 않음
- 의식이 흐려짐

### 뇌졸중 의심 (FAST)

| 확인 항목 | 방법 | 이상 소견 |
|----------|------|----------|
| F (얼굴) | "이~" 해보세요 | 한쪽이 처짐 |
| A (팔) | 양팔 앞으로 들기 | 한쪽이 내려감 |
| S (말) | "대한민국" 말해보세요 | 발음이 어눌함 |
| T (시간) | 위 중 하나라도 해당 | 즉시 119 |

**중요:** 증상이 나타난 시간을 정확히 기록하세요. 치료 시 매우 중요한 정보입니다.

### 저혈압 증상 (어지러움, 실신)

- 즉시 앉거나 눕습니다
- 다리를 심장보다 높이 올립니다
- 물을 마십니다
- 의식이 돌아오면 천천히 일어납니다
- 반복되면 병원을 방문합니다
