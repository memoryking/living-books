# 90일 아이디어 검증 로드맵: 오늘부터 시작하기

## 왜 90일인가

90일은 **충분히 길어서 의미 있는 검증이 가능하고, 충분히 짧아서 긴장감을 유지**할 수 있는 기간입니다. 3개월 안에 아이디어의 시장성을 판단하지 못한다면, 문제는 기간이 아니라 방법에 있습니다.

이 로드맵은 앞선 9개 장에서 다룬 모든 프레임워크를 **시간순으로 정리한 실행 가이드**입니다. 각 단계에서 "무엇을", "어떻게", "어디까지" 해야 하는지를 구체적으로 안내합니다.

## Phase 1: 시장 조사 + 페르소나 (1일~30일)

### 1주차: 아이디어 정리 + 초기 리서치
- [ ] 내 아이디어를 한 문장으로 정의: "[타겟 고객]의 [문제]를 [방법]으로 해결한다"
- [ ] 기존 해결책(경쟁사/대체재) 20개 이상 리스트업
- [ ] 네이버 카페, 블라인드, 에브리타임에서 관련 키워드 검색, 불만/질문 게시글 50개 수집

### 2주차: 페르소나 + 심층 인터뷰
- [ ] 고객 페르소나 초안 작성 (인구통계 5항목 + 심리통계 5항목)
- [ ] 타겟 고객 후보 20명 리스트업 (지인, 온라인 커뮤니티, 카카오 오픈채팅)
- [ ] 심층 인터뷰 10명 실행 (30분씩, 문제의 심각도와 현재 해결 방식 중심)
- [ ] 인터뷰 인사이트 정리 (공통 패턴 3~5가지 도출)

### 3주차: 정량 조사 + 경쟁 분석
- [ ] 온라인 설문 설계 + 배포 (최소 100명 목표)
- [ ] 경쟁사 분석 3단계 실행 (경쟁 지도 → 강약점 매트릭스 → 차별화 포인트)
- [ ] 7가지 틈새시장 발견법으로 기회 영역 탐색

### 4주차: Phase 1 종합 + 가설 수립
- [ ] 조사 결과 종합 리포트 작성 (A4 2~3장)
- [ ] 4가지 유형별 핵심 가설 수립 (시장/고객/제품/비즈니스 모델)
- [ ] 가정 우선순위 매트릭스로 "가장 위험한 가설" 3개 선정
- [ ] Phase 1 결론: Go / Pivot / Kill 결정

**Phase 1 체크포인트:** "우리의 타겟 고객은 [구체적 사람]이고, 그들은 [구체적 문제]로 [구체적 고통]을 겪고 있으며, 현재 해결책에 [구체적 불만]을 가지고 있다"를 데이터로 뒷받침할 수 있는가?

## Phase 2: 가설 검증 + MVP (31일~60일)

### 5주차: 핵심 가설 검증 실험
- [ ] 가장 위험한 가설에 대한 실험 설계 (6단계 프로세스 적용)
- [ ] 성공 기준 사전 정의 (구체적 숫자로)
- [ ] 스모크 테스트 실행: 랜딩페이지 제작 + 소액 광고 (5~10만 원)

### 6주차: 검증 결과 분석 + MVP 유형 선택
- [ ] 스모크 테스트 결과 분석 (전환율, 반응 데이터)
- [ ] A/B 테스트 1회 실행 (가격 또는 가치 제안)
- [ ] 5가지 MVP 유형 중 적합한 것 선택
- [ ] MVP 범위 정의 (버킷 1/2/3 분류)

### 7주차: MVP 개발/구축
- [ ] MVP 제작 착수 (유형에 따라 1~2주)
- [ ] 컨시어지/위자드오브오즈: 수동 서비스 프로세스 설계
- [ ] 랜딩페이지/패치워크: 노코드 도구로 구축
- [ ] 싱글 피처: 핵심 기능 개발 집중

### 8주차: MVP 출시 + 초기 데이터 수집
- [ ] MVP를 얼리어답터 20~50명에게 공개
- [ ] 피드백 수집 채널 설정 (채널톡, 카카오톡 오픈채팅, 구글 폼)
- [ ] 핵심 지표 측정 시작 (사용률, 재방문율, NPS)
- [ ] Phase 2 결론: MVP 반응 1차 평가

**Phase 2 체크포인트:** "실제 타겟 고객이 우리 MVP를 사용해 봤고, [구체적 반응]을 보였다. 핵심 지표는 [숫자]이다."

## Phase 3: 피드백 + 피벗/확장 (61일~90일)

### 9주차: 피드백 루프 본격 가동
- [ ] 피드백 시스템 5단계 운영 (수집→분류→분석→실행→확인)
- [ ] 고객 인터뷰 추가 5~10명 (MVP 사용 경험 기반)
- [ ] ICE 스코어링으로 개선 우선순위 결정

### 10주차: 반복 개선 (Iteration)
- [ ] 피드백 기반 MVP 1차 개선
- [ ] Build-Measure-Learn 루프 1회전 완료
- [ ] NPS 재측정 (개선 전후 비교)

### 11주차: 피벗 vs 지속 결정
- [ ] 지속 신호 vs 피벗 신호 점검
- [ ] PMF 지표 확인 (숀 엘리스 테스트)
- [ ] 피벗이 필요하면: 유형 선택 + 새로운 가설 수립
- [ ] 지속이 결정되면: 확장 계획 초안 작성

### 12주차: 90일 종합 + 다음 단계
- [ ] 90일 검증 결과 종합 리포트 작성
- [ ] 핵심 학습 5가지 정리 (What we learned)
- [ ] 다음 90일 계획 수립
- [ ] 필요시: 투자 유치 준비 / 팀 빌딩 시작 / 정부 지원 사업 지원

**Phase 3 체크포인트:** "우리 아이디어는 [검증됨/수정 필요/중단]이다. 근거는 [데이터]이다. 다음 단계는 [구체적 행동]이다."

## 90일 요약 대시보드

| 주차 | 핵심 활동 | 산출물 | 판단 기준 |
|------|----------|--------|----------|
| 1~2주 | 리서치 + 인터뷰 | 페르소나, 인터뷰 노트 | 고객 문제가 실재하는가? |
| 3~4주 | 설문 + 경쟁 분석 | 조사 리포트, 가설 목록 | 시장 기회가 있는가? |
| 5~6주 | 가설 검증 + 실험 | 실험 결과, MVP 계획 | 가설이 지지되는가? |
| 7~8주 | MVP 제작 + 출시 | MVP, 초기 데이터 | 고객이 사용하는가? |
| 9~10주 | 피드백 + 개선 | 개선된 MVP, NPS | 지표가 개선되는가? |
| 11~12주 | 결정 + 계획 | 종합 리포트, 다음 계획 | 사업을 진행할 것인가? |
