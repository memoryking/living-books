## 템플릿 5: MVP 유형 선택 가이드

### 상황 체크리스트

아래 질문에 답하여 적합한 MVP 유형을 선택하세요.

| 질문 | 답변 |
|------|------|
| 개발자/기술 역량이 있는가? | Yes / No |
| 투입 가능한 예산은? | 0~50만 / 50~500만 / 500만+ |
| 타겟 고객을 직접 만날 수 있는가? | Yes / No |
| 경쟁 제품이 이미 있는가? | Yes / No |
| B2B인가 B2C인가? | B2B / B2C |

### 추천 MVP 유형

- 예산 0~50만 + 고객 접근 가능 → **컨시어지 MVP**
- 예산 0~50만 + 고객 접근 어려움 → **랜딩페이지 MVP**
- 예산 50~500만 + 기술 역량 없음 → **패치워크 MVP**
- 예산 50~500만 + 기술 역량 있음 → **싱글 피처 MVP**
- B2B + 프로토타입 필요 → **위자드 오브 오즈 MVP**

## 템플릿 7: 피벗 vs 지속 결정 프레임워크

### 현재 상태 진단

**지속 신호 체크 (해당 항목 체크):**
- [ ] 핵심 지표가 꾸준히 개선 중
- [ ] 고객이 자발적으로 추천 (구전 계수 > 0.5)
- [ ] 유료 전환율이 업계 평균 이상
- [ ] "이거 없으면 곤란하다" 반응 있음
- [ ] 문제가 제품이 아닌 마케팅/유통에 있음

→ 체크 개수: /5

**피벗 신호 체크 (해당 항목 체크):**
- [ ] 3개월 이상 핵심 지표 정체/하락
- [ ] CAC가 지속 상승
- [ ] 무료는 많지만 유료 전환 거의 없음
- [ ] "있으면 좋지만 없어도 된다" 반응 반복
- [ ] PMF 감이 안 옴
- [ ] 경쟁사가 압도적 우위

→ 체크 개수: /6

### 판단 기준
- 지속 신호 3개 이상 + 피벗 신호 2개 이하 → **지속**
- 피벗 신호 3개 이상 + 지속 신호 2개 이하 → **피벗 검토**
- 둘 다 비슷 → **추가 데이터 수집 후 2주 내 재판단**

## FAQ 10선

**Q1. 아이디어가 여러 개인데 어떤 것부터 검증해야 하나요?**
가장 빠르고 저렴하게 검증할 수 있는 것부터 시작하세요. 랜딩페이지 스모크 테스트를 각 아이디어에 대해 실행하고, 전환율이 가장 높은 것에 집중합니다.

**Q2. 인터뷰 대상을 어디서 찾나요?**
네이버 카페, 카카오 오픈채팅방, 에브리타임, 링크드인에서 타겟 고객이 모이는 곳을 찾으세요. "커피 한 잔 사드릴게요, 30분만 이야기해 주세요"라는 접근이 의외로 잘 통합니다.

**Q3. 설문 응답이 안 모이면 어떻게 하나요?**
인센티브를 제공하세요 (커피 쿠폰 1,000~3,000원). 설문 길이를 5분 이내로 줄이세요. 타겟 커뮤니티에 직접 게시하되, 관리자 허락을 먼저 받으세요.

**Q4. 경쟁사가 너무 많으면 포기해야 하나요?**
경쟁사가 많다는 것은 시장이 존재한다는 증거입니다. 중요한 것은 "경쟁사의 수"가 아니라 "차별화할 수 있는 틈"이 있는가입니다.

**Q5. MVP에 디자인이 중요한가요?**
핵심 가치 전달을 방해하지 않을 정도면 충분합니다. "예쁘지만 쓸모없는 MVP"보다 "못생겼지만 문제를 해결하는 MVP"가 낫습니다.

**Q6. 돈이 없어도 검증할 수 있나요?**
네. 컨시어지 MVP, 랜딩페이지 MVP, 패치워크 MVP 모두 50만 원 이하로 가능합니다. 심층 인터뷰는 무료입니다. 네이버 폼 설문도 무료입니다.

**Q7. 검증 결과가 애매하면 어떻게 하나요?**
"약간 긍정적"은 대부분 "부정적"입니다. 정말 통하는 아이디어는 명확한 신호를 보냅니다. 애매하면 가설을 수정하고 다시 검증하세요.

**Q8. 직장 다니면서 검증할 수 있나요?**
90일 로드맵은 하루 1~2시간 투자 기준으로 설계했습니다. 주말에 집중적으로 인터뷰하고, 평일 저녁에 데이터 분석하면 충분히 가능합니다.

**Q9. 팀 없이 혼자서도 가능한가요?**
검증 단계는 혼자서도 가능합니다. 오히려 혼자 하면 의사 결정이 빠릅니다. 팀은 검증이 끝나고 확장할 때 구성해도 늦지 않습니다.

**Q10. 검증 후 실패로 판명되면 시간 낭비 아닌가요?**
3개월 만에 "이 아이디어는 안 된다"를 알게 된 것은 1년과 수천만 원을 절약한 것입니다. 실패한 검증은 시간 낭비가 아니라 가장 값싼 수업료입니다.
