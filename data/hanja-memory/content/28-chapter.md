# 28장. 채움과 경계, 옛 시간

술과 잔, 채움과 대답을 지나 경계와 시간으로 이어집니다. 빈 것과 찬 것, 옛것과 지금을 대비합니다.

**읽는 순서:** 그림을 보고 → 한자의 획을 짚고 → 훈음을 말하고 → 답을 가리고 떠올립니다.
