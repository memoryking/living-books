# 한자 암기앱 개선 근거와 구현

## 공식 문서 조사

2026-09-25에 공식 안내를 조사했다. 유료 앱을 직접 사용해 비교한 결과나 학습 효과 순위는 아니다. 일본어·중국어 문자 학습 서비스에서 한국어 훈음 학습에도 적용할 수 있는 흐름을 참고했다.

| 서비스 | 참고점 | 우리 앱 적용 |
| --- | --- | --- |
| [한자카드](https://www.choe.name/apps/hanja-card) | 훈음·부수·예문을 카드에서 확인하는 한국어 한자 학습 | 정확한 훈음과 활용 예시를 유지하되, 기본 학습에서는 그림을 먼저 본 후 답을 가리는 순서로 구성 |
| [Anki](https://docs.ankiweb.net/studying.html) | 답을 떠올린 후 공개하고 평가. 네 버튼이 어렵다면 Again/Good만 사용 가능 | 정답 보기 → 다시 연습 / 맞혔어요. 모호했던 넘기기 제거 |
| [WaniKani](https://knowledge.wanikani.com/wanikani/app-settings/) | 기본 수업 묶음 5개 후 퀴즈 | 새 글자 최대 5개를 그림·연상·예시로 먼저 보고 전체 묶음을 가리고 확인 |
| [Skritter](https://docs.skritter.com/article/245-due-cards) | 예정된 복습을 모으고, 작은 범위로 학습하며 두 등급 평가 제공 | 오늘의 학습 시작 하나로 예정 복습 우선, 오래 기다린 순 최대 10개 |

## 적용 규칙

- 기본 진입은 오늘 학습. `#item-N` 링크는 해당 글자의 책 읽기로 바로 연결.
- 복습 예정 시각을 지난 항목이 있으면 새 글자보다 먼저 추천한다. 없다면 기록 없는 항목을 원고 순 최대 5개 제공한다. 이는 세션 크기이며 하루 학습 상한은 아니다.
- 새 글자 그림을 넘기는 행동은 정답으로 기록하지 않는다. 모든 그림을 본 다음 같은 묶음을 가린다. 중간에 나가면 미평가 항목은 새 항목으로 유지된다.
- 정답 보기 전 그림·훈음·암기법을 숨긴다. 뜻→쓰기에서는 훈음만 단서로 공개한다.
- 다시 연습은 약 10분 후, 맞힘은 기존 1·3·7·14·30일 일정. 버튼에 다음 복습 시각 표시. 예정 시각 전 재도전은 단계를 올리지 않는다.
- 종료 화면에서 헷갈린 글자만 재도전 가능. 오답 무한 재출제나 암기 완료 보장은 하지 않는다.
- 책 읽기, 쓰기, 비교, 메모·책갈피·기록 백업은 유지. 검색·책 소개·음성 재생을 다시 추가하지 않는다.
- `book.json`이 양쪽 전자책의 공통 원고이며 ID·localStorage v1은 유지한다. 앱 UI 개편으로 기존형 뷰어를 변경하지 않는다.

## 검증

`check-hanja.mjs`는 복습 우선순위·묶음 제한·복습 간격·백업 호환성을 검사한다. `qa-hanja-compact.mjs`는 네 화면 크기의 본문/회상, 320×568의 다섯 글자 사전 학습·가림·평가·저장·조기 재도전을 확인한다. 실제 모바일 기기 검증과는 구분한다.
