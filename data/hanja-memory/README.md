# 그림으로 기억하는 한자 453

입력 순서 그대로 453개 학습 항목을 담은 그림 암기 전자책입니다. 중복 글자와 부수·구성 요소를 포함하므로 서로 다른 독립 한자 453자라는 뜻은 아닙니다.

## 읽기

- `/premium/hanja-memory`: 책 소개
- `/premium/hanja-memory/read`: 한 화면 학습 앱. 단원·학습 목록·글자 선택, 양방향 회상, 자기평가와 간격 복습, 쓰기판, 책갈피, 개인 메모, 기록 내보내기·가져오기
- `/premium/hanja-memory/read/full`: 내보내기와 동일한 기존형 뷰어. 목차·전체 본문·스크롤/페이지 전환·오른쪽 아래 고정 목차 버튼. 전체 목록 링크 없음.
- `outputs/한자453_전자책.html`: 기존 위젯 뷰어 형식의 단일 파일. 본문과 삽화를 포함하며 인터넷 없이 브라우저에서 읽을 수 있습니다. 글자 크기·야간 모드·목차·페이지 전환 기능을 제공합니다. 학습 기록과 쓰기 연습은 웹 학습 화면에서 사용합니다.
- 기존 관리자 내보내기의 전자책 목록에도 등록했습니다. 외부 삽입 코드는 서비스 배포 후 해당 서비스의 이미지 주소를 사용합니다.

## 구성과 편집

- 29개 단원, 453개 이미지 연상과 암기 문장, 906개 단어·구성 예시
- 18개 헷갈림 비교, 학습법, 원문 대조·교정표
- **`book.json`만 수정합니다.** 그림 학습형이 직접 읽는 공통 원고이며 글자·훈음·암기법·예시·교정·그림 위치·단원·비교 내용을 함께 보관합니다.
- `source.tsv`는 보존용 입력 원문입니다. `lessons.tsv`, `editorial.json`, `chapters.json`, `comparisons.json`, 단원별 Markdown은 자동 생성된 사본이므로 직접 수정하지 않습니다.
- 어느 형식에서 발견한 수정이든 공통 원고에 반영합니다. `npm run build`와 `npm run dev` 시작 시 본문을 자동 동기화합니다. 개발 서버 실행 중에는 `npm run content:sync`를 실행합니다. 배포 빌드에서도 자동 실행되어 두 형식이 함께 바뀝니다.
- 다운로드한 단일 HTML 파일은 고정 사본입니다. 원고 변경 후 `node scripts/export-hanja.mjs`로 다시 내보내야 합니다. 이 명령도 먼저 본문을 동기화합니다. 이미 사용자가 내려받은 파일이 원격으로 자동 변경되지는 않습니다.
- 27개 항목의 학습 표기를 교정하고 44개 항목에 설명을 붙였습니다. 모든 암기 이야기는 창작 연상이며 역사적 자원 설명과 구별합니다.
- 희귀 부수는 일상 단어 두 개를 억지로 만들지 않고 관련 글자의 구성·문어 예시임을 밝혔습니다.
- 이미지 생성 도구로 제작한 30개 이미지 묶음을 각 항목에서 한 장면씩 표시합니다. 원본 PNG와 웹용 WebP를 `public/hanja-memory/`에 보존했습니다. 프롬프트는 `image-prompts.json`에 있습니다.

## 재생성 및 확인

프로젝트 루트 `living-books`에서 실행합니다.

```sh
node scripts/build-hanja.mjs
npm run test:memory-sync
node scripts/check-hanja.mjs
node scripts/export-hanja.mjs
npm run build
npm run start -- --hostname 127.0.0.1 --port 3100
```

Windows의 Chrome으로 확인하려면 실행 중인 서버에 대해 `node scripts/qa-hanja-browser.mjs`를 사용합니다. 결과와 화면은 `artifacts/hanja-qa/`에 남습니다. 브라우저 검사는 별도 프로필의 이 책 학습 기록만 초기화합니다.

원본 PNG를 새로 만들거나 교체했을 때만 `node scripts/optimize-hanja.mjs`로 웹용 WebP를 재생성합니다. 표시 경계만 수정하는 작업에서는 원본 이미지 파일을 바꾸지 않습니다.

검증: 전체 항목·예시·그림 연결, 복습 간격, 기록 파일 검증, 빌드, 변경 코드 ESLint, PC·모바일 표시, 답 숨김·공개, 자기평가·책갈피 저장과 새로고침 복원, 쓰기판, 중복 항목 검색, 단원 링크, 전체 본문의 453개 그림, 단일 HTML 파일의 본문·야간 모드·목차.

학습 기록은 사용하는 브라우저에 저장됩니다. 다른 기기로 옮길 때는 학습 안내에서 JSON 기록을 내보내고 가져옵니다. 간격 일정은 조정 가능한 학습 운영 예시이며 암기 효과를 보장하는 수치는 아닙니다.

## 모바일 학습 화면

### 최신 변경: 한 화면 학습

검색 입력, 상단 책 소개·브랜드·큰 제목·통계 영역, 훈음·연상 듣기를 제거했습니다. 책 읽기와 꺼내 보기 화면은 `100dvh` 안에 맞춥니다. 단원·학습 목록·글자를 선택창으로 고르고, 그림과 한자 옆/아래의 암기법·예시·메모·쓰기·표기 안내 탭을 바꿔 학습합니다. 긴 설명은 `TextPages.tsx`가 화면에 맞게 나누어 ‘다음 설명’으로 보여주며 본문을 잘라 숨기지 않습니다. 안내·비교 화면과 긴 메모 입력 영역은 별도 탐색/편집 영역입니다.

기존형 전체 본문 뷰어와 공통 원고는 유지됩니다. 그림은 `--image-ratio`와 컨테이너 크기로 비율을 보존합니다. 두 글자 이상인 구성 학습 표기도 카드 밖으로 넘치지 않도록 크기를 조절합니다.

현재 그림 학습형 검증 명령은 `node scripts/qa-hanja-compact.mjs`입니다. 1280×800, 390×844, 320×568, 844×390에서 학습 패널·정답 확인·그림 비율·표기 안내를 검사했습니다. `qa-hanja-browser.mjs`의 검색·옛 목록 배치 검사는 이전 화면용이므로 현재 UI의 통과 근거로 사용하지 않습니다. 기존형은 계속 `qa-hanja-classic.mjs`로 검사합니다. 아래의 검색·목차 접기 관련 설명과 옛 검사 결과는 이전 화면 기록입니다.

사용자 선택에 따라 카드 학습 화면을 기본으로 유지합니다. 관리자 내보내기에서 그림 학습형과 기존 전자책형을 따로 선택하며, 학습 화면 상단에는 형식 전환 버튼을 표시하지 않습니다. 전체 본문은 10가지 탭 없이 바로 열립니다. 모바일에서는 목차를 접어 시작하고, 항목을 선택하거나 다음 글자로 이동하면 카드 위쪽으로 이동합니다. 터치 버튼은 최소 44px 높이, 입력 글자는 16px로 보완했습니다.

320·360·390·430·768px의 Chrome 모바일·터치 재현 환경에서 가로 넘침, 터치 쓰기와 지우기, 다음 항목 이동, 양방향 복습, 헷갈림 비교를 확인했습니다. 실제 iOS Safari·Android 기기의 검사는 아직 수행하지 않았습니다. 결과는 `artifacts/hanja-qa/mobile-report.json`에 있습니다.

## 기존 전자책형의 확정 동작

- 관리자 `/admin/export`에서 **① 그림 학습형 / ② 기존 전자책형**을 따로 제공합니다. 기존형에는 ‘전체 목록으로’와 ‘꼭 알아야 할 10가지’ 탭이 없습니다.
- `001 · 日 — 날 일` 같은 번호 제목이 한 학습 페이지의 시작입니다. 그림·설명·예시·가리고 꺼내기를 같은 페이지로 묶습니다. 확대하거나 정답을 펼쳐도 다른 글자로 넘어가지 않으며, 긴 내용은 해당 페이지 안에서 세로로 스크롤합니다.
- 들어가며 등 일반 글은 기존 흐름형 페이지 나눔을 유지합니다. 본문 클릭은 페이지를 넘기지 않으며, 이전·다음 버튼이나 좌우 방향키로 이동합니다.
- 상단 도구는 **화면 너비와 관계없이 약 3초 뒤 숨고 화면 상단 60px 영역을 클릭·터치하면 다시 표시**됩니다. 키보드로 도구에 초점을 둔 동안은 숨기지 않습니다. 좁은 모바일 화면에서도 버튼은 한 줄입니다.
- 오른쪽 아래 ‘목차로 가기’는 고정 표시합니다. 페이지형에서는 목차 오버레이를 열고 마지막 항목에서 스크롤이 멈춥니다. 뒤쪽 본문이나 iframe 높이가 늘어나는 방식으로 이어지지 않도록 처리했습니다.
- **29개 단원의 ‘이 장을 덮기 전에’도 한 페이지**입니다. ‘단원 정답 펼치기’를 열면 같은 페이지 안에 번호·한자·훈음 목록이 나타납니다. 길면 세로로 스크롤합니다. 정답 목록을 다단 흐름형으로 배치하면 목록이 다음 칸으로 밀려 빈 상자로 보이므로 되돌리지 않습니다.
- 정답 원고는 `- **033** · 飛 · 날 비` 형식입니다. `- 33.`처럼 쓰면 Markdown이 중첩 목록으로 해석해 불필요한 들여쓰기와 간격을 만듭니다.

구현은 `public/widget/hanja-reader.js`이며 전체 본문 URL·iframe·다운로드 HTML이 같은 스크립트를 사용합니다. 웹 스크립트 수정 시 `src/lib/generate-widget.ts`, `src/app/embed/[bookId]/route.ts`, 배포 검증 스크립트의 버전을 함께 갱신합니다. 현재 참조는 `hanja-reader.js?v=5`입니다. 다른 책의 공통 `eb-script.js`는 이 책의 예외 처리로 변경하지 않습니다.

## 이미지 경계와 제작 기록

그림은 이미지 생성 도구로 16장면씩 묶어 제작했으며, 생성 당시의 정확한 모델명·버전은 저장 기록으로 확인할 수 없습니다. 사용 프롬프트는 `image-prompts.json`에 보관합니다.

생성된 묶음은 칸 간격이 완벽한 4등분이 아닙니다. 고정 400% 배경 크기와 행·열 번호만으로 표시하면 038 豕 아래에 말의 갈기가 섞이고, 042 馬의 머리가 잘리며, 121 耳 아래에 다른 인물의 머리카락이 보일 수 있습니다.

- `book.json`의 **`imageCrop`**: 원본 대비 0~1 범위의 `[왼쪽, 위, 너비, 높이]`. 453개 항목의 실제 표시 경계를 보관합니다.
- **`imageMask`**: 인접 그림의 윤곽이 맞물리는 예외에만 적용하는 CSS 표시 마스크입니다. 빈 문자열이면 마스크가 없습니다.
- `imageRow`·`imageColumn`은 기존 칸 식별 정보입니다. 실제 렌더링은 `imageCrop`의 위치·크기·종횡비를 사용합니다. 예전 `imageClipBottom` 방식은 제거했습니다.
- 그림형 `src/components/hanja/HanjaImage.tsx`와 본문 생성기 `scripts/build-hanja.mjs`가 같은 공통 값을 사용합니다. 원본을 덮어쓰거나 모든 그림의 아래쪽을 일괄 가리지 않습니다.
- `node scripts/audit-hanja-image-bounds.mjs`는 흰 여백을 분석해 **검토 후보만** 만듭니다. 투명 픽셀은 흰 배경으로 해석합니다. 후보를 원고에 자동 적용하지 않으며, 사람이 검토한 범위만 반영합니다.
- `node scripts/qa-hanja-image-bounds.mjs`로 전체 검토 화면을 만듭니다. 후보와 검토 이미지는 `artifacts/hanja-image-bounds/`에 있습니다. 실제 화면 확인에는 `artifacts/hanja-qa/corrected-image-38.png`, `corrected-image-42.png`, `corrected-image-121.png`를 참고합니다.

## 학습 앱 개선 — 2026-09-25

### 범위 학습 후속 개편 (현재 기준)

최신 목록 규칙: 골라 학습의 ‘복습할 항목’을 ‘통과한 항목’으로 교체했습니다. 평가 횟수가 있고 마지막 결과가 맞힘이면 통과한 항목, 다시 연습이면 다시 볼 항목입니다. 기한이 지난 항목은 두 목록 중 어디에 있든 오늘 학습에서 모읍니다. `CharacterPicker.tsx`의 선택창은 10분 빨강, 1일 자주, 3일 주황, 7일 노랑, 14일 연두, 30일 초록으로 stage를 표시하며 새 항목은 회색입니다. 색은 남은 시간이 아닙니다. 기한이 지나면 ‘복습 시간 됨’을 표시합니다. 훈음은 계속 숨기며 기존 기록/일정은 변경하지 않습니다. 조기 재도전에서 맞힌 stage 0 항목은 통과 목록에 있으면서 10분 색상을 유지할 수 있습니다. `qa-hanja-stages.mjs`가 분류·색상·오늘 복습·모바일 목록·Escape를 검증합니다.

**필수 유지보수 규칙:** 기능 변경 시 별도 요청 없이 학습 안내의 설명·예시·FAQ를 함께 갱신하고, 해당 화면이 달라졌다면 부분 캡처와 R2 매니페스트도 갱신합니다. 기능만 배포하고 안내를 남겨두지 않습니다. [학습 안내 유지보수 절차](../../docs/LEARNING_GUIDE_MAINTENANCE.md)와 루트 `AGENTS.md`를 따릅니다.

안내 이미지의 최신 표시 규칙: 전체 화면 캡처와 별도 ‘화면 보기’ 링크를 사용하지 않습니다. 캡처 스크립트가 해당 조작 영역의 DOM 경계만 촬영하며 실제 PNG 크기를 매니페스트에 저장합니다. 안내 항목을 펼치면 PC에서는 이미지 왼쪽·설명 오른쪽, 700px 이하에서는 이미지 위·설명 아래로 표시합니다. R2 원본을 직접 표시하며 설명용 데이터를 사용합니다. `qa-hanja-guide.mjs`는 인라인 이미지, 필터 부분 캡처 높이, 좌우/세로 배치를 검사합니다.
