# 9장: 구충제, 비타민, 영양제


![ch9-supplements](https://pub-d0d60c2fafe34c62a9d8993114fe64ca.r2.dev/ebook/otc-medicine-guide/ch9-supplements.png)

## 영양제 시장의 현실을 먼저 알고 시작합시다

한국 건강기능식품 시장은 연 6조 원을 넘었습니다. TV 광고, 유튜브, SNS에서 쏟아지는 영양제 정보는 넘쳐나지만, 과장과 진실이 뒤섞여 있습니다. 약사로서 정직하게, 과학적 근거에 기반하여 "진짜 필요한 것"과 "광고에 속지 말아야 할 것"을 구분해 드리겠습니다.

## 구충제: 아직도 먹어야 하나요?

### 한국에서 구충제가 필요한가?

과거 한국은 기생충 감염률이 매우 높았지만, 현재는 위생 환경이 크게 개선되어 감염률이 매우 낮습니다. 하지만 완전히 사라진 것은 아닙니다.

| 감염 가능 경로 | 설명 |
|-------------|------|
| 생선회(민물고기) | 간흡충(간디스토마) |
| 덜 익힌 돼지고기 | 갈고리촌충 |
| 반려동물 접촉 | 개회충, 고양이회충 |
| 해외여행 (동남아 등) | 각종 기생충 |
| 김치, 된장 등 발효식품 | 매우 드물지만 가능 |

### 알벤다졸 (구충제)

| 항목 | 내용 |
|------|------|
| 대표 제품 | 젤콤(알벤다졸 400mg) |
| 복용법 | 1회 1정(400mg), 씹어서 복용 |
| 복용 시기 | 식후 (지방 식이와 함께 흡수 증가) |
| 반복 복용 | 2주 후 1회 더 (재감염 방지) |
| 가족 동시 복용 | 가족 전원이 같은 날 복용 권장 |

### 구충제 복용 가이드

| 항목 | 권장 |
|------|------|
| 일반 성인 | 연 1~2회 (봄, 가을) — 필수는 아니지만 권장 |
| 반려동물 키우는 가정 | 연 1~2회 권장 |
| 생선회 자주 먹는 분 | 연 1~2회 권장 (특히 민물회) |
| 해외여행 후 | 귀국 후 1회 복용 고려 |
| 어린이 (2세 이상) | 의사 상담 후 복용 |
| 임산부 | 금기 (기형 유발 가능) |

**약사 코멘트:** "구충제를 반드시 먹어야 한다"는 강박은 불필요합니다. 하지만 1년에 한 번 정도 가족 모두 함께 복용하는 것은 합리적인 예방입니다. 비용도 저렴하고 부작용도 거의 없습니다.

## 비타민D: 한국인이 가장 부족한 영양소

### 비타민D 부족 현황

한국 성인의 **약 70~80%**가 비타민D 부족 상태입니다. 이것은 과장이 아니라 국민건강영양조사에서 반복적으로 확인된 사실입니다.

| 비타민D 부족 원인 | 설명 |
|-----------------|------|
| 실내 생활 | 사무실, 학교에서 하루 대부분 보냄 |
| 자외선 차단 | 선크림, 의복으로 자외선 차단 |
| 위도 | 한국(위도 33~38도)은 겨울철 비타민D 합성 어려움 |
| 식이 섭취 부족 | 비타민D 풍부한 음식이 적음 |

### 비타민D 혈중 농도 기준

| 수치 (25(OH)D) | 판정 |
|----------------|------|
| 30ng/mL 이상 | 충분 |
| 20~29ng/mL | 부족 |
| 20ng/mL 미만 | 결핍 |
| 10ng/mL 미만 | 심한 결핍 |

### 비타민D 권장 복용량

| 대상 | 일일 권장량 | 상한 섭취량 |
|------|-----------|-----------|
| 성인 (19~64세) | 800~2,000IU | 4,000IU |
| 고령자 (65세 이상) | 1,000~2,000IU | 4,000IU |
| 임산부 | 1,000~2,000IU | 4,000IU |
| 소아 (1~18세) | 600~1,000IU | 2,000~4,000IU |
| 영아 | 400IU | 1,000IU |

**비타민D3(콜레칼시페롤)을 선택하세요.** D2(에르고칼시페롤)보다 체내 이용률이 2~3배 높습니다.

**복용 팁:** 지용성이므로 식사와 함께 복용하면 흡수가 좋습니다.

### 비타민D 과량 복용 주의

비타민D는 지용성이므로 체내에 축적됩니다. 1일 10,000IU 이상을 장기간 복용하면 고칼슘혈증(구역, 구토, 신장 결석)이 발생할 수 있습니다. 권장량을 지키세요.

## 비타민B군

### 비타민B군의 역할

| 비타민 | 주요 역할 | 결핍 시 증상 |
|--------|----------|-------------|
| B1(티아민) | 탄수화물 대사 | 각기병, 피로 |
| B2(리보플라빈) | 에너지 대사 | 구각염, 구내염 |
| B3(나이아신) | 에너지 대사, 피부 | 펠라그라 |
| B5(판토텐산) | 에너지 대사 | 피로, 불면 |
| B6(피리독신) | 아미노산 대사, 신경 | 말초신경병증 |
| B7(비오틴) | 모발, 피부 | 탈모, 피부 문제 |
| B9(엽산) | 세포 분열, DNA 합성 | 빈혈, 태아 기형 |
| B12(코발라민) | 신경, 혈액 생성 | 악성빈혈, 신경 손상 |

### 비타민B군 보충이 필요한 사람

| 대상 | 이유 |
|------|------|
| 채식주의자 | B12 부족 (동물성 식품에만 존재) |
| 임산부 | 엽산(B9) 필수 (태아 신경관 결손 예방) |
| 고령자 | B12 흡수 저하 |
| 음주가 잦은 분 | B1 소모 증가 |
| 구내염 잦은 분 | B2, B6 부족 가능 |
| 만성 피로 | B군 복합 보충 고려 |

**약사 코멘트:** B군 비타민은 수용성이므로 과량 복용 시 소변으로 배출됩니다. 소변이 노랗게 변하는 것은 B2(리보플라빈) 때문이며 정상입니다. 다만 B6는 장기 고용량 복용(1일 200mg 이상) 시 말초신경병증을 유발할 수 있으니 주의하세요.

## 철분제

### 철분 부족 증상

| 증상 | 설명 |
|------|------|
| 피로, 무기력 | 가장 흔한 증상 |
| 창백한 피부, 잇몸 | 혈색소 감소 |
| 숨이 참 | 산소 운반 능력 저하 |
| 두통, 어지러움 | 뇌 산소 공급 감소 |
| 손발 차가움 | 말초 혈류 감소 |
| 얼음 씹기(이식증) | 철분 결핍의 특이 증상 |

### 철분제 종류와 선택

| 종류 | 특징 | 부작용 |
|------|------|--------|
| 황산철 | 흡수율 보통, 저렴 | 위장 장애 가장 심함 |
| 푸마르산철 | 흡수율 좋음 | 위장 장애 중간 |
| 글루콘산철 | 위장 부작용 적음 | 흡수율 보통 |
| 헴철(heme iron) | 위장 부작용 최소 | 가격 높음 |
| 비스글리시네이트철 | 위장 부작용 적음, 흡수 좋음 | 가격 높음 |

### 철분제 복용법

| 원칙 | 설명 |
|------|------|
| 공복 복용 | 흡수가 가장 좋음 (위장 불편하면 식후) |
| 비타민C와 함께 | 흡수율 2~3배 증가 |
| 카페인, 유제품 피하기 | 흡수 방해 (2시간 간격) |
| 제산제와 간격 | 위산 감소 시 흡수 저하 (2시간 간격) |
| 변 색 변화 | 검은 변은 정상 (철분 때문) |
| 변비 대처 | 마그밀 병용 가능, 취침 전 복용 |

## 오메가3

### 오메가3의 형태

| 형태 | 특징 | 흡수율 |
|------|------|--------|
| TG형(자연 형태) | 생선 기름 원래 형태 | 보통 |
| EE형(에틸에스터) | 정제 과정 중간체, 저렴 | 낮음 |
| rTG형(재에스터화) | TG로 재전환, 고순도 | 높음 |

**약사 코멘트:** rTG형이 흡수율이 가장 좋습니다. 제품을 선택할 때 EPA+DHA 함량(최소 500mg 이상/일)과 형태를 확인하세요. "오메가3 1,000mg"이라고 표시된 것은 캡슐 무게이지 EPA+DHA 함량이 아닐 수 있습니다.

### 오메가3 복용 주의

| 주의 대상 | 이유 |
|----------|------|
| 혈액 희석제 복용자 | 출혈 위험 증가 |
| 수술 2주 전 | 출혈 위험으로 중단 권장 |
| 해산물 알레르기 | 원료 확인 필요 |
| 임산부 | DHA는 권장, 비타민A 함유 제품 주의 |

## 마그네슘

### 마그네슘 부족 증상

| 증상 | 설명 |
|------|------|
| 근육 경련 (쥐) | 야간 다리 경련이 대표적 |
| 눈꺼풀 떨림 | 스트레스, 카페인과 복합 |
| 피로, 무기력 | 에너지 대사에 관여 |
| 불면, 불안 | 신경 안정에 필요 |
| 두통 | 편두통 예방 효과 연구 있음 |

### 마그네슘 형태별 차이

| 형태 | 흡수율 | 특징 |
|------|--------|------|
| 산화마그네슘 | 낮음(4%) | 변비 완화 효과, 저렴 |
| 구연산마그네슘 | 중간 | 흡수 양호, 대중적 |
| 비스글리시네이트 | 높음 | 위장 부작용 적음, 수면에 도움 |
| 트레온산마그네슘 | 높음 | 뇌 건강(인지기능) 연구 |
| 타우린산마그네슘 | 높음 | 심혈관 건강 연구 |

**약사 코멘트:** 변비 완화 목적이면 산화마그네슘, 수면이나 근육 이완 목적이면 비스글리시네이트, 전반적 보충 목적이면 구연산마그네슘을 추천합니다.

## "영양제 꼭 먹어야 하나요?"의 정직한 답

### 근거가 확실한 영양제 (대부분의 사람에게 권장)

| 영양제 | 이유 | 권장량 |
|--------|------|--------|
| 비타민D | 한국인 대부분 부족, 뼈·면역·근육 | 1,000~2,000IU/일 |
| 엽산 (임산부) | 태아 신경관 결손 예방 | 400~800mcg/일 |
| 철분 (월경 여성, 빈혈 진단) | 빈혈 치료/예방 | 검사 후 결정 |

### 조건부 권장 (해당되는 사람에게만)

| 영양제 | 대상 | 근거 |
|--------|------|------|
| 비타민B12 | 채식주의자, 고령자 | 식이 섭취 부족 |
| 오메가3 | 생선 섭취 부족한 사람 | 심혈관 건강 |
| 칼슘+비타민D | 골다공증 위험군 | 뼈 건강 |
| 마그네슘 | 근육 경련, 수면 문제 | 부족 시 보충 |
| 유산균 | 항생제 복용 시 | 설사 예방 |

### 근거가 약한 영양제 (광고에 속지 마세요)

| 영양제 | 실상 |
|--------|------|
| 콜라겐 | 먹은 콜라겐이 피부 콜라겐이 되지 않음 |
| 글루코사민 | 관절 건강 효과 논란, 대규모 연구 부정적 |
| 코엔자임Q10 | 스타틴 복용자 외에는 근거 약함 |
| 종합비타민 | 건강한 식사를 하는 사람에게는 불필요 |
| 고용량 비타민C | 감기 예방 효과 미미, 과량 시 신장 결석 |

**약사의 결론:** 영양제는 부족한 영양소를 보충하는 것이지, 건강한 식사를 대체하는 것이 아닙니다. "비싼 영양제를 많이 먹으면 더 건강해진다"는 생각을 버리세요. 정말 필요한 것 2~3가지만 적절한 용량으로 복용하는 것이 현명합니다.

혈액검사를 통해 자신에게 부족한 영양소가 무엇인지 확인하고, 그것만 보충하세요. 그것이 가장 과학적이고 경제적인 접근입니다.

## 약사가 당부하는 핵심 정리

1. **구충제는 연 1회, 가족 동시 복용, 임산부 금기**
2. **비타민D는 한국인 대부분에게 필요합니다** - 1,000~2,000IU/일
3. **철분제는 비타민C와 함께, 카페인과는 2시간 간격**
4. **오메가3는 rTG형, EPA+DHA 함량을 확인하세요**
5. **영양제는 2~3가지만 필요한 것을 선택하세요** - 다다익선이 아닙니다
6. **확실하지 않으면 혈액검사 먼저 받으세요**
