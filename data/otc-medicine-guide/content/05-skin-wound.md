# 5장: 상처, 화상, 피부 약

## 상처 치료의 패러다임이 바뀌었습니다

어릴 때 우리는 상처가 나면 빨간약(머큐로크롬)을 바르고, 딱지가 앉으면 잘 낫고 있다고 배웠습니다. 하지만 현대 상처 치료의 원칙은 완전히 달라졌습니다.

**현대 상처 치료의 핵심 원칙: 습윤 드레싱(Moist Wound Healing)**

상처는 건조하게 말리는 것이 아니라, **적절한 습도를 유지해야** 세포가 빠르게 재생됩니다. 딱지는 오히려 세포 이동을 방해하고 흉터를 남깁니다.

## 상처 치료 단계별 가이드

### 1단계: 세척

| 방법 | 권장 여부 | 이유 |
|------|----------|------|
| 흐르는 깨끗한 물 | 강력 권장 | 이물질 제거, 조직 손상 없음 |
| 생리식염수 | 권장 | 조직에 자극 없음 |
| 과산화수소(옥시풀) | 비권장 | 정상 세포도 파괴, 치유 지연 |
| 알코올(에탄올) | 비권장 | 극심한 통증, 세포 손상 |

**과산화수소(옥시풀)를 쓰지 마세요!** 과산화수소가 거품을 내며 "소독이 되고 있다"는 느낌을 주지만, 실제로는 세균뿐 아니라 상처를 치유하는 정상 세포까지 파괴합니다. 현대 상처 치료에서 과산화수소는 권장되지 않습니다.

### 2단계: 소독 (필요시)

**포비돈요오드(베타딘)**

| 항목 | 내용 |
|------|------|
| 성분 | 포비돈요오드 10% |
| 사용법 | 상처 주변에 얇게 도포 |
| 장점 | 광범위 살균, 내성 발생 적음 |
| 단점 | 착색, 갑상선 질환자 주의 |
| 주의 | 깊은 상처 내부에 넣지 않기 |

**약사 코멘트:** 소독이 필요한 경우 포비돈요오드가 가장 적합합니다. 다만 가벼운 찰과상은 깨끗한 물로 세척만 해도 충분하며, 소독제 사용이 반드시 필요한 것은 아닙니다. 소독보다 세척이 더 중요합니다.

### 3단계: 연고 도포

## 항생제 연고와 재생 연고

### 후시딘 (후시드산)

| 항목 | 내용 |
|------|------|
| 성분 | 후시드산나트륨 2% |
| 분류 | 항생제 연고 |
| 적응증 | 세균 감염 방지/치료 |
| 사용법 | 1일 2~3회 얇게 도포 |
| 사용 기간 | 최대 7~10일 |
| 주의 | 장기 사용 시 내성균 발생 |

**약사 코멘트:** 감염 위험이 있는 상처(오염된 상처, 동물에 물린 상처)에 적합합니다. 깨끗한 칼에 베인 상처 같은 경우에는 반드시 필요하지 않습니다. **항생제 연고는 예방 목적으로 장기간 사용하지 마세요.** 내성균이 발생하면 나중에 진짜 감염이 생겼을 때 약이 듣지 않게 됩니다.

### 마데카솔 (센텔라아시아티카)

| 항목 | 내용 |
|------|------|
| 성분 | 센텔라아시아티카 추출물 |
| 분류 | 상처 치유 촉진제 |
| 적응증 | 상처 치유 촉진, 흉터 예방 |
| 사용법 | 1일 1~2회 도포 |
| 사용 기간 | 상처 치유까지 |
| 종류 | 일반 마데카솔, 복합 마데카솔(항생제 포함) |

**종류별 차이:**

| 제품 | 포함 성분 | 적합한 상황 |
|------|----------|-----------|
| 마데카솔 연고 | 센텔라 추출물만 | 깨끗한 상처, 흉터 예방 |
| 복합 마데카솔 | 센텔라 + 네오마이신(항생제) | 감염 우려 상처 |
| 마데카솔 분말 | 센텔라 분말 | 진물 나는 상처 |

**약사 코멘트:** 상처가 깨끗하고 감염 우려가 없다면 일반 마데카솔이면 충분합니다. 복합 마데카솔에는 항생제(네오마이신)가 포함되어 있으므로, 감염이 의심될 때만 사용하세요.

### 베판텐 (덱스판테놀)

| 항목 | 내용 |
|------|------|
| 성분 | 덱스판테놀(프로비타민B5) 5% |
| 분류 | 보습/재생 연고 |
| 적응증 | 피부 보습, 가벼운 상처 재생, 기저귀 발진 |
| 사용법 | 1일 수회 도포 |
| 특징 | 영유아에게도 안전 |

**약사 코멘트:** 가벼운 상처, 건조한 피부, 아기 기저귀 발진에 안전하게 사용할 수 있습니다. 항생제 성분이 없으므로 감염 방지 목적으로는 부적합합니다.

### 후시딘 vs 마데카솔 vs 베판텐 선택 가이드

| 상황 | 추천 제품 | 이유 |
|------|----------|------|
| 감염 우려 상처 | 후시딘 | 항생제 효과 |
| 깨끗한 상처, 흉터 예방 | 마데카솔 | 재생 촉진 |
| 가벼운 찰과상, 건조 | 베판텐 | 보습+재생 |
| 오염된 상처 + 흉터 걱정 | 복합 마데카솔 | 항생제+재생 |
| 아기 피부 트러블 | 베판텐 | 안전성 높음 |

### 4단계: 드레싱(반창고)

## 반창고 종류와 올바른 선택

| 종류 | 대표 제품 | 적합한 상처 | 교체 주기 |
|------|----------|-----------|----------|
| 일반 반창고 | 대일밴드 | 작은 베인 상처 | 매일 |
| 습윤 밴드 | 듀오덤, 메디폼 | 찰과상, 화상 | 2~3일 |
| 방수 반창고 | 넥스케어 방수밴드 | 물 닿는 부위 | 매일 |
| 거즈+반창고 | 멸균 거즈+의료용 테이프 | 넓은 상처 | 매일~2일 |
| 지혈 반창고 | 지혈밴드 | 출혈이 있는 상처 | 지혈 후 교체 |

**습윤 밴드 사용법:**
1. 상처를 깨끗이 세척하고 주변 물기를 닦습니다
2. 연고 없이 습윤 밴드를 직접 붙입니다 (연고 위에 붙이면 접착이 안 됩니다)
3. 밴드가 하얗게 부풀어 오르는 것은 정상입니다 (삼출물 흡수)
4. 부풀어 오른 부분이 가장자리에 닿으면 교체합니다
5. 감염 징후(붉어짐 확대, 열감, 고름)가 보이면 제거하고 병원 방문

## 화상 단계별 처치법

### 화상 응급 처치 (모든 화상의 첫 단계)

**즉시 흐르는 찬 물(15~25도)에 20분 이상 식히세요.** 이것이 가장 중요한 처치입니다.

| 해야 할 것 | 하면 안 되는 것 |
|-----------|---------------|
| 흐르는 물에 20분 식히기 | 얼음 직접 대기 (동상 위험) |
| 깨끗한 천으로 덮기 | 된장, 소주, 치약 바르기 |
| 반지, 시계 빨리 빼기 (부종 전) | 물집 터뜨리기 |
| 화상 부위 높이 올리기 | 달라붙은 옷 억지로 벗기기 |

### 화상 단계별 특성과 대처

| 구분 | 1도 화상 | 2도 화상(표재성) | 2도 화상(심재성) | 3도 화상 |
|------|---------|----------------|----------------|---------|
| 깊이 | 표피만 | 표피+진피 상부 | 진피 깊이 | 전층 |
| 외관 | 빨갛게 | 물집 | 물집+하얗게 | 검거나 하얗게 |
| 통증 | 따끔 | 매우 아픔 | 보통~심함 | 신경 손상으로 덜 아픔 |
| 치유 | 3~5일 | 1~2주 | 2~3주+ | 수술 필요 |
| 처치 | 냉각+보습 | 약국 처치 가능 | 병원 필요 | 응급실 |

### 약국에서 구입할 수 있는 화상 치료제

| 제품 | 성분 | 용도 |
|------|------|------|
| 실바덴 | 설파디아진은(항균) | 감염 방지(1~2도) |
| 베판텐 | 덱스판테놀 | 1도 화상 보습/재생 |
| 메디폼(습윤 드레싱) | 폼 드레싱 | 2도 화상 드레싱 |

## 벌레 물림과 두드러기 대처

### 일반적인 벌레 물림(모기, 벌레)

| 단계 | 처치 |
|------|------|
| 즉각 | 물린 부위 깨끗이 세척 |
| 가려움 | 항히스타민 크림(쏘크 등) 또는 칼라민 로션 |
| 부기 | 냉찜질 |
| 심한 가려움 | 히드로코르티손 크림(약한 스테로이드) |

### 벌(꿀벌, 말벌)에 쏘였을 때

| 상황 | 대처 |
|------|------|
| 일반적 | 침 제거(카드로 긁어내기), 냉찜질, 항히스타민 복용 |
| 아나필락시스 의심 | 즉시 119 (호흡 곤란, 전신 두드러기, 의식 저하) |

**꿀벌 침 제거 주의:** 핀셋으로 집으면 독낭이 눌려 더 많은 독이 들어갑니다. 신용카드 등 평평한 것으로 긁어서 빼세요.

## 무좀약

### 무좀(족부백선)의 진실

무좀은 곰팡이(진균) 감염입니다. 약을 바르면 증상이 금방 좋아지지만, **균이 완전히 죽으려면 최소 4주 이상** 꾸준히 발라야 합니다.

### 약국에서 구입할 수 있는 무좀약

| 제품 | 성분 | 도포 횟수 | 특징 |
|------|------|----------|------|
| 라미실 크림 | 테르비나핀 | 1일 1~2회 | 가장 보편적, 효과 좋음 |
| 카네스텐 | 클로트리마졸 | 1일 2~3회 | 오래된 성분, 효과 검증 |
| 풀케어 | 부테나핀 | 1일 1회 | 1일 1회 편리 |
| 피나클 | 시클로피록스 | 1일 2회 | 손발톱 무좀에도 사용 |

**무좀약 사용 핵심 원칙:**
1. 증상이 사라져도 **최소 2~4주 더** 사용
2. 발가락 사이, 발바닥 전체에 넓게 도포
3. 양말과 신발도 관리 (통풍, 건조)
4. 가족 간 수건 공유 금지
5. 손발톱 무좀은 바르는 약만으로 부족할 수 있음 - 의사 상담 권장

## 약사가 당부하는 핵심 정리

1. **과산화수소(옥시풀)는 더 이상 상처에 쓰지 마세요** - 치유를 방해합니다
2. **습윤 드레싱(듀오덤 등)이 딱지보다 흉터가 적습니다**
3. **항생제 연고(후시딘)는 7~10일 이내만 사용하세요** - 내성 방지
4. **화상 시 즉시 흐르는 물에 20분, 된장/치약은 절대 금지**
5. **무좀약은 증상이 나아져도 4주 이상 계속 사용하세요**
6. **벌에 쏘인 후 호흡 곤란이 오면 즉시 119**
