## 부록 3: 약물 상호작용 위험 조합표

**이 조합들은 반드시 약사에게 확인하세요.**

### 일반의약품 간 위험 조합

| 약물 A | 약물 B | 위험 | 위험도 |
|--------|--------|------|--------|
| 타이레놀 | 종합감기약 | 아세트아미노펜 이중 복용 → 간독성 | 높음 |
| 이부프로펜 | 아스피린 | 아스피린 효과 감소 + 위출혈 | 높음 |
| 종합감기약 A | 종합감기약 B | 다수 성분 이중 복용 | 높음 |
| 코막힘 스프레이 | 감기약(슈도에페드린) | 혈관수축제 이중 → 혈압 상승 | 중간 |
| 항히스타민제 | 수면 보조제(디펜히드라민) | 과도한 진정 | 중간 |
| 제산제 | 항생제/철분제 | 흡수 방해 | 중간 |

### 일반의약품 + 전문의약품 위험 조합

| 일반의약품 | 전문의약품 | 위험 | 위험도 |
|----------|----------|------|--------|
| 이부프로펜 | 와파린(혈액 희석제) | 출혈 위험 증가 | 매우 높음 |
| 슈도에페드린(감기약) | MAOI(항우울제) | 고혈압 위기 | 매우 높음 |
| 덱스트로메토르판(기침약) | SSRI(항우울제) | 세로토닌 증후군 | 높음 |
| 슈도에페드린(감기약) | 고혈압약 | 혈압 조절 실패 | 높음 |

| 감초 함유 한약 | 이뇨제 | 저칼륨혈증 | 높음 |

## 부록 5: 어린이 약 용량표

### 아세트아미노펜 좌약 (세토펜) 체중별 가이드

구토가 심해서 시럽을 먹일 수 없을 때 사용합니다.

| 체중(kg) | 좌약 용량 | 간격 | 비고 |
|----------|---------|------|------|
| 5~8 | 100mg 좌약 1개 | 4~6시간 | 생후 3개월 이상 |
| 8~12 | 100mg 좌약 1개 | 4~6시간 | |
| 12~17 | 200mg 좌약 1개 | 4~6시간 | |
| 17~25 | 200mg 좌약 1개 | 4~6시간 | 또는 시럽 |
| 25~37 | 200mg 좌약 1~2개 | 4~6시간 | 시럽 가능하면 시럽 |

**좌약 사용법:**
1. 냉장고에서 꺼내 포장 벗기기
2. 좌약 끝에 바셀린이나 물을 살짝 묻히기
3. 아이를 옆으로 눕힌 후 뾰족한 쪽을 항문에 부드럽게 삽입
4. 1~2분간 엉덩이를 가볍게 모아주기 (빠지지 않게)
5. 삽입 후 바로 나오면 다시 넣기, 10분 후 나오면 추가 투여 않기

### 어린이 약 복용 시 절대 하면 안 되는 것

| 금지 사항 | 이유 |
|----------|------|
| 성인 약을 쪼개서 주기 | 정확한 용량 조절 불가, 서방정은 위험 |
| 숟가락으로 시럽 계량 | 부정확 (계량 주사기 사용) |
| "한 번 더 주면 빨리 낫겠지" | 과량 투여 위험 |
| 꿀에 섞어 주기 (1세 미만) | 보툴리누스 중독 위험 |
| 다른 아이 약 빌려 먹기 | 체중, 알레르기 다름 |
