# 10장: 상비약 보관, 폐기, 응급 대처


![ch10-storage](https://pub-d0d60c2fafe34c62a9d8993114fe64ca.r2.dev/ebook/otc-medicine-guide/ch10-storage.png)

## 약을 사는 것만큼 보관하는 것도 중요합니다

아무리 좋은 약이라도 잘못 보관하면 효과가 떨어지거나 오히려 해로울 수 있습니다. 약의 보관, 유효기간 관리, 폐기 방법, 그리고 응급 상황 대처까지. 이 챕터는 모든 가정에서 반드시 알아야 할 내용입니다.

## 약의 올바른 보관법

### 보관의 3대 적: 온도, 습도, 빛

| 요인 | 영향 | 대처 |
|------|------|------|
| 고온 | 약물 분해 가속, 변질 | 서늘한 곳(15~25도) 보관 |
| 습도 | 정제 붕괴, 곰팡이 | 밀폐 용기, 제습 |
| 직사광선 | 약물 분해, 변색 | 어두운 곳, 갈색 병 |

### 장소별 보관 적합성

| 장소 | 적합 여부 | 이유 |
|------|----------|------|
| 서랍장 (거실/침실) | 적합 | 서늘, 어둡고, 건조 |
| 화장실 | 부적합 | 습도 높음, 온도 변화 |
| 주방 (가스레인지 근처) | 부적합 | 고온, 습기 |
| 차량 내부 | 매우 부적합 | 여름 60도 이상 |
| 냉장고 | 일부만 적합 | 지시된 약만 냉장 보관 |

### 냉장 보관이 필요한 약

| 약 | 냉장 이유 |
|----|----------|
| 일부 안약 (개봉 후) | 방부제 없는 제품 변질 방지 |
| 좌약 | 체온에서 녹으므로 냉장 필수 |
| 일부 시럽제 (개봉 후) | 변질 방지 |
| 유산균 | 생균 유지 (냉장 보관형) |

**주의:** "냉장 보관"과 "냉동 보관"은 다릅니다. 약을 절대 냉동하지 마세요. 동결-해동 과정에서 약물 구조가 파괴됩니다.

### PTP 포장(알약 낱개 포장)에서 꺼내지 마세요

알약을 미리 꺼내서 약통에 모아두는 분이 계십니다. 이는 좋지 않습니다.

| 문제 | 설명 |
|------|------|
| 습기 노출 | PTP 포장이 습기를 차단 |
| 약물 혼동 | 어떤 약인지 구별 어려움 |
| 유효기간 불명 | 포장에서 분리하면 유효기간 확인 불가 |
| 오염 | 손으로 만져서 오염 가능 |

## 유효기간과 개봉 후 사용기한

### 유효기간의 의미

유효기간은 **밀봉 상태에서** 약효와 안전성이 보장되는 기간입니다. 개봉하면 이 기간이 대폭 단축됩니다.

### 개봉 후 사용기한

| 약 형태 | 미개봉 유효기간 | 개봉 후 사용기한 |
|---------|-------------|----------------|
| 정제/캡슐 (PTP) | 표시 기한 | 표시 기한까지 (포장 유지 시) |
| 시럽제 | 표시 기한 | 개봉 후 1~3개월 |
| 안약 (방부제 포함) | 표시 기한 | 개봉 후 1개월 |
| 안약 (1회용) | 표시 기한 | 개봉 당일 |
| 연고/크림 | 표시 기한 | 개봉 후 6개월~1년 |
| 좌약 | 표시 기한 | 개봉 후 즉시 사용 |
| 가루약 (조제) | - | 조제 후 30일 |

### 변질된 약의 징후

| 형태 | 변질 징후 |
|------|----------|
| 정제 | 변색, 부서짐, 이상한 냄새, 표면 얼룩 |
| 캡슐 | 부풀어오름, 변색, 끈적임 |
| 시럽 | 색 변화, 침전물, 이상한 냄새, 혼탁 |
| 연고 | 분리(기름+수분), 변색, 악취 |
| 안약 | 혼탁, 부유물, 변색 |

**원칙:** 의심되면 버리세요. 아까워도 변질된 약을 복용하는 것이 더 위험합니다.

## 폐의약품 올바른 처리법

약을 일반 쓰레기통이나 변기에 버리면 환경을 오염시킵니다. 수질 오염과 항생제 내성 문제를 일으킬 수 있습니다.

### 폐의약품 수거 방법

| 방법 | 설명 |
|------|------|
| 약국 반납 (가장 권장) | 가까운 약국의 폐의약품 수거함에 투입 |
| 보건소 반납 | 지역 보건소 수거함 |
| 주민센터 | 일부 주민센터 수거 가능 |

### 반납 시 주의

| 주의사항 | 설명 |
|---------|------|
| PTP 포장째 반납 | 알약은 포장째 |
| 시럽은 병째 | 내용물만 따르지 말 것 |
| 마약류/항정신성 | 별도 관리 (약국 상담) |
| 주사기/주사침 | 안전 용기에 넣어 반납 |

## 어린이 약 사고 예방

어린이 약물 사고는 가정에서 가장 흔하게 발생하는 응급 상황 중 하나입니다.

### 예방 원칙

| 원칙 | 구체적 방법 |
|------|-----------|
| 높은 곳에 보관 | 어린이 손이 닿지 않는 120cm 이상 높이 |
| 잠금 장치 | 약 보관함에 잠금 장치 설치 |
| 아이 앞에서 복용 자제 | 아이가 사탕으로 오인할 수 있음 |
| 약이라고 설명 | "사탕"이라고 말하지 않기 |
| 어린이 안전 포장 확인 | Child-resistant 포장 선택 |
| 조부모 집 점검 | 할머니/할아버지 약도 관리 |

### 어린이가 약을 삼켰을 때

| 단계 | 행동 |
|------|------|
| 1 | 당황하지 말고 약 이름과 추정 복용량 확인 |
| 2 | 아이 상태 관찰 (의식, 호흡, 증상) |
| 3 | 119 또는 독성정보센터(1899-8119)에 전화 |
| 4 | 남은 약, 포장지를 가지고 병원 방문 |

**절대 하지 말아야 할 것:**
- 임의로 구토 유발하지 말 것 (일부 약물은 구토 시 더 위험)
- 우유나 물을 억지로 먹이지 말 것 (의료진 지시 전)

## 응급 상황별 대처법

### 과량 복용 (성인)

| 약물 | 위험 증상 | 즉시 해야 할 것 |
|------|----------|---------------|
| 아세트아미노펜 | 초기 무증상 → 24~48시간 후 간부전 | 119, 복용량 알려주기 |
| NSAIDs | 위출혈, 신부전 | 119, 검은 변/피 토하면 응급 |
| 수면제/안정제 | 의식 저하, 호흡 느려짐 | 119, 기도 확보 |
| 감기약 과량 | 심박수 증가, 흥분, 경련 | 119 |

**아세트아미노펜 과량 복용의 함정:** 처음에는 아무 증상이 없습니다. "괜찮네"라고 안심하면 안 됩니다. 24~72시간 후에 간 손상이 나타나며, 이때는 이미 치료가 어려울 수 있습니다. 과량 복용이 의심되면 증상이 없더라도 즉시 응급실에 가세요.

### 아나필락시스(중증 알레르기 반응)

약물, 음식, 벌 쏘임 등으로 발생할 수 있는 생명 위협 상황입니다.

| 증상 | 설명 |
|------|------|
| 전신 두드러기 | 급속히 퍼지는 발진 |
| 얼굴/목 부종 | 입술, 혀, 목이 부어오름 |
| 호흡 곤란 | 쌕쌕거림, 숨쉬기 어려움 |
| 혈압 저하 | 어지러움, 의식 소실 |
| 복통, 구토 | 동반 가능 |

**대처법:**
1. 즉시 119 전화
2. 에피네프린 자가주사기가 있다면 사용 (허벅지 바깥쪽)
3. 환자를 눕히고 다리를 높이기 (호흡 곤란 시 앉히기)
4. 의식이 있으면 항히스타민제 복용

### 열성경련 (어린이)

| 단계 | 행동 |
|------|------|
| 1 | 아이를 바닥에 눕히기 (떨어질 위험 제거) |
| 2 | 고개를 옆으로 돌리기 (구토물 흡인 방지) |
| 3 | 주변 위험한 물건 치우기 |
| 4 | 시간 재기 (5분 이상이면 119) |
| 5 | 경련 후 의식 확인 |

**절대 하면 안 되는 것:**
- 아이 입에 수저 등을 넣지 말 것 (혀를 깨무는 것보다 이빨 부러짐이 더 위험)
- 억지로 붙잡지 말 것
- 경련 중에 약이나 물을 먹이지 말 것

## 약국에서 상담받는 방법

약국을 더 효과적으로 이용하는 방법입니다.

### 약사에게 이것만은 꼭 알려주세요

| 정보 | 이유 |
|------|------|
| 현재 복용 중인 약 | 상호작용 확인 |
| 알레르기 이력 | 같은 계열 약 회피 |
| 임신/수유 여부 | 금기 약물 확인 |
| 기저질환 | 고혈압, 당뇨, 간/신장 질환 |
| 연령 | 용량 조절 |
| 이전 부작용 경험 | 같은 문제 방지 |

### 약국에서 물어봐야 할 것

| 질문 | 이유 |
|------|------|
| "이 약 어떻게 먹나요?" | 식전/식후, 복용 간격 |
| "다른 약이랑 같이 먹어도 되나요?" | 상호작용 |
| "얼마나 오래 먹어야 하나요?" | 적정 복용 기간 |
| "어떤 부작용이 있나요?" | 예상 부작용 대비 |
| "이 증상이면 병원에 가야 하나요?" | 자가 치료 한계 판단 |

## 119에 전화해야 할 때

### 지체 없이 119에 전화해야 하는 상황

| 상황 | 이유 |
|------|------|
| 의식 소실 | 심각한 상태 |
| 호흡 곤란 | 기도 확보 필요 |
| 심한 가슴 통증 | 심근경색 의심 |
| 갑작스런 편마비/언어장애 | 뇌졸중 의심 |
| 대량 출혈 | 지혈 필요 |
| 심한 알레르기(아나필락시스) | 에피네프린 필요 |
| 약물 과량 복용 | 해독제 필요 가능 |
| 고열 + 경련 | 즉각 조치 필요 |
| 심한 화상 (넓은 범위, 3도) | 전문 치료 필요 |

### 119 전화 시 알려야 할 정보

| 정보 | 내용 |
|------|------|
| 위치 | 정확한 주소 |
| 환자 상태 | 의식, 호흡, 출혈 여부 |
| 발생 시간 | 언제부터 증상이 시작되었는지 |
| 복용 약물 | 어떤 약을 얼마나 먹었는지 |
| 연령, 성별 | 기본 정보 |
| 기저 질환 | 알고 있는 질환 |

## 약사가 당부하는 핵심 정리

1. **약은 화장실이 아닌 서늘하고 어두운 곳에 보관하세요**
2. **개봉한 안약은 1개월, 시럽은 1~3개월이 한도입니다**
3. **유효기간 지난 약은 약국 폐의약품 수거함에 반납하세요**
4. **어린이 손 닿지 않는 곳에 약을 보관하세요** - 잠금장치 권장
5. **아세트아미노펜 과량 복용은 증상이 없어도 응급실에 가세요**
6. **119 전화를 망설이지 마세요** - 의심되면 전화하는 것이 맞습니다
