# 7장: 변비, 설사, 장 건강


![ch7-gut-health](https://pub-d0d60c2fafe34c62a9d8993114fe64ca.r2.dev/ebook/otc-medicine-guide/ch7-gut-health.png)

## 장 건강이 전신 건강의 열쇠입니다

장은 단순한 소화 기관이 아닙니다. 면역세포의 70%가 장에 존재하고, 세로토닌(행복 호르몬)의 90%가 장에서 만들어집니다. "제2의 뇌"라고 불리는 이유입니다. 장이 건강해야 면역도, 기분도, 피부도 좋아집니다.

하지만 현대인의 장은 고통받고 있습니다. 불규칙한 식사, 스트레스, 가공식품, 운동 부족. 변비와 설사는 가장 흔한 장 문제이며, 올바른 대처법을 알면 삶의 질이 크게 달라집니다.

## 변비: 원인부터 이해해야 약을 제대로 씁니다

### 변비의 정의

의학적으로 변비는 다음 중 2가지 이상에 해당할 때 진단합니다.

| 기준 | 내용 |
|------|------|
| 배변 횟수 | 주 3회 미만 |
| 변의 형태 | 딱딱하고 건조한 변 |
| 배변 시 힘주기 | 전체 배변의 25% 이상에서 과도한 힘주기 |
| 불완전 배출감 | 배변 후에도 남은 느낌 |
| 항문 폐색감 | 변이 막혀 있는 느낌 |

**중요:** "매일 안 나오면 변비"가 아닙니다. 이틀에 한 번이라도 편안하게 배변한다면 정상입니다.

### 변비의 주요 원인

| 원인 | 설명 |
|------|------|
| 식이섬유 부족 | 가공식품 위주 식사 |
| 수분 섭취 부족 | 하루 1.5L 미만 |
| 운동 부족 | 장 운동 저하 |
| 변의 무시 | 바빠서 참는 습관 |
| 약물 부작용 | 철분제, 칼슘제, 진통제(코데인) |
| 스트레스 | 자율신경 교란 |
| 갑상선 기능 저하 | 대사 저하로 장 운동 감소 |

## 변비약의 종류: 종류별 차이를 반드시 알아야 합니다

### 변비약 종류별 비교

| 종류 | 작용 원리 | 대표 제품 | 효과 발현 | 장기 사용 |
|------|----------|----------|----------|----------|
| 삼투성 하제 | 장에 수분 끌어들임 | 마그밀, 듀파락 | 6~12시간 | 비교적 안전 |
| 자극성 하제 | 장벽 자극하여 운동 촉진 | 둘코락스, 비코그린 | 6~12시간 | 주의 필요 |
| 팽창성 하제 | 수분 흡수하여 변 부피 증가 | 무타실, 실리움 | 1~3일 | 안전 |
| 대변 연화제 | 변에 수분 침투 | 도큐세이트 | 1~3일 | 비교적 안전 |
| 관장제 | 직장에 직접 작용 | 그린관장 | 5~30분 | 비상용만 |

### 둘코락스 (비사코딜)

| 항목 | 내용 |
|------|------|
| 성분 | 비사코딜 5mg |
| 종류 | 자극성 하제 |
| 복용법 | 취침 전 1~2정 |
| 효과 발현 | 6~12시간 (아침에 배변) |
| 좌약(항문 삽입) | 15~60분 |

**주의사항:**
- 습관성이 있습니다. 장기 복용하면 장이 약에 의존하게 되어 자연 배변이 더 어려워집니다.
- 2주 이상 연속 사용하지 마세요
- 복통, 설사가 생길 수 있음
- 장 경련을 유발할 수 있으므로 과민성 장 증후군 환자는 주의

### 마그밀 (산화마그네슘)

| 항목 | 내용 |
|------|------|
| 성분 | 산화마그네슘 250~500mg |
| 종류 | 삼투성 하제 |
| 복용법 | 취침 전 2~4정 (250mg 기준) |
| 효과 발현 | 6~12시간 |
| 작용 원리 | 장으로 수분을 끌어들여 변을 부드럽게 |

**약사 코멘트:** 자극성 하제보다 안전하여 비교적 장기 사용이 가능합니다. 하지만 신장 기능이 저하된 분(고령자 포함)은 마그네슘이 축적될 수 있으므로 주의가 필요합니다. 충분한 물(200mL 이상)과 함께 복용하세요.

### 듀파락 (락툴로스)

| 항목 | 내용 |
|------|------|
| 성분 | 락툴로스 시럽 |
| 종류 | 삼투성 하제 |
| 복용법 | 1일 1~2회, 15~30mL |
| 효과 발현 | 1~2일 |
| 특징 | 임산부, 소아에게도 안전 |

**약사 코멘트:** 임산부 변비에 가장 먼저 권하는 약입니다. 장내 유익균의 먹이가 되므로 장 건강에도 도움이 됩니다. 처음에 가스가 찰 수 있지만 며칠 지나면 적응됩니다.

### 변비약 선택 가이드

| 상황 | 추천 약 | 이유 |
|------|---------|------|
| 가끔 변비 | 마그밀 | 안전, 효과적 |
| 임산부 변비 | 듀파락 | 안전성 검증 |
| 급한 변비 | 둘코락스 좌약 | 빠른 효과 (15~60분) |
| 만성 변비 | 팽창성 하제(실리움) + 생활습관 | 가장 자연스러움 |
| 여행 중 변비 | 둘코락스 정 | 휴대 편리 |
| 약물 유발 변비 | 마그밀 | 원인 약물 상담도 필요 |

### 변비약 장기 복용의 문제

| 약 종류 | 장기 복용 위험 |
|---------|--------------|
| 자극성 하제(둘코락스) | 장 신경 손상, 의존성, 전해질 불균형 |
| 삼투성 하제(마그밀) | 신장 질환자 마그네슘 축적 |
| 팽창성 하제(실리움) | 비교적 안전, 수분 섭취 필수 |
| 관장제 | 직장 손상, 전해질 불균형 |

## 설사: 멈추는 것만이 능사가 아닙니다

### 설사의 원인 구별

| 원인 | 특징 | 대처 |
|------|------|------|
| 바이러스(노로, 로타) | 수양성 설사, 구토, 미열 | 수분 보충, 경과 관찰 |
| 세균(식중독) | 혈변, 고열, 심한 복통 | 병원 방문 필요 |
| 스트레스(과민성 장) | 긴장 시 악화, 만성 | 생활습관 + 약물 |
| 약물 부작용 | 항생제 복용 후 | 유산균 보충 |
| 유당불내증 | 유제품 후 설사 | 유당분해효소, 유제품 회피 |

### 급성 설사 대처법

**가장 중요한 것은 수분과 전해질 보충입니다.** 설사 자체보다 탈수가 더 위험합니다.

| 수분 보충 방법 | 적합성 |
|--------------|--------|
| 경구수액(ORS) | 가장 적합 |
| 보리차 + 소금 약간 | 차선책 |
| 이온음료(포카리스웨트) | 가능 (당분 많지만) |
| 탄산음료, 과일주스 | 부적합 (설사 악화) |
| 커피 | 부적합 (이뇨 + 장 자극) |

### 스멕타 (디옥타헤드랄 스멕타이트)

| 항목 | 내용 |
|------|------|
| 성분 | 디옥타헤드랄 스멕타이트 3g |
| 작용 | 장 점막 보호, 독소 흡착 |
| 복용법 | 1일 3포, 물에 타서 |
| 특징 | 영유아에게도 안전 |

**약사 코멘트:** 급성 설사에 안전하고 효과적입니다. 장의 운동을 억제하는 것이 아니라 장 점막을 보호하고 독소를 흡착하는 방식이므로 안전합니다. 다만 다른 약과 2시간 간격을 두세요(흡수 방해 가능).

### 정로환

앞 챕터에서도 다루었지만, 설사에 대한 효과를 보충합니다.

| 항목 | 내용 |
|------|------|
| 성분 | 목크레오소트, 황백, 감초 |
| 작용 | 장내 살균, 수분 흡수 촉진 |
| 복용법 | 1회 3~4알, 1일 3회 |
| 적합한 상황 | 급성 설사, 여행자 설사, 가벼운 식중독 증상 |

## 유산균(프로바이오틱스): "진짜 효과가 있나요?"

이 질문에 대한 정직한 답변입니다.

### 유산균의 과학적 근거

| 효과 | 근거 수준 | 설명 |
|------|----------|------|
| 항생제 관련 설사 예방 | 강함 | 가장 확실한 효과 |
| 급성 감염성 설사 기간 단축 | 중간~강함 | 소아에서 특히 효과적 |
| 과민성 장 증후군 증상 개선 | 중간 | 균주에 따라 다름 |
| 면역력 향상 | 약함~중간 | 일부 균주에서 효과 |
| 아토피 예방 | 약함~중간 | 임산부/영아 복용 시 일부 효과 |
| 체중 감량 | 약함 | 과장된 광고 많음 |
| 우울증 개선 | 연구 초기 | 아직 결론 내기 어려움 |

### 유산균 선택 가이드

| 선택 기준 | 권장 |
|----------|------|
| 균주 수 | 다다익선이 아님, 검증된 균주 1~2종이면 충분 |
| 함량 | 최소 100억 CFU 이상 |
| 보장 균수 | "제조 시"가 아닌 "유통기한까지" 보장 확인 |
| 보관 | 냉장 보관 제품이 생존율 높음 |
| 코팅 | 장용 코팅(위산에서 보호)되어야 장까지 도달 |

### 검증된 유산균 균주

| 균주 | 주요 효과 |
|------|----------|
| Lactobacillus rhamnosus GG (LGG) | 설사 예방, 소아 장 건강 |
| Lactobacillus reuteri | 영유아 산통, 설사 |
| Saccharomyces boulardii | 항생제 관련 설사 |
| Bifidobacterium lactis | 변비 개선, 면역 |
| Lactobacillus acidophilus | 일반 장 건강 |

**약사의 정직한 조언:** 유산균은 약이 아니라 보조 수단입니다. 식이섬유가 풍부한 식사, 충분한 수분, 규칙적인 운동이 장 건강의 기본이며, 유산균은 이를 보완하는 역할입니다. "유산균만 먹으면 장이 건강해진다"는 기대는 버리세요.

## 과민성 장 증후군(IBS)

변비와 설사가 번갈아 나타나거나, 스트레스를 받으면 배가 아픈 분들은 과민성 장 증후군일 수 있습니다.

| 특징 | 설명 |
|------|------|
| 복통 | 배변 후 호전 |
| 배변 습관 변화 | 설사형, 변비형, 혼합형 |
| 가스, 복부 팽만 | 흔함 |
| 검사 정상 | 내시경, 혈액검사 이상 없음 |
| 스트레스 관련 | 긴장 시 악화 |

**약국에서 도움받을 수 있는 것:**
- 유산균 (일부 균주 효과 있음)
- 식이섬유 보충제
- 페퍼민트 오일 (장 경련 완화)
- 심한 경우 의사 진료 필요

## 약사가 당부하는 핵심 정리

1. **변비약은 종류를 알고 선택하세요** - 자극성 하제(둘코락스)는 단기, 삼투성 하제(마그밀)가 더 안전
2. **자극성 하제는 2주 이상 사용하지 마세요** - 장이 약에 의존합니다
3. **설사 시 가장 중요한 것은 수분 보충입니다** - 지사제보다 물이 먼저
4. **유산균은 만능이 아닙니다** - 식이섬유 + 수분 + 운동이 기본
5. **혈변, 체중 감소, 야간 설사는 반드시 병원에 가세요** - 단순 장 문제가 아닐 수 있습니다
