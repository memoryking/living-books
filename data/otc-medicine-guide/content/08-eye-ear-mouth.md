# 8장: 눈, 귀, 입 약

![ch8-eye-ear-mouth](https://pub-d0d60c2fafe34c62a9d8993114fe64ca.r2.dev/ebook/otc-medicine-guide/ch8-eye-ear-mouth.png)

## 눈, 귀, 입은 매일 사용하지만 관리는 소홀합니다

스마트폰 시대에 눈 건강은 심각한 위협을 받고 있습니다. 구내염은 피로의 바로미터이며, 귀 관리는 잘못된 습관이 너무나 흔합니다. 이 챕터에서는 약국에서 쉽게 구할 수 있는 눈, 귀, 입 관련 약의 올바른 사용법을 알려드리겠습니다.

## 인공눈물: 종류가 이렇게 많은 이유

### 인공눈물이 필요한 이유

안구건조증은 현대인의 고질병입니다. 원인은 다양합니다.

| 원인 | 설명 |
|------|------|
| 스마트폰/컴퓨터 | 눈 깜빡임 횟수 감소 (정상 15회/분 → 5회/분) |
| 에어컨/난방 | 실내 습도 저하 |
| 콘택트렌즈 | 눈물막 불안정 |
| 노화 | 눈물 분비 자체 감소 |
| 약물 | 항히스타민제, 항우울제, 이뇨제 |
| 질환 | 쇼그렌 증후군, 갑상선 질환 |

### 인공눈물 성분별 비교

| 성분 | 특징 | 대표 제품 | 적합한 사람 |
|------|------|----------|-----------|
| 히알루론산 | 보습력 우수, 점안감 좋음 | 히알루론점안액 | 일반 안구건조증 |
| 카르복시메틸셀룰로오스(CMC) | 오래 사용된 성분, 안전 | 리프레쉬 | 가벼운 건조증 |
| 히프로멜로스(HPMC) | 점도 높음, 오래 지속 | - | 심한 건조증 |
| 폴리에틸렌글리콜(PEG) | 부드러운 점안감 | 시스테인 | 렌즈 사용자 |
| 트레할로스 | 세포 보호 효과 | 씨클리어 | 환경 자극 많은 경우 |

### 방부제 유무의 차이

| 구분 | 방부제 포함 (다회용) | 방부제 무함유 (1회용) |
|------|-------------------|---------------------|
| 형태 | 병 타입 | 낱개 포장 (미니 앰플) |
| 사용 기간 | 개봉 후 1개월 | 개봉 즉시 (당일 사용) |
| 가격 | 저렴 | 비싼 편 |
| 안전성 | 방부제 자극 가능 | 자극 없음 |
| 렌즈 위 사용 | 불가 | 가능 (히알루론산) |
| 권장 대상 | 가끔 사용 | 하루 4회 이상 사용 시 |

**약사 코멘트:** 인공눈물을 하루 4회 이상 사용한다면 반드시 방부제 무함유(1회용) 제품을 사용하세요. 방부제(벤잘코늄클로라이드)가 각막 상피세포를 손상시킬 수 있습니다.

### 인공눈물 올바른 사용법

| 단계 | 방법 |
|------|------|
| 1 | 손을 깨끗이 씻기 |
| 2 | 고개를 뒤로 젖히거나 살짝 올려다보기 |
| 3 | 아래 눈꺼풀을 살짝 당기기 |
| 4 | 결막낭(아래 눈꺼풀 안쪽)에 1~2방울 점안 |
| 5 | 눈을 감고 1~2분 유지 (깜빡이지 않기) |
| 6 | 눈 안쪽 코 쪽 부위(누점)를 가볍게 누르기 |

**주의사항:**
- 용기 끝이 눈이나 손에 닿지 않게 하세요 (오염 방지)
- 2종류 이상의 안약을 사용할 때는 5분 이상 간격을 두세요
- 1회용 인공눈물은 개봉 후 당일 사용이 원칙입니다

## 충혈 제거 안약: 남용하면 안 됩니다

### 충혈 제거 안약의 작용

나프졸린, 테트라히드로졸린 등의 혈관수축제가 들어 있어 눈의 혈관을 수축시켜 빨간 눈을 하얗게 만듭니다.

**대표 제품:** 비지네(나프졸린), 아이봉(테트라히드로졸린)

### 충혈 제거 안약의 문제점

| 문제 | 설명 |
|------|------|
| 반동 충혈 | 약효가 떨어지면 원래보다 더 충혈 |
| 의존성 | 점점 더 자주 넣게 됨 |
| 근본 해결 불가 | 충혈 원인은 치료하지 않음 |
| 안압 상승 | 녹내장 위험 |

**약사의 강한 권고:** 충혈 제거 안약은 정말 필요한 경우(중요한 미팅 등)에만 일시적으로 사용하세요. 습관적으로 사용하면 눈 건강을 해칩니다. 충혈의 원인(안구건조, 알레르기, 감염)을 찾아 치료하는 것이 옳습니다.

### 눈이 충혈되었을 때 판단 가이드

| 증상 | 가능한 원인 | 대처 |
|------|-----------|------|
| 충혈 + 가려움 | 알레르기 결막염 | 항히스타민 안약, 냉찜질 |
| 충혈 + 끈적한 눈곱 | 세균 결막염 | 안과 진료(항생제 안약 필요) |
| 충혈 + 통증 + 시력 저하 | 각막염, 포도막염 | 즉시 안과 방문 |
| 충혈 + 건조감 | 안구건조증 | 인공눈물 |
| 한쪽 눈 전체 빨간색 | 결막하 출혈 | 보통 자연 흡수 (1~2주) |

## 가글(구강 세정제)

### 가글의 종류와 효과

| 제품 | 주요 성분 | 주요 효과 | 주의사항 |
|------|----------|----------|---------|
| 리스테린 | 에센셜 오일(티몰, 유칼립톨) | 치태 억제, 치은염 예방 | 알코올 함유 제품은 구강 건조 |
| 가그린 | 세틸피리디늄(CPC) | 항균, 구취 제거 | 비교적 순함 |
| 클로르헥시딘 가글 | 클로르헥시딘 | 강력 항균, 수술 후 관리 | 착색, 미각 변화 (장기 사용 시) |
| 포비돈요오드 가글 | 포비돈요오드 | 인후통, 감기 예방 | 갑상선 질환자 주의 |
| 탄툼 가글 | 벤지다민 | 인후통, 구강 통증 완화 | 소염 효과 |

### 가글 올바른 사용법

| 단계 | 방법 |
|------|------|
| 1 | 양치질 후 30분 이상 지나서 사용 (치약 성분과 상충 방지) |
| 2 | 적정량(10~20mL)을 입에 머금기 |
| 3 | 30초~1분간 가글 (뱉기, 삼키지 않기) |
| 4 | 사용 후 30분간 음식, 음료 피하기 |

**약사 코멘트:** 가글은 양치질을 대체할 수 없습니다. 칫솔질과 치실 사용이 기본이고, 가글은 보조 수단입니다. 알코올이 포함된 가글은 구강 건조를 유발할 수 있으므로 안구건조증처럼 입이 마른 분은 무알코올 제품을 선택하세요.

## 구내염 약

### 구내염이 생기는 이유

| 원인 | 설명 |
|------|------|
| 피로, 스트레스 | 가장 흔한 원인 |
| 비타민 B 결핍 | B2, B12 부족 |
| 철분 결핍 | 빈혈과 동반 |
| 면역력 저하 | 감기, 수면 부족 |
| 기계적 자극 | 교정 장치, 입안 상처 |
| 호르몬 변화 | 생리 전, 폐경기 |

### 약국에서 구입할 수 있는 구내염 약

| 제품 | 성분 | 형태 | 사용법 | 특징 |
|------|------|------|--------|------|
| 오라메디 | 트리암시놀론(스테로이드) | 연고 | 환부에 얇게 도포 | 가장 보편적, 효과 좋음 |
| 알보칠 | 폴리크레줄렌 | 액체 | 면봉으로 찍어 바름 | 매우 따가움, 즉각 효과 |
| 페리덱스 | 클로르헥시딘 | 가글 | 30초 가글 | 2차 감염 예방 |
| 아프니벤큐 | 벤지다민 | 스프레이 | 환부에 분사 | 통증 완화 빠름 |
| 구내염 패치 | 트리암시놀론 | 패치 | 환부에 부착 | 보호+약물 전달 |

### 오라메디 vs 알보칠

| 비교 | 오라메디 | 알보칠 |
|------|---------|--------|
| 통증 | 바를 때 약간 불편 | 바를 때 매우 따가움 |
| 작용 | 항염증(스테로이드) | 조직 응고(소작 효과) |
| 효과 발현 | 1~2일 후 개선 | 즉각적(단, 통증도 즉각적) |
| 사용법 | 식후, 취침 전 도포 | 면봉으로 살짝 찍어 바름 |
| 주의 | 7일 이상 사용 시 구강 칸디다증 가능 | 정상 조직에 닿지 않게 |

**약사 코멘트:** 알보칠은 효과가 빠르지만 정말 아픕니다. 통증에 민감한 분은 오라메디가 나을 수 있습니다. 구내염이 2주 이상 낫지 않으면 반드시 치과나 이비인후과를 방문하세요. 드물지만 구강암의 초기 증상일 수 있습니다.

### 구내염 예방법

| 방법 | 설명 |
|------|------|
| 비타민B 보충 | B2, B6, B12 복합제 |
| 충분한 수면 | 7~8시간 |
| 스트레스 관리 | 규칙적 운동, 휴식 |
| 구강 위생 | 부드러운 칫솔 사용, 자극적인 치약 피하기 |
| SLS-free 치약 | 소듐라우릴설페이트(SLS) 없는 치약이 구내염 재발 감소 |

## 귀 관리

### 면봉으로 귀를 파면 안 됩니다

이것은 약사만이 아니라 이비인후과 의사 모두가 강조하는 내용입니다.

| 하면 안 되는 것 | 이유 |
|---------------|------|
| 면봉으로 귀 안쪽 파기 | 귀지를 더 안으로 밀어넣음, 고막 손상 위험 |
| 귀이개로 깊이 파기 | 외이도 피부 손상, 감염 위험 |
| 촛불 귀 세정 | 효과 없음, 화상 위험 |

**귀지의 진실:** 귀지는 제거해야 할 "더러운 것"이 아닙니다. 귀지는 외이도를 보호하고 항균 작용을 합니다. 귀는 자정 작용이 있어 귀지가 자연스럽게 밖으로 밀려 나옵니다.

### 귀 세정이 필요한 경우

귀가 막힌 느낌이 들거나, 청력이 감소한 느낌이 든다면 귀지 막힘(cerumen impaction)일 수 있습니다.

| 방법 | 적합성 |
|------|--------|
| 이비인후과 방문 (가장 권장) | 가장 안전 |
| 약국 귀 세정 용액 | 가벼운 경우 |
| 미지근한 물 관류 (주사기) | 주의 필요 |

### 약국에서 구입할 수 있는 귀 관련 제품

| 제품 | 용도 | 사용법 |
|------|------|--------|
| 귀지 연화제 | 딱딱한 귀지 부드럽게 | 수일간 점적 후 자연 배출 |
| 수영 후 이어드라이 | 외이도 습기 제거 | 수영/샤워 후 점적 |

## 약사가 당부하는 핵심 정리

1. **인공눈물을 하루 4회 이상 쓴다면 방부제 무함유(1회용)를 선택하세요**
2. **충혈 제거 안약은 습관적으로 사용하지 마세요** - 반동 충혈이 옵니다
3. **가글은 양치질의 보조이지 대체가 아닙니다**
4. **구내염이 2주 이상 낫지 않으면 반드시 병원에 가세요**
5. **면봉으로 귀를 파지 마세요** - 귀지는 자연적으로 나옵니다
6. **안약을 2종류 이상 넣을 때는 5분 간격을 두세요**
