# 6장: 알레르기와 비염약


![ch6-allergy](https://pub-d0d60c2fafe34c62a9d8993114fe64ca.r2.dev/ebook/otc-medicine-guide/ch6-allergy.png)

## 알레르기, 왜 점점 많아지는 걸까요?

30년 전만 해도 알레르기 비염은 드문 질환이었습니다. 하지만 지금은 한국 성인 3명 중 1명이 알레르기 비염을 가지고 있고, 아이들은 더 많습니다. 미세먼지, 황사, 도시화, 실내 생활 증가 등 다양한 원인이 복합적으로 작용합니다.

알레르기를 완전히 치료하기는 어렵지만, **올바른 약 사용과 생활 관리로 충분히 조절**할 수 있습니다.

## 항히스타민제의 이해

알레르기 반응의 핵심 물질은 히스타민입니다. 꽃가루, 먼지, 진드기 같은 알레르겐이 들어오면 면역세포가 히스타민을 분비하고, 이것이 콧물, 재채기, 가려움, 두드러기를 일으킵니다. 항히스타민제는 이 히스타민의 작용을 차단합니다.

### 1세대 vs 2세대 항히스타민제

| 구분 | 1세대 | 2세대 |
|------|-------|-------|
| 졸음 | 심함 | 거의 없음~약간 |
| 지속시간 | 4~6시간 | 12~24시간 |
| 복용 횟수 | 1일 3~4회 | 1일 1~2회 |
| 입마름 | 심함 | 경미 |
| 집중력 영향 | 큼 | 적음 |
| 대표 성분 | 클로르페니라민, 디펜히드라민 | 세티리진, 로라타딘, 펙소페나딘 |
| 운전 | 금지 | 가능(펙소페나딘 가장 안전) |

**약사 코멘트:** 알레르기 치료 목적이라면 2세대 항히스타민제를 선택하세요. 1세대는 졸음이 심해 일상생활에 지장을 줍니다. 1세대가 필요한 경우는 취침 전 가려움 완화가 필요할 때 정도입니다.

## 주요 알레르기약 완전 비교

### 지르텍 (세티리진)

| 항목 | 내용 |
|------|------|
| 성분 | 세티리진 10mg |
| 복용법 | 1일 1회, 취침 전 권장 |
| 효과 발현 | 1시간 이내 |
| 지속시간 | 24시간 |
| 졸음 | 약간 있음 (2세대 중 가장 높음) |
| 장점 | 강력한 효과, 저렴 |
| 단점 | 일부에서 졸음 유발 |

**약사 코멘트:** 2세대 항히스타민제 중 효과가 가장 강한 편입니다. 졸음이 약간 있을 수 있어 취침 전 복용을 권합니다. 알레르기 증상이 심한 분에게 추천합니다.

### 클라리틴 (로라타딘)

| 항목 | 내용 |
|------|------|
| 성분 | 로라타딘 10mg |
| 복용법 | 1일 1회 |
| 효과 발현 | 1~3시간 |
| 지속시간 | 24시간 |
| 졸음 | 거의 없음 |
| 장점 | 졸음 부작용 적음 |
| 단점 | 세티리진보다 효과 약간 약할 수 있음 |

**약사 코멘트:** 졸음 걱정이 큰 분, 낮에 운전이나 업무를 해야 하는 분에게 적합합니다.

### 알레그라 (펙소페나딘)

| 항목 | 내용 |
|------|------|
| 성분 | 펙소페나딘 60mg 또는 120mg |
| 복용법 | 60mg은 1일 2회, 120mg은 1일 1회 |
| 효과 발현 | 1~2시간 |
| 지속시간 | 12~24시간 |
| 졸음 | 없음 (2세대 중 가장 적음) |
| 장점 | 졸음 거의 0, 운전 완전 안전 |
| 단점 | 가격이 상대적으로 높음 |

**약사 코멘트:** 졸음이 아예 없어야 하는 분(운전기사, 기계 조작자)에게 가장 권장합니다. 미국 FDA에서도 운전에 영향을 주지 않는다고 인정한 유일한 항히스타민제입니다.

### 3가지 항히스타민제 최종 비교

| 항목 | 지르텍(세티리진) | 클라리틴(로라타딘) | 알레그라(펙소페나딘) |
|------|----------------|------------------|-------------------|
| 효과 강도 | 강 | 중 | 중~강 |
| 졸음 | 약간 | 거의 없음 | 없음 |
| 운전 적합 | 주의 | 가능 | 완전 가능 |
| 가격 | 저렴 | 보통 | 높음 |
| 복용 편의 | 1일 1회 | 1일 1회 | 1일 1~2회 |
| 어린이 사용 | 6개월+ | 2세+ | 6세+ |
| 음식 영향 | 없음 | 없음 | 과일주스와 간격 |

**알레그라 주의:** 자몽주스, 오렌지주스, 사과주스와 함께 복용하면 흡수가 감소합니다. 물과 함께 복용하세요.

## 비염 스프레이

### 비염 스프레이의 종류

약국에서 구입할 수 있는 비염 스프레이는 크게 3가지입니다.

| 종류 | 성분 | 작용 | 사용 기간 제한 |
|------|------|------|--------------|
| 혈관수축제 | 옥시메타졸린(오트리빈) | 코막힘 즉시 해소 | 3~5일 이내 |
| 스테로이드 | 플루티카손, 모메타손 | 염증 억제 | 장기 사용 가능 |
| 식염수 | 생리식염수 | 세척, 보습 | 제한 없음 |

### 코막힘 스프레이(혈관수축제)의 위험

**오트리빈, 코리시딘 등 혈관수축제 스프레이는 3~5일까지만 사용하세요.**

연속 사용 시 **약물성 비염(rhinitis medicamentosa)**이 발생합니다. 약을 뿌리지 않으면 코가 더 심하게 막히는 악순환에 빠집니다.

| 사용 기간 | 상태 |
|----------|------|
| 1~3일 | 효과 좋음, 코막힘 해소 |
| 5~7일 | 효과 감소, 더 자주 뿌리게 됨 |
| 2주 이상 | 약물성 비염 발생, 뿌리지 않으면 더 막힘 |
| 수개월 | 코점막 손상, 만성 비염 |

### 스테로이드 비염 스프레이

| 제품 | 성분 | 처방 여부 |
|------|------|----------|
| 나조넥스 | 모메타손 | 전문의약품 |
| 아바미스 | 플루티카손 | 전문의약품 |
| 플릭소나제 | 플루티카손 | 일부 OTC 전환 |

**스테로이드 비염 스프레이에 대한 오해:**

"스테로이드"라는 이름 때문에 겁을 먹는 분이 많습니다. 하지만 코에 뿌리는 스테로이드는 **국소 작용**하므로 전신 부작용이 거의 없습니다. 알레르기 비염의 가장 효과적인 치료제이며, 의사 처방 하에 장기 사용도 가능합니다.

**올바른 사용법:**
1. 사용 전 코를 풀어 콧물 제거
2. 고개를 살짝 숙이고 반대편 눈 방향으로 분사
3. 코 중간벽(비중격)에 직접 분사하지 않기 (점막 손상 방지)
4. 흡입하지 말고 그냥 분사만 (폐로 들어갈 필요 없음)
5. 효과는 수일~2주 후 최대, 즉각적 효과를 기대하지 말 것

## 졸음 부작용과 운전

항히스타민제의 졸음 부작용은 단순한 "졸린 느낌"이 아닙니다. **인지 기능과 반응 속도가 저하**되어 음주 운전과 비슷한 수준의 위험을 초래할 수 있습니다.

| 약물 | 운전 영향 | 권장 |
|------|----------|------|
| 1세대 항히스타민제(감기약 포함) | 심각한 영향 | 운전 금지 |
| 세티리진(지르텍) | 약간 영향 가능 | 주의 |
| 로라타딘(클라리틴) | 거의 없음 | 가능 |
| 펙소페나딘(알레그라) | 없음 | 안전 |

**중요:** 종합감기약(판콜에이 등)에 포함된 항히스타민제(클로르페니라민)는 1세대입니다. 감기약을 먹고 운전하는 것은 위험합니다.

## 꽃가루/미세먼지 시즌 대비

### 알레르기 시즌 캘린더 (한국 기준)

| 시기 | 주요 알레르겐 | 대비 |
|------|-------------|------|
| 2~4월 | 나무 꽃가루(오리나무, 자작나무) | 스테로이드 스프레이 2주 전 시작 |
| 5~6월 | 잔디 꽃가루 | 항히스타민제 복용 |
| 8~10월 | 돼지풀, 쑥 꽃가루 | 가장 심한 시기 |
| 연중 | 집먼지진드기, 반려동물 | 환경 관리 필수 |
| 3~5월, 10~11월 | 미세먼지/황사 | 마스크, 코 세척 |

### 알레르기 시즌 실전 대비 전략

| 전략 | 구체적 방법 |
|------|-----------|
| 약물 선제 투여 | 증상 시작 2주 전부터 항히스타민제 복용 |
| 코 세척 | 생리식염수로 아침저녁 세척 |
| 환경 관리 | 창문 닫기, 빨래 실내 건조, 외출 후 샤워 |
| 마스크 | KF94 이상 마스크 외출 시 착용 |
| 의사 상담 | 증상이 심하면 면역치료 고려 |

## 아토피 관리 기본

아토피 피부염은 알레르기와 밀접한 관련이 있는 만성 피부 질환입니다.

### 약국에서 구입할 수 있는 아토피 관리 제품

| 제품 종류 | 역할 | 사용법 |
|----------|------|--------|
| 저자극 보습제(세타필, 아토베리어) | 피부 장벽 보호 | 1일 2회 이상, 목욕 후 3분 이내 |
| 히드로코르티손 크림(0.5~1%) | 급성 악화 시 가려움/염증 완화 | 얇게, 짧게(7일 이내), 얼굴 주의 |
| 항히스타민제(세티리진) | 가려움 완화 | 취침 전 복용 |
| 콜로이달 오트밀 제품 | 가려움 완화, 보습 | 목욕 시 사용 |

### 아토피 관리 핵심 원칙

| 원칙 | 설명 |
|------|------|
| 보습이 최우선 | 스테로이드보다 보습이 먼저 |
| 미지근한 물 목욕 | 뜨거운 물은 가려움 악화 |
| 목욕 시간 10~15분 | 너무 오래 하면 건조해짐 |
| 목욕 후 3분 이내 보습 | 수분이 남아 있을 때 보습제 도포 |
| 면 소재 옷 | 모직, 합성 섬유 자극 피하기 |
| 손톱 짧게 | 무의식적 긁기로 인한 피부 손상 방지 |

**중요:** 아토피가 넓은 범위에 심하게 악화되면 약국 약만으로는 부족합니다. 피부과 전문의의 진료를 받으세요. 처방용 스테로이드, 면역조절제(타크로리무스 등)가 필요할 수 있습니다.

## 약사가 당부하는 핵심 정리

1. **알레르기약은 2세대를 선택하세요** - 1세대는 졸음이 심합니다
2. **코막힘 스프레이는 3~5일만 사용하세요** - 약물성 비염이 생깁니다
3. **스테로이드 비염 스프레이는 안전합니다** - 이름에 겁먹지 마세요
4. **운전 전에 복용 중인 약의 졸음 부작용을 확인하세요**
5. **알레르기 시즌 2주 전부터 선제 투여가 효과적입니다**
6. **아토피는 보습이 치료의 절반입니다**
