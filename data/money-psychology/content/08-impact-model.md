# 부를 이루기 위한 '심리 구조' 사용하기: IMPACT 모델

## 왜 프레임워크가 필요한가

지금까지 배운 것들 - 인지 편향, 감정 관리, 리스크 관리, 성장 마인드셋 - 을 하나로 통합하는 프레임워크가 필요합니다. 개별 도구를 알아도, 전체를 아우르는 구조가 없으면 실전에서 활용하기 어렵습니다.

**IMPACT 모델**은 사업의 모든 재정 결정에 적용할 수 있는 6단계 통합 프레임워크입니다.

## IMPACT 프레임워크 6단계

### I - Identify (감정과 상황 인식)

모든 판단의 첫 단계는 "지금 내가 어떤 상태인가"를 아는 것입니다.

**확인 사항:**
- 현재 감정 상태는? (불안 / 흥분 / 조급 / 차분)
- 이 결정을 촉발한 계기는? (기회 / 위기 / 압박 / 습관)
- 결정의 긴급도는? (즉시 / 이번 주 / 이번 달 / 분기)
- 이해관계자는 누구인가? (나 / 가족 / 직원 / 투자자)

**실전 팁:** 중요한 결정을 앞두고 있다면, 먼저 종이 상단에 오늘 날짜와 감정 상태를 적으세요. 이것만으로도 객관성이 올라갑니다.

### M - Map Biases (편향 지도 그리기)

어떤 인지 편향이 이 결정에 영향을 줄 수 있는지 미리 매핑합니다.

**편향 체크리스트:**
| 편향 | 점검 질문 | 해당 여부 |
|------|-----------|-----------|
| 앵커링 | 특정 숫자에 고정되어 있는가? | O / X |
| 과신 | "반드시 성공한다"고 확신하는가? | O / X |
| 확증 편향 | 내 생각을 지지하는 정보만 수집했는가? | O / X |
| 손실 회피 | "잃을까봐" 두려운가? | O / X |
| 시간 편향 | 단기 이익에 끌리고 있는가? | O / X |
| 군중 심리 | "다들 하니까"라는 이유인가? | O / X |

해당하는 편향이 2개 이상이면, 결정을 서두르지 마세요.

### P - Process Data (데이터 처리)

감정과 편향을 인식한 후, 순수한 데이터를 수집하고 분석합니다.

**필수 데이터:**
- 재무 수치 (매출, 비용, 이익, 현금 흐름)
- 시장 데이터 (경쟁사, 트렌드, 고객 행동)
- 과거 데이터 (유사한 결정의 결과)
- 벤치마크 데이터 (업종 평균, 성공 사례)

**주의:** 데이터도 편향될 수 있습니다. 출처를 다양화하고, 최신 데이터를 사용하세요.

### A - Analyze Alternatives (대안 분석)

최소 3가지 선택지를 만들고, 각각을 분석합니다.

**각 대안에 대해 작성:**
1. 예상 비용 (돈 + 시간 + 에너지)
2. 예상 수익 (단기 + 중기 + 장기)
3. 리스크 수준 (높음 / 중간 / 낮음)
4. 실행 가능성 (현재 자원으로 가능한가?)
5. 기회 비용 (이것을 하면 못 하는 다른 것은?)

### C - Consider Culture (문화적 맥락 고려)

한국 사업 환경의 문화적 요인을 반드시 고려합니다.

**문화적 체크 포인트:**
- 이 결정에 체면이나 관계가 영향을 미치고 있는가?
- 집단적 동조 압력이 작용하고 있는가?
- 한국 시장의 특수한 규제나 관행이 있는가?
- 한국 소비자의 문화적 특성을 반영했는가?

### T - Track Outcomes (결과 추적)

결정 후 반드시 결과를 추적하고 학습합니다.

**추적 시스템:**
- 결정일, 내용, 예측을 기록
- 1주 / 1개월 / 3개월 후 실제 결과 기록
- 예측과 결과의 차이 분석
- 학습 포인트 정리

## 심리적 안전감 (Psychological Safety)

IMPACT 모델이 효과적으로 작동하려면, 조직 내에 **심리적 안전감**이 필요합니다.

심리적 안전감이란, 실수나 다른 의견을 말해도 벌을 받지 않을 것이라는 믿음입니다.

**심리적 안전감이 높은 조직의 특징:**
- 실패를 처벌하지 않고 학습 기회로 활용
- "모르겠다"고 말할 수 있는 분위기
- 상사의 의견에 반대해도 안전한 환경
- 새로운 아이디어를 자유롭게 제안 가능

**만드는 방법:**
1. 리더가 먼저 자신의 실수를 공개적으로 인정합니다
2. "좋은 질문이네요" → 질문을 환영하는 말습관
3. 실패 사례 공유 세션 (매월 1회, "이달의 실패에서 배운 것")
4. 다른 의견을 제시한 사람에게 감사 표현

## 감정 지능(EI) 훈련

Frontiers of Psychology 연구에 따르면, 감정 지능이 높은 사업자는 위기 상황에서 생존율이 **65% 더 높습니다.**

**감정 지능 4가지 영역과 훈련법:**

1. **자기 인식:** 매일 감정 일기 쓰기 (2분)
2. **자기 관리:** 스트레스 상황에서 6초 호흡법 실천
3. **사회적 인식:** 대화 시 상대방의 감정 먼저 읽기 연습
4. **관계 관리:** 갈등 상황에서 "나 전달법" 사용

## 크로스러닝 세션

다른 분야에서 배우는 것이 편향을 깨는 가장 효과적인 방법입니다.

**월 1회 크로스러닝 세션 구성:**
- 다른 업종 사업자 1명 초대
- "우리 업종에서는 이렇게 하는데, 당신 업종에서는?" 대화
- 서로의 IMPACT 사례 공유
- 새로운 관점 3가지 메모

## 측정 → 실행 → 적응 (3단계 사이클)

IMPACT 모델을 현실에 적용하는 3단계 사이클입니다.

### 측정 (Measure)
- 현재 상태를 숫자로 파악합니다
- IMPACT 모델 적용 전후의 결정 품질을 비교합니다
- 월간 의사결정 정확도를 계산합니다

### 실행 (Execute)
- IMPACT 6단계를 모든 중요 결정에 적용합니다
- 팀 미팅에서 IMPACT 프로세스를 공식 절차로 도입합니다
- 결정 로그를 작성합니다

### 적응 (Adapt)
- 매 분기 IMPACT 적용 결과를 리뷰합니다
- 자주 빠뜨리는 단계를 보강합니다
- 업종/상황에 맞게 체크리스트를 수정합니다

## 오늘의 실천

1. 현재 고민 중인 재정 결정 하나에 IMPACT 6단계를 적용해보세요
2. 팀에 심리적 안전감 수준을 1~10점으로 자가진단해보세요
3. 이번 달 크로스러닝 세션 1회를 잡아보세요

> **핵심 메시지:** IMPACT 모델은 한 번 배워서 끝나는 도구가 아닙니다. 측정 → 실행 → 적응을 반복하면서, 당신의 사업에 맞게 진화시키세요.
