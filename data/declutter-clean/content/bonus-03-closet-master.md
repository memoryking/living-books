# 보너스 3: 옷장 정리 마스터 가이드

## 곤마리 + 실전 팁 통합

옷장은 집에서 가장 감정적인 공간 중 하나입니다. 추억이 담긴 옷, "살 빠지면 입을" 옷, "비쌌는데 안 입는" 옷. 이 가이드는 곤마리의 철학과 Reddit 커뮤니티의 실전 팁을 결합한 옷장 완전 정복법입니다.

---

## Step 1: 전부 꺼내기

이것이 가장 중요한 단계입니다.

옷장, 서랍, 행거, 계절 보관함 — **모든 옷을 한 곳에 꺼내세요.** 침대 위, 바닥 위, 어디든 좋습니다.

전부 꺼내면 놀라게 됩니다. "이렇게 많았어?"

이 충격이 중요합니다. 옷장에 넣어두면 양을 체감하지 못합니다. 한꺼번에 보면 비로소 현실을 직면하게 됩니다.

Reddit의 r/konmari에서:

> *"전부 꺼내니까 침대 위에 산처럼 쌓였다. 이걸 보고 나서야 '너무 많다'는 걸 체감했다."*

---

## Step 2: 카테고리별 분류

꺼낸 옷을 카테고리별로 나누세요:

| 카테고리 | 예시 |
|----------|------|
| 상의 | 티셔츠, 블라우스, 셔츠, 니트 |
| 하의 | 바지, 스커트, 청바지 |
| 원피스/세트 | 원피스, 정장 세트 |
| 겉옷 | 자켓, 코트, 패딩, 바람막이 |
| 속옷/양말 | 속옷, 양말, 스타킹 |
| 잠옷/홈웨어 | 잠옷, 실내복 |
| 운동복 | 운동복, 레깅스, 스포츠 브라 |
| 특수 | 정장, 한복, 수영복, 등산복 |

카테고리별로 분류하면 중복이 눈에 보입니다. "검은 티셔츠가 8장이나 있었어?"

---

## Step 3: 판단하기

각 옷에 대해 아래 질문을 던지세요:

### 남기기 판단 플로우차트

```
이 옷을 지난 1년간 입은 적 있는가?
├─ YES → 상태가 괜찮은가?
│         ├─ YES → 남기기 ✅
│         └─ NO → 수선 가능? → YES → 수선 후 남기기
│                              └─ NO → 보내기
└─ NO → 특별한 이유가 있는가?
         ├─ 계절 옷이라 → 남기기 ✅
         ├─ 특수 목적 (정장, 한복) → 남기기 ✅
         ├─ "살 빠지면 입을 거야" → 보내기 (아래 참조)
         ├─ "비싸게 샀는데" → 보내기 (아래 참조)
         └─ 감정적 이유 → 사진 찍고 보내기
```

### "살 빠지면 입을 거야" 옷에 대하여

솔직한 질문: 그 옷을 사이즈가 됐을 때, 정말로 입고 싶을까요?

대부분의 경우, 체형이 바뀌면 취향도 바뀝니다. 3년 전에 좋아했던 스타일이 3년 후에도 좋을 가능성은 높지 않습니다.

**보내세요.** 실제로 살이 빠지면, 새 옷을 사는 것이 더 큰 보상이 됩니다.

### "비싸게 샀는데" 옷에 대하여

이미 쓴 돈은 돌아오지 않습니다(매몰비용). 옷장에 넣어둬도 돈은 돌아오지 않습니다. 하지만 공간은 돌아옵니다.

비싼 옷이 안 입히는 이유:
- 불편하다
- 취향이 바뀌었다
- 체형이 바뀌었다
- 관리가 어렵다

어떤 이유든, **안 입는 비싼 옷**은 입는 저렴한 옷보다 가치가 없습니다.

중고 판매(당근마켓 등)로 일부 가치를 회수하거나, 깨끗이 세탁해서 기부하세요.

---

## Step 4: 정리하기

남기기로 한 옷을 옷장에 다시 넣습니다.

### 행거 배치법

**순서:** 왼쪽에서 오른쪽으로, 무거운 것 → 가벼운 것
- 코트/패딩 → 자켓/블레이저 → 원피스 → 셔츠/블라우스 → 티셔츠

**색상:** 같은 카테고리 안에서 색상별로 정렬
- 흰색 → 밝은색 → 어두운색 → 검정

**간격:** 옷 사이에 1~2cm 여백. 빽빽하면 구겨지고, 뭐가 있는지 안 보입니다.

### 서랍 접기법 (곤마리 폴딩)

서랍에 넣는 옷은 **세워서 접기** (곤마리 방식):

1. 옷을 반으로 접는다 (세로)
2. 한 번 더 반으로 접는다
3. 3등분으로 접어서 세운다

**장점:**
- 서랍을 열면 모든 옷이 한눈에 보인다
- 위에서 꺼내도 아래가 무너지지 않는다
- 같은 공간에 더 많이 들어간다

### 속옷·양말 서랍

- 칸막이 활용 (다이소 칸막이면 충분)
- 속옷: 3등분 접어서 세로로 세우기
- 양말: 한쪽 안에 다른 한쪽 넣기 (뒤집어 말지 않기 — 고무줄 늘어남)

---

## Step 5: 계절 전환 시스템

### 계절별 관리

**봄/가을 전환 (3월, 10월):**
- 겨울 코트/패딩 세탁 후 보관
- 봄/가을 옷 꺼내기
- 보관 전 "이번 시즌에 한 번도 안 입은 것" 체크 → 보내기 후보

**여름/겨울 전환 (6월, 12월):**
- 시즌 끝난 옷 세탁 후 보관
- 보관 시: 방충제 + 밀폐 가능한 수납 박스
- 이전 시즌에 안 입은 것 → 보내기

### 보관 팁

- **진공 압축팩:** 패딩, 이불에 효과적. 공간 절약 + 방충
- **수납 박스:** 투명한 것으로 (뭐가 들어있는지 보여야)
- **방충제:** 서랍/박스마다 1개씩
- **라벨링:** 박스에 "겨울 코트", "여름 원피스" 등 표시

## 적정 옷 수량 가이드

"몇 벌이 적당한가요?"는 생활 패턴에 따라 다르지만, 참고 수치:

### 직장인 기본 수량

| 카테고리 | 수량 | 비고 |
|----------|------|------|
| 상의 | 10~15벌 | 출근용 + 캐주얼 |
| 하의 | 5~8벌 | 출근용 + 캐주얼 |
| 원피스 | 3~5벌 | 필요한 경우 |
| 겉옷 | 3~5벌 | 계절별 1~2개 |
| 속옷 | 7~10벌 | 일주일 분량 |
| 양말 | 7~10켤레 | 일주일 분량 |
| 잠옷 | 2~3벌 | |
| 운동복 | 2~3세트 | |

Reddit의 r/konmari에서:

> *"30벌에서 50벌로 정리했다. 계절 옷 포함. 충분한 변형이 가능했다."*

50벌이면 매일 다른 옷을 입어도 거의 2개월을 버틸 수 있습니다. 생각보다 적은 수로도 충분합니다.

## 옷장 유지 루틴

**매일:**
- 입은 옷을 세탁함 또는 행거에 즉시 걸기
- "의자 위에 쌓기" 금지

**주 1회:**
- 세탁물 정리 + 수납
- 행거 간격 확인 (옷 사이 여백 유지)

**계절 전환 시 (연 4회):**
- 시즌 옷 교체
- 안 입은 옷 점검 → 기부

**연 1회:**
- 옷장 전체 비우기 + 재정리
- 대대적 기부/정리

## 실천 과제

**지금 당장 (5분):**
옷장에서 "확실히 안 입는 옷" 3벌을 기부 봉투에 넣으세요.

**이번 주말 (2~3시간):**
Step 1~4를 실행하세요. 전부 꺼내기 → 분류 → 판단 → 정리.

**기억할 것:**
> *"다음 날 아침에 옷장 앞에 앉아서 깨끗함을 음미했다."*

그 느낌을 경험해보세요. 깨끗한 옷장 앞에 앉는 그 순간이, 모든 노력의 보상입니다.
