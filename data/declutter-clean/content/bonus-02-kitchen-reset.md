# 보너스 2: 주방 완전 리셋 가이드

## 주방을 처음부터 다시 세팅하는 법

주방은 집에서 가장 빠르게 어질러지는 곳이자, 깨끗하면 가장 큰 만족감을 주는 곳입니다. 이 가이드는 주방을 "완전 리셋"하는 방법과 매일 유지하는 루틴을 다룹니다.

---

## Phase 1: 주방 완전 비우기 (2~3시간)

주말 중 2~3시간을 투자하세요. 단 한 번이면 됩니다.

### 1단계: 전부 꺼내기

주방의 모든 서랍, 수납장, 선반에서 물건을 **전부** 꺼내세요. 바닥이나 식탁 위에 늘어놓으세요.

"이렇게까지 해야 하나요?" 네, 해야 합니다. 전부 꺼내야 비로소:
- 뭘 가지고 있는지 파악됩니다
- 중복된 것이 보입니다
- 쓰지 않는 것이 드러납니다

### 2단계: 빈 주방 청소

물건을 전부 꺼냈으면, 빈 서랍과 선반을 깨끗하게 닦으세요. 이것을 할 기회는 자주 없습니다.

- 서랍 안쪽 닦기
- 선반 먼지 제거
- 필요하면 서랍 매트/깔판 교체

### 3단계: 분류

꺼낸 물건을 네 그룹으로 나누세요:

**남길 것:**
- 매일 또는 매주 사용하는 것
- 제 기능을 하는 것
- 하나만 있으면 되는 것

**버릴 것:**
- 고장난 것 (깨진 그릇, 녹슨 도구)
- 유통기한 지난 식재료/양념
- 손상된 플라스틱 용기 (뚜껑 없는 것 포함)

**기부할 것:**
- 멀쩡하지만 안 쓰는 것 (선물 받은 머그컵 세트 등)
- 중복된 것 (주걱 3개 중 2개)

**다른 곳으로:**
- 주방에 있으면 안 되는 것 (문구류, 약 등)

### 4단계: 다시 넣기 — 구역 설정

**구역별 배치 원칙:**

| 구역 | 위치 | 배치할 것 |
|------|------|----------|
| 조리 구역 | 가스레인지/인덕션 근처 | 냄비, 프라이팬, 조리도구, 양념 |
| 준비 구역 | 도마 놓는 곳 근처 | 칼, 도마, 볼, 계량도구 |
| 설거지 구역 | 싱크대 근처 | 세제, 수세미, 행주, 쓰레기통 |
| 식기 구역 | 식탁 근처 | 그릇, 컵, 수저 |
| 저장 구역 | 상부장/팬트리 | 식재료, 통조림, 비축 식품 |

**핵심 원칙:** 사용하는 곳 근처에 보관. 매일 쓰는 것은 눈높이에. 가끔 쓰는 것은 위/아래에.

## Phase 2: 냉장고 리셋

### 냉장고 구역 설정

| 위치 | 보관할 것 | 이유 |
|------|----------|------|
| 상단 | 바로 먹을 것 (반찬, 남은 음식) | 눈에 바로 보여서 잊지 않음 |
| 중단 | 유제품, 음료, 소스 | 가장 자주 손 닿는 곳 |
| 하단 | 생고기, 생선 | 냉기 가장 찬 곳 + 누출 방지 |
| 서랍 | 채소, 과일 | 적정 습도 유지 |
| 문쪽 | 소스, 양념, 음료 | 온도 변화 가장 큼 (장기 보관 X) |

### 냉장고 관리 루틴

**매일:** 유통기한 확인 + 상한 것 제거 (장 볼 때)
**주 1회:** 남은 반찬 점검 → 소비 or 폐기
**월 1회:** 냉장고 전체 비우기 + 닦기 + 재배치

## Phase 3: 매일 밤 주방 리셋 루틴

### 기본 루틴 (10~15분)

| 순서 | 할 일 | 시간 |
|------|------|------|
| 1 | 남은 음식 밀폐용기에 담아 냉장고에 | 2분 |
| 2 | 싱크대 그릇 전부 씻기 (or 식기세척기) | 5분 |
| 3 | 조리대 세정제로 닦기 | 1분 |
| 4 | 가스레인지/인덕션 표면 닦기 | 1분 |
| 5 | 음식물 쓰레기 봉투 묶기 | 30초 |
| 6 | 수세미/행주 소독 (끓는 물 or 전자레인지) | 1분 |
| 7 | 싱크대 주변 물기 닦기 | 30초 |

### 주간 심화 루틴

| 요일 | 추가 작업 | 시간 |
|------|----------|------|
| 월 | 냉장고 점검 (남은 반찬 처리) | 5분 |
| 수 | 쓰레기통 비우기 + 쓰레기통 세척 | 5분 |
| 금 | 바닥 닦기 (주방 바닥만) | 10분 |
| 토 | 오븐/전자레인지 내부 닦기 | 10분 |

## 주방 필수 청소 도구

최소한 이것만 갖추세요:

**매일 사용:**
- 주방 세정제 (만능 세정제)
- 마이크로파이버 걸레 2~3장
- 수세미 (연마/비연마)
- 행주 3~4장 (매일 교체)
- 음식물 쓰레기 봉투

**주 1회 사용:**
- 베이킹소다 (연마 + 탈취)
- 구연산 (물때 제거)
- 기름때 전용 세정제
- 바닥 청소 도구 (밀대걸레 등)

**월 1회 사용:**
- 배수구 세정제
- 냉장고 탈취제
- 수세미 교체용

## "요리하면서 동시에 설거지" 실전 팁

**기본 원칙:** 불 위에서 조리하는 동안 = 싱크대에서 설거지하는 시간

**실전 흐름 예시 (된장찌개 + 밥):**

1. 밥솥에 밥 세팅 → 밥 짓는 동안 재료 손질
2. 재료 손질 완료 → 도마, 칼 즉시 세척
3. 재료 냄비에 넣고 끓이기 시작 → 재료 담았던 볼, 계량컵 세척
4. 찌개 끓는 동안 → 조리대 닦기, 양념통 제자리
5. 요리 완성 → 냄비·프라이팬 외에 거의 모든 설거지 완료

**결과:** 식사 후 싱크대에는 식기 + 냄비만 남음 → 5분이면 설거지 끝

---

## 주방 정리 유지의 황금 규칙 5가지

1. **조리대 위에는 매일 쓰는 것만** — 조리대가 비어야 요리가 쉽다
2. **싱크대에 그릇을 재우지 마라** — 하나 올려놓으면 열 개가 쌓인다
3. **냉장고는 70%만 채워라** — 가득 채우면 뭐가 있는지 모른다
4. **식재료는 선입선출** — 새로 산 것은 뒤에, 기존 것은 앞에
5. **매일 밤 리셋은 협상 불가** — 이것만 지키면 주방은 항상 깨끗하다

## 실천 과제

**즉시 할 수 있는 것:**
- 오늘 밤 주방 리셋 실행 (기본 루틴 10분)

**이번 주말에 할 것:**
- 주방 서랍 1개 완전 리셋 (전부 꺼내기 → 분류 → 다시 넣기)

**한 달 내에 할 것:**
- 주방 전체 리셋 (Phase 1 완전 실행)

한 번에 다 하지 않아도 됩니다. 서랍 하나부터. 5분이면 충분합니다.
