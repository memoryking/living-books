# Chapter 5: 수납 전문가의 공간별 동선 및 수납 실전 기술

## 3초 안에 꺼내고 넣을 수 없다면, 시스템이 잘못된 것입니다

수납의 핵심은 "예쁘게 정리하는 것"이 아닙니다. **3초 안에 꺼내고 3초 안에 넣을 수 있는 구조를 만드는 것**입니다.

이것을 **"3초 원칙"**이라고 부릅니다.

물건을 꺼내는 데 3초 이상 걸리면? 그 물건은 점점 안 쓰게 됩니다.
물건을 넣는 데 3초 이상 걸리면? 제자리에 안 돌려놓게 됩니다.

예를 들어봅시다.

**나쁜 수납:** 프라이팬이 냄비 3개 아래에 있고, 냄비를 빼려면 옆에 쌓인 뚜껑을 먼저 치워야 합니다. → 꺼내는 데 15초, 넣는 데 20초 → 결국 가스레인지 위에 방치.

**좋은 수납:** 프라이팬이 서랍형 선반에 세로로 꽂혀 있습니다. → 꺼내는 데 2초, 넣는 데 2초 → 사용 후 바로 제자리.

수납이 제대로 되어 있으면 정리가 자동으로 됩니다. 수납이 잘못되어 있으면 아무리 의지력이 강해도 어질러집니다.

## 사용 빈도별 위치 기준표

물건을 어디에 놓을지 결정하는 가장 과학적인 기준은 **사용 빈도**입니다.

| 사용 빈도 | 최적 위치 | 예시 |
|-----------|-----------|------|
| **매일** | 손이 바로 닿는 곳 (눈높이~허리 높이) | 식기, 수저, 칫솔, 자주 쓰는 조리도구 |
| **주 2~3회** | 한 번 손을 뻗으면 닿는 곳 | 믹서기, 제빵 도구, 세탁 세제 |
| **월 1~2회** | 발판 없이 닿는 상단 or 하단 | 손님용 식기, 계절 용품 |
| **분기 1회 이하** | 수납장 깊숙이, 창고, 다용도실 | 명절 용품, 캠핑 장비, 계절 옷 |

**핵심 원칙: 자주 쓰는 물건일수록 접근이 쉬운 곳에.**

많은 가정에서 정반대의 실수를 합니다. 매일 쓰는 접시가 상단 선반에 있고, 1년에 한 번 쓰는 손님용 접시가 가장 접근하기 좋은 위치에 있는 경우입니다.

지금 집을 한 번 둘러보세요. 매일 쓰는 물건이 가장 편한 위치에 있나요?

## 세로 수납의 마법: 공간을 1.5~2배로

수납 공간이 부족하다고 느끼시나요? 아마 물건을 **가로(수평)로 쌓고** 계실 겁니다.

### 가로 수납의 문제

- 위에 쌓인 것을 치워야 아래 것을 꺼낼 수 있음
- 아래에 뭐가 있는지 보이지 않음
- 쌓인 것이 무너짐
- 공간의 높이를 활용하지 못함

### 세로 수납의 장점

- 한눈에 모든 물건이 보임
- 하나를 꺼내도 나머지가 무너지지 않음
- 같은 공간에 1.5~2배 더 많이 수납 가능
- 3초 원칙 자동 달성

### 세로 수납 적용 예시

| 공간 | 가로 수납 (X) | 세로 수납 (O) |
|------|-------------|-------------|
| 옷장 서랍 | 옷을 포개서 쌓기 | 옷을 세로로 접어 세우기 |
| 주방 서랍 | 뚜껑을 냄비 위에 포개기 | 파일꽂이에 뚜껑을 세로로 꽂기 |
| 냉장고 | 반찬통을 겹겹이 쌓기 | 바구니에 세로로 넣기 |
| 서류함 | 서류를 산처럼 쌓기 | 파일꽂이에 세로로 꽂기 |
| 가방 수납 | 가방을 선반에 쌓기 | 후크에 걸거나 세로로 세우기 |

옷장 서랍 하나만 세로 수납으로 바꿔봐도 차이를 체감하실 수 있습니다. 곤마리 접기(KonMari folding)를 검색하면 영상으로 쉽게 배울 수 있습니다.

## 수납함 구매 공식: 실패하지 않는 사이즈 선택법

수납함을 사려고 매장에 가면 사이즈 고르기가 어렵습니다. 너무 크면 공간에 안 들어가고, 너무 작으면 효율이 떨어집니다.

**수납함 구매 공식을 기억하세요:**

> **높이: 수납 공간 높이 - 2cm**
> **가로: 수납 공간 가로 - 1cm**

-2cm과 -1cm의 여유를 두는 이유:
- 넣고 뺄 때 걸리지 않게
- 약간의 공간 변형을 흡수
- 뚜껑이 있는 경우를 고려

**구매 전 반드시 해야 할 것:**
1. 수납할 공간의 가로, 세로, 높이를 줄자로 측정
2. 측정값을 메모에 적어 매장 방문
3. 공식 적용하여 적합한 사이즈 선택
4. 같은 종류로 통일하면 시각적으로 깔끔

## 종이 쇼핑백 DIY 수납함 만들기

수납함을 사기 전에, 집에 있는 종이 쇼핑백으로 먼저 테스트해보세요.

### 만드는 법

1. 튼튼한 종이 쇼핑백을 준비합니다 (브랜드 종이 쇼핑백이 좋음)
2. 끈(손잡이)을 잘라냅니다
3. 원하는 높이에 맞게 윗부분을 안으로 접어 넣습니다
4. 서랍이나 선반에 넣습니다

### 장점

- **비용 0원** — 어차피 버릴 쇼핑백 재활용
- **사이즈 자유자재** — 접는 높이를 조절하면 됨
- **실패해도 부담 없음** — 마음에 안 들면 그냥 버리면 됨
- **테스트용으로 최적** — 이 크기가 맞는지 확인 후 제대로 된 수납함 구매

서랍 안 칸막이, 냉장고 안 정리, 세면대 아래 소품 정리 등 다양한 곳에 활용 가능합니다.

## 공간별 동선 수납 실전 가이드

### 현관

동선: 들어온다 → 신발 벗는다 → 열쇠/가방 내려놓는다 → 외투 건다

- **신발장 1단:** 가장 자주 신는 신발 (가족 수 x 2켤레)
- **벽 훅:** 열쇠, 가방, 우산
- **트레이:** 지갑, 카드, 소지품
- **외투 걸이:** 계절별 1~2벌만 (나머지는 옷장)

### 주방

동선: 냉장고 → 싱크대(씻기) → 조리대(준비) → 가스레인지(조리) → 식탁(배식)

- **싱크대 하단:** 세제, 수세미, 행주 (씻기 관련)
- **조리대 위:** 자주 쓰는 양념 3~5개만 (나머지는 수납장)
- **조리대 근처 서랍:** 칼, 도마, 조리도구 (준비 관련)
- **가스레인지 하단:** 냄비, 프라이팬 (세로 수납)
- **상단 선반:** 잘 안 쓰는 식기, 손님용

### 욕실

동선: 들어온다 → 세면대(세수/양치) → 샤워/목욕 → 나간다

- **세면대 선반/컵:** 칫솔, 치약, 폼클렌저 (매일)
- **거울 뒤 수납장:** 스킨케어, 면도기, 면봉 (매일~주 2~3회)
- **샤워 선반:** 샴푸, 바디워시 (매일)
- **세면대 하단:** 청소 도구, 여분의 치약/비누 (월 1~2회)

### 침실/옷장

동선: 일어난다 → 옷 고른다 → 입는다 → 벗은 옷 처리

- **옷장 눈높이:** 이번 시즌 자주 입는 옷
- **옷장 상단:** 이불, 여행 가방, 계절 옷
- **옷장 하단/서랍:** 속옷, 양말, 잠옷 (세로 수납)
- **세탁함:** 옷장 근처 또는 욕실 (벗은 옷 즉시 투입)

## 수납의 3대 적(敵)

수납을 무너뜨리는 세 가지 적을 알아두세요.

### 1. "혹시 몰라서 보관"

- "언젠가 쓸지 몰라"라며 보관하는 물건이 전체 수납 공간의 30~50%를 차지합니다
- **해결:** 6개월간 안 쓴 것은 보내기

### 2. "수납용품 과다 구매"

- 수납함을 사면 정리된다는 착각 → 수납함만 늘어남
- **해결:** 먼저 줄이고, 그다음 수납하기. 물건을 줄이면 수납함이 필요 없을 수도 있습니다

### 3. "보이지 않는 곳에 밀어넣기"

- 서랍에 밀어넣으면 정리된 것 같지만, 꺼낼 때 문제 발생
- **해결:** 서랍 안도 세로 수납 + 칸막이

## 실천 과제: 집에서 가장 어지러운 수납공간 1곳에 3초 원칙 적용하기

오늘의 과제는 이것입니다.

**과제: 수납공간 1곳 3초 원칙 적용**

1. 집에서 **가장 어지러운 수납공간 1곳**을 선택하세요 (서랍 하나, 선반 한 칸, 싱크대 하단 등)
2. 물건을 **전부 꺼내세요**
3. 사용 빈도별로 분류하세요:
   - 매일 쓰는 것 / 가끔 쓰는 것 / 안 쓰는 것
4. 안 쓰는 것은 **기부 봉투에** 넣으세요
5. 매일 쓰는 것을 **가장 접근하기 쉬운 위치에** 놓으세요
6. 가능하면 **세로 수납**으로 전환하세요
7. 종이 쇼핑백으로 칸막이를 만들어보세요

**테스트:** 물건 하나를 꺼내고 넣어보세요. 3초 안에 되나요? 된다면 성공입니다!

다음에 수납 공간이 신경 쓰일 때마다, 이 3초 원칙을 떠올려주세요. **3초 안에 꺼내고 넣을 수 있는 수납이 좋은 수납입니다.**

수납은 예쁜 것이 아니라, **작동하는 것**이 중요합니다.
