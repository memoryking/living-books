# 부록. 바로 꺼내 쓰는 관계의 도구함

### 부록 A. 상황별 대화 스크립트 15

그대로 읽으라는 대본이 아니라, 내 말투로 고쳐 쓰는 뼈대예요. 모두 나-전달법 구조(상황+감정+부탁)로 되어 있어요.

**서운함을 전할 때**
1. 연락이 뜸해졌을 때: "요즘 연락 텀이 길어져서, 나는 네 하루에서 내가 멀어진 느낌이 들었어. 바쁜 건 아는데, 늦어질 것 같은 날엔 한 줄만 미리 알려 줄 수 있을까?"
2. 약속이 자꾸 미뤄질 때: "약속이 두 번 미뤄지니까 나는 우선순위에서 밀리는 기분이 들더라. 사정이 있는 건 알아. 다음 약속은 좀 지켜졌으면 해."
3. 내 이야기를 건성으로 들을 때: "아까 얘기할 때 휴대폰을 보길래, 나는 벽에 말하는 기분이었어. 5분이라도 눈 보고 이야기하고 싶어."
4. 기념일을 잊었을 때: "기념일이 그냥 지나가서 사실 좀 허전했어. 챙기는 방식은 달라도 되는데, 그날이 우리에게 의미 있었으면 좋겠어."
5. 다른 사람들 앞에서 나를 낮췄을 때: "아까 그 농담, 사람들 앞에서라 나는 좀 창피했어. 둘일 때는 괜찮은 얘기도 남들 앞에선 조심해 주면 좋겠어."

**부탁하고 거절할 때**
6. 혼자만의 시간이 필요할 때: "오늘은 내 배터리가 방전이라, 혼자 충전이 좀 필요해. 너랑 있기 싫은 게 전혀 아니고, 내일 저녁엔 같이 맛있는 거 먹자."
7. 상대의 부탁을 거절할 때: "그건 나한테는 좀 어려운 부탁이야. 대신 이렇게 하는 건 어때?"
8. 휴대폰을 보여 달라는 요구에: "네가 불안한 마음은 듣고 싶어. 그런데 검사로 만드는 안심은 오래 못 가는 것 같아. 뭐가 불안하게 했는지 얘기해 줄래?"
9. 소비 습관 이야기를 꺼낼 때: "돈 얘기는 서로 예민해서 조심스러운데, 우리 앞으로를 위해 한 번은 정리하고 싶어. 주말에 커피 마시면서 가볍게 얘기해 볼까?"
10. 스킨십 속도를 조절하고 싶을 때: "나는 너랑 있는 게 좋아. 그리고 이 부분은 내 속도가 좀 느린 편이야. 기다려 주면, 그만큼 더 편해질 것 같아."

**갈등과 화해의 순간**
11. 싸움이 격해질 때(타임아웃): "잠깐, 우리 약속한 거 하자. 나 지금 너무 올라와서 좋은 말이 안 나올 것 같아. 30분만 걷고 와서 다시 얘기할게."
12. 내가 잘못했을 때: "어제 내 말은 선을 넘었어. 변명 안 할게, 미안해. 네가 어떤 마음이었는지 듣고 싶어."
13. 사과를 받았지만 아직 아플 때: "사과해 줘서 고마워. 진심인 거 알아. 그래도 마음이 풀리는 데는 시간이 좀 걸릴 것 같아. 기다려 줄래?"
14. 사후 정리를 열 때: "어제 일, 다시 싸우자는 건 아니고. 그때 서로 무슨 마음이었는지만 나눠 보고 싶어. 나부터 말하면, 나는 사실 무섭더라."
15. 관계를 정의하고 싶을 때: "나는 너 만나는 시간이 좋아서, 내 마음을 분명히 말하고 싶어. 나는 우리가 연인이 됐으면 해. 네 속도가 다르면 그것도 존중할게. 다만 네 마음도 듣고 싶어."

### 부록 B. 월 1회 관계 점검 체크리스트

한 달에 한 번, 10분. 혼자 해도 좋고 둘이 함께하면 더 좋아요. 각 문항에 O/△/X로 답하세요.

| 영역 | 점검 문항 | O/△/X |
|---|---|---|
| 연결 | 이번 달, 상대의 사소한 말에 잘 응답해 주었다 | |
| 연결 | 휴대폰 없이 대화한 시간이 주 1회 이상 있었다 | |
| 표현 | 고마움을 구체적인 말로 전한 적이 주 1회 이상 있다 | |
| 표현 | 서운함을 쌓아 두지 않고 나-전달법으로 전했다 | |
| 갈등 | 이번 달의 갈등에서 네 가지 독(비난·경멸·방어·담쌓기)을 쓰지 않았다 | |
| 갈등 | 싸운 뒤 사후 정리를 했다 (싸움이 없었다면 O) | |
| 경계 | 나의 시간·우정·취미가 살아 있다 | |
| 경계 | 상대의 시간·우정·취미를 존중했다 | |
| 성장 | 함께한 새로운 경험이 한 가지 이상 있었다 | |
| 성장 | 상대의 도전이나 성장을 응원하는 말을 했다 | |

X가 나온 영역이 다음 달의 가꾸기 포인트예요. X가 3개 이상 반복되는 영역이 있다면, 그 영역의 챕터를 다시 펴 보세요.

### 부록 C. 나의 애착 성향 간이 체크

정식 심리 검사가 아니라 자기 이해를 위한 간이 체크예요. 각 문항에 그렇다(2)/가끔(1)/아니다(0)로 점수를 매기세요.

**A 묶음**: 상대의 답장이 늦으면 마음이 크게 흔들린다 / 상대의 마음이 변할까 봐 자주 걱정한다 / 관계에서 확인받고 싶은 욕구가 크다 / 상대에게 서운한 게 생기면 시험해 보고 싶어진다 / 혼자 남는 것이 몹시 두렵다

**B 묶음**: 너무 가까워지면 답답함을 느낀다 / 힘든 일을 혼자 처리하는 편이 편하다 / 속마음을 표현하는 것이 어색하다 / 상대가 의지해 오면 부담을 느낀다 / 관계가 깊어질 때쯤 떠나고 싶어진 적이 있다

A 합계가 6점 이상이면 불안 성향, B 합계가 6점 이상이면 회피 성향이 상대적으로 높은 편이에요. 둘 다 높다면 혼란 성향, 둘 다 낮다면 안정 성향에 가깝고요. 다시 강조하지만 이것은 낙인이 아니라 현재 위치예요. 2챕터의 '획득된 안정'을 기억하세요.

### 부록 D. 마음이 깊어지는 대화 질문 30

데이트가 "뭐 먹지"와 "요즘 어때"에서 멈출 때 꺼내는 질문들이에요. 가벼운 것부터 깊은 것 순서로, 한 번에 두세 개면 충분해요.

**웃으며 시작하는 질문**: 요즘 제일 사소한 행복이 뭐야? / 스트레스 받으면 뭘로 풀어? / 어릴 때 별명이 뭐였어? / 인생 최고의 여행지는? / 요즘 배우고 싶은 게 있어? / 하루가 48시간이면 뭘 할 거야? / 제일 좋아하는 냄새는? / 최근에 크게 웃었던 일은? / 어른이 됐다고 처음 느낀 순간은? / 우리 처음 만난 날, 첫인상 솔직히 어땠어?

**서로를 알아 가는 질문**: 너를 제일 잘 아는 사람은 누구야? / 가족 중 누구를 제일 닮았어? / 힘들 때 혼자 있고 싶어, 같이 있고 싶어? / 사랑받는다고 느끼는 순간은 언제야? / 반대로 서운함을 느끼는 포인트는? / 살면서 제일 잘한 결정은? / 지금의 너를 만든 경험 하나를 꼽는다면? / 요즘 제일 큰 고민은 뭐야? / 10년 뒤에 어떤 모습이고 싶어? / 네가 생각하는 좋은 관계는 어떤 모양이야?

**깊어진 뒤의 질문**: 나한테 말 안 했지만 말하고 싶었던 게 있어? / 우리 관계에서 제일 좋았던 순간은? / 내가 어떻게 해 줄 때 제일 편안해? / 싸웠을 때 내가 어떻게 해 주면 좋겠어? / 네가 두려워하는 건 뭐야? / 서로에게 지켜 줬으면 하는 선이 있어? / 우리가 함께 해 봤으면 하는 것 하나는? / 요즘 나 때문에 참고 있는 게 있어? / 너의 부모님의 관계에서 배우고 싶은 것과 닮고 싶지 않은 것은? / 지금 이 관계에서 더 바라는 게 있다면?

### 부록 D-2. 갈등 후 회복 대화 가이드 (사후 정리의 순서)

7챕터의 사후 정리를 실제로 진행하는 순서예요. 싸움이 끝나고 하루 이틀 안에, 15분이면 충분해요.

1. **자리 세팅**: 마주 보고 앉기보다 나란히(산책, 드라이브, 소파)가 부담이 적어요. "다시 싸우자는 게 아니라, 그때 마음을 나누고 싶어"로 시작해요.
2. **한 사람씩, 그때의 내 마음만**: 상대의 잘못이 아니라 내 감정을 말해요. "그때 나는 사실 ○○한 기분이었어." 부록 E의 감정 단어를 활용하세요. 듣는 사람은 반박하지 않고 끝까지 들어요.
3. **서로의 방아쇠 확인**: "내 어떤 말/행동이 제일 아팠어?" 하나씩만 물어요. 대답은 방어 없이 접수해요. "그게 그렇게 들렸구나."
4. **하나씩만 부탁하기**: "다음에 비슷한 상황이 오면, 나는 네가 ○○해 주면 좋겠어." 둘 다 하나씩. 목록이 길어지면 청문회가 돼요.
5. **복구 의식으로 마무리**: 안아 주기, 손잡기, 함께 맛있는 것 먹기. 몸의 화해가 마음의 화해를 완성해요.

이 15분이 처음엔 어색해요. 그런데 두세 번 반복하면, 싸움이 더 이상 관계의 위협이 아니라 서로의 사용 설명서가 업데이트되는 시간이라는 걸 몸이 알게 돼요. 잘 싸우는 커플의 비밀은 싸움의 기술 절반, 정리의 기술 절반이에요.

### 부록 E. 감정 단어 사전: "짜증나"와 "몰라" 너머의 말들

감정을 정확히 말하려면 어휘가 필요해요. "짜증나"로 뭉뚱그려지는 마음들을 펼쳐 볼게요.

- **서운함 계열**: 섭섭하다, 소외된 기분이다, 뒷전이 된 것 같다, 잊힌 것 같다, 기대가 무너졌다
- **불안 계열**: 초조하다, 확신이 없어 흔들린다, 버려질까 겁난다, 눈치 보게 된다, 조마조마하다
- **분노 계열**: 무시당한 기분이다, 존중받지 못한 것 같다, 억울하다, 선을 넘었다고 느낀다, 지쳤다
- **슬픔 계열**: 외롭다, 허전하다, 마음이 가라앉는다, 그립다, 공허하다
- **부끄러움 계열**: 창피하다, 작아지는 기분이다, 초라하게 느껴진다, 들킨 것 같아 움츠러든다
- **긍정 계열**: 든든하다, 안심된다, 벅차다, 충만하다, 존중받는 기분이다, 살아 있는 것 같다

쓰는 법은 간단해요. 마음이 복잡할 때 이 목록을 훑으며 "지금 내 마음과 가장 가까운 단어"를 골라 보세요. 감정에 정확한 이름을 붙이는 것만으로 감정의 크기가 줄어든다는 것은 심리학의 잘 알려진 발견이에요. 그리고 그 단어를 나-전달법에 실어 보내면, 상대는 처음으로 내 마음의 정확한 좌표를 알게 돼요.

### 부록 E-2. 관계를 살리는 일주일 미니 챌린지

책을 덮은 뒤 첫 일주일 동안 해 볼 수 있는 하루 하나짜리 실천이에요. 연인이 없다면 가족·친구에게 적용해도 그대로 통해요.

- **월요일**: 상대의 다가감 신호 하나에 하던 일을 멈추고 몸을 돌려 응답하기.
- **화요일**: 구체적인 고마움 한 문장 전하기. 행동 뒤의 마음까지 짚어서.
- **수요일**: 서운했던 것 하나를 나-전달법(상황+감정+부탁)으로 말해 보기.
- **목요일**: 상대의 이야기에 해결책 대신 목격자의 문장으로만 반응해 보기. "그랬구나, 힘들었겠다."
- **금요일**: 부록 D의 질문 하나를 꺼내 휴대폰 없이 20분 대화하기.
- **토요일**: 함께(또는 혼자) 처음 해 보는 것 하나 시도하기. 새 동네, 새 메뉴, 새 활동.
- **일요일**: 나를 위한 시간 30분 확보하기. 그리고 이번 주 배운 것 세 줄 기록.

일곱 개를 다 해내는 것이 목표가 아니에요. 하나를 하더라도 "기술은 연습으로만 몸에 붙는다"는 감각을 얻는 것이 목표예요. 다음 주에는 가장 효과 있던 것 두 개만 남겨 반복하세요.

### 부록 F. 자주 묻는 질문

**Q1. 모태솔로인데 이 책이 도움이 되나요?** 네. 1~5챕터는 관계 시작 전의 준비에 관한 내용이고, 6챕터 이후의 기술들은 연애만이 아니라 우정, 가족, 직장 관계에서도 그대로 쓰여요. 연습 상대는 모든 관계예요.

**Q2. 지금 애인과 읽어도 되나요?** 오히려 추천해요. 특히 7챕터의 타임아웃 신호 정하기, 부록 B의 월간 점검, 부록 D의 질문들은 둘이 함께할 때 효과가 커요. 단, 책 내용을 상대 공격의 근거로 쓰는 것("이 책에서 너 같은 사람을 회피형이래")은 금물이에요.

**Q3. 상대가 노력하지 않으면 소용없는 것 아닌가요?** 절반은 맞아요. 관계는 둘의 작품이니까요. 하지만 상호작용의 패턴은 한쪽이 바뀌면 반드시 출렁여요. 내가 비난을 나-전달법으로 바꾸면 상대의 방어도 줄어드는 식이죠. 내 몫의 변화를 먼저 하고, 그래도 반응 없는 관계라면 9챕터의 마지막 절이 그다음 이야기예요.

**Q4. 헤어진 연인을 잊는 법도 알려 주나요?** 이 책은 이별 회복 전문서는 아니에요. 다만 1~3챕터의 패턴 이해와 자기 돌봄은 이별 후의 시간에 특히 힘이 돼요. 이별의 고통이 일상을 오래 무너뜨린다면 전문 상담의 도움을 받으세요.

**Q5. 애착 유형 검사는 어디서 받을 수 있나요?** 부록 C의 간이 체크로 방향을 잡고, 더 정확한 이해를 원하면 심리 상담 기관의 정식 검사를 권해요. 인터넷의 무료 검사는 재미로만 보세요.

**Q5-1. 회피형인 제가 노력해도 바뀌지 않는 느낌이에요.** 애착의 변화는 체감상 아주 느려요. 특히 회피형의 변화는 극적인 전환이 아니라 "닫히려는 순간을 한 번 더 버티는 것"의 누적이에요. 상대에게 "잠깐 혼자 있고 싶은데, 도망가는 건 아니야"라고 말해 준 한 번, 힘든 일을 혼자 삼키는 대신 한 조각 나눠 본 한 번. 그 한 번들이 변화예요. 방향이 맞다면 속도는 문제가 아니에요.

**Q5-2. 상대가 이 책에 나온 '통제의 신호'에 해당하는 것 같아요.** 8챕터의 목록(고립, 감시, 위협, 행동 통제)에 해당하는 일이 반복된다면, 그것은 관계 기술의 문제가 아니라 안전의 문제예요. 혼자 판단하려 하지 말고 믿을 수 있는 주변인에게 상황을 알리고, 필요하면 전문 상담 기관의 도움을 받으세요. 관계를 지키는 것보다 나를 지키는 것이 먼저예요.

**Q6. 이 책대로 하면 연애에 성공하나요?** 이 책은 성공(특정 상대와 사귀게 됨)을 약속하지 않아요. 약속하는 건 건강함이에요. 불안에 덜 휘둘리고, 마음을 더 정확히 전하고, 갈등에서 덜 다치는 것. 경험상, 건강함은 성공 확률도 함께 올려 줘요. 순서가 반대가 아닐 뿐이에요.

### 부록 G. 이 책의 개념 미니 사전

- **각본**: 과거 관계 경험이 만든 자동 반응 패턴. 방아쇠→반응→결론의 구조로 반복된다.
- **애착 유형**: 관계에서의 불안 축과 회피 축 조합으로 나눈 성향(안정·불안·회피·혼란). 낙인이 아니라 현재 위치.
- **획득된 안정**: 타고나지 못했어도 좋은 관계 경험과 연습으로 도달하는 안정 애착 상태.
- **자기 자비**: 실수한 나에게 친구를 대하듯 말하는 태도. 자기 합리화가 아니라 회복의 기술.
- **단순 노출 효과**: 자주 마주치는 대상에게 호감이 커지는 심리 현상.
- **자기 개방**: 자기 이야기를 여는 것. 상호적·점진적일 때 친밀감을 만든다.
- **추적자-도피자 패턴**: 한쪽이 다가갈수록 다른 쪽이 물러나는 관계의 악순환.
- **나-전달법**: 상황+내 감정+부탁의 구조로 말하는 대화법. 비난 없이 마음을 전달한다.
- **감정의 인정**: 상대의 판단에 동의하는 것과 별개로, 상대의 감정이 실재함을 알아주는 반응.
- **네 가지 독**: 관계를 부수는 대화 습관 — 비난, 경멸, 방어, 담쌓기.
- **타임아웃**: 복귀 시간을 약속하고 싸움을 잠시 멈추는 정비 기술. 담쌓기와 다르다.
- **복구 시도**: 싸움 중 긴장을 낮추려는 작은 신호(유머, 사과, 스킨십). 보내는 것만큼 받는 것이 중요하다.
- **영구적 문제**: 성격·가치관 차이처럼 완전히 해결되지 않는 갈등. 해결이 아니라 관리의 대상.
- **경계선**: 상대를 막는 벽이 아니라 내 영역을 알리는 울타리. 나-전달법으로 세운다.
- **다가감의 신호(bid)**: "나랑 연결돼 줘"라는 일상의 작은 초대. 응답률이 관계의 운명을 가른다.
- **자기 확장**: 사랑을 통해 서로의 세계가 넓어지는 경험. 오래가는 관계의 엔진.
- **회고적 질투**: 상대의 과거에 대한 반복적 불안. 정보 수집으로는 해소되지 않는다.
- **사랑의 언어**: 사랑을 표현·수신하는 주된 채널(말, 시간, 행동, 선물, 스킨십)이 사람마다 다르다는 실용적 렌즈.
