## 부록 4: 바이오(소개글) 작성 공식

### 3줄 공식

```
1줄: [나는 누구] — 직업, 전문성, 차별점
2줄: [무엇을 제공하는가] — 팔로우할 이유, 콘텐츠 주제
3줄: [행동 유도] — 링크 클릭, DM 유도, 구독 안내
```

### 바이오 작성 워크시트

| 요소 | 나의 답 |
|---|---|
| 나는 누구인가? (직업/전문성) | |
| 무엇을 다루는가? (콘텐츠 주제) | |
| 팔로우하면 뭘 얻는가? (혜택) | |
| 어떤 행동을 유도할 것인가? (CTA) | |

### 바이오 예시 모음

**약사/건강 분야:**
```
약사 김약사 | 건강정보 큐레이터
매일 1분 건강 상식 💊 쉽고 정확하게
👇 무료 영양제 가이드 받기
```

**뷰티/화장품 분야:**
```
피부 관리 전문가 | 전 화장품 연구원
돈 아끼는 스킨케어 루틴 공유
DM으로 '피부타입' 보내면 맞춤 추천 🎁
```

**요리/푸드 분야:**
```
집밥 레시피 연구가 🍳
재료 3개로 만드는 10분 요리
매주 월수금 레시피 업로드 📌
```

**비즈니스/마케팅 분야:**
```
1인 사업자 마케팅 코치
광고비 0원으로 매출 올리는 SNS 전략
👇 무료 SNS 가이드 다운로드
```
