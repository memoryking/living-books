# 3장: 첫 100명의 진짜 팔로워 만들기 — 초기 성장 전략

## 왜 첫 100명이 중요한가

SNS에서 가장 힘든 구간은 **0에서 100**입니다. 팔로워가 0명일 때는 게시물을 올려도 아무도 보지 않고, 아무도 보지 않으니 올릴 의욕이 사라집니다. 이 악순환을 깨는 것이 첫 번째 과제입니다.

하지만 100명만 넘기면 상황이 달라집니다:

- **알고리즘이 작동하기 시작합니다** — 반응 데이터가 쌓여 추천이 시작됨
- **사회적 증거가 생깁니다** — "이 계정 사람들이 보네?" 효과
- **피드백 루프가 만들어집니다** — 어떤 콘텐츠가 먹히는지 데이터로 확인 가능
- **자신감이 붙습니다** — 꾸준히 할 동력이 생김

> **핵심:** 첫 100명은 "진짜 팔로워"여야 합니다. 맞팔·선팔·구매 팔로워는 숫자만 늘리고 참여율을 떨어뜨립니다.

## 계정 세팅: 첫인상이 90%를 결정한다

팔로워를 모으기 전에 **계정 자체가 매력적**이어야 합니다. 내 프로필에 들어온 사람이 3초 안에 "팔로우할 이유"를 찾지 못하면 그냥 나갑니다.

### 프로필 최적화 체크리스트

| 요소 | 해야 할 것 | 하지 말아야 할 것 |
|---|---|---|
| **프로필 사진** | 얼굴이 보이는 밝은 사진 | 로고, 풍경, 캐릭터(개인 계정) |
| **이름/닉네임** | 검색 가능한 키워드 포함 | 영어+숫자 조합의 의미 없는 ID |
| **바이오(소개글)** | 누구인지 + 무엇을 주는지 + CTA | 명언, 가사, 모호한 문구 |
| **링크** | 블로그/스토어/채널 링크 | 빈 칸으로 방치 |
| **하이라이트/고정글** | 카테고리별 대표 콘텐츠 | 비어있는 하이라이트 |

### 바이오 작성 공식 (3줄 공식)

```
1줄: [나는 누구] — 직업/전문성
2줄: [무엇을 제공하는가] — 팔로우할 이유
3줄: [행동 유도] — 링크 클릭, DM 유도 등
```

**예시:**
```
약사 김약사 | 건강정보 큐레이터
매일 1분 건강 상식 💊 쉽고 정확하게
👇 무료 영양제 가이드 받기
```

## 첫 100명을 만드는 7가지 전술

### 전술 1: 주변 네트워크 활성화 (목표: 30명)

가장 빠르고 확실한 방법입니다.

- 카카오톡 프로필에 SNS 계정 링크 추가
- 카카오톡 단체방에 "SNS 시작했어요" 자연스럽게 알리기
- 명함, 이메일 서명에 SNS 링크 추가
- 매장이 있다면 QR코드 부착

> **주의:** "팔로우 해주세요"보다 **"이런 콘텐츠 올리는데 피드백 좀 부탁해요"**가 훨씬 효과적입니다.

### 전술 2: 타깃 커뮤니티 참여 (목표: 20명)

내 분야와 관련된 **온라인 커뮤니티에 먼저 가치를 제공**하세요.

- **네이버 카페**: 관련 카페에서 도움이 되는 답변 달기
- **에브리타임/블라인드**: 타깃 연령대가 있는 커뮤니티
- **페이스북 그룹**: 관심사 기반 그룹 참여
- **오픈카톡방**: 관련 분야 오픈카톡에서 활동

**핵심 규칙:** 홍보하지 말고, 진심으로 도움을 주세요. 프로필에 SNS 링크를 넣어두면 관심 있는 사람이 자연스럽게 찾아옵니다.

### 전술 3: 관련 계정에 진심 댓글 달기 (목표: 20명)

매일 같은 분야 계정 10개에 **의미 있는 댓글**을 다세요.

| 나쁜 댓글 | 좋은 댓글 |
|---|---|
| "좋은 정보네요!" | "비타민D 부분 정말 공감합니다. 저도 약국에서 상담하면 10명 중 8명이 부족하더라고요." |
| "팔로우했어요 맞팔해주세요" | "이 시리즈 정말 유익해요. 다음 편도 기대됩니다!" |
| "👍👍" | "3번 팁은 바로 적용해봐야겠어요. 혹시 ~에 대해서도 다뤄주실 계획 있으신가요?" |

**진심 댓글의 효과:**
- 해당 계정 운영자가 내 프로필을 확인 → 팔로우 가능성
- 댓글을 본 다른 사람들이 내 프로필을 확인 → 팔로우 가능성
- 알고리즘이 나를 해당 분야 관련 계정으로 인식 → 추천 노출 증가

### 전술 4: 콘텐츠 10개 먼저 채우기 (목표: 기반 구축)

프로필에 들어왔는데 게시물이 1-2개뿐이면 팔로우하지 않습니다. **최소 9-12개의 콘텐츠**를 먼저 채우세요.

추천 초기 콘텐츠 구성:
1. 자기소개 (나는 누구, 이 계정에서 무엇을 다루는지)
2. 전문 분야 핵심 정보 3개
3. 개인 스토리/경험 2개
4. 유용한 팁·리스트 3개
5. 질문형 게시물 1개 (참여 유도)

### 전술 5: 네이버 블로그 검색 유입 (목표: 15명)

네이버 블로그는 **검색으로 모르는 사람이 찾아오는** 거의 유일한 플랫폼입니다.

- 검색량이 있는 키워드로 글 작성 (네이버 키워드 플래너 활용)
- 글 하단에 인스타그램/유튜브 링크 삽입
- **"더 많은 정보는 인스타에서 매일 올리고 있어요"** 식의 자연스러운 유도

### 전술 6: 릴스/쇼츠 바이럴 도전 (목표: 10명)

짧은 영상은 팔로워가 0명이어도 수천 조회가 가능합니다.

- 15-30초 짧은 정보 영상
- 트렌딩 오디오 활용
- 자막 필수 (소리 없이 보는 비율 80%)
- **첫 1초에 핵심 훅** 넣기

### 전술 7: 콘텐츠 리퍼포징 (목표: 5명)

하나의 콘텐츠를 여러 플랫폼에 맞게 재가공하세요.

```
블로그 글 1개 → 인스타 카드뉴스 → 릴스 30초 → 스레드 글 → 카카오톡 채널 포스트
```

같은 노력으로 5배의 노출을 만들 수 있습니다.

## 초기 성장에서 절대 하지 말아야 할 3가지

아무리 급해도 이 세 가지는 피하세요. 단기적으로는 숫자가 올라가는 것처럼 보이지만, 장기적으로 계정을 망칩니다.

### 1. 팔로워 구매
돈을 주고 팔로워를 사면 숫자는 늘지만 **참여율이 0%에 수렴**합니다. 알고리즘은 참여율이 낮은 계정을 "관심 없는 콘텐츠"로 판단하고 노출을 줄입니다. 결국 진짜 팔로워에게도 도달하지 못하는 악순환에 빠집니다.

### 2. 무차별 맞팔/선팔
"1,000명 팔로우하면 300명이 맞팔한다"는 전략은 2020년 이전의 방법입니다. 지금은 알고리즘이 이런 패턴을 감지해 **계정 제한(섀도우밴)**을 걸 수 있습니다.

### 3. 댓글 봇/자동화 프로그램
자동 댓글, 자동 좋아요 프로그램은 계정 정지 사유입니다. 인스타그램과 유튜브 모두 자동화 봇 탐지 기능을 강화하고 있습니다. **수동이 느려 보이지만 가장 안전하고 효과적**입니다.

## 핵심 정리

- 첫 100명은 **진성 팔로워**여야 알고리즘이 작동한다
- **프로필 최적화**가 팔로우 전환율을 3배 높인다
- 주변 네트워크 + 커뮤니티 참여 + 진심 댓글이 **초기 성장의 3대 축**
- 콘텐츠 9-12개를 먼저 채운 후 홍보 시작
- **14일이면 100명** 달성 가능 — 핵심은 꾸준한 실행
