# 5장: 해시태그 · SEO · 알고리즘 — 무료로 노출 극대화하기

## 같은 콘텐츠, 10배 다른 노출

똑같이 좋은 콘텐츠를 만들어도 **노출 전략을 아는 사람**과 모르는 사람의 결과는 10배 이상 차이 납니다. 이 장에서는 돈 한 푼 쓰지 않고 콘텐츠가 더 많은 사람에게 도달하게 만드는 세 가지 무기를 다룹니다.

1. **해시태그** — SNS의 분류 시스템
2. **SEO** — 검색 엔진에서 발견되는 기술
3. **알고리즘** — 플랫폼이 콘텐츠를 밀어주는 원리

## 해시태그 전략

### 해시태그의 진짜 역할

해시태그는 단순한 꾸밈이 아닙니다. **내 콘텐츠를 관심 있는 사람에게 연결하는 분류 태그**입니다.

### 해시태그 3단계 피라미드

| 단계 | 게시물 수 | 비율 | 예시 |
|---|---|---|---|
| **대형** | 100만 이상 | 20% (2-3개) | #건강, #다이어트, #맛집 |
| **중형** | 1만-100만 | 50% (5-7개) | #영양제추천, #비타민D, #약사추천 |
| **소형(니치)** | 1만 미만 | 30% (3-5개) | #약사일상, #유원소망약국, #비타코치 |

**왜 이 비율인가?**
- 대형 해시태그만 쓰면: 경쟁이 치열해 묻힘
- 소형만 쓰면: 검색량 자체가 적어 노출 한계
- **섞어 쓰면**: 소형에서 상위 노출 → 중형으로 확장 → 대형에서도 기회 포착

### 플랫폼별 해시태그 최적 개수

| 플랫폼 | 권장 개수 | 위치 |
|---|---|---|
| 인스타그램 | 10-15개 | 본문 또는 첫 댓글 |
| 네이버 블로그 | 5-10개 | 글 하단 태그 |
| 틱톡 | 3-5개 | 캡션에 포함 |
| 유튜브 | 5-8개 | 설명란 + 태그 필드 |
| 스레드 | 1-3개 | 본문에 자연스럽게 |

### 해시태그 리서치 방법

**무료 도구 활용:**
- **인스타그램 검색창:** 키워드 입력 시 관련 해시태그와 게시물 수 표시
- **네이버 키워드 플래너:** 월간 검색량 확인 (무료)
- **유튜브 자동완성:** 검색창에 키워드 입력 시 인기 연관어 표시
- **Hashtagify/Display Purposes:** 영문 해시태그 리서치 (무료)

**직접 리서치 3단계:**
1. 나의 핵심 키워드 5개 작성
2. 각 키워드를 플랫폼 검색창에 입력 → 연관 해시태그 20개 수집
3. 게시물 수 기준으로 대형/중형/소형 분류

> **김약사 팁:** 저는 해시태그 세트를 3개 만들어 돌려가며 사용합니다. 같은 해시태그만 반복하면 알고리즘이 스팸으로 인식할 수 있어요.

## SEO: 검색에서 발견되는 기술

### SNS에서 SEO가 왜 중요한가

2024년부터 **인스타그램, 틱톡도 검색 엔진**처럼 사용되기 시작했습니다. 특히 Gen Z의 40%가 구글 대신 틱톡/인스타에서 검색한다는 조사 결과가 있습니다.

한국에서는 **네이버 블로그 SEO**가 여전히 가장 강력합니다.

### 네이버 블로그 SEO 핵심 요소

| 요소 | 설명 | 실행 방법 |
|---|---|---|
| **C-Rank** | 특정 분야 전문성 점수 | 하나의 주제에 집중하여 꾸준히 글 작성 |
| **D.I.A.** | 콘텐츠 품질 평가 | 원본 이미지, 충분한 텍스트(1,500자 이상), 체류 시간 |
| **제목 키워드** | 검색어와 제목 매칭 | 핵심 키워드를 제목 앞쪽에 배치 |
| **본문 키워드** | 자연스러운 키워드 반복 | 핵심 키워드 3-5회 자연스럽게 삽입 |

### 프로필/바이오 SEO 최적화

프로필도 검색 대상입니다. **이름 필드에 키워드를 포함**하세요.

| 플랫폼 | 최적화 전 | 최적화 후 |
|---|---|---|
| 인스타그램 이름 | "김약사" | "김약사 | 영양제·건강정보" |
| 유튜브 채널명 | "유원소망약국" | "유원소망약국 | 약사가 알려주는 건강" |
| 네이버 블로그 | "김약사의 일상" | "김약사의 건강노트 | 영양제·비타민 정보" |

### 콘텐츠 리퍼포징(Repurposing)으로 SEO 효과 극대화

하나의 콘텐츠를 여러 형태로 재가공하면 **다양한 검색 경로**에서 발견됩니다.

```
[원본] 블로그 글: "비타민D 부족 증상 5가지와 해결법"
  ↓
[리퍼포징 1] 인스타 카드뉴스 5장
[리퍼포징 2] 릴스 30초 요약 영상
[리퍼포징 3] 스레드 핵심 요약 텍스트
[리퍼포징 4] 카카오톡 채널 포스트
[리퍼포징 5] 유튜브 쇼츠 15초 핵심 팁
```

## 알고리즘: 플랫폼이 내 콘텐츠를 밀어주는 조건

### 모든 SNS 알고리즘의 공통 원리

플랫폼마다 디테일은 다르지만, **핵심 원리는 동일**합니다:

> **"사용자가 플랫폼에 오래 머물게 하는 콘텐츠"를 더 많이 노출한다.**

### 알고리즘이 좋아하는 6가지 신호

| 신호 | 설명 | 가중치 |
|---|---|---|
| **저장** | 나중에 다시 보고 싶다는 강한 신호 | 매우 높음 |
| **공유** | 다른 사람에게 보여줄 만큼 가치 있다 | 매우 높음 |
| **댓글** | 대화를 유발하는 콘텐츠 | 높음 |
| **체류 시간** | 콘텐츠를 오래 봤다 | 높음 |
| **좋아요** | 기본적인 긍정 반응 | 보통 |
| **프로필 방문** | 콘텐츠를 보고 계정에 관심을 가짐 | 높음 |

> **핵심 인사이트:** "좋아요를 눌러주세요"보다 **"저장해 두세요"**가 알고리즘에 3배 효과적입니다.

### 플랫폼별 알고리즘 공략 팁

**인스타그램:**
- 릴스 게시 후 **30분 내 댓글에 모두 답글** 달기
- 스토리 투표/퀴즈 기능으로 참여율 높이기
- 캐러셀(여러 장) 게시물로 체류 시간 높이기

**유튜브:**
- **클릭률(CTR)과 시청 지속 시간**이 핵심
- 처음 30초에 핵심 내용 예고
- 관련 영상끼리 재생목록으로 묶기

**네이버 블로그:**
- **체류 시간**이 D.I.A. 핵심 지표
- 이미지 10장 이상 + 텍스트 1,500자 이상
- 같은 주제 글끼리 시리즈 연결

**틱톡/릴스/쇼츠:**
- **완주율(영상을 끝까지 보는 비율)**이 핵심
- 15-30초가 최적 길이
- 루프(반복) 시청되는 구조 만들기

### AI 도구를 활용한 콘텐츠 최적화

무료 AI 도구를 활용하면 효율을 높일 수 있습니다:

- **ChatGPT/Claude:** 해시태그 아이디어, 캡션 초안, 콘텐츠 아이디어 브레인스토밍
- **Canva AI:** 이미지/카드뉴스 자동 디자인
- **CapCut:** 자동 자막 생성, 영상 편집
- **네이버 키워드 플래너:** 검색량 데이터 확인

> **주의:** AI로 초안을 만들되, **반드시 나의 경험과 목소리로 수정**하세요. AI가 쓴 글 그대로 올리면 차별화가 불가능합니다.

## 핵심 정리

- 해시태그는 **대형 20% + 중형 50% + 소형 30%** 피라미드로 구성
- 네이버 블로그 SEO는 **C-Rank(전문성) + D.I.A.(품질)**가 핵심
- 프로필 이름에 **검색 키워드**를 포함하면 발견 확률 상승
- 알고리즘은 **저장 > 공유 > 댓글 > 좋아요** 순으로 가중치 부여
- AI 도구는 초안용, **나의 경험으로 차별화**하는 것이 핵심
