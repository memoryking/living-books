# 7장: 콘텐츠 캘린더 시스템 — 주 3회 게시로 매일 성장하기

## 매일 올려야 한다는 강박에서 벗어나기

"SNS를 성장시키려면 매일 올려야 하나요?"

가장 많이 받는 질문입니다. 답은 **"아니오"**입니다.

매일 올리다 지쳐서 포기하는 것보다, **주 3회를 1년간 꾸준히** 올리는 것이 100배 낫습니다. 핵심은 빈도가 아니라 **시스템**입니다.

이 장에서는 바쁜 1인 사업자도 실행 가능한 **콘텐츠 캘린더 시스템**을 만듭니다.

## 콘텐츠 캘린더란

콘텐츠 캘린더는 **언제, 어떤 콘텐츠를, 어디에 올릴지 미리 계획하는 시스템**입니다.

### 캘린더가 있으면 달라지는 것

| 캘린더 없이 | 캘린더와 함께 |
|---|---|
| "오늘 뭘 올리지?" 매일 고민 | 이번 주 콘텐츠가 이미 정해져 있음 |
| 영감이 없으면 게시 중단 | 계획대로 실행만 하면 됨 |
| 콘텐츠 유형이 편향됨 | 다양한 유형을 균형 있게 배분 |
| 80/20 법칙 무시 | 가치 80% + 홍보 20% 자동 유지 |
| 번아웃 → 포기 | 지속 가능한 루틴 |

## 주 3회 게시 시스템 설계

### 요일별 콘텐츠 유형 배분

| 요일 | 콘텐츠 유형 | 목적 | 예시 |
|---|---|---|---|
| **월요일** | 정보/교육형 | 가치 제공 (80%) | "~하는 법 5가지" |
| **수요일** | 스토리텔링/경험형 | 관계 형성 (80%) | "실제 사례로 본 ~" |
| **금요일** | 참여 유도/가벼운 콘텐츠 | 소통 (80%) + 가끔 홍보 (20%) | 투표, Q&A, 이벤트 |

> **포인트:** 3개 중 2-3개가 가치 제공, 4-5주에 1번 정도 홍보성 콘텐츠를 넣으면 80/20 법칙이 자연스럽게 유지됩니다.

### 콘텐츠 유형 매트릭스

다양성을 유지하려면 **콘텐츠 유형을 돌려가며** 사용하세요.

| 유형 | 형태 | 빈도 | 예시 |
|---|---|---|---|
| **리스트형** | 카드뉴스/캐러셀 | 월 2-3회 | "TOP 5", "3가지 방법" |
| **방법론** | 단계별 가이드 | 월 2회 | "A to Z 가이드" |
| **비포/애프터** | 변화 스토리 | 월 1-2회 | "3개월 전 vs 지금" |
| **질문/투표** | 참여형 | 월 2-3회 | "A vs B?", "어떻게 생각하세요?" |
| **일상/비하인드** | 스토리·릴스 | 월 2-3회 | 작업 과정, 일상 공유 |
| **고객 후기** | UGC 리포스트 | 월 1-2회 | 리뷰, 태그된 게시물 |

## 1개월 콘텐츠 캘린더 템플릿

### 월간 계획 (4주 기준)

| 주차 | 월 | 수 | 금 | 스토리 (매일 1개) |
|---|---|---|---|---|
| **1주** | 정보형 리스트 | 개인 경험담 | 질문/투표 | 일상 비하인드 |
| **2주** | 방법론 가이드 | 고객 사례 | 참여 유도 | 작업 과정 |
| **3주** | 정보형 리스트 | 트렌드 분석 | **홍보 콘텐츠** | Q&A 스토리 |
| **4주** | 방법론 가이드 | 비포/애프터 | 감사/커뮤니티 | 한 주 돌아보기 |

> **홍보 콘텐츠는 월 1-2회만.** 3주차 금요일에 배치한 이유는, 이때쯤이면 2주간 가치 콘텐츠로 신뢰가 쌓여 있기 때문입니다.

## 콘텐츠 제작 배치 시스템

### "한 번에 몰아서 만들기" 전략

매번 1개씩 만들면 비효율적입니다. **주 1회, 2-3시간을 투자해 1주일 치를 한 번에 만드세요.**

### 주말 콘텐츠 제작 루틴 (2시간)

| 시간 | 활동 |
|---|---|
| 0-20분 | 이번 주 콘텐츠 주제 3개 확정 |
| 20-40분 | 게시물 1 제작 (텍스트 + 이미지) |
| 40-60분 | 게시물 2 제작 |
| 60-80분 | 게시물 3 제작 |
| 80-100분 | 해시태그 세팅 + 캡션 최종 점검 |
| 100-120분 | 예약 발행 설정 (Meta Business Suite, 네이버 예약 발행 등) |

### 무료 예약 발행 도구

| 도구 | 지원 플랫폼 | 비용 |
|---|---|---|
| **Meta Business Suite** | 인스타그램, 페이스북 | 무료 |
| **네이버 블로그 예약 발행** | 네이버 블로그 | 무료 |
| **유튜브 스튜디오** | 유튜브 | 무료 |
| **TikTok 예약 게시** | 틱톡 (웹에서) | 무료 |
| **Buffer (무료 플랜)** | 다중 플랫폼 3개 | 무료 (월 10게시물) |
| **Later (무료 플랜)** | 인스타그램 중심 | 무료 (월 12게시물) |

## 콘텐츠 아이디어가 고갈되지 않는 시스템

### 아이디어 수집 파이프라인

"콘텐츠 아이디어가 없어요"라는 말이 나오는 이유는 **평소에 수집하지 않기 때문**입니다.

**아이디어 수집 습관 만들기:**

1. **메모 앱에 "콘텐츠 아이디어" 폴더** 만들기
2. 일상에서 떠오르는 아이디어 즉시 메모 (카카오톡 나에게 보내기 활용)
3. 팔로워 질문/댓글을 캡처해 폴더에 저장
4. 경쟁 계정의 반응 좋은 게시물 스크랩 (베끼기가 아닌 영감용)
5. 네이버 트렌드, 구글 트렌드에서 시즌 키워드 확인

### 무한 콘텐츠 아이디어 공식

하나의 주제에서 **최소 5개의 콘텐츠**를 만들 수 있습니다:

```
주제: "비타민D"
  → [리스트] 비타민D 부족 증상 5가지
  → [방법론] 비타민D 올바른 복용법 A to Z
  → [스토리] 비타민D로 달라진 고객 이야기
  → [비교] 비타민D2 vs D3, 뭐가 다를까?
  → [Q&A] 비타민D에 대한 오해와 진실
```

어떤 분야든 핵심 주제 10개만 있으면 **50개 이상의 콘텐츠**를 만들 수 있습니다.

### 시즌 콘텐츠 활용

한국의 시즌 이벤트를 미리 캘린더에 넣어두세요.

| 월 | 시즌 키워드 | 콘텐츠 방향 |
|---|---|---|
| 1월 | 신년, 새해 목표, 다이어트 | "올해 SNS 성장 목표 세우기" |
| 3월 | 봄, 새 학기, 꽃가루 | 시즌 맞춤 정보 |
| 5월 | 가정의 달, 어버이날 | 감성 콘텐츠 + 선물 추천 |
| 7-8월 | 여름 휴가, 더위 | 시즌 맞춤 정보 |
| 9월 | 추석, 가을 | 명절 관련 콘텐츠 |
| 11월 | 블랙프라이데이, 연말 준비 | 할인·이벤트 콘텐츠 |
| 12월 | 송년, 연말 결산 | 한 해 돌아보기 |

## 콘텐츠 재활용 시스템

3개월 전에 올렸던 콘텐츠를 **업데이트해서 다시 올려도** 됩니다. 팔로워의 80%는 3개월 전 게시물을 기억하지 못합니다.

### 재활용 방법

1. **디자인만 바꾸기** — 같은 내용, 새로운 비주얼
2. **데이터 업데이트** — 최신 수치로 갱신
3. **형태 전환** — 카드뉴스를 릴스로, 블로그 글을 쇼츠로
4. **시리즈화** — "~시리즈 Part 2"로 확장
5. **반응 좋은 게시물 강화** — 잘 된 콘텐츠를 더 깊이 다루기
