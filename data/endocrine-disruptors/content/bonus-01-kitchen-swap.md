# 보너스 1: 주방 완전 교체 가이드

## 플라스틱 → 유리/스테인리스/실리콘 교체 체크리스트

주방을 한 번에 바꾸려 하면 비용도, 노력도 부담됩니다. **우선순위에 따라 단계적으로** 진행하세요.

---

## 교체 우선순위

### 🔴 1순위: 열에 노출되는 것 (즉시 교체)

이것들은 환경호르몬 용출이 가장 많습니다. 가능하면 지금 바로 교체하세요.

| 기존 | → 교체 | 이유 |
|------|--------|------|
| 전자레인지용 플라스틱 용기 | → 유리 밀폐용기 | 열+플라스틱=대량 용출 |
| 코팅 벗겨진 논스틱 팬 | → 스테인리스 또는 주철 | PFAS 노출 |
| 플라스틱 국자/뒤집개 | → 나무 또는 스테인리스 | 열에 플라스틱 녹음 |
| 플라스틱 전기포트 | → 스테인리스 전기포트 | 끓는 물+플라스틱 |
| 플라스틱 밥솥 내솥 뚜껑 | → 제조사에 스테인리스 뚜껑 문의 | 증기+플라스틱 |

### 🟡 2순위: 음식과 직접 접촉하는 것 (1~3개월 내)

| 기존 | → 교체 | 이유 |
|------|--------|------|
| 플라스틱 도마 | → 나무 도마 | 칼질 시 미세플라스틱 발생 |
| 플라스틱 밀폐용기 (냉장 보관용) | → 유리 밀폐용기 | 산성 음식 보관 시 용출 |
| PVC 랩 | → 밀랍랩 또는 실리콘 뚜껑 | 프탈레이트 포함 가능 |
| 플라스틱 물병/텀블러 | → 스테인리스 물병 | 매일 사용, 누적 효과 |
| 플라스틱 컵/접시 | → 세라믹 또는 스테인리스 | 직접 접촉 |

### 🟢 3순위: 간접 접촉 (여유 있을 때)

| 기존 | → 교체 | 이유 |
|------|--------|------|
| 플라스틱 양념통 | → 유리 양념통 | 장기 보관 시 용출 가능 |
| 플라스틱 수납함 | → 교체 불필요 (음식 비접촉) | 급하지 않음 |
| 플라스틱 식기건조대 | → 스테인리스 | 미관+내구성 |
| 지퍼백 | → 실리콘 지퍼백 (Stasher 등) | 재사용 가능, 열 안전 |

## 정수기 선택 가이드

### 타입별 비교

| 정수기 타입 | PFAS | 미세플라스틱 | 중금속 | 월 비용 | 추천 |
|-----------|------|-----------|-------|--------|------|
| **직수형 RO (역삼투압)** | ◎ | ◎ | ◎ | 3~5만원 (렌탈) | 최고 성능 |
| **직수형 나노 필터** | ○ | ◎ | ○ | 2~4만원 (렌탈) | 가성비 |
| **정수형 (활성탄)** | △ | ○ | △ | 1~2만원 (필터) | 기본 |
| **피처형 (브리타 등)** | △ | △ | △ | 5천~1만원 (필터) | 최소 투자 |
| **수도꼭지 부착형** | △ | ○ | △ | 5천원 (필터) | 간편 |

### 선택 기준

1. **PFAS가 걱정된다면** → RO(역삼투압) 정수기
2. **미세플라스틱이 걱정된다면** → 나노 필터 이상
3. **예산이 제한적이라면** → 피처형이라도 없는 것보다 훨씬 나음
4. **어떤 정수기든** → **필터 교체 주기를 반드시 지키세요** (이것이 핵심)

### 정수기 관리 원칙

- 필터 교체 주기를 스마트폰 알림으로 설정
- 정수기 내부 살균 주기적으로 (6개월~1년)
- 오래 사용하지 않은 정수기는 물을 먼저 흘려보낸 후 사용
- 정수한 물은 스테인리스 또는 유리 용기에 보관

## 한국 시장 추천 제품 (카테고리별)

> 특정 브랜드를 광고하는 것이 아니라, 한국에서 구입 가능한 안전한 제품 유형을 안내합니다.

### 유리 밀폐용기
- **글라스락:** 한국 대표 유리 용기 브랜드, 내열유리, 다양한 크기
- **이케아 365+:** 가성비, 유리+대나무 뚜껑 옵션
- **코렐:** 내열 유리, 전자레인지/오븐 가능

### 스테인리스 조리도구
- **쿡셀:** 한국산 스테인리스 팬, 다양한 크기
- **피스탈:** 독일 브랜드, 한국 유통
- **해피콜 3중 바닥 스테인리스:** 중간 가격대

### 주철 팬
- **롯지(Lodge):** 미국산, 가성비 최고, 온라인 구입 용이
- **르크루제/스타우브:** 에나멜 코팅 주철, 고급

### 스테인리스 물병/텀블러
- **스탠리:** 보온보냉, 다양한 크기
- **락앤락 스테인리스:** 한국 브랜드, 가성비
- **클린캔틴:** 미국 브랜드, BPA-free 인증

### 나무 도마
- **히노끼(편백나무) 도마:** 항균성, 한국에서 인기
- **대나무 도마:** 경도 높음, 가성비
- **아카시아 도마:** 내구성 우수
