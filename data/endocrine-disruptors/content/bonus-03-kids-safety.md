# 보너스 3: 아이 용품 안전 체크리스트

## 원칙: 입에 닿는 것 > 피부에 닿는 것 > 공기로 접촉하는 것

아이 용품을 바꿀 때, 이 우선순위를 기억하세요. 모든 것을 한꺼번에 바꿀 수 없다면, **입에 들어가는 것부터** 시작하세요.

---

## 1. 젖병/빨대컵 — 안전한 소재 선택

### 소재별 안전도

| 소재 | 안전도 | 장점 | 단점 |
|------|--------|------|------|
| **유리** | ★★★★★ | 화학물질 용출 없음, 열탕소독 가능 | 깨질 위험 (실리콘 커버로 보완) |
| **PPSU** | ★★★★☆ | 경량, 내열성 우수, BPA/BPS 없음 | 플라스틱이지만 가장 안전한 종류 |
| **트라이탄 (Tritan)** | ★★★☆☆ | 경량, 내구성, BPA-free | EA(에스트로겐 활성) 논란 있음 |
| **PP (폴리프로필렌)** | ★★★☆☆ | 저렴, 경량 | 열탕 소독 시 미세플라스틱 방출 가능 |
| **실리콘** | ★★★★☆ | 유연, 안전, 떨어뜨려도 안 깨짐 | 단독 젖병으로는 드뭄 |

### 추천

- **최선:** 유리 젖병 + 실리콘 보호 커버 (Dr. Brown's, 쁘띠앤 등)
- **차선:** PPSU 젖병 (우텐실, 시밀락 등)
- **젖꼭지:** 실리콘 젖꼭지 (대부분 안전)
- **빨대컵 전환기:** 스테인리스 빨대컵 또는 실리콘 빨대

### 젖병 관리 원칙
- 열탕 소독보다 **UV 소독기**가 화학물질 용출 면에서 안전
- PP 젖병을 열탕 소독하면 미세플라스틱 방출 → PPSU나 유리로 교체 권장
- 젖병에 금이 가거나 변색되면 **즉시 교체**
- 전자레인지 소독은 피하기 (플라스틱 젖병의 경우)

## 2. 이유식/유아식 용기

### 안전한 이유식 용기

| 용도 | 추천 소재 | 제품 예시 |
|------|----------|----------|
| 이유식 보관 | 유리 밀폐용기 (소형) | 글라스락 미니, 이케아 365+ 소형 |
| 이유식 데우기 | 유리 또는 세라믹 | 전자레인지용 유리 용기 |
| 외출용 이유식 | 스테인리스 보온용기 | 써모스, 타이거 이유식 보온병 |
| 유아 식기 | 실리콘 흡착 식기 | 에즈피지, 먼치킨 등 식품용 실리콘 |
| 유아 수저 | 스테인리스 또는 나무 | 코모비 스테인리스, 대나무 수저 |

### 주의사항
- 이유식을 **플라스틱 용기에 넣고 전자레인지 돌리지 않기** (가장 중요)
- 멜라민 식기 → 60°C 이상에서 멜라민/포름알데히드 용출 → 뜨거운 음식 담지 않기
- 다이소 등 저가 플라스틱 식기 → KC 마크 확인, 가능하면 피하기

## 3. 장난감 선택 기준

### 안전한 장난감 vs 위험한 장난감

| 안전한 장난감 | 피해야 할 장난감 |
|-------------|---------------|
| 천연 나무 (무도장 또는 식물성 도료) | 부드러운 PVC 플라스틱 (프탈레이트) |
| 천연 고무 (치발기) | 강한 화학 냄새가 나는 장난감 |
| 식품용 실리콘 | 저가 수입 페인트 칠 장난감 (납) |
| 유기농 면 인형 | 폼(스펀지) 소재 (난연제) |
| 스테인리스 조리놀이 세트 | 슬라임, 퍼티 (붕사, 프탈레이트) |

### 장난감 구매 체크리스트

- [ ] **KC 마크** 확인 (한국 안전 인증)
- [ ] **CE 마크** 확인 (유럽 안전 기준, KC보다 엄격)
- [ ] 포장을 열었을 때 **강한 화학 냄새**가 나는지 확인
- [ ] 부드러운 플라스틱 장난감은 **PVC-free** 여부 확인
- [ ] 페인트 칠 장난감은 **식물성 도료** 또는 **EN71 인증** 확인
- [ ] 아이가 입에 넣을 가능성이 있는 크기인지 확인 (질식 위험 + 화학물질)

### 슬라임/점토 주의

슬라임은 아이들이 좋아하지만:
- 붕사(보레이트) 함유 → 피부 자극, 내분비교란 가능성
- 프탈레이트 포함 가능 (향 첨가 슬라임)
- PVA 기반 슬라임 자체보다 **첨가제가 문제**

**대안:** 밀가루 반죽, 천연 클레이, 밀랍 점토

## 4. 매트리스 — 안전한 수면 환경

아기는 하루 14~17시간을 잡니다. 매트리스와의 접촉 시간이 **하루 중 가장 깁니다.**

### 일반 매트리스의 문제
- 폴리우레탄 폼 → VOC 방출 (새 매트리스 냄새)
- 난연제 (PBDE, TDCPP 등) → 내분비교란
- 방수 커버 → PFAS 또는 PVC 코팅

### 안전한 매트리스 선택

| 기준 | 확인 사항 |
|------|----------|
| 소재 | 유기농 면, 천연 라텍스, 울 |
| 인증 | OEKO-TEX Standard 100, GOTS, GREENGUARD Gold |
| 난연제 | "Flame Retardant Free" 또는 천연 소재 난연 (울) |
| 방수 | PFAS-free 방수 커버 또는 유기농 면 방수 패드 |

### 현실적 대안 (예산 제한 시)
- 기존 매트리스에 **OEKO-TEX 인증 매트리스 커버** 씌우기
- 새 매트리스는 **환기 후 사용** (최소 3~7일 개봉 상태로 환기)
- 방수 매트리스 패드: 유기농 면 + TPU 코팅 (PVC/PFAS 대신)

## 5. 카시트 — 장시간 밀폐 공간

카시트는 아이가 장시간 밀착하는 제품이며, 차 안의 열로 인해 화학물질 방출이 증가합니다.

### 카시트 안전 등급

미국 Ecology Center의 "Healthy Stuff" 프로젝트에서 카시트 화학물질 등급을 발표합니다. 일반적으로:

**안전한 쪽:** UPPAbaby, Clek, Nuna (저독성 소재 사용 선언)
**주의:** 저가 카시트는 난연제, PVC, 중금속 함량이 높을 수 있음

### 카시트 관리 방법
- 차에 오래 주차할 때 → 카시트에 밝은 천을 덮어 온도 상승 방지
- 새 카시트 → **창문 열고 며칠 환기** 후 사용
- 카시트 커버 → 유기농 면 커버 교체 가능한 제품 선호
- 정기적으로 커버 세탁 (먼지 + 화학물질 축적 방지)

## 6. 아기 옷 — 입히기 전 반드시 세탁

### 새 옷에 있을 수 있는 화학물질
- **포름알데히드:** 구김 방지 가공
- **난연제:** 잠옷 등 (특히 미국 기준 제품)
- **염료 잔류물:** 아조 염료 등 일부 발암 의심
- **NPE (노닐페놀에톡실레이트):** 섬유 가공 보조제, 에스트로겐 모방

### 실천 방법

1. **새 아기 옷은 최소 2~3회 세탁 후 착용** (Fragrance-free 세제로)
2. **유기농 면 (GOTS 인증)** 선호
3. **중고 아기 옷도 좋은 선택** → 여러 번 세탁되어 화학물질 상당량 제거
4. **밝은 색 > 짙은 색** → 염료 잔류물이 적음
5. **"Iron-free" "Wrinkle-free" 표시 옷은 주의** → 포름알데히드 가공

### 추천 인증
- **OEKO-TEX Standard 100 Class 1** (영유아용 최고 기준)
- **GOTS (Global Organic Textile Standard)**
- **GOT (유기농 섬유 인증)**

## 연령별 핵심 체크리스트

### 0~6개월
- [ ] 유리/PPSU 젖병
- [ ] UV 소독기 (열탕 대신)
- [ ] 유기농 면 내의, 속싸개
- [ ] 오가닉 매트리스 또는 OEKO-TEX 커버
- [ ] 새 옷 세탁 후 착용

### 6~18개월
- [ ] 실리콘 흡착 식기
- [ ] 스테인리스 이유식 보관용기
- [ ] 천연 고무/실리콘 치발기
- [ ] 나무 장난감 (입에 넣는 크기)
- [ ] 외출용 스테인리스 물병

### 18개월~5세
- [ ] 스테인리스 빨대컵/물병
- [ ] 슬라임 대신 밀가루 반죽/천연 클레이
- [ ] 장난감 PVC/프탈레이트 확인
- [ ] 어린이집 도시락용기: 스테인리스
- [ ] 손 씻기 습관 (먼지 속 EDC 제거)

### 5세~초등학교
- [ ] 학교용 스테인리스 물병
- [ ] 도시락 용기: 스테인리스
- [ ] 학용품: 향 나는 지우개/마커 피하기
- [ ] 문구류: PVC-free 파일, 필통
- [ ] 손 씻기 후 식사 습관
