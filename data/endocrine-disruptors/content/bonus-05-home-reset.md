# 보너스 5: 가정 환경 리셋 체크리스트

## 방별 EDC 점검 가이드

집 전체를 한꺼번에 바꿀 필요는 없습니다. **방 하나씩, 주말 하나씩** 점검하세요. 이 가이드를 인쇄하거나 저장해두고 체크리스트로 활용하세요.

---

## 1. 주방 점검

주방은 환경호르몬 노출이 가장 큰 공간입니다. (자세한 내용은 Chapter 5, 보너스 1 참고)

### 체크리스트

**용기와 조리도구:**
- [ ] 전자레인지용 플라스틱 용기 → 유리/세라믹으로 교체
- [ ] 코팅 벗겨진 논스틱 팬 → 스테인리스/주철/세라믹 교체
- [ ] 플라스틱 국자, 뒤집개 → 나무/스테인리스/실리콘 교체
- [ ] 플라스틱 도마 → 나무 도마 교체
- [ ] PVC 랩 → 밀랍랩/실리콘 뚜껑/유리 밀폐용기

**음료:**
- [ ] 플라스틱 물병 → 스테인리스/유리 물병
- [ ] 플라스틱 전기포트 → 스테인리스 전기포트
- [ ] 정수기 필터 교체 상태 확인 (교체 주기 스마트폰 알림 설정)

**습관:**
- [ ] 전자레인지에 플라스틱 넣지 않기
- [ ] 뜨거운 음식 플라스틱에 담지 않기
- [ ] 캔 식품 → 유리병/냉동 대안 고려
- [ ] 포장째 전자레인지 돌리지 않기

---

## 2. 욕실 점검

욕실은 화장품과 세면도구를 통한 **피부 흡수** 노출이 큰 공간입니다.

### 체크리스트

**세면도구:**
- [ ] 샴푸 성분표에 "Fragrance" 확인 → Fragrance-free 제품 고려
- [ ] 바디워시 성분표에 "Fragrance" 확인 → Fragrance-free 또는 천연 비누
- [ ] 치약에 Triclosan 확인 → SLS-free 불소 치약
- [ ] 항균 비누(Antibacterial) → 일반 비누로 교체 (항균 성분 불필요)

**화장품:**
- [ ] 가장 자주 쓰는 3개 제품 → 화해 앱으로 성분 확인
- [ ] 선크림 → 미네랄(산화아연/이산화티타늄) 선크림 고려
- [ ] 데오도란트 → 알루미늄-free / Fragrance-free

**욕실 환경:**
- [ ] PVC 샤워커튼 → 면 또는 PEVA 소재 교체
- [ ] PVC 바닥 매트 → 천연 고무/면 매트
- [ ] 방향제/플러그인 디퓨저 → 제거 또는 환기로 대체
- [ ] 사용 후 환기 (습기+화학물질 농도 감소)

---

## 3. 침실 점검

하루 7~9시간을 보내는 공간입니다. 장시간 밀착 접촉이 일어납니다.

### 체크리스트

**침구:**
- [ ] 매트리스 커버 상태 확인 (찢어지거나 폼 노출 여부)
- [ ] 매트리스 커버 → OEKO-TEX 인증 커버 사용
- [ ] 베개 → 유기농 면/라텍스/메밀 베개 고려
- [ ] 이불 → 천연 소재 (면, 거위털, 울) 선호
- [ ] 침구 주 1회 세탁 (먼지 + 화학물질 축적 방지)

**의류:**
- [ ] 잠옷 소재 확인 → 면 또는 유기농 면
- [ ] 새 옷은 세탁 후 착용
- [ ] 옷장 방향제 (나프탈렌 등) → 삼나무 블록/라벤더 주머니

**환경:**
- [ ] 침실 방향제/향초 제거
- [ ] 취침 전 10분 환기
- [ ] 실내 식물 배치 (공기 정화 효과는 미미하지만, 습도 조절에 도움)
- [ ] 전자제품 최소화 (가열 시 PBDE 등 방출)

---

## 4. 거실 점검

### 체크리스트

**가구:**
- [ ] 소파 커버 상태 확인 (폼 노출 → 난연제 방출)
- [ ] 찢어진 소파 커버 → 교체 또는 보수
- [ ] 새 가구 구매 시 GREENGUARD/OEKO-TEX 인증 확인
- [ ] 2005년 이전 가구 → 난연제(PBDE) 함량 높을 수 있음

**바닥:**
- [ ] PVC 바닥재 → 기회가 되면 나무/타일로 교체
- [ ] 카펫 → 정기적으로 HEPA 진공청소기로 청소
- [ ] 오래된 카펫 (10년+) → 교체 고려 (PBDE + 먼지 축적)
- [ ] 러그 → 유기농 면/울 러그

**먼지 관리:**
- [ ] 주 2회 이상 물걸레질
- [ ] HEPA 필터 진공청소기 사용
- [ ] TV, 컴퓨터 등 전자제품 뒤쪽 먼지 정기 청소
- [ ] 잡동사니 정리 (먼지 쌓이는 표면 줄이기)

---

## 5. 세탁실/다용도실 점검

### 체크리스트

**세제:**
- [ ] 세탁 세제 → Fragrance-free 제품 교체
- [ ] 섬유유연제 → 제거 또는 식초로 대체
- [ ] 표백제 → 산소계 표백제 (과탄산소다)
- [ ] 건조기 시트 → 양모 드라이어볼

**세탁 습관:**
- [ ] 합성섬유 세탁 시 미세섬유 세탁망 사용
- [ ] 세탁 온도 낮추기 (30°C 세탁 → 미세섬유 방출 감소)
- [ ] 세탁 빈도 합리화 (꼭 세탁 필요할 때만)
- [ ] 새 합성섬유 옷 → 첫 세탁 시 미세섬유 세탁망 필수 (가장 많이 방출)

---

## 세탁 시 미세플라스틱 줄이기 — 상세 가이드

세탁은 미세플라스틱의 주요 발생원입니다. 합성섬유 옷 한 번 세탁에 **수십만~수백만 개의 미세섬유**가 방출됩니다.

### 미세섬유 방출 줄이는 5가지 방법

**1. 미세섬유 포집 세탁망 사용**
- Guppyfriend 세탁백 (가장 많이 연구됨, 효과 검증)
- 미세섬유 필터 볼
- 세탁기 외부 부착 필터 (Lint LUV-R 등)

**2. 저온 세탁**
- 30°C 이하 찬물 세탁 → 섬유 손상 감소 → 미세섬유 방출 감소
- 뜨거운 물은 섬유를 풀어서 더 많은 미세섬유 방출

**3. 부드러운 세탁 모드**
- 울/섬세 모드 → 마찰 감소 → 미세섬유 감소
- 최대 탈수 회전수 낮추기

**4. 세탁 시간 단축**
- 짧은 세탁 프로그램 사용
- 긴 세탁 시간 = 더 많은 마찰 = 더 많은 미세섬유

**5. 세탁 빈도 줄이기**
- 한 번 입었다고 바로 세탁하지 않기 (속옷, 양말 제외)
- 바람에 말리기, 스팀 다리미로 냄새 제거
- 현실적으로 필요할 때만 세탁

## 환기·청소·먼지 관리 종합 가이드

### 환기 원칙

| 상황 | 환기 방법 | 시간 |
|------|----------|------|
| 기본 (매일) | 아침, 점심, 저녁 창문 열기 | 각 10분 |
| 요리 후 | 레인지후드 + 창문 | 15분 |
| 청소 후 | 창문 활짝 | 15분 |
| 새 가구/전자제품 | 며칠간 집중 환기 | 가능한 길게 |
| 세제/화학제품 사용 후 | 즉시 환기 | 15~30분 |
| 미세먼지 높은 날 | 공기청정기 가동 + 짧게 환기 | 5분 |

### 청소 원칙

1. **물걸레 > 마른걸레 > 진공청소기** (먼지 제거 효율 순서)
2. **HEPA 필터 진공청소기** 사용 (미세 먼지/EDC 포집)
3. **주 2회 이상** 물걸레질
4. **전자제품 뒤쪽, 가구 아래** 먼지 월 1회 제거
5. **세제:** Fragrance-free, 식초+베이킹소다도 효과적
6. **청소 후 반드시 환기**

### 먼지 관리의 핵심

- **신발은 현관에서 벗기** → 외부 화학물질 유입 80% 감소
- **잡동사니 줄이기** → 먼지 쌓이는 표면 감소
- **침구, 커튼 정기 세탁** → 먼지+EDC 축적 방지
- **반려동물이 있다면** → 더 자주 청소 (동물 털에 먼지+EDC 부착)
- **아이가 바닥에서 논다면** → 바닥 청소 빈도 높이기

## 계절별 점검 스케줄

### 봄 (3~5월)
- [ ] 겨울 동안 밀폐된 실내 → **대대적 환기**
- [ ] 겨울 옷 세탁 후 보관 (먼지+화학물질 축적 제거)
- [ ] 에어컨 필터 청소/교체 (여름 전 준비)
- [ ] 봄 대청소: 먼지가 많이 쌓인 곳 집중 청소
- [ ] 정수기 필터 교체 상태 확인

### 여름 (6~8월)
- [ ] 에어컨 사용 중에도 **하루 2회 이상 환기**
- [ ] 차 안에 플라스틱 물병 두지 않기 (고온 = 대량 용출)
- [ ] 선크림 성분 확인 (미네랄 선크림으로)
- [ ] 벌레 기피제: DEET-free 대안 고려
- [ ] 에어컨 제습으로 곰팡이 방지

### 가을 (9~11월)
- [ ] 여름 동안 사용한 에어컨 필터 청소
- [ ] 난방 시작 전 보일러/히터 필터 청소
- [ ] 가을 대청소: 카펫, 러그 세탁
- [ ] 침구 교체 시 소재 확인 (유기농 면, OEKO-TEX)
- [ ] 정수기 필터 교체 상태 확인

### 겨울 (12~2월)
- [ ] 난방으로 밀폐된 실내 → **환기 잊지 않기** (가장 중요한 계절)
- [ ] 가습기 사용 시 → 수돗물(끓인 물) 사용, 정기 청소
- [ ] 실내 건조 → 자연 보습 (빨래 실내 건조, 식물)
- [ ] 새해 점검: 주방 용기, 세면도구 교체 진행 상황 확인
- [ ] 정수기 필터 교체 상태 확인

## 전체 가정 리셋 — 12주 플랜

한 번에 모든 것을 바꾸려 하면 지칩니다. **12주(3개월)에 걸쳐 점진적으로** 진행하세요.

| 주차 | 할 일 | 예상 비용 |
|------|-------|----------|
| **1~2주** | 주방 플라스틱 용기 점검, 유리 밀폐용기 구입 | 2~4만원 |
| **3~4주** | 논스틱 팬 상태 확인, 필요시 교체 | 3~8만원 |
| **5~6주** | 욕실 세면도구 성분 확인, 다 쓴 것부터 교체 | 1~3만원 |
| **7~8주** | 세탁 세제 교체, 미세섬유 세탁망 구입 | 1~2만원 |
| **9~10주** | 침실 점검: 매트리스 커버, 침구 소재 | 2~5만원 |
| **11~12주** | 거실 점검: 먼지 관리, 환기 습관 정착 | 0원 |

**총 예상 비용: 9~22만원 (3개월에 걸쳐)**

이것으로 가정 내 환경호르몬 노출의 **80% 이상을 줄일 수 있습니다.**

## 마지막 점검: 가정 환경 리셋 완료 확인

모든 것을 완료했다면, 다음을 확인하세요:

- [ ] 전자레인지에 플라스틱을 넣지 않는 습관이 잡혔다
- [ ] 스테인리스/유리 물병을 매일 사용하고 있다
- [ ] 세면도구에서 "Fragrance" 없는 제품을 쓰고 있다
- [ ] 주 2~3회 이상 환기하고 있다
- [ ] 신발을 현관에서 벗고 있다
- [ ] 물걸레질을 정기적으로 하고 있다
- [ ] 정수기 필터를 제때 교체하고 있다

**7개 중 5개 이상 체크했다면, 당신은 이미 충분히 잘하고 있습니다.**

> 완벽할 필요 없습니다. **80%면 충분합니다.**
