# 보너스 4: 세면도구/화장품 교체 가이드

## 교체 원칙: 다 쓰면 바꾸기

지금 쓰고 있는 제품을 당장 버릴 필요는 없습니다. **다 쓰면 다음 제품을 살 때** 더 나은 선택을 하면 됩니다. 이 방법이 경제적으로도, 심리적으로도 지속 가능합니다.

---

## 제품별 안전한 대안

### 샴푸

**피해야 할 성분:**
- Fragrance / Parfum
- DMDM Hydantoin (포름알데히드 방출)
- Methylisothiazolinone (MI) — 강한 알레르기 유발
- Sodium Lauryl Sulfate (SLS) — 자극성 (환경호르몬은 아니지만 피부 장벽 손상)

**안전한 선택 기준:**
- "Fragrance-free" 표시
- EWG 1~2등급 제품
- 유기농 인증 (COSMOS, ECOCERT)

**한국 시장 대안:**
- 닥터브로너스 캐스틸 솝 (바디+샴푸 겸용)
- 아로마티카 로즈마리 샴푸 (EWG 그린등급)
- 라보에이치 (무향 라인)
- 이솝 (Fragrance 포함이지만 에센셜 오일 기반)

### 바디워시

**피해야 할 성분:**
- Fragrance / Parfum
- Triclosan (항균 표시 제품)
- Parabens

**안전한 선택:**
- 무향 바디워시
- 캐스틸 비누 (올리브유 기반)
- 천연 바 비누 (고체 비누)

**한국 시장 대안:**
- 닥터브로너스 무향 캐스틸 솝
- CeraVe 바디워시 (Fragrance-free)
- 무인양품 무향 바디소프
- 수제 천연비누 (동네 비누 공방 제품)

### 로션/보습제

**피해야 할 성분:**
- Fragrance / Parfum
- BHA / BHT
- Parabens
- Oxybenzone (선크림 겸용 로션)

**안전한 선택:**
- Fragrance-free 보습제
- 세라마이드 기반 제품
- 시어버터, 호호바 오일 등 천연 오일

**한국 시장 대안:**
- CeraVe 모이스처라이징 크림 (Fragrance-free)
- 아토팜 MLE 크림
- 라로슈포제 시카플라스트
- 순수 시어버터 또는 코코넛 오일 (1성분 제품)

### 선크림

**피해야 할 성분 (화학적 자외선 차단제):**
- Oxybenzone — 에스트로겐 모방
- Octinoxate — 에스트로겐 모방
- Homosalate — 내분비교란 가능성
- Octocrylene — 알레르기 + 벤조페논 생성

**안전한 선택 (물리적/미네랄 자외선 차단제):**
- **산화아연 (Zinc Oxide)** — 가장 안전
- **이산화티타늄 (Titanium Dioxide)** — 안전 (나노입자 흡입 논란은 있으나, 피부 도포 시 안전)

**한국 시장 대안:**
- 라로슈포제 앙뗄리오스 미네랄 라인
- 닥터지 그린 마일드 업 선
- 아이소이 선크림 (미네랄 기반)
- 마더케이 순한 선크림 (아기용, 산화아연 100%)

### 데오도란트

**피해야 할 성분:**
- Aluminum compounds (알루미늄) — 내분비교란 논란
- Fragrance / Parfum
- Triclosan
- Parabens

**안전한 선택:**
- 미네랄 (알룸) 데오도란트 — 논란이 있지만 기존 알루미늄보다 안전한 편
- 베이킹소다 기반 천연 데오도란트
- 무향 데오도란트

**한국 시장 대안:**
- 크리스탈 바디 데오도란트 (미네랄)
- 닥터브로너스 유기농 데오도란트
- Native 데오도란트 (알루미늄-free)

### 치약

**피해야 할 성분:**
- Triclosan — 갑상선 교란 (대부분 퇴출되었지만 확인)
- SLS (Sodium Lauryl Sulfate) — 구내염 유발 가능
- 인공 향료, 색소

**안전한 선택:**
- 불소(Fluoride)는 **포함하는 것이 좋음** (충치 예방. 불소 = 환경호르몬 아님)
- SLS-free 치약
- 무향료 또는 에센셜 오일 향

**한국 시장 대안:**
- 2080 퓨어 (SLS-free 라인)
- 닥터노아 대나무 치약
- 데이비즈 (Tom's of Maine 한국판)

## "Unscented" vs "Fragrance-free" 상세 비교

이 차이는 매우 중요합니다:

### Unscented (무향)
- **의미:** 제품에서 향이 나지 않음
- **실제:** 원재료의 냄새를 중화시키기 위해 **향을 차폐하는 화학물질(masking fragrance)**이 추가될 수 있음
- **성분표:** "Fragrance"가 여전히 포함되어 있을 수 있음
- **안전도:** ⚠️ Fragrance-free보다 덜 안전할 수 있음

### Fragrance-free (무향료)
- **의미:** 향을 내기 위한 성분이 **전혀 사용되지 않음**
- **실제:** 원재료 자체의 약한 냄새는 있을 수 있음 (하지만 향료 미첨가)
- **성분표:** "Fragrance" 항목이 없음
- **안전도:** ✅ 프탈레이트 등 향료 관련 화학물질 노출 없음

**결론: 항상 "Fragrance-free"를 선택하세요.**

## 성별 맞춤 추천

### 여성

여성은 평균적으로 남성보다 **더 많은 개인 관리 제품**을 사용합니다. EWG에 따르면 여성은 하루 평균 12개 제품, 남성은 6개 제품을 사용합니다.

**우선 교체 순서:**
1. **바디로션/바디워시** → 전신 면적, 매일 사용
2. **선크림** → 매일 사용, 화학적→미네랄
3. **샴푸/컨디셔너** → 매일 사용
4. **파운데이션/베이스** → 얼굴 전체, 장시간
5. **립 제품** → 경구 섭취 가능성

**TIP:** 메이크업 제품 수를 줄이는 것 자체가 노출 감소. "노 메이크업" 또는 "미니멀 메이크업" 트렌드는 피부 건강에도 이롭습니다.

### 남성

남성 제품도 "Fragrance"가 흔합니다. 특히 애프터쉐이브, 향수, 데오도란트.

**우선 교체 순서:**
1. **바디워시** → 매일 사용, 넓은 면적
2. **데오도란트** → 겨드랑이 흡수율 높음
3. **쉐이빙 크림/애프터쉐이브** → 면도 후 미세 상처에 흡수
4. **샴푸** → 매일 사용
5. **향수/콜로** → 사용 빈도에 따라

## DIY 대안

시판 제품 대신 집에서 만들 수 있는 간단한 대안:

### 올인원 클렌저: 캐스틸 비누
- 닥터브로너스 캐스틸 솝 1병이면 바디워시, 샴푸, 세안, 세제까지
- 물로 희석해서 사용 (비용 절약)

### 데오도란트: 베이킹소다 + 코코넛 오일
- 베이킹소다 2큰술 + 코코넛 오일 2큰술 + 콘스타치 2큰술
- 소량씩 겨드랑이에 바르기
- 민감 피부는 베이킹소다 비율 줄이기

### 헤어 린스: 식초
- 사과식초 1큰술 + 물 1컵
- 샴푸 후 헹굼 단계에서 사용
- 머릿결 부드럽게, 두피 pH 조절

### 얼굴 보습: 순수 오일
- 호호바 오일 — 피지와 구조 유사, 모든 피부타입
- 아르간 오일 — 건성 피부
- 로즈힙 오일 — 흉터/색소침착 관리
- 코코넛 오일 — 바디 보습 (얼굴에는 모공 막힘 주의)

### 치약 대안: 베이킹소다
- 베이킹소다를 물에 살짝 적셔 칫솔에 묻혀 사용
- 맛이 좋지 않지만 세정력은 우수
- 주 1~2회만 (연마력이 강하므로 매일은 비추천)
- **불소가 포함되지 않으므로, 주 치약으로는 불소 치약을 사용하세요**
