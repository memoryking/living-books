# 복사해 쓰는 매트릭스 실행 키트

이 부록은 바로 출력해서 쓸 수 있는 실전 도구 모음이다. 읽기만 하지 말고, 실제로 사용하라. 가장 효과적인 사용법은 출력해서 눈에 보이는 곳에 두는 것이다.

---

## 1. 아이젠하워 매트릭스 체크리스트

### 셋업 단계 (1일차)
- [ ] 매트릭스 양식 출력 또는 노트에 그리기
- [ ] 아침 리추얼 시간 결정 (출근 전/출근 직후/출근길)
- [ ] 스마트폰 불필요한 알림 끄기
- [ ] 캘린더에 Q2 시간 블록 최소 3개 등록
- [ ] 포모도로 타이머 준비 (앱 또는 물리적 타이머)

### 일일 리추얼 단계 (매일)
- [ ] 브레인 덤프 완료 (3분)
- [ ] 사분면 분류 완료 (4분)
- [ ] Q1 + Q2 캘린더 스케줄링 (4분)
- [ ] Q3 배칭/위임 계획 (2분)
- [ ] Q4 제거 또는 제한 (2분)

### 실행 단계 (매일)
- [ ] Q1 최우선 업무 완료
- [ ] Q2 시간 블록 사수 (최소 1블록)
- [ ] Q3 배칭 시간에 일괄 처리 (이메일, 카톡)
- [ ] Q4 의도적 휴식만 허용

### 모니터링 단계 (주간)
- [ ] 주간 리뷰 30분 완료
- [ ] 사분면 비율 추정 기록
- [ ] Q1 위기 예방 가능 여부 분석
- [ ] Q2 진척도 확인
- [ ] 다음 주 설계 완료

### 트러블슈팅 단계 (필요시)
- [ ] 2분 버전으로 즉시 복귀 (리추얼 중단 시)
- [ ] "하나만 한다면" 테스트 (모든 게 Q1일 때)
- [ ] 환경 리셋 (습관 흐려질 때)
- [ ] 생존 모드 전환 (에너지 바닥일 때)

## 4. 사분면별 업무 예시표 (한국 직장인 기준)

### Q1: 소방서 (지금 당장 해야 하며 정말 중요한 일)
| 업무 영역 | 예시 |
|---|---|
| 보고/발표 | 내일 임원 보고 자료 최종 수정 |
| 고객 관리 | 주요 고객 긴급 클레임 대응 |
| 시스템 | 서비스 장애 복구 |

| 법/규제 | 감사 자료 제출 기한 당일 |

### Q2: 성공 존 (중요하지만 아직 급하지 않은 일)
| 업무 영역 | 예시 |
|---|---|
| 전략 | 분기 사업 계획 수립 |
| 역량 개발 | 파이썬/SQL 학습, 자격증 공부 |
| 프로세스 | 반복 업무 자동화 구축 |

| 재정 | 투자 포트폴리오 점검, 연금 관리 |

## 5. "우아하게 거절하기" 스크립트 5가지

### 스크립트 1: 시간 대안 제시형
**상황:** 동료가 지금 당장 도움을 요청할 때
> "지금은 [현재 업무]에 집중하고 있어서요. [구체적 시간] 이후에 도와드려도 괜찮으실까요? 그때 제대로 도와드릴 수 있을 것 같습니다."

### 스크립트 2: 우선순위 확인형 (상사용)
**상황:** 팀장/부서장이 추가 업무를 지시할 때
> "네, 하겠습니다. 다만 현재 [A 업무]와 [B 업무]가 진행 중인데요, 이 업무를 먼저 하려면 어느 것의 마감을 조정해도 될까요? 우선순위를 정해주시면 가장 중요한 것부터 하겠습니다."

### 스크립트 3: 대안 인물 추천형
**상황:** 내가 아닌 다른 사람이 더 적합한 업무일 때
> "이 부분은 [OO씨/OO팀]이 더 전문이실 것 같아요. 직접 연결해드릴까요? 제가 하는 것보다 더 좋은 결과가 나올 거예요."

### 스크립트 4: 범위 축소형
**상황:** 전체를 거절하기 어려울 때
> "전체를 다 맡기는 현재 일정상 어렵지만, [구체적 부분]은 제가 도와드릴 수 있어요. 나머지 부분은 [대안]을 활용하시는 건 어떨까요?"

### 스크립트 5: 프로세스 제안형
**상황:** 같은 종류의 요청이 반복될 때
> "이런 요청이 꽤 자주 있는 것 같은데요, 매주 [요일]에 모아서 처리하는 시간을 만들면 어떨까요? 그러면 더 체계적으로 도와드릴 수 있을 것 같습니다."

## 8. FAQ 10선

**Q1. 매트릭스 분류가 헷갈립니다. Q2인지 Q3인지 어떻게 구분하나요?**

핵심 질문: "이것이 나의 장기적 성장, 목표, 가치에 직접 기여하는가?" 기여한다면 Q2, 기여하지 않는다면 Q3이다. 여전히 헷갈리면 "1년 후에 이것을 한 것이 의미가 있을까?"를 물어보라.

**Q2. 상사가 시키는 일은 전부 Q1 아닌가요?**

아니다. 상사가 "급하다"고 해도 그것이 당신의 핵심 업무가 아니라면 Q3이다. 물론 상사의 지시를 무시할 수는 없다. 하지만 우선순위 확인 스크립트를 사용하여 조율할 수 있다.

**Q3. 모든 일이 급한 날에는 매트릭스가 소용없지 않나요?**

아니다. 그런 날일수록 매트릭스가 필요하다. "모든 것이 급하다"는 것은 "우선순위가 없다"는 뜻이다. "하나만 한다면" 테스트로 강제로 순서를 정하라.

**Q4. 아이가 있는데 아침에 15분 확보가 불가능합니다.**

출근길 대중교통에서 5분이면 된다. 2분 버전(오늘의 Q1 하나, Q2 하나만 적기)으로 시작하라. 완벽한 15분이 아니어도 2분이 0분보다 낫다.

**Q5. 종이가 좋나요, 앱이 좋나요?**

처음 30일은 종이를 추천한다. 손으로 쓰는 행위가 분류를 더 신중하게 만든다. 시스템이 익숙해진 후에 노션이나 앱으로 전환하라.

**Q6. 직장 상사가 카톡 즉답을 요구하는데 어떻게 하나요?**

집중 시간에 카톡 상태 메시지를 변경하라: "집중 업무 중 (OO시까지). 급하신 분은 전화 주세요." 정말 급한 사안이면 전화가 온다. 카톡으로 오는 것은 대부분 30분-1시간 뒤에 답해도 문제없다. 한 번 시도해보라.

**Q7. 주간 리뷰를 자꾸 건너뛰게 됩니다.**

리뷰를 좋아하는 카페에서 좋아하는 음료와 함께 하라. 보상과 연결하면 지속 가능성이 높아진다. 또는 같이 하는 동료를 찾아라. "금요일 4시에 같이 주간 정리 하자"고 제안해보라.

**Q8. 위임할 사람이 없습니다. 1인 기업/프리랜서입니다.**

사람에게 위임할 수 없다면 시스템에 위임하라. 반복 업무를 자동화하고, 템플릿을 만들고, 도구를 활용하라. 또한 외주(크몽, 탈잉 등)를 활용할 수 있는 Q3 업무가 없는지 점검하라.

**Q9. 매트릭스를 시작했는데 3주째 효과를 못 느끼겠습니다.**

정상이다. 사분면 2의 효과는 최소 2-3개월 후에 나타난다. 지금 중요한 것은 효과를 느끼는 것이 아니라 시스템을 유지하는 것이다. 90일을 채워라. 반드시 차이를 느끼게 된다.

**Q10. 번아웃 상태인데 매트릭스를 시작해도 되나요?**

번아웃 상태에서는 매트릭스를 풀 버전으로 시작하지 마라. 먼저 회복이 필요하다. "해야 하는 것"과 "안 해도 되는 것" 두 가지로만 분류하는 생존 모드부터 시작하라. 체력과 정신력이 회복된 후에 본격적으로 도입하라. 필요하면 전문가의 도움을 받아라.
