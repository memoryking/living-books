# 부록. 복사해 쓰는 스레드 실행 키트

### 부록 A. 첫 줄 훅 템플릿 30

괄호를 내 주제로 바꿔 쓰세요. 유형별 5개씩이에요.

**숫자 선언형**
1. "(기간) 동안 (행동)하고 알게 된 (숫자)가지"
2. "(주제) 초보가 가장 많이 하는 실수 (숫자)개"
3. "(금액/성과)을 만든 건 거창한 게 아니라 이 (숫자)가지 습관이었어요"
4. "(주제)에서 상위 10%만 아는 (숫자)가지 기준"
5. "(숫자)년 차가 신입에게 꼭 해 주고 싶은 말 (숫자)가지"

**의외성/반전형**
6. "(상식적 행동)을 그만두고 나서 오히려 (좋은 결과)가 생겼어요"
7. "다들 (A)가 중요하다는데, 해 보니 진짜는 (B)였어요"
8. "(주제), 열심히 할수록 망하는 이유가 있어요"
9. "저는 (모두가 하는 것)을 안 합니다"
10. "(비싼 것) 없이도 (결과)가 되더라고요"

**실패 고백형**
11. "(기간) 동안 (돈/시간)을 날리고 배운 것"
12. "어제 (실수)를 저질렀습니다. 같은 실수 하지 마시라고 공유해요"
13. "(주제) 시작하고 제일 후회하는 결정 하나"
14. "솔직히 말할게요. 저 (기간) 동안 성과 0이었어요"
15. "그때 누가 이 말을 해 줬다면 (손실)은 없었을 거예요"

**질문 직격형**
16. "혹시 (상황)일 때 어떻게 하세요?"
17. "(주제) 하시는 분들, (구체적 고민) 저만 그런가요?"
18. "만약 (금액/시간)이 생기면 (주제)에서 뭐부터 하실 건가요?"
19. "(A)와 (B), 여러분은 어느 쪽이에요?"
20. "(주제)에서 딱 하나만 남긴다면 뭘 남기시겠어요?"

**손해 회피형**
21. "이거 모르고 (행동)하면 (구체적 손해)까지 갈 수 있어요"
22. "(주제)에서 절대 하면 안 되는 것 하나만 꼽으라면"
23. "(기한) 전에 확인 안 하면 손해 보는 것들"
24. "많이들 놓치는 (혜택/기능), 아직 안 늦었어요"
25. "(가격) 아끼려다 (더 큰 비용) 쓴 이야기"

**경험 티저형**
26. "오늘 (큰 사건)이 있었습니다"
27. "드디어 (목표)를 해냈어요. 과정을 공유합니다"
28. "(기간) 전의 저에게 편지를 쓴다면"
29. "이 글은 (특정 상황인 분)만 보세요"
30. "(주제)를 시작한 지 정확히 (기간) 됐습니다. 중간 결산해요"

### 부록 B-2. 일요일 주간 회고 템플릿

매주 일요일 10분, 아래 다섯 칸만 채우세요. 회고 글의 재료이자 데이터 리뷰예요.

- **이번 주 발행 수**: ___개 (목표 대비 ___%)
- **가장 반응 좋았던 글**: 제목/유형/첫 줄에 쓴 장치: ______
- **가장 반응 없었던 글**: 무엇이 달랐나: ______

이 다섯 줄이 쌓이면 그게 내 계정의 공략집이 돼요. 아무리 바빠도 이 10분은 지키세요.

### 부록 C. 주제별 글감 아이디어 60

어느 주제든 아래 질문에 답하면 글이 돼요. 12개 질문 × 5각도로 쓰면 60개예요.

1. 내 주제를 시작한 계기는? (과거의 나 / 전환점 / 첫 시도 / 첫 실패 / 첫 성공)
2. 초보가 가장 먼저 알아야 할 것은? (개념 / 도구 / 순서 / 예산 / 시간)
3. 가장 흔한 오해는? (통념 / 과장 광고 / 미신 / 잘못된 순서 / 불필요한 소비)
4. 내가 쓰는 도구·앱·서비스는? (최애 / 무료 대안 / 돈값 하는 것 / 산 것 중 후회 / 조합법)
5. 오늘 실행한 것과 결과는? (숫자 / 느낀 점 / 예상과 다른 점 / 다음 실험 / 교훈)
6. 자주 받는 질문과 답은? (질문 5개면 글 5개)
7. 내 주제의 하루/일주일 루틴은? (아침 / 저녁 / 주말 / 슬럼프 때 / 바쁠 때)
8. 절대 하지 말라고 말리고 싶은 것은? (돈 / 시간 / 관계 / 건강 / 멘탈 관점에서)
9. 최근 배운 것 중 충격이었던 것은? (책 / 영상 / 사람 / 실패 / 데이터에서)
10. 시작 전으로 돌아가면 바꿀 것은? (순서 / 예산 / 도구 / 마인드 / 사람)
11. 내 주제에서 돈이 오가는 지점은? (아끼는 법 / 버는 법 / 사기 유형 / 적정 가격 / 무료로 하는 법)
12. 남들과 다른 내 관점은? (반대하는 통념 / 나만의 기준 / 포기한 것 / 지키는 원칙 / 예측)

### 부록 E. 자주 묻는 질문

**Q1. 익명으로 해도 정말 되나요?** 네. 스레드에는 익명·부캐 계정이 많고, 신뢰는 얼굴이 아니라 글의 일관성에서 나와요. 다만 서비스·코칭(8챕터 길 3)으로 확장할 때는 어느 정도의 신원 공개가 신뢰에 도움이 돼요.

**Q2. 하루에 몇 개를 올려야 하나요?** 기본은 1개, 최대 2~3개예요. 개수보다 매일이 중요하고, 무리한 다발행은 품질과 멘탈을 갉아먹어요.

**Q3. 글이 하나도 안 터져요. 재능이 없는 걸까요?** 터지는 글은 확률 게임이에요. 검증된 운영자들도 타율은 10~20%대예요. 30개는 발행해 보고 판단하세요. 그 전까지의 성적은 데이터 수집 비용이에요.

**Q4. 맞팔 이벤트라도 해야 하지 않을까요?** 비추천이에요. 맞팔 팔로워는 반응하지 않는 유령이 되고, 반응률이 낮아지면 알고리즘 평가만 나빠져요.

**Q5. 인스타·블로그를 이미 하고 있는데 스레드를 또 해야 하나요?** 기존 채널이 있다면 오히려 유리해요. 7챕터의 재가공 흐름을 거꾸로 쓰면 되니까요. 다만 첫 4주는 스레드의 문법(대화체, 솔직함)에 적응하는 데 집중하세요. 인스타 말투 복붙은 잘 안 통해요.

**Q6. 계정이 어느 날 제한·정지되면 어떡하죠?** 그래서 7챕터의 자산 분산이 보험이에요. 커뮤니티 가이드라인(스팸성 반복 행동, 과도한 팔로우/언팔로우 등)을 지키는 게 기본이고, 명단(뉴스레터·오픈채팅)이 최후의 방어선이에요.

### 부록 F. 스레드 용어 미니 사전

- **훅(Hook)**: 스크롤을 멈추게 하는 첫 줄 장치. 숫자·질문·의외성·고백 등.
- **타래**: 글 하나에 여러 글을 이어 붙이는 연재 형식. 체류 시간을 늘린다.
- **리포스트**: 남의 글을 내 팔로워에게 공유. **인용**은 내 코멘트를 얹은 공유.
- **도달(리치)**: 글이 노출된 사람 수. 조회수와 함께 기회의 크기를 보여 주는 지표.
- **반응률**: 조회 대비 반응(좋아요·답글·리포스트)의 비율. 글의 실력 지표.
- **비팔로워 노출**: 나를 팔로우하지 않는 사람에게 추천 피드로 노출되는 것. 성장의 엔진.
- **골든타임**: 내 팔로워층이 가장 활발한 발행 시간대. 데이터 실험으로 찾는다.
- **주제 기둥(필러)**: 계정이 반복해서 다루는 3개 안팎의 하위 주제.
- **원 소스 멀티 유즈(OSMU)**: 하나의 소재를 여러 플랫폼 형식으로 재가공하는 전략.
- **리메이크**: 반응이 검증된 과거 글을 형태를 바꿔 다시 발행하는 것.
- **단골(코어 팬)**: 반복적으로 반응하는 소수의 팔로워. 확산의 시동 모터.
- **품앗이(엔게이지먼트 그룹)**: 서로 반응을 몰아 주는 인위적 그룹. 장기적으로 계정을 해친다.
- **어그로**: 자극적 내용으로 관심을 끄는 행위. 구경꾼은 모아도 고객은 못 모은다.
- **CTA(행동 유도)**: 글 끝에서 답글·팔로우·클릭 등 행동을 청하는 문장.
- **인사이트**: 플랫폼이 제공하는 계정·게시물 통계 화면.
- **표시광고법 표기**: 대가를 받은 콘텐츠에 협찬·광고임을 밝히는 법적 의무 표기.

**Q7. 사진이나 영상을 꼭 넣어야 하나요?** 필수는 아니에요. 스레드는 텍스트만으로 충분히 확산돼요. 다만 인증·기록형 콘텐츠(가계부, 요리, 운동)는 사진 한 장이 신뢰를 크게 올려요. 넣는다면 글의 증거가 되는 사진 1장이 장식용 여러 장보다 나아요.

**Q8. 여러 계정을 동시에 운영해도 되나요?** 첫 90일은 한 계정만 추천해요. 계정 두 개는 노력이 2배가 아니라 4배 들어요(콘텐츠 2배, 참여 2배). 첫 계정이 유지 모드로 돌아갈 만큼 시스템화된 뒤에 두 번째를 고민하세요.

**Q9. 나이가 많은데(50대+) 너무 늦지 않았나요?** 오히려 기회예요. 스레드의 주 사용자층이 2040이라는 건, 5060의 경험담이 희소하다는 뜻이거든요. "30년 직장 생활에서 배운 것", "은퇴 준비 실전기" 같은 주제는 젊은 사용자들에게도 수요가 커요. 연륜은 콘텐츠 시장에서 재고가 아니라 희소 자원이에요.
