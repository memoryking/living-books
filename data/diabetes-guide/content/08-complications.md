# Chapter 8: 합병증 예방

---

## "합병증이 정말 올까요?"

합병증. 당뇨인이 가장 두려워하는 단어입니다. 실명, 투석, 절단. 인터넷에서 검색하면 공포스러운 이야기만 가득합니다.

하지만 한 가지 **절대적으로 중요한 사실**을 먼저 말씀드리겠습니다.

**합병증은 "관리 안 했을 때" 오는 것입니다. 관리하면 예방할 수 있습니다.**

> "I've had Type 1 diabetes for 30 years. Zero complications. Eyes perfect, kidneys perfect, feet perfect. My secret? I just... managed it. Consistently. Not perfectly, but consistently."
> — Reddit r/diabetes_t1

> "My dad had Type 2 for 25 years. He managed it well. Died at 82 of old age, not diabetes. It's not a death sentence."
> — Reddit r/diabetes_t2

## 합병증은 왜 생기는가?

합병증의 근본 원인은 **만성적인 고혈당**입니다. 높은 혈당이 오랜 기간 지속되면 혈관과 신경이 손상됩니다.

**만성 고혈당 → 혈관 내벽 손상 → 작은 혈관(미세혈관) 먼저 영향 → 눈·신장·신경·발 → 큰 혈관(대혈관) → 심장·뇌**

핵심 키워드는 **"오랜 기간"**과 **"높은 혈당"**입니다. A1C를 7% 미만으로 유지하면 합병증 위험이 **극적으로 감소**합니다.

| A1C 수준 | 미세혈관 합병증 위험 |
|:---|:---|
| 7% 미만 | 크게 낮음 |
| 7~8% | 중간 |
| 8~9% | 높음 |
| 9% 이상 | 매우 높음 |

## 눈: 당뇨 망막병증

당뇨가 눈에 미치는 영향은 **망막의 미세혈관 손상**에서 시작됩니다.

### 진행 단계

| 단계 | 증상 | 치료 |
|:---|:---|:---|
| 초기 (비증식성) | 대부분 무증상 | 혈당 관리로 진행 억제 |
| 중기 (중등도 비증식성) | 미세한 시력 변화 | 정기 검진, 혈당 관리 강화 |
| 진행기 (증식성) | 시력 저하, 비문증 | 레이저 치료, 주사 치료 |
| 말기 (당뇨 황반부종) | 심한 시력 저하 | 안과 전문 치료 |

**가장 중요한 것:** 초기에는 **증상이 없습니다.** 눈이 잘 보인다고 괜찮은 것이 아닙니다. 반드시 **연 1회 안저 검사**를 받으세요.

> "I skipped my eye exam for 3 years because I could see fine. When I finally went, they found early retinopathy. My doctor said if I'd waited another year, it might have been too late for easy treatment. Get your eyes checked."
> — Reddit r/diabetes

### 눈 보호 실천

| 실천 항목 | 빈도 |
|:---|:---|
| 안저 검사 (산동 검사) | 연 1회 이상 |
| A1C 7% 미만 유지 | 지속적 |
| 혈압 관리 (130/80 미만) | 지속적 |
| 금연 | 즉시 |
| 시력 변화 즉시 안과 방문 | 필요 시 |

## 신장: 당뇨 신증

신장은 혈액을 걸러서 노폐물을 소변으로 내보내는 장기입니다. 고혈당이 지속되면 신장의 미세 혈관(사구체)이 손상됩니다.

| 단계 | 지표 | 상태 |
|:---|:---|:---|
| 정상 | 알부민뇨 음성 | 건강한 신장 |
| 초기 | 미세알부민뇨 양성 | 조기 발견, 회복 가능 |
| 진행 | 거대알부민뇨 | 적극적 치료 필요 |
| 심화 | eGFR 감소 | 신장 기능 저하 |
| 말기 | 투석 또는 이식 필요 | 만성 신부전 |

### 신장 보호 전략

| 전략 | 설명 |
|:---|:---|
| 미세알부민뇨 검사 | 연 1회 (소변 검사) |
| 혈당 관리 | A1C 7% 미만 |
| 혈압 관리 | 130/80 미만 (ARB/ACEi 약물 고려) |
| SGLT-2 억제제 | 신장 보호 효과 입증 (포시가, 자디앙) |
| 단백질 과다 섭취 주의 | 신장 부담 감소 |
| 충분한 수분 섭취 | 신장 기능 유지 |

## 신경: 말초신경병증

당뇨성 신경병증은 **가장 흔한 합병증** 중 하나입니다. 주로 발과 다리에서 시작됩니다.

| 증상 | 설명 |
|:---|:---|
| 저림 | 발, 손가락이 저리거나 무감각 |
| 따끔거림 | 바늘로 찌르는 듯한 느낌 |
| 타는 듯한 통증 | 특히 밤에 심해짐 |
| 감각 저하 | 온도, 통증을 잘 못 느낌 |
| 근력 약화 | 진행된 경우 |

> "The tingling in my feet scared me into action. I got my A1C from 9 to 6.2, and the tingling went away after about 6 months. Early nerve damage CAN be reversed."
> — Reddit r/diabetes_t2

**희망적인 소식:** 초기 신경병증은 혈당 관리로 **개선될 수 있습니다.** 완전히 돌이킬 수는 없더라도, 진행을 막고 증상을 줄일 수 있습니다.

## 발: 매일 점검이 생명입니다

당뇨와 발의 관계는 단순합니다.

**신경병증으로 감각 저하 → 상처를 모르고 지남 → 고혈당으로 상처 치유 지연 → 감염 → 심하면 절단**

이 과정은 **매일 발을 확인하는 것만으로** 예방할 수 있습니다.

### 매일 발 점검 체크리스트

| 확인 항목 | 방법 |
|:---|:---|
| 상처, 물집 | 발 전체를 눈으로 확인 (거울 활용) |
| 발톱 상태 | 파고든 발톱, 변색 확인 |
| 피부 변화 | 건조함, 갈라짐, 굳은살 |
| 색깔 변화 | 붉은색, 푸른색 부위 |
| 온도 차이 | 한쪽 발이 유난히 차거나 뜨겁지 않은지 |
| 부종 | 붓기가 있는지 |

### 발 관리 규칙

| 규칙 | 이유 |
|:---|:---|
| 맨발로 걷지 않기 | 상처 예방 |
| 발을 매일 씻고 잘 말리기 | 감염 예방 (발가락 사이 특히) |
| 보습제 바르기 | 건조한 피부 갈라짐 예방 |
| 꽉 끼는 신발 피하기 | 물집과 압박 예방 |
| 발톱은 일자로 자르기 | 파고든 발톱 예방 |
| 작은 상처라도 즉시 치료 | 감염 확대 방지 |

## 심혈관: 혈압+콜레스테롤 동시 관리

당뇨인의 가장 큰 사망 원인은 합병증 자체보다 **심혈관 질환**(심장마비, 뇌졸중)입니다. 당뇨는 혈관을 손상시키기 때문입니다.

| 관리 항목 | 목표 수치 |
|:---|:---|
| 혈압 | 130/80 mmHg 미만 |
| LDL 콜레스테롤 | 100 mg/dL 미만 (심혈관 위험 시 70 미만) |
| 중성지방 | 150 mg/dL 미만 |
| HDL 콜레스테롤 | 남성 40, 여성 50 mg/dL 이상 |
| 금연 | 즉시 (가장 효과적인 심혈관 보호) |

## 연 1회 필수 검사 리스트

당뇨인이 매년 반드시 받아야 하는 검사입니다.

| 검사 항목 | 목적 | 빈도 |
|:---|:---|:---|
| A1C | 혈당 관리 평가 | 3~6개월마다 |
| 안저 검사 (눈) | 당뇨 망막병증 조기 발견 | 연 1회 |
| 미세알부민뇨 (소변) | 당뇨 신증 조기 발견 | 연 1회 |
| 신장 기능 (eGFR) | 신장 기능 평가 | 연 1회 |
| 지질 검사 (콜레스테롤) | 심혈관 위험 평가 | 연 1회 |
| 발 검사 | 신경병증, 혈류 확인 | 연 1회 (매일 자가 점검) |
| 혈압 측정 | 고혈압 관리 | 매 진료 시 |
| 갑상선 검사 | 갑상선 기능 이상 확인 | 연 1회 |

## 이번 장 핵심 정리

| 핵심 | 내용 |
|:---|:---|
| 합병증 = 관리 안 했을 때 | 관리하면 예방 가능 |
| A1C 7% 미만 | 합병증 위험 극적 감소 |
| 눈 | 안저 검사 연 1회 필수 (무증상 시기가 중요) |
| 신장 | 미세알부민뇨 검사로 조기 발견 |
| 신경 | 초기 저림은 혈당 관리로 개선 가능 |
| 발 | 매일 점검, 작은 상처도 즉시 치료 |
| 심혈관 | 혈압+콜레스테롤 동시 관리 필수 |
