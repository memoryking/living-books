# Chapter 2: 당뇨의 종류와 메커니즘

---

## 당뇨, 정확히 무슨 병인가요?

당뇨의 핵심은 단 한 줄로 설명됩니다.

**혈액 속 포도당(혈당)이 세포 안으로 제대로 들어가지 못하는 상태.**

음식을 먹으면 탄수화물이 포도당으로 분해되어 혈액으로 들어갑니다. 이 포도당이 세포 안으로 들어가려면 **인슐린**이라는 열쇠가 필요합니다. 당뇨는 이 열쇠에 문제가 생긴 것입니다.

열쇠 자체가 없는 경우가 **1형 당뇨**, 열쇠는 있는데 자물쇠가 녹슬어서 안 열리는 경우가 **2형 당뇨**입니다.

## 당뇨의 4가지 종류

### 1형 당뇨: 열쇠 공장이 파괴된 경우

1형 당뇨는 **자가면역 질환**입니다. 면역 시스템이 실수로 췌장의 베타세포(인슐린 생산 세포)를 공격해서 파괴합니다. 인슐린을 만들 수 없으니, 외부에서 인슐린을 주사해야 합니다.

| 항목 | 1형 당뇨 |
|:---|:---|
| 원인 | 자가면역 (면역계가 베타세포 파괴) |
| 발병 시기 | 주로 소아~청소년, 성인도 가능 |
| 체형 | 마르거나 정상 체중인 경우 많음 |
| 인슐린 필요 | 생존을 위해 반드시 필요 |
| 전체 당뇨 비율 | 약 5~10% |
| 예방 가능성 | 현재로서는 불가능 |

> "Type 1 is NOT caused by eating too much sugar. It's an autoimmune disease. I wish people would stop blaming us."
> — Reddit r/diabetes_t1

### 2형 당뇨: 자물쇠가 녹슨 경우

2형 당뇨는 **인슐린 저항성**이 핵심입니다. 췌장은 인슐린을 만들지만, 세포가 인슐린에 제대로 반응하지 않습니다. 처음에는 췌장이 더 많은 인슐린을 만들어 보상하지만, 결국 지쳐서 인슐린 분비도 줄어듭니다.

| 항목 | 2형 당뇨 |
|:---|:---|
| 원인 | 인슐린 저항성 + 점진적 분비 감소 |
| 발병 시기 | 주로 40대 이후, 최근 젊은 층 증가 |
| 체형 | 과체중이 많지만, 마른 2형도 있음 |
| 인슐린 필요 | 초기에는 불필요, 진행 시 필요할 수 있음 |
| 전체 당뇨 비율 | 약 90~95% |
| 생활습관으로 개선 | 가능 (많은 성공 사례) |

### LADA (1.5형): 천천히 진행되는 1형

**LADA(Latent Autoimmune Diabetes in Adults)**는 성인에게 천천히 발생하는 자가면역 당뇨입니다. 처음에는 2형처럼 보이지만, 실제로는 면역계가 베타세포를 천천히 파괴하고 있습니다.

> "I was diagnosed as Type 2 at 32. Metformin worked for a while, then stopped. 3 years later, my doctor finally tested my antibodies — GAD65 positive. I was LADA the whole time. Wasted 3 years on wrong treatment."
> — Reddit r/diabetes

**LADA를 의심해야 하는 경우:**

- 마른 체형인데 2형 진단을 받았다
- 경구약 효과가 점점 줄어든다
- 진단 시 나이가 25~45세
- 다른 자가면역 질환이 있다 (갑상선, 류마티스 등)

LADA가 의심되면 **GAD 항체 검사**와 **C-펩타이드 검사**를 요청하세요.

### 임신성 당뇨

임신 중 호르몬 변화로 인슐린 저항성이 증가하면서 발생합니다. 출산 후 대부분 사라지지만, **향후 2형 당뇨 발생 위험이 높아집니다.**

| 항목 | 임신성 당뇨 |
|:---|:---|
| 발생 시기 | 임신 24~28주 |
| 원인 | 태반 호르몬에 의한 인슐린 저항성 |
| 관리 | 식단 조절, 필요시 인슐린 |
| 출산 후 | 대부분 정상화 |
| 장기 위험 | 향후 10년 내 2형 당뇨 발생 확률 50% |

## 인슐린 저항성의 메커니즘

2형 당뇨의 핵심인 인슐린 저항성을 좀 더 깊이 이해해봅시다.

정상적인 과정은 이렇습니다.

**음식 섭취 → 혈당 상승 → 췌장에서 인슐린 분비 → 인슐린이 세포 문을 열어줌 → 포도당이 세포로 이동 → 혈당 정상화**

인슐린 저항성이 있으면 이렇게 됩니다.

**음식 섭취 → 혈당 상승 → 인슐린 분비 → 세포가 인슐린에 반응하지 않음 → 포도당이 혈액에 남음 → 췌장이 더 많은 인슐린 분비 → 결국 췌장 피로 → 인슐린 분비 감소 → 혈당 지속 상승**

### 인슐린 저항성을 높이는 요인

| 요인 | 영향 |
|:---|:---|
| 내장지방 | 염증 물질 분비로 인슐린 신호 방해 |
| 만성 스트레스 | 코르티솔이 혈당을 올리고 저항성 증가 |
| 수면 부족 | 하룻밤만 못 자도 인슐린 저항성 증가 |
| 운동 부족 | 근육의 포도당 흡수 능력 저하 |
| 정제 탄수화물 | 급격한 혈당 상승 → 인슐린 과다 분비 반복 |
| 유전 | 가족력이 있으면 위험 증가 |

**좋은 소식은** 이 요인들 대부분이 **생활습관으로 개선 가능**하다는 것입니다.

## 한국 당뇨 현황

한국의 당뇨 상황은 심각합니다.

| 항목 | 수치 |
|:---|:---|
| 당뇨 환자 수 | 약 600만 명 이상 |
| 30세 이상 유병률 | 약 16% (6명 중 1명) |
| 당뇨 전단계 포함 | 약 1,500만 명 |
| 본인이 모르는 비율 | 약 30% |
| 관리 목표 달성률 | 약 25% |

특히 주목할 점은 **본인이 당뇨인 줄 모르는 비율이 30%**라는 것입니다. 당뇨는 초기에 증상이 거의 없기 때문입니다.

## 마른 당뇨: 뚱뚱해야만 당뇨인 것은 아닙니다

> "I'm 5'10, 160 lbs, and I got diagnosed with Type 2. Everyone keeps telling me I don't look like a diabetic. What does a diabetic look like?"
> — Reddit r/diabetes_t2

한국에서 특히 중요한 이야기입니다. 동아시아인은 서양인에 비해 **낮은 BMI에서도 당뇨가 발생**합니다. 이는 체형의 문제가 아니라 **내장지방과 인슐린 분비 능력**의 문제입니다.

마른 2형 당뇨의 특징:

- BMI 정상 범위이지만 내장지방이 높음
- 근육량이 적고 체지방률이 높은 "마른 비만"
- 인슐린 분비 능력 자체가 낮은 경우
- LADA(1.5형)일 가능성도 고려 필요

## 1형 vs 2형: 핵심 비교

| 비교 항목 | 1형 당뇨 | 2형 당뇨 |
|:---|:---|:---|
| 인슐린 생산 | 거의 없음 | 있으나 효과 감소 |
| 주요 원인 | 자가면역 | 인슐린 저항성 |
| 발병 속도 | 빠름 (수주~수개월) | 느림 (수년) |
| 치료 핵심 | 인슐린 주사 필수 | 생활습관+약물 |
| 생활습관으로 완치 | 불가능 | 관해(remission) 가능 |
| 자가항체 | 양성 (GAD, IA-2 등) | 음성 |
| C-펩타이드 | 낮음 | 정상~높음 |

**중요:** 1형과 2형 모두 **환자 잘못이 아닙니다.** 1형은 자가면역, 2형은 유전+환경의 복합 결과입니다. 자기 자신을 탓하지 마세요.

## 이번 장 핵심 정리

| 핵심 | 내용 |
|:---|:---|
| 당뇨의 본질 | 인슐린 문제로 혈당이 세포에 못 들어감 |
| 1형 | 인슐린 생산 불가 (자가면역) |
| 2형 | 인슐린 저항성 (생활습관으로 개선 가능) |
| LADA | 성인 자가면역 당뇨, 2형으로 오진 많음 |
| 핵심 메시지 | 내 당뇨 타입을 정확히 아는 것이 관리의 시작 |
