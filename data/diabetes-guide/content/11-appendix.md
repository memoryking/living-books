## 부록 3: 당뇨 약물 비교표

### 경구약

| 약물 계열 | 대표 약 | A1C 감소 | 체중 | 저혈당 위험 | 월 비용 (추정) |

| 약물 계열 | 대표 약 | A1C 감소 | 체중 | 저혈당 위험 | 월 비용 (추정) |

## 부록 5: 응급 대처 카드

이 카드의 내용을 숙지하고, 필요시 지갑이나 핸드폰에 저장해두세요.

### 저혈당 응급 대처 (혈당 70 mg/dL 미만)

**증상:** 손 떨림, 식은땀, 어지러움, 극심한 배고픔, 심장 빠르게 뛰기

**15-15 규칙:**

| 단계 | 행동 |
|:---|:---|
| 1단계 | 포도당 15g 섭취 (포도당 정제 3~4알 또는 주스 120mL) |
| 2단계 | 15분 대기 |
| 3단계 | 혈당 재측정 |
| 4단계 | 여전히 70 미만이면 15g 추가 섭취 |
| 5단계 | 정상화되면 간식 섭취 (크래커+치즈 등) |

**의식이 없는 경우:** 절대 입에 음식을 넣지 마세요. 즉시 119에 전화하세요. 글루카곤 키트가 있으면 사용하세요.

### 고혈당 응급 대처 (혈당 300 mg/dL 이상 지속)

**증상:** 극심한 갈증, 잦은 소변, 시야 흐림, 메스꺼움, 구토

| 단계 | 행동 |
|:---|:---|
| 1단계 | 물을 충분히 마시기 |
| 2단계 | 처방된 약물 복용 확인 |
| 3단계 | 2~4시간 후 재측정 |
| 4단계 | 여전히 300 이상이거나 증상 지속 시 병원 방문 |
| 5단계 | 구토가 동반되면 즉시 응급실 |

## 부록 7: 자주 묻는 질문 (FAQ)

| 질문 | 답변 |
|:---|:---|
| 당뇨는 완치되나요? | 2형은 "관해(remission)" 가능, 1형은 현재 불가 |
| 약을 평생 먹어야 하나요? | 생활습관 개선으로 줄이거나 중단 가능 (의사와 상의) |
| 과일을 먹어도 되나요? | 소량의 베리류는 가능, 혈당계로 확인 |
| 당뇨가 유전인가요? | 유전적 소인이 있지만, 생활습관이 발현을 결정 |
| 운동은 뭐가 좋나요? | 식후 걷기가 가장 효과적, 근력 운동도 추천 |
| 인슐린 맞으면 끝인가요? | 아님, 인슐린은 도구일 뿐, 생활습관 관리는 계속 |
| CGM이 꼭 필요한가요? | 필수는 아니지만, 패턴 파악에 매우 유용 |
| 스트레스가 혈당을 올리나요? | 네, 코르티솔이 직접적으로 혈당을 올림 |

이 부록의 도구들은 **사용할 때 가치가 있습니다.** 완벽하게 채울 필요 없습니다. 하루에 한 칸이라도 채우는 것이 시작입니다.

**당신은 할 수 있습니다. 이미 시작했으니까요.**
