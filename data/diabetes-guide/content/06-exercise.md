# Chapter 6: 운동과 혈당

---

## 걷기만으로 달라지는 혈당 곡선

운동이 당뇨에 좋다는 것은 누구나 압니다. 하지만 대부분의 사람들이 모르는 것이 있습니다. **헬스장에 갈 필요 없이, 식후 10분 걷기만으로 혈당이 극적으로 바뀐다**는 것입니다.

> "Walking completely killed my sugar spikes. I eat the same food, but if I walk 15 minutes after, my spike goes from 200 to 130. It's like magic."
> — Reddit r/diabetes_t2 (66+ upvotes)

이것은 마법이 아닙니다. 과학입니다.

## 식후 걷기의 과학

음식을 먹으면 혈당이 올라갑니다. 이때 걷기를 하면 근육이 포도당을 연료로 사용합니다. 그것도 **인슐린 없이** 직접 사용합니다.

**식사 → 혈당 상승 → 걷기 시작 → 근육이 포도당 흡수 → 혈당 스파이크 감소**

### 식후 걷기 효과 (연구 기반)

| 항목 | 효과 |
|:---|:---|
| 식후 혈당 스파이크 | 평균 30~50% 감소 |
| 최적 타이밍 | 식후 15~30분 이내 시작 |
| 최소 시간 | 10분도 효과 있음 |
| 최적 시간 | 15~30분 |
| 강도 | 빠르게 걸을 필요 없음, 산책 수준 |

> "My doctor said 'just walk after meals.' I didn't believe something so simple could work. My CGM proved him right. The difference is night and day."
> — Reddit r/diabetes_t2

## 아침 산책의 코르티솔 리셋 효과

아침에 일어나면 코르티솔(스트레스 호르몬)이 자연적으로 높아집니다. 이 코르티솔이 혈당을 올립니다. 이것이 **새벽 현상(Dawn Phenomenon)**의 원인 중 하나입니다.

아침 산책이 이 문제를 해결합니다.

| 아침 산책 효과 | 설명 |
|:---|:---|
| 코르티솔 정상화 | 아침 코르티솔 스파이크를 자연스럽게 낮춤 |
| 공복 혈당 감소 | 새벽 현상으로 높아진 공복 혈당 개선 |
| 인슐린 감수성 향상 | 하루 종일 지속되는 효과 |
| 수면 질 개선 | 아침 햇빛이 체내 시계 리셋 |
| 기분 개선 | 세로토닌 분비로 정신건강에도 도움 |

**실전 팁:** 아침에 일어나서 15~20분만 밖에서 걸으세요. 커피를 들고 가도 좋고, 음악을 들어도 좋습니다. 중요한 것은 **밖에 나가서 움직이는 것**입니다.

## NEAT: 운동이 아닌 움직임의 힘

NEAT(Non-Exercise Activity Thermogenesis)는 공식적인 "운동"이 아닌 일상 활동으로 소비되는 에너지입니다. 연구에 따르면 NEAT는 하루 열량 소비의 **15~30%**를 차지합니다.

| NEAT 활동 | 효과 |
|:---|:---|
| 계단 오르기 | 엘리베이터 대신 2~3층은 계단으로 |
| 서서 일하기 | 앉아 있는 것보다 혈당 반응 개선 |
| 집안일 | 청소, 설거지, 빨래 모두 움직임 |
| TV 보며 스트레칭 | 앉아만 있지 말고 가벼운 동작 |
| 전화 받으며 걷기 | 전화 올 때마다 일어나서 걷기 |
| 30분마다 일어나기 | 장시간 앉은 자세는 혈당에 나쁨 |

> "I got a standing desk and started taking the stairs at work. Didn't change my diet at all. My fasting glucose dropped 15 points in a month."
> — Reddit r/diabetes_t2

## 근력 운동과 인슐린 감수성

걷기가 **즉각적인** 혈당 효과를 준다면, 근력 운동은 **장기적인** 효과를 줍니다. 근육량이 늘어나면 인슐린 감수성이 향상되고, 포도당을 저장하는 용량이 커집니다.

**근육 = 혈당을 저장하는 창고**라고 생각하세요. 창고가 클수록 혈당이 넘칠 일이 줄어듭니다.

### 초보자를 위한 근력 운동

| 운동 | 방법 | 횟수 |
|:---|:---|:---|
| 벽 푸쉬업 | 벽에 손 대고 팔굽혀펴기 | 10~15회 x 3세트 |
| 의자 스쿼트 | 의자에서 일어났다 앉기 | 10~15회 x 3세트 |
| 계단 오르내리기 | 한 층을 왕복 | 5~10회 |
| 밴드 운동 | 저항밴드로 당기기 | 10~15회 x 3세트 |
| 물병 들기 | 500mL 물병으로 컬 | 10~15회 x 3세트 |

**시작이 중요합니다.** 처음부터 무거운 것을 들 필요 없습니다. 자기 체중만으로도 충분합니다.

## 운동 시 저혈당 대처법

인슐린이나 설포닐유레아를 사용하는 분들은 운동 중 **저혈당**이 올 수 있습니다.

### 저혈당 증상

저혈당 경고 신호를 반드시 알아두세요.

| 증상 | 설명 |
|:---|:---|
| 손 떨림 | 갑자기 손이 떨림 |
| 식은땀 | 운동 강도와 무관한 식은땀 |
| 어지러움 | 갑자기 어지럽거나 흐릿함 |
| 심장 빠른 뛰기 | 맥박이 갑자기 빨라짐 |
| 배고픔 | 극심한 허기 |
| 집중력 저하 | 생각이 잘 안 됨 |

### 저혈당 대처 (15-15 규칙)

**혈당 70 mg/dL 미만 → 포도당 15g 섭취 → 15분 대기 → 재측정**

| 포도당 15g 해당 식품 | 예시 |
|:---|:---|
| 포도당 정제 | 3~4알 |
| 과일주스 | 120~150mL |
| 사탕 | 3~4개 |
| 꿀 | 1큰술 |

**운동 시 항상 포도당 정제나 주스를 가지고 다니세요.** 특히 인슐린 사용자는 필수입니다.

## 주차별 운동 강도 가이드

처음부터 무리하면 3일 만에 포기합니다. **점진적으로** 늘려가세요.

### 1~2주차: 시작

| 항목 | 내용 |
|:---|:---|
| 목표 | 움직이는 습관 만들기 |
| 식후 걷기 | 10~15분, 하루 1~2회 |
| 강도 | 대화 가능한 속도 |
| 주 목표 | 주 3~4일 |

### 3~4주차: 확장

| 항목 | 내용 |
|:---|:---|
| 목표 | 시간과 빈도 늘리기 |
| 식후 걷기 | 15~20분, 하루 2회 |
| 근력 운동 추가 | 주 2회, 15~20분 |
| 주 목표 | 주 5일 |

### 5주차 이후: 시스템화

| 항목 | 내용 |
|:---|:---|
| 목표 | 일상의 일부로 정착 |
| 유산소 | 30~45분, 걷기+조깅 혼합 |
| 근력 운동 | 주 3회, 20~30분 |
| NEAT | 일상 전반에 움직임 통합 |
| 주 목표 | 주 5~6일 |

> "I started with 10-minute walks after dinner. Now, 6 months later, I'm doing 5K runs. I never thought I'd say this, but I actually enjoy exercise now. And my A1C? 5.2."
> — Reddit r/diabetes_t2

## 운동이 싫은 날

운동이 매일 즐거울 수는 없습니다. 그럴 때는 이렇게 생각하세요.

**"운동 안 하는 날은 없다. 강도가 낮은 날이 있을 뿐이다."**

| 기분 상태 | 최소한의 운동 |
|:---|:---|
| 너무 피곤하다 | 5분만 밖에서 걷기 |
| 비가 온다 | 실내에서 제자리 걷기 |
| 시간이 없다 | 계단 한 번 오르내리기 |
| 의욕이 없다 | 좋아하는 음악 틀고 걷기 |
| 몸이 아프다 | 가벼운 스트레칭만 |

**5분이라도 하는 것이 0분보다 무한히 낫습니다.**

## 이번 장 핵심 정리

| 핵심 | 내용 |
|:---|:---|
| 식후 걷기 | 10~15분으로 혈당 스파이크 30~50% 감소 |
| 아침 산책 | 코르티솔 리셋, 공복 혈당 개선 |
| NEAT | 일상의 작은 움직임이 모여 큰 효과 |
| 근력 운동 | 근육 = 혈당 저장 창고, 인슐린 감수성 향상 |
| 점진적 증가 | 10분 시작 → 5주 후 30~45분 |
| 저혈당 대비 | 인슐린 사용자는 포도당 정제 휴대 필수 |
