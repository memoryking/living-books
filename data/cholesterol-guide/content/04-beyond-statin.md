# Chapter 4. 스타틴 외 약물: 에제티미브, PCSK9, 피브레이트

---

## 스타틴만으로 부족할 때

스타틴은 강력하지만, 모든 환자에게 충분하지는 않습니다. 다음과 같은 경우에 추가 약물이 필요합니다.

- 고용량 스타틴을 써도 **LDL 목표에 도달하지 못할 때**
- 스타틴 **부작용으로 충분한 용량을 쓸 수 없을 때**
- **중성지방이 별도로 높을 때**
- 가족성 고콜레스테롤혈증처럼 **유전적으로 매우 높을 때**

이 장에서는 스타틴의 "파트너" 역할을 하는 약물들을 하나씩 살펴보겠습니다.

---

## 에제티미브 (Ezetimibe)

### 한눈에 보는 에제티미브

| 항목 | 내용 |
|------|------|
| 대표 상품명 | 이지트롤, 제티아 |
| 작용 기전 | 소장에서 콜레스테롤 흡수 억제 |
| LDL 감소율 | 단독 15~20%, 스타틴과 병용 시 추가 20~25% |
| 복용법 | 1일 1회 10mg, 식사 무관 |
| 주요 장점 | 부작용 매우 적음, 스타틴과 시너지 |
| 주요 단점 | 단독으로는 효과 제한적 |

### 작용 원리

스타틴이 간에서 콜레스테롤 **생산**을 줄인다면, 에제티미브는 소장에서 콜레스테롤 **흡수**를 줄입니다. 두 약은 서로 다른 경로로 작용하기 때문에, 병용하면 효과가 더해집니다.

소장 세포에 있는 **NPC1L1**이라는 콜레스테롤 운반 단백질을 차단하여, 음식이나 담즙을 통해 장으로 들어온 콜레스테롤이 흡수되는 것을 막습니다.

### 임상적 위치

에제티미브의 가장 큰 역할은 **스타틴과의 병용**입니다.

| 상황 | 전략 |
|------|------|
| 스타틴 중강도로 LDL 목표 미달 | 에제티미브 추가 (스타틴 용량 올리기보다 효율적) |
| 스타틴 부작용으로 저용량만 가능 | 저용량 스타틴 + 에제티미브 |
| 스타틴 불내성 (아예 못 먹는 경우) | 에제티미브 단독 사용 |

**IMPROVE-IT 연구** 결과, 스타틴+에제티미브 병용이 스타틴 단독보다 심혈관 사건을 유의미하게 줄인다는 것이 입증되었습니다.

### 복합제의 편리함

스타틴과 에제티미브를 한 알에 합친 **복합제**도 있습니다.

| 복합제 | 구성 |
|--------|------|
| 로수젯플러스 | 로수바스타틴 + 에제티미브 |
| 아토젯 | 아토르바스타틴 + 에제티미브 |
| 리피로우이지 | 아토르바스타틴 + 에제티미브 |

약을 2알에서 1알로 줄이면 복약 순응도(약을 꾸준히 먹는 비율)가 올라갑니다. 하루에 먹는 약이 많은 분에게 좋은 선택입니다.

## PCSK9 억제제: 최강의 LDL 저하제

### 한눈에 보는 PCSK9 억제제

| 항목 | 에볼로쿠맙(레파타) | 알리로쿠맙(프랄루엔트) |
|------|-------------------|----------------------|
| 투여 방법 | 피하 주사 | 피하 주사 |
| 투여 주기 | 2주 1회 또는 4주 1회 | 2주 1회 |
| LDL 감소율 | 50~60% (스타틴에 추가시) | 50~60% (스타틴에 추가시) |
| 가격 | 고가 (연간 수백만 원) | 고가 (연간 수백만 원) |
| 보험 적용 | 조건부 급여 | 조건부 급여 |

### 작용 원리

**PCSK9**은 간세포 표면의 LDL 수용체를 분해하는 단백질입니다. LDL 수용체가 줄어들면 혈중 LDL을 회수하지 못해 LDL이 올라갑니다.

PCSK9 억제제는 이 PCSK9 단백질을 차단하여 LDL 수용체가 오래 살아남게 합니다. 결과적으로 혈중 LDL을 더 많이 회수할 수 있게 되어 LDL이 극적으로 떨어집니다.

### 누가 대상인가

PCSK9 억제제는 고가이기 때문에 모든 환자에게 처방되지 않습니다.

| 대상 | 조건 |
|------|------|
| 가족성 고콜레스테롤혈증 | 스타틴+에제티미브로도 목표 미달 |
| 죽상동맥경화성 심혈관질환 | 고강도 스타틴+에제티미브 병용에도 LDL 70 이상 |
| 스타틴 불내성 | 2가지 이상 스타틴에서 부작용 발생 |

### 건강보험 급여 기준 (한국)

| 조건 | 기준 LDL |
|------|----------|
| 관상동맥질환 + 최대 내약 용량 스타틴+에제티미브 | LDL 70mg/dL 이상 |
| 가족성 고콜레스테롤혈증 + 최대 내약 용량 치료 | LDL 100mg/dL 이상 |

**약사의 한마디:** PCSK9 억제제는 혁신적인 약이지만, 아직 비용 부담이 큽니다. 급여 기준을 정확히 확인하고, 해당되면 담당 의사에게 적극적으로 문의하시기 바랍니다.

## 인클리시란 (Inclisiran): 6개월에 1번 주사

최근 등장한 새로운 개념의 약물입니다.

| 항목 | 내용 |
|------|------|
| 상품명 | 레크비오 |
| 작용 기전 | siRNA로 간에서 PCSK9 생산 자체를 억제 |
| 투여 주기 | 초회, 3개월 후, 이후 6개월마다 |
| LDL 감소율 | 약 50% |
| 장점 | 투여 횟수 극히 적음 (연 2회) |
| 현재 상황 | 한국 보험 적용 논의 중 |

## 피브레이트: 중성지방 전문가

### 한눈에 보는 피브레이트

| 항목 | 내용 |
|------|------|
| 대표 약물 | 페노피브레이트(리판틸), 베자피브레이트(베자립) |
| 작용 기전 | PPARα 활성화로 중성지방 분해 촉진 |
| TG 감소율 | 30~50% |
| HDL 증가율 | 5~15% |
| 주요 적응증 | 중성지방 500mg/dL 이상 (췌장염 예방) |

### 언제 사용하나

| 상황 | 치료 전략 |
|------|-----------|
| TG 500mg/dL 이상 | 피브레이트 우선 투여 (췌장염 예방이 급선무) |
| TG 200~499mg/dL | 먼저 LDL 목표 달성 후, TG 높으면 피브레이트 추가 |
| TG 150~199mg/dL | 생활습관 개선 우선 |

### 스타틴과의 병용 주의

| 피브레이트 종류 | 스타틴 병용 | 비고 |
|----------------|-----------|------|
| 페노피브레이트 | 가능 (주의하면서) | 스타틴과 병용 시 선호 |
| 젬피브로질 | 금기 | 횡문근융해증 위험 크게 증가 |

**절대 기억하세요:** 젬피브로질과 스타틴은 **함께 사용하면 안 됩니다.** 피브레이트를 스타틴과 병용해야 한다면 반드시 페노피브레이트를 사용합니다.

## 고용량 오메가3 지방산 (처방 의약품)

일반 건강기능식품의 오메가3와는 다릅니다. **처방 의약품**으로서의 고용량 오메가3를 말합니다.

| 구분 | 건강기능식품 오메가3 | 처방 오메가3 |
|------|-------------------|-------------|
| EPA+DHA 함량 | 500~1000mg | 2000~4000mg |
| 주요 목적 | 일반 건강 유지 | 중성지방 감소 치료 |
| TG 감소 효과 | 미미 | 20~45% |
| 대표 제품 | 다양한 브랜드 | 오마코(EPA+DHA), 바세파(EPA 단독) |
| 보험 적용 | 없음 | 조건부 급여 |

### REDUCE-IT 연구의 의미

2019년 발표된 REDUCE-IT 연구에서, EPA 단독 고용량 제제(이코사펜트 에틸, 4g/일)가 스타틴 치료 중인 환자에서 심혈관 사건을 **25% 추가로** 줄인다는 결과가 나왔습니다.

다만 이 결과가 EPA 자체의 효과인지, 사용된 위약(미네랄 오일)의 문제인지에 대한 논란이 있어, 아직 모든 가이드라인에서 일률적으로 권장하지는 않습니다.

## 약물 병용 전략 정리

| 목표 | 1차 선택 | 2차 추가 | 3차 추가 |
|------|---------|---------|---------|
| LDL 감소 | 스타틴 | + 에제티미브 | + PCSK9 억제제 |
| TG 감소 (500 이상) | 피브레이트 | + 고용량 오메가3 | + 스타틴 (LDL도 높으면) |
| LDL + TG 동시 | 스타틴 | + 에제티미브 + 페노피브레이트 | + 고용량 오메가3 |

---

## 이 장의 핵심 정리

1. **에제티미브**는 스타틴의 가장 좋은 파트너입니다. 부작용이 적고, 추가 LDL 감소 효과가 확실합니다
2. **PCSK9 억제제**는 LDL을 극적으로 낮추지만, 고가이며 급여 조건이 제한적입니다
3. **피브레이트**는 중성지방이 매우 높을 때 필수적입니다. 단, 젬피브로질은 스타틴과 병용 금기입니다
4. **처방 오메가3**는 건강기능식품과 다르며, 고용량에서 중성지방 감소 효과가 있습니다
5. 약물 치료는 **단계적으로** 진행합니다. 처음부터 모든 약을 한꺼번에 쓰지 않습니다

다음 장에서는 약 없이(혹은 약과 함께) 콜레스테롤을 관리하는 **식이요법**에 대해 알아보겠습니다.
