# Chapter 10. 콜레스테롤 관리 90일 로드맵

---

## 지식을 행동으로 바꾸는 시간

지금까지 9개 장에 걸쳐 콜레스테롤에 대한 모든 것을 다루었습니다. 이제 마지막 장에서는 이 모든 지식을 **구체적인 행동 계획**으로 정리합니다.

90일, 즉 약 3개월입니다. 이 기간은 생활습관 변화의 효과가 지질 검사에 반영되기에 충분한 시간이며, 동시에 새로운 습관이 몸에 배기에 적절한 기간입니다.

---

## 시작 전: 나의 목표 LDL 확인하기

로드맵을 시작하기 전에, 자신의 **위험 등급과 LDL 목표**를 먼저 확인하세요.

| 위험 등급 | 해당 대상 | LDL 목표 | 관리 강도 |
|-----------|-----------|----------|-----------|
| 초고위험군 | 심근경색, 뇌졸중, 말초동맥질환 병력 | 55mg/dL 미만 | 최강 (약물 필수) |
| 고위험군 | 당뇨+표적장기 손상, 경동맥 협착 | 70mg/dL 미만 | 강 (약물 우선) |
| 중등도 위험군 | 위험인자 2개 이상 | 100mg/dL 미만 | 중 (약물+생활습관) |
| 저위험군 | 위험인자 0~1개 | 130mg/dL 미만 | 생활습관 우선 |

자신의 위험 등급을 모르면 담당 의사에게 확인하세요. 이 로드맵은 **모든 위험 등급**에 적용 가능하지만, 약물 관련 부분은 위험 등급에 따라 달라집니다.

## Week 1~2: 현재 상태 파악 + 기초 검사

### 이 시기의 목표
> "내 몸의 현재 상태를 정확히 아는 것"

### 실천 항목

| 항목 | 구체적 행동 | 체크 |
|------|------------|------|
| 지질 검사 | 공복 12시간 후 채혈 (TC, LDL, HDL, TG) | |
| 기본 검사 | 혈당, 간기능, 신기능, 갑상선 기능 | |
| 혈압 측정 | 가정용 혈압계로 아침·저녁 측정 시작 | |
| 허리둘레 측정 | 배꼽 높이에서 줄자로 측정 | |
| 체중 기록 | 매일 같은 시간 측정, 기록 시작 | |
| 가족력 확인 | 부모·형제의 심혈관 질환 병력 확인 | |
| 현재 식단 기록 | 3일간 먹는 것 모두 기록 (사진 찍기) | |
| 운동량 파악 | 만보계 앱으로 일일 걸음 수 확인 | |

### 의사 상담 시 준비할 질문

| 질문 | 목적 |
|------|------|
| 제 심혈관 위험 등급은 어떻게 되나요? | 목표 LDL 확인 |
| 약물 치료가 필요한 수준인가요? | 치료 방향 결정 |
| 추가 검사(경동맥 초음파 등)가 필요할까요? | 혈관 상태 직접 확인 |
| 다른 약과 상호작용은 없나요? | 안전한 약물 선택 |

## Week 3~4: 식단 전환

### 이 시기의 목표
> "콜레스테롤을 낮추는 식단으로 전환 시작"

급격한 변화보다 **점진적 교체**가 지속 가능합니다.

### 1주차 식단 변화 (Week 3)

| 변화 영역 | 구체적 행동 |
|-----------|------------|
| 기름 교체 | 조리용 기름을 올리브오일·들기름으로 교체 |
| 아침 식사 | 주 3회 이상 오트밀 + 과일 + 견과류로 변경 |
| 간식 교체 | 과자·빵 대신 무염 견과류 30g, 과일로 대체 |
| 음료 교체 | 설탕 음료 → 물, 녹차, 블랙커피 |

### 2주차 식단 변화 (Week 4)

| 변화 영역 | 구체적 행동 |
|-----------|------------|
| 단백질 교체 | 삼겹살·갈비 빈도 줄이기, 생선·닭가슴살·두부로 |
| 잡곡밥 전환 | 백미에 귀리·보리·현미 혼합 |
| 외식 전략 | 생선구이 정식, 비빔밥, 된장찌개 우선 선택 |
| 야식 줄이기 | 야식 빈도 주 1회 이하로 제한 |

### 식단 전환 주간 체크리스트

| 항목 | 주간 목표 |
|------|-----------|
| 생선 섭취 | 주 2회 이상 |
| 견과류 섭취 | 매일 한 줌(30g) |
| 채소 반찬 | 매끼 2종류 이상 |
| 과일 섭취 | 매일 1~2회 |
| 삼겹살·갈비 | 주 1회 이하 |
| 라면·튀김 | 주 1회 이하 |
| 당류 음료 | 주 2회 이하 |

## Week 5~8: 운동 본격화 + 체중 관리

### 이 시기의 목표
> "주 150분 이상 운동 습관 정착, 체중 2~3% 감량"

### 운동 주간 계획

| 요일 | Week 5~6 | Week 7~8 |
|------|---------|---------|
| 월 | 빠르게 걷기 30분 | 빠르게 걷기 40분 |
| 화 | 근력 운동 20분 | 근력 운동 30분 |
| 수 | 빠르게 걷기 30분 | 자전거/수영 40분 |
| 목 | 스트레칭 15분 | 가벼운 걷기 20분 |
| 금 | 빠르게 걷기 30분 | 빠르게 걷기/조깅 40분 |
| 토 | 근력 운동 20분 | 근력 운동 30분 |
| 일 | 산책 30분 | 자유 활동 30분 |

### 체중 관리 목표

| 기간 | 목표 | 방법 |
|------|------|------|
| Week 5~6 | 현재 체중의 1~1.5% 감량 | 식단 전환 효과 + 운동 시작 |
| Week 7~8 | 누적 2~3% 감량 | 운동 강도 증가 + 식단 유지 |
| 예시 (80kg) | 78.4~77.6kg 도달 | 주 0.5kg 감량 페이스 |

### 이 시기에 추가할 생활습관

| 항목 | 구체적 행동 |
|------|------------|
| 식후 산책 | 저녁 식사 후 20~30분 걷기 (중성지방 관리) |
| 음주 조절 | 주 2회 이하, 1회 소주 2잔 이하 |
| 수면 관리 | 11시 전 취침 목표, 7~8시간 확보 |
| 스트레스 관리 | 주 3회 이상 이완 활동 (명상, 취미, 산책) |

---

## Week 9~12: 재검사 + 약물 최적화

### 이 시기의 목표
> "90일간의 노력 결과 확인, 향후 계획 수립"

### 재검사 일정

| 시기 | 검사 항목 | 목적 |
|------|-----------|------|
| Week 9~10 | 공복 지질 검사 (TC, LDL, HDL, TG) | 생활습관 변화 효과 확인 |
| Week 9~10 | 체중, 허리둘레 재측정 | 체성분 변화 확인 |
| Week 9~10 | 간기능, 혈당 재검사 | 전반적 대사 상태 확인 |

### 재검사 결과에 따른 대응

| 결과 | 대응 |
|------|------|
| LDL 목표 달성 + 생활습관만으로 충분 | 현재 생활습관 유지, 6~12개월 후 재검사 |
| LDL 목표 미달 + 약 미복용 | 의사와 약물 치료 시작 논의 |
| LDL 목표 미달 + 이미 약 복용 중 | 약물 용량 조절 또는 병용 약물 추가 논의 |
| LDL 목표 달성 + 약 복용 중 | 현재 치료 유지 (약 임의 중단 금지!) |
| 중성지방 여전히 높음 | 탄수화물·알코올 추가 감량, 피브레이트/오메가3 고려 |

## 90일 이후: 평생 관리의 시작

90일 로드맵이 끝이 아닙니다. 여기서 만든 습관을 **평생 유지**하는 것이 진짜 목표입니다.

### 장기 관리 스케줄

| 주기 | 해야 할 일 |
|------|-----------|
| 매일 | 운동 (최소 30분), 건강 식단 유지 |
| 매주 | 체중 측정, 운동량 점검 |
| 매월 | 식단·운동 일지 리뷰, 개선점 찾기 |
| 3~6개월마다 | 지질 검사 (약물 복용 중인 경우) |
| 6~12개월마다 | 지질 검사 (안정적인 경우) |
| 매년 | 종합 건강검진, 심혈관 위험도 재평가 |

## 90일 로드맵 전체 요약

| 주차 | 핵심 테마 | 주요 행동 | 기대 효과 |
|------|-----------|-----------|-----------|
| 1~2 | 현재 파악 | 검사, 측정, 기록 | 출발점 확인 |
| 3~4 | 식단 전환 | 기름·간식·단백질 교체 | LDL 5~10% 감소 시작 |
| 5~6 | 운동 시작 | 주 150분 유산소 + 근력 | HDL 상승, TG 감소 시작 |
| 7~8 | 습관 정착 | 운동 강도 올리기, 체중 감량 | 체중 3~5% 감량 |
| 9~10 | 재검사 | 지질 재검사, 결과 분석 | 변화 확인, 전략 수정 |
| 11~12 | 최적화 | 약물 조절, 장기 계획 수립 | 목표 달성 또는 조정 |

## 당신이 할 수 있는 가장 좋은 투자

콜레스테롤 관리는 오늘 당장 눈에 보이는 결과를 주지 않습니다. 하지만 10년, 20년 뒤 **심장마비나 뇌졸중을 막는** 가장 확실한 투자입니다.

처음부터 완벽할 필요 없습니다. 이 로드맵의 **70~80%만 실천**해도 의미 있는 변화가 나타납니다. 중요한 것은 시작하는 것이고, 포기하지 않는 것입니다.

혈관은 관리한 만큼 보답합니다.

오늘부터 시작하세요. 여러분의 혈관이 감사할 것입니다.
