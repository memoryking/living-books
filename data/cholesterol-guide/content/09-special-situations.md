# Chapter 9. 특수 상황의 콜레스테롤 관리

---

## 모든 사람에게 같은 기준이 적용되지 않습니다

지금까지 일반적인 콜레스테롤 관리를 다루었습니다. 하지만 특정 질환이 있거나, 특정 상황에 있는 분들은 **다른 접근**이 필요합니다. 이 장에서는 약국과 병원에서 자주 만나는 특수 상황별 관리법을 정리합니다.

---

## 가족성 고콜레스테롤혈증 (FH)

### 유전이 만드는 극단적인 콜레스테롤

가족성 고콜레스테롤혈증은 **유전적 결함**으로 LDL 수용체가 제대로 작동하지 않아, 태어날 때부터 LDL이 매우 높은 질환입니다.

| 구분 | 이형접합체 FH | 동형접합체 FH |
|------|-------------|-------------|
| 유전 형태 | 부모 중 한쪽에서 유전 | 양쪽 부모에서 유전 |
| 빈도 | 약 200~500명 중 1명 | 약 100만 명 중 1명 |
| 치료 전 LDL | 190~400mg/dL | 400~1000mg/dL |
| 심혈관 사건 시기 | 30~50대 | 10~20대 (치료 없으면) |
| 치료 반응 | 스타틴+에제티미브로 상당히 개선 | 약물만으로 부족, LDL 성분채혈 필요 |

### FH를 의심해야 하는 경우

| 상황 | 설명 |
|------|------|
| LDL 190mg/dL 이상 | 특히 젊은 나이에 (식이 원인 배제 후) |
| 가족 중 조기 심혈관 질환 | 부모/형제가 55세(남), 65세(여) 이전 발병 |
| 아킬레스건 황색종 | 아킬레스건이 두껍게 부어오름 |
| 눈 주위 황색종 | 눈꺼풀에 노란 지방 침착 |
| 각막환 | 40세 이전 각막 가장자리에 흰 고리 |

**약사의 한마디:** FH는 생활습관 개선만으로는 절대 해결할 수 없습니다. "젊은데 콜레스테롤이 왜 이렇게 높지?"라고 생각되면 **가족력을 꼭 확인**하세요. 조기 발견하면 약물 치료로 심혈관 사건을 예방할 수 있습니다.

### FH 치료 전략

| 단계 | 치료 |
|------|------|
| 1단계 | 고강도 스타틴 (로수바스타틴 20mg 또는 아토르바스타틴 40~80mg) |
| 2단계 | + 에제티미브 10mg |
| 3단계 | + PCSK9 억제제 |
| 4단계 (동형접합체) | LDL 성분채혈 (Lipoprotein Apheresis) |

## 당뇨병 + 고지혈증: 가장 흔한 조합

당뇨병 환자의 약 70%가 이상지질혈증을 동반합니다. 이 조합은 심혈관 위험을 **기하급수적으로** 높입니다.

### 당뇨병성 이상지질혈증의 특징

| 특징 | 설명 |
|------|------|
| LDL 수치 | 정상이거나 약간 높음 (속지 마세요!) |
| LDL 입자 크기 | 작고 밀도 높은(sdLDL) 위험한 형태 |
| 중성지방 | 상승 (인슐린 저항성으로) |
| HDL | 감소 |
| 비HDL 콜레스테롤 | 크게 상승 |

**핵심:** 당뇨 환자는 LDL이 130mg/dL "밖에" 안 되더라도 안심하면 안 됩니다. LDL의 **질적 악화**가 동반되어 있기 때문입니다.

### 당뇨 환자의 콜레스테롤 치료 기준

| 당뇨 환자 분류 | LDL 목표 | 치료 |
|---------------|----------|------|
| 표적장기 손상 없음 | 100mg/dL 미만 | 중등도 스타틴 |
| 표적장기 손상 있음 (신장병, 망막병 등) | 70mg/dL 미만 | 고강도 스타틴 |
| 심혈관 질환 동반 | 55mg/dL 미만 | 고강도 스타틴 + 에제티미브 |

## 만성 신장병 (CKD)

### CKD와 콜레스테롤의 관계

만성 신장병 환자는 심혈관 질환으로 사망할 확률이 일반인의 **10~30배**입니다.

| CKD 단계 | eGFR | 지질 치료 |
|----------|------|-----------|
| 1~2단계 | 60 이상 | 일반인과 동일 기준 |
| 3단계 | 30~59 | 스타틴 또는 스타틴+에제티미브 권장 |
| 4단계 | 15~29 | 스타틴+에제티미브 (용량 주의) |
| 5단계 (투석) | 15 미만 | 논란 있음. 이미 복용 중이면 유지, 새로 시작은 신중 |

### 신장병 환자의 약물 주의사항

| 주의 약물 | 내용 |
|-----------|------|
| 로수바스타틴 | eGFR 30 미만에서 최대 10mg (20mg 금기) |
| 피브레이트 | 신기능 저하 시 용량 감량 또는 금기 |
| 에제티미브 | 신기능 관계없이 사용 가능 (장점) |
| PCSK9 억제제 | 신기능 관계없이 사용 가능 |

## 고령자의 콜레스테롤 관리

### 75세 이상의 딜레마

고령자에서 스타틴의 효과에 대해서는 아직 **논란**이 있습니다.

| 상황 | 권고 |
|------|------|
| 75세 이상, 이미 스타틴 복용 중 | 유지하는 것이 원칙 |
| 75세 이상, 심혈관 질환 병력 있음 | 스타틴 유지 또는 시작 |
| 75세 이상, 1차 예방 목적 | 개별화된 판단 필요 |
| 기대 여명이 짧은 경우 | 약물 중단 고려 가능 |
| 다약제 복용 (5개 이상) | 상호작용 주의, 용량 조절 |

### 고령자 특유의 고려사항

| 고려사항 | 설명 |
|----------|------|
| 근육 부작용 | 고령자에서 더 빈번. 저용량으로 시작 |
| 낙상 위험 | 근육통으로 인한 활동 저하 → 낙상 |
| 인지 기능 | 스타틴이 인지 기능에 영향? → 현재까지 증거 불충분 |
| 다약제 상호작용 | 복용 약이 많을수록 상호작용 위험 |
| 영양 상태 | 과도한 식이 제한은 영양 부족 초래 가능 |

**약사의 한마디:** 고령자에게 "나이가 많으니 약을 끊자"고 일방적으로 결정하는 것도, "무조건 계속 먹어야 한다"고 고집하는 것도 옳지 않습니다. **개인의 전반적 건강 상태, 기대 여명, 복용 약물 수, 부작용 유무**를 종합적으로 고려해야 합니다.

## 임신과 수유 중 콜레스테롤 관리

### 임신 중 스타틴: 절대 금기

| 약물 | 임신 중 | 수유 중 |
|------|---------|---------|
| 모든 스타틴 | 절대 금기 (FDA Category X) | 금기 |
| 에제티미브 | 금기 | 안전성 미확립 |
| PCSK9 억제제 | 안전성 미확립 | 안전성 미확립 |
| 피브레이트 | 금기 | 금기 |
| 담즙산 결합 수지 | 사용 가능 (흡수 안 됨) | 사용 가능 |

### 임신 계획 중인 여성

| 시점 | 조치 |
|------|------|
| 임신 계획 1~3개월 전 | 스타틴 중단, 의사 상담 |
| 임신 중 | 콜레스테롤 약 중단 (자연적으로 상승하는 것은 정상) |
| 출산 후 수유 종료 시 | 스타틴 재개 가능 |

**참고:** 임신 중 콜레스테롤이 올라가는 것은 **정상적인 현상**입니다. 태아 발달에 콜레스테롤이 필요하기 때문입니다. 특별한 경우(가족성 고콜레스테롤혈증)가 아니면 임신 중 지질 치료는 하지 않습니다.

## 갑상선 기능 저하증과 콜레스테롤

갑상선 기능이 떨어지면 LDL이 올라갑니다. 이것은 갑상선 호르몬이 간의 LDL 수용체 발현을 조절하기 때문입니다.

| 상황 | 대처 |
|------|------|
| 갑상선 기능 저하증 + 높은 LDL | 먼저 갑상선 호르몬 보충 치료 (레보티록신) |
| 갑상선 정상화 후에도 LDL 높음 | 그때 스타틴 시작 |
| 무증상 갑상선 기능 저하증 (TSH만 약간 높음) | 지질 검사 반복, 필요시 치료 |

**중요:** 콜레스테롤이 높다고 무조건 스타틴부터 쓰는 것이 아닙니다. **이차성 원인**(갑상선, 신장, 간 질환, 약물 등)을 먼저 확인하고 교정하는 것이 우선입니다.

## 약물 상호작용: 같이 먹으면 위험한 조합

스타틴을 포함한 콜레스테롤 약은 다른 약물과 상호작용할 수 있습니다.

### 스타틴과 주의해야 할 약물

| 병용 약물 | 영향받는 스타틴 | 위험 | 대처 |
|-----------|-------------|------|------|
| 사이클로스포린 (면역억제제) | 모든 스타틴 | 근육병증 위험 크게 증가 | 용량 제한, 프라바스타틴 선호 |
| 마크로라이드 항생제 (클라리스로마이신) | 심바스타틴, 아토르바스타틴 | 혈중 농도 상승 | 일시 중단 또는 로수바스타틴으로 변경 |
| 아졸계 항진균제 (이트라코나졸) | 심바스타틴, 아토르바스타틴 | 혈중 농도 크게 상승 | 병용 금기 또는 로수바스타틴으로 변경 |
| 아미오다론 (부정맥 약) | 심바스타틴 | 근육병증 위험 | 심바스타틴 20mg 이하로 제한 |
| 딜티아젬/베라파밀 | 심바스타틴 | 근육병증 위험 | 심바스타틴 용량 제한 |
| 젬피브로질 | 모든 스타틴 | 횡문근융해증 | 절대 병용 금기 |
| 워파린 | 일부 스타틴 | INR 변동 | 로수바스타틴, 프라바스타틴이 상대적 안전 |

### 상호작용이 적은 스타틴

| 스타틴 | CYP3A4 대사 | 상호작용 위험 |
|--------|------------|-------------|
| 로수바스타틴 | 거의 없음 | 낮음 |
| 프라바스타틴 | 없음 | 가장 낮음 |
| 피타바스타틴 | 거의 없음 | 낮음 |
| 아토르바스타틴 | 있음 | 중등도 |
| 심바스타틴 | 있음 | 높음 |

**약사의 한마디:** 약을 여러 개 드시는 분은 **약국에서 복약 상담**을 꼭 받으세요. 약사가 상호작용을 확인해드립니다. 새로운 약이 추가되거나, 다른 병원에서 약을 받을 때 특히 중요합니다.

## 이 장의 핵심 정리

1. **가족성 고콜레스테롤혈증**은 생활습관 개선만으로 해결되지 않으며, 적극적 약물 치료가 필수입니다
2. **당뇨 환자**는 LDL이 정상처럼 보여도 안심하면 안 됩니다. 더 엄격한 기준이 적용됩니다
3. **만성 신장병** 환자는 심혈관 위험이 매우 높으며, 약물 용량 조절이 필요합니다
4. **고령자**는 개인의 전반적 상황을 고려하여 치료 결정을 해야 합니다
5. **임신 중 스타틴은 절대 금기**입니다. 임신 계획 시 미리 상담하세요
6. 콜레스테롤이 높으면 **갑상선 기능** 등 이차성 원인부터 확인하세요
7. 여러 약을 함께 드시면 **약물 상호작용**을 반드시 확인하세요

다음 장에서는 모든 내용을 종합한 **90일 콜레스테롤 관리 로드맵**을 제시하겠습니다.
