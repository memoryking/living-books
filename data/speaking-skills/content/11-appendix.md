# 부록: 실전 템플릿과 체크리스트

## 부록 1: PREP 템플릿

PREP 법칙은 어떤 상황에서든 논리적으로 말할 수 있게 해주는 만능 프레임워크입니다. 아래 템플릿을 복사하여 중요한 발언이나 의견 전달 전에 정리해 보세요.

### PREP 기본 템플릿

| 단계 | 질문 | 나의 내용 |
|------|------|----------|
| **P** (Point) | 내가 하고 싶은 말의 핵심은? | |
| **R** (Reason) | 왜 그렇게 생각하는가? | |
| **E** (Example) | 구체적 사례나 데이터는? | |
| **P** (Point) | 다시 한번 강조하면? | |

### PREP 활용 예시 모음

**상황 1: 회의에서 의견 제시**

| 단계 | 내용 |
|------|------|
| P | "이번 캠페인은 인스타그램에 집중해야 합니다." |
| R | "타깃 고객의 80%가 인스타그램을 주력 채널로 사용하기 때문입니다." |
| E | "경쟁사 B도 인스타그램 전환 후 참여율이 3배 증가했습니다." |
| P | "따라서 인스타그램 집중 전략을 제안합니다." |

**상황 2: 상사에게 제안하기**

| 단계 | 내용 |
|------|------|
| P | "재택근무를 주 2일로 확대하면 좋겠습니다." |
| R | "통근 시간 절약으로 업무 효율이 올라가기 때문입니다." |
| E | "지난달 재택근무 시행 결과, 팀 생산성이 15% 향상됐습니다." |
| P | "주 2일 재택근무 확대를 검토해 주시면 감사하겠습니다." |

**상황 3: 일상 대화에서 추천하기**

| 단계 | 내용 |
|------|------|
| P | "이번 주말 강릉 여행 추천해!" |
| R | "요즘 날씨가 딱 좋고, 바다도 보고 카페거리도 있어서." |
| E | "나도 지난달에 갔는데 순두부 맛집이 진짜 대박이었어." |
| P | "강릉 2박 3일, 후회 안 할 거야!" |

## 부록 2: 보고 STAR 템플릿

업무 보고, 면접 답변, 성과 정리에 활용하는 STAR 프레임워크입니다.

### STAR 기본 템플릿

| 단계 | 질문 | 나의 내용 |
|------|------|----------|
| **S** (Situation) | 어떤 상황이었는가? (배경, 맥락) | |
| **T** (Task) | 해결해야 할 과제는 무엇이었는가? | |
| **A** (Action) | 구체적으로 무엇을 했는가? | |
| **R** (Result) | 결과와 성과는 무엇인가? (숫자로) | |

### STAR 활용 예시

**예시 1: 업무 보고**

| 단계 | 내용 |
|------|------|
| S | "3분기 고객 문의 응답 시간이 평균 6시간으로 고객 불만이 증가하고 있었습니다." |
| T | "응답 시간을 2시간 이내로 단축하는 것이 목표였습니다." |
| A | "AI 챗봇을 도입하여 단순 문의 자동 응답 체계를 구축하고, 복잡한 문의는 전담 인력을 배치했습니다." |
| R | "응답 시간이 평균 1.5시간으로 단축되었고, 고객 만족도가 25% 상승했습니다." |

**예시 2: 면접 답변**

| 단계 | 내용 |
|------|------|
| S | "신제품 런칭을 앞두고 핵심 협력업체가 갑자기 계약을 철회했습니다." |
| T | "2주 안에 대체 업체를 확보하고 일정을 맞춰야 했습니다." |
| A | "3일 만에 5개 업체를 컨택하여 비교 분석하고, 가장 적합한 업체와 긴급 계약을 체결했습니다." |
| R | "일정 지연 없이 런칭에 성공했고, 새 업체와의 단가가 기존보다 10% 낮았습니다." |
