# 9장: 디지털 시대의 소통

## 화면 뒤에서도 소통 능력이 필요하다

우리는 하루에 카카오톡 메시지를 수십 개 보내고, 이메일을 확인하고, 화상회의에 참석합니다. 대면 소통만큼이나 **디지털 소통 능력**이 중요한 시대입니다.

문제는 디지털 소통에서는 표정, 목소리, 바디랭귀지가 제한되거나 없다는 것입니다. 그래서 같은 말도 오해받기 쉽습니다. "네" 한 글자가 "알겠다"가 될 수도, "기분 나쁘다"가 될 수도 있습니다.

---

## 카카오톡 메시지 잘 쓰기

카카오톡은 한국인의 일상 소통 수단 1위입니다. 하지만 의외로 카톡 때문에 오해가 생기고, 관계가 틀어지는 경우가 많습니다.

### 카톡 메시지 기본 원칙

| 원칙 | 나쁜 예 | 좋은 예 |
|------|--------|--------|
| 줄바꿈 활용 | "내일 회의 10시에 3층 회의실에서 하는데 자료 준비해서 오세요 참고로 김 과장도 참석합니다" | "내일 회의 안내드립니다. / 시간: 10시 / 장소: 3층 회의실 / 자료 준비 부탁드려요. / 김 과장님도 참석합니다." |
| 용건을 먼저 | "안녕하세요~ 요즘 바쁘시죠? 다름이 아니라..." | "안녕하세요! 다음 주 미팅 일정 조율 관련해서 연락드렸어요." |
| 이모티콘 적절히 | 매 문장마다 이모티콘 | 핵심 메시지 뒤에 1~2개 |

### 카톡에서 오해를 줄이는 법

| 오해 유발 표현 | 대안 |
|-------------|------|
| "네." (마침표가 차갑게 느껴짐) | "네!" 또는 "네~" 또는 "넵!" |
| "ㅇㅇ" (무성의하게 느껴짐) | "응응" 또는 "그래!" |
| "알겠습니다" (격식이 차갑게 느껴질 때) | "알겠습니다!" 또는 "네, 확인했어요~" |
| 읽씹 (읽고 답 안 하기) | 바로 답하기 어려우면 "확인했어요, 좀 이따 답할게요!" |
| 장문 메시지 폭탄 | 긴 내용은 전화나 대면으로 |

### 카톡 타이밍

| 상황 | 적절한 타이밍 |
|------|-------------|
| 업무 메시지 | 근무 시간 내 (9시~18시) |
| 친구 연락 | 상대 패턴에 맞추기 (야행성 친구에게 아침 7시 메시지는 피하기) |
| 급한 용건 | 전화로 하세요 (카톡은 실시간이 아닙니다) |
| 안부 | 명절, 생일 등 자연스러운 계기에 |
| 사과/감사 | 가능하면 직접 만나서 |

## 이메일 제목 쓰기

이메일은 제목이 반입니다. 제목이 나쁘면 열어보지도 않습니다.

### 이메일 제목 공식

**좋은 제목 = 핵심 키워드 + 행동 요청 + 기한**

| 나쁜 제목 | 좋은 제목 |
|----------|----------|
| "안녕하세요" | "Q3 마케팅 예산안 검토 요청 (9/20까지)" |
| "문의드립니다" | "신규 거래처 계약서 서명 관련 확인 요청" |
| "보고서" | "9월 매출 보고서 최종본 첨부" |
| "급한 건입니다" | "서버 장애 발생: 긴급 대응 필요 (9/15 오전)" |
| "Re: Re: Re: Re: 회의" | 새 제목으로 갱신하세요 |

### 이메일 제목 접두어 활용

| 접두어 | 용도 | 예시 |
|--------|------|------|
| 요청 | 상대에게 행동을 요구할 때 | "요청: 거래처 연락처 공유 부탁" |
| 공유 | 정보 전달 목적 | "공유: 3분기 시장 분석 리포트" |
| 회신 | 답변이 필요할 때 | "회신 요망: 워크숍 참석 여부 확인" |
| 긴급 | 즉시 확인이 필요할 때 | "긴급: 고객사 미팅 시간 변경" |
| FYI | 참고용 | "FYI: 업계 동향 뉴스레터" |

## 화상 회의 에티켓

화상 회의는 이제 일상이지만, 아직 에티켓을 모르는 분들이 많습니다.

### 화상 회의 기본 에티켓

| 항목 | 권장 사항 |
|------|----------|
| 접속 | 5분 전에 접속하여 마이크·카메라 테스트 |
| 카메라 | 켜기 (끄면 참여도가 낮아 보임) |
| 마이크 | 발언하지 않을 때는 음소거 |
| 배경 | 깔끔한 실내 또는 블러 배경 |
| 복장 | 상의는 단정하게 (하의도... 만약을 위해) |
| 발언 | 손들기 기능 사용 또는 "한 가지 말씀드려도 될까요?" |
| 채팅 | 질문이나 링크 공유에 활용 |
| 이름 | 실명으로 설정 ("iPhone" 대신 이름) |

### 화상 회의에서 존재감 있게 참여하는 법

**방법 1: 카메라 렌즈 보기**
상대 얼굴이 아닌 카메라 렌즈를 보면, 상대 화면에서는 눈을 마주치는 것으로 보입니다.

**방법 2: 리액션 크게 하기**
작은 화면에서는 미세한 표정이 안 보입니다. 고개를 크게 끄덕이고, 표정도 평소보다 크게.

**방법 3: 이름 불러주기**
"김 과장님 의견에 동의합니다" — 온라인에서 이름을 불러주면 존재감과 연결감이 높아집니다.

**방법 4: 채팅 적극 활용**
발언하기 어려울 때, 채팅으로 "좋은 아이디어입니다!", "데이터 공유 감사합니다"를 남기세요.

## SNS에서 의견 표현하기 (싸우지 않고)

SNS에서 의견이 다른 글을 보면 한마디 하고 싶을 때가 있습니다. 하지만 온라인 논쟁은 대부분 생산적이지 않습니다.

### SNS 소통 원칙

| 원칙 | 설명 |
|------|------|
| 30분 규칙 | 감정적으로 반응하고 싶으면, 30분 후에 다시 생각해 보기 |
| 사실과 의견 구분 | "이건 사실이 아닙니다" (사실 교정) vs "저는 다르게 생각합니다" (의견 표현) |
| 인신공격 금지 | 의견에 반대하되, 사람을 공격하지 않기 |
| 떠나는 용기 | 논쟁이 감정적으로 흐르면, 멈추는 것이 이기는 것 |
| 공개 vs DM | 건설적 토론은 공개, 민감한 이야기는 DM으로 |

### 반대 의견을 말할 때

"그건 틀렸어요" 대신 "저는 조금 다른 관점이 있는데요. 이런 면도 있지 않을까요?"

"말도 안 돼요" 대신 "흥미로운 시각이네요. 이런 데이터도 참고해 보시면 좋을 것 같습니다."

## 음성 메시지 vs 텍스트

카카오톡 음성 메시지, 언제 쓰는 게 좋을까요?

### 상황별 적합한 소통 수단

| 상황 | 적합한 수단 | 이유 |
|------|-----------|------|
| 간단한 확인 | 텍스트 | 빠르고, 기록이 남음 |
| 복잡한 설명 | 음성 메시지 또는 전화 | 텍스트로 쓰면 너무 길어짐 |
| 감정 전달 | 음성 메시지 또는 전화 | 텍스트는 감정이 잘 안 전달됨 |
| 공식적 기록 | 이메일 | 증빙·검색 가능 |
| 긴급한 일 | 전화 | 즉시 확인 가능 |
| 여러 명에게 공유 | 그룹 채팅 또는 이메일 | 동시 전달 |

### 음성 메시지 에티켓

- 30초 이내로 짧게
- 시작에 용건을 먼저: "미팅 시간 변경 관련입니다"
- 시끄러운 곳에서 보내지 않기
- 상대가 음성 메시지를 선호하는지 확인하기 (싫어하는 사람도 있음)

## 세대별 소통 차이

같은 한국어를 쓰는데, 세대마다 소통 방식이 다릅니다.

### 세대별 소통 특성

| 구분 | MZ세대 (1990~2010년생) | X세대 (1970~1980년생) | 베이비붐 세대 (1955~1969년생) |
|------|---------------------|---------------------|--------------------------|
| 선호 채널 | 카톡, 슬랙, DM | 이메일, 전화 | 전화, 대면 |
| 메시지 스타일 | 짧고 캐주얼 | 적당히 격식 | 격식 중시 |
| 이모티콘 | 적극 사용 | 가끔 사용 | 거의 안 사용 |
| 업무 보고 | 실시간 공유 | 정기 보고 | 대면 보고 선호 |
| 피드백 | 즉각적, 솔직 | 단계적 | 완곡한 표현 |

### 세대 간 소통 팁

**MZ세대가 윗세대에게:** 중요한 내용은 전화나 대면으로. 이모티콘 사용 줄이기. 격식체 사용.

**윗세대가 MZ세대에게:** 긴 전화 대신 핵심만 짧게. 카톡/슬랙 활용. "OO씨 생각은 어때?" 의견 물어보기.

**핵심:** 내가 편한 방식이 아니라, **상대가 편한 방식**으로 소통하세요.

## AI 시대에 더 중요해진 소통 능력

AI가 글도 쓰고, 번역도 하고, 요약도 해주는 시대입니다. 그러면 소통 능력은 덜 중요해질까요? **정반대입니다.**

### AI가 대체할 수 없는 소통 영역

| AI가 잘하는 것 | 사람만 할 수 있는 것 |
|-------------|-----------------|
| 문법에 맞는 글쓰기 | 상대의 감정을 읽고 공감하기 |
| 정보 요약 | 신뢰를 바탕으로 설득하기 |
| 다국어 번역 | 관계를 쌓고 유지하기 |
| 데이터 분석 | 갈등을 해결하고 협상하기 |
| 템플릿 생성 | 리더십과 동기부여 |

### AI 시대에 기르자야 할 소통 능력

**1. 질문력:** AI에게 좋은 결과물을 얻으려면 좋은 질문(프롬프트)을 해야 합니다. 이것은 곧 소통 능력입니다.

**2. 공감력:** AI가 못하는 영역. 사람과의 대화에서 감정을 읽고 공감하는 능력의 가치가 더 올라갑니다.

**3. 협업력:** 다양한 배경의 사람들과 소통하며 시너지를 만드는 능력. AI 도구를 활용하되, 최종 소통은 사람이 합니다.

**4. 스토리텔링:** 데이터는 AI가 분석하지만, 그 데이터를 사람의 마음을 움직이는 이야기로 만드는 것은 사람의 몫입니다.

## 이 장의 핵심 정리

1. 카톡은 **줄바꿈, 용건 먼저, 이모티콘 적절히** 사용
2. 이메일 제목은 **핵심 키워드 + 행동 요청 + 기한**
3. 화상 회의에서는 **카메라 ON, 리액션 크게, 이름 불러주기**
4. SNS에서는 **30분 규칙**으로 감정적 반응 자제
5. **상대의 세대에 맞는** 소통 방식을 선택하라
6. AI 시대에 **공감력, 질문력, 스토리텔링**의 가치는 더 올라간다

> "도구가 아무리 발전해도, 소통의 본질은 사람과 사람 사이의 연결이다."
