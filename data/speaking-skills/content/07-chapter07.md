# 7장: 갈등과 어려운 대화 다루기

## 피할 수 없는 대화라면, 잘하자

살다 보면 꼭 해야 하지만 하기 싫은 대화가 있습니다.

- 동료에게 실수를 지적해야 할 때
- 연인과 불만을 이야기해야 할 때
- 부모님과 의견이 다를 때
- 화가 난 고객을 응대해야 할 때

이런 대화를 피하면 문제는 더 커집니다. 하지만 잘못 대화하면 관계가 깨집니다. **어려운 대화를 잘 다루는 것이 진짜 소통 능력**입니다.

---

## 비난 없이 문제 제기하기: I-Message

갈등 상황에서 가장 중요한 기술은 **I-Message (나-메시지)**입니다.

### You-Message vs I-Message

| You-Message (비난) | I-Message (전달) |
|-------------------|-----------------|
| "**넌** 왜 맨날 늦어?" | "약속 시간에 늦으면 **나는** 걱정이 돼." |
| "**너는** 항상 내 말을 무시하잖아." | "내 의견이 반영되지 않으면 **나는** 소외감을 느껴." |
| "**당신이** 일을 제대로 안 하니까 문제지." | "이 부분이 수정되지 않으면 **저는** 다음 단계를 진행하기 어렵습니다." |

### I-Message 공식

**"(상황)일 때, 나는 (감정)을 느껴. (원하는 것)해주면 좋겠어."**

### 실전 적용

| 상황 | I-Message |
|------|----------|
| 배우자가 집안일을 안 할 때 | "내가 혼자 집안일을 하면 체력적으로 힘들어. 주말에 역할을 나눠서 하면 좋겠어." |
| 동료가 마감을 안 지킬 때 | "자료가 늦어지면 저도 후속 작업이 밀려서 부담이 됩니다. 가능한 일정을 알려주시면 제가 조율하겠습니다." |
| 친구가 약속을 자주 취소할 때 | "약속이 갑자기 취소되면 나는 좀 서운해. 미리 알려주면 다른 계획을 세울 수 있으니까." |
| 아이가 정리를 안 할 때 | "장난감이 바닥에 있으면 엄마가 다칠 수 있어서 걱정돼. 놀고 나서 정리해 줄 수 있을까?" |

## 감정적 대화에서 냉정 유지하기

화가 났을 때 말하면 후회할 말이 나옵니다. 감정이 격해졌을 때는 **일단 멈추는 것**이 최선입니다.

### 감정 조절 4단계

**1단계: 인식하기**
"아, 지금 내가 화가 나고 있구나." 감정을 인식하는 것만으로도 감정의 강도가 줄어듭니다.

**2단계: 멈추기**
"잠깐, 이 상태에서 말하면 안 되겠다." 심호흡을 3번 하거나, 물을 한 잔 마시세요.

**3단계: 시간 벌기**
"이 문제는 중요하니까 좀 더 생각해 보고 다시 이야기하자."
"지금은 감정이 앞서는 것 같아서, 내일 차분하게 대화하면 안 될까?"

**4단계: 준비 후 대화하기**
감정이 가라앉은 후, I-Message로 정리해서 대화합니다.

### 상대가 감정적일 때 대응법

| 상대의 상태 | 나의 대응 |
|-----------|----------|
| 화를 내며 소리 지를 때 | 목소리를 낮추고 천천히 말하기 "말씀하시는 부분 이해합니다" |
| 울면서 말할 때 | 조용히 기다려 주기 "천천히 말씀하셔도 돼요" |
| 비꼬거나 냉소적일 때 | 감정에 반응하지 말고 내용에 집중 "구체적으로 어떤 부분이 문제인지 말씀해 주시겠어요?" |
| 말을 안 하고 침묵할 때 | 압박하지 않기 "준비되면 이야기해 줘. 기다릴게" |

## 사과의 기술: 진심이 전달되는 4단계

"미안해"라고 말했는데 상대가 "진심이야?"라고 물어본 적 있나요? 사과에도 기술이 필요합니다.

### 진심 있는 사과 4단계

**1단계: 잘못 인정하기**
구체적으로 무엇을 잘못했는지 말합니다.
"내가 약속 시간에 30분이나 늦어서 기다리게 했지."

**2단계: 상대의 감정 인정하기**
"많이 기다렸고, 화도 났을 거야. 당연히 그럴 수 있어."

**3단계: 재발 방지 약속하기**
"다음부터는 30분 전에 출발할게. 만약 늦을 것 같으면 미리 연락할게."

**4단계: 보상하기 (가능하다면)**
"오늘 저녁은 내가 살게. 가고 싶은 데 있어?"

### 잘못된 사과 유형

| 잘못된 사과 | 문제점 |
|-----------|--------|
| "미안해, 근데 네가 먼저..." | 변명이 붙으면 사과가 아니다 |
| "내가 뭘 잘못했는데?" | 잘못을 모르면 사과 전에 먼저 물어봐라 |
| "미안해, 됐지?" | 강압적. 상대의 감정을 존중하지 않음 |
| "그런 뜻이 아니었어" | 의도와 상관없이 상대가 상처받은 사실을 인정해야 함 |
| "미안미안~" (가볍게) | 진지하지 않은 사과는 더 화나게 함 |

## 피드백 샌드위치: 긍정 → 개선 → 격려

누군가에게 개선점을 말할 때, 샌드위치 기법을 사용하면 상대의 방어 반응을 줄일 수 있습니다.

### 피드백 샌드위치 구조

**빵 (긍정):** 잘한 점을 먼저 인정합니다.

**속재료 (개선):** 개선할 점을 구체적으로 말합니다.

**빵 (격려):** 발전 가능성을 격려합니다.

### 실전 예시

| 대상 | 피드백 샌드위치 |
|------|--------------|
| 후배 직원에게 | **긍정:** "이번 보고서 전체 구성이 깔끔해서 좋았어요." **개선:** "다만 3페이지 데이터 출처가 누락됐는데, 이 부분만 보완하면 완벽할 것 같아요." **격려:** "이 정도 퀄리티면 다음 프로젝트도 기대됩니다." |
| 아이에게 | **긍정:** "오늘 숙제 스스로 한 거 진짜 대단해!" **개선:** "글씨를 조금 더 또박또박 쓰면 선생님이 더 읽기 쉬울 거야." **격려:** "매일 이렇게 하면 금방 더 잘하게 될 거야." |

### 주의할 점

- 긍정이 **진심**이어야 합니다. 억지 칭찬은 상대가 느낍니다
- "하지만"이라는 단어는 앞의 긍정을 지웁니다. **"그리고"** 또는 **"추가로"**를 사용하세요
- 개선 피드백은 **구체적인 행동**에 대해서만 (성격이나 인격은 절대 건드리지 마세요)

## 가족 갈등 대화법

가족 사이의 갈등은 가장 어렵습니다. 감정의 역사가 깊기 때문입니다.

### 부모님과의 갈등

| 상황 | 피하기 | 대신 이렇게 |
|------|--------|-----------|
| 부모님이 간섭할 때 | "좀 그만 간섭해요!" | "걱정해 주시는 거 알아요. 제가 이렇게 하려고 하는 이유를 한번 들어봐 주실래요?" |
| 의견이 다를 때 | "엄마는 몰라요" | "엄마 생각도 맞을 수 있어요. 제 생각은 이런데, 한번 같이 얘기해 볼까요?" |
| 잔소리에 지칠 때 | 무시하기, 화내기 | "엄마 말씀 중에 이 부분은 정말 그런 것 같아요. 제가 신경 쓸게요." (부분 동의) |

### 배우자/연인과의 갈등

**핵심 규칙 3가지:**

1. **"항상", "맨날", "전혀"** 같은 극단적 단어 금지
   - "너는 항상 늦잖아" → "지난주에 두 번 늦었잖아" (구체적 사실)

2. **과거 끄집어내기 금지**
   - "그때도 그랬잖아" → 지금 이 상황에만 집중

3. **승패가 아닌 해결에 초점**
   - "내가 맞잖아" → "우리 둘 다 만족할 수 있는 방법을 찾자"

## 화가 난 고객 응대법

고객이 화를 내면 당황스럽지만, 공식이 있습니다.

### 고객 응대 HEAT 공식

**H - Hear (듣기):** 끝까지 들어줍니다. 중간에 끊지 마세요.

**E - Empathize (공감):** "불편을 드려서 정말 죄송합니다. 충분히 화가 나실 만합니다."

**A - Apologize (사과):** "저희 잘못으로 불편을 끼쳐드린 점 진심으로 사과드립니다."

**T - Take action (해결):** "바로 확인해서 30분 내로 처리해 드리겠습니다."

### 고객 응대 시 금기

| 절대 하면 안 되는 말 | 대안 |
|-------------------|------|
| "그건 저희 잘못이 아닌데요" | "어떤 상황이셨는지 자세히 말씀해 주시겠어요?" |
| "원래 그렇습니다" | "이 부분은 현재 시스템 상 이렇게 되어 있는데, 개선 방안을 찾아보겠습니다" |
| "다른 분은 불만이 없는데요" | "고객님의 의견이 중요합니다" |
| "잠깐만요" (그리고 오래 대기) | "확인에 약 5분 정도 소요됩니다. 기다려 주시겠어요?" |

## "대화가 안 통하는 사람" 대처법

아무리 노력해도 소통이 안 되는 사람은 존재합니다. 이때 필요한 것은 **기대 수준 조절**입니다.

### 유형별 대처법

| 유형 | 특징 | 대처법 |
|------|------|--------|
| 자기 말만 하는 사람 | 상대 말에 관심 없음 | 핵심만 짧게 전달, 구두보다 문서로 소통 |
| 부정적인 사람 | 모든 것에 "안 돼" | 구체적 대안을 함께 제시 "이건 어떨까요?" |
| 감정 기복이 심한 사람 | 예측 불가 | 감정에 휘말리지 않기, 사실에만 집중 |
| 은근히 공격적인 사람 | 비꼬기, 뒷담화 | 직접적으로 확인 "혹시 제게 하실 말씀이 있으신가요?" |
| 결정을 못 하는 사람 | 우유부단 | 선택지를 2개로 줄여서 제시 |

### 최후의 전략: 경계 설정

"저는 이런 식의 대화는 어렵습니다. 서로 존중하면서 이야기하면 좋겠습니다."
이 말을 차분하게, 단호하게 전달하세요. 경계를 설정하는 것은 무례한 것이 아닙니다.

## 이 장의 핵심 정리

1. **I-Message**로 비난 없이 문제를 전달하라
2. 감정적일 때는 **멈추고, 시간을 벌어라**
3. 사과는 **잘못 인정 → 감정 인정 → 재발 방지 → 보상** 4단계로
4. 피드백은 **긍정 → 개선 → 격려** 샌드위치로
5. 가족 갈등에서는 **극단적 단어를 피하고, 해결에 초점**
6. 대화가 안 통하는 사람에게는 **경계를 설정**하라

> "어려운 대화를 피하면 문제가 커지고, 잘못하면 관계가 깨진다. 기술을 배우면 둘 다 지킬 수 있다."
