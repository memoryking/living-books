# 2장: 경청 — 말 잘하는 사람의 진짜 비밀 무기

## 말 잘하는 사람은 말을 적게 한다

아이러니하게 들리겠지만, 진짜 말 잘하는 사람들의 비밀은 **"잘 듣는 것"**입니다.

생각해 보세요. 대화 후에 "이 사람이랑 얘기하니까 좋다"고 느꼈던 사람을 떠올려 보세요. 그 사람이 혼자 많이 떠들었나요? 아닙니다. 그 사람은 **내 이야기를 잘 들어줬던 사람**입니다.

데일 카네기가 말했습니다. "대화의 달인이 되려면, 좋은 경청자가 되어라."

---

## 80/20 법칙: 80% 듣기, 20% 말하기

대화에서 말 잘하는 사람들은 이 비율을 지킵니다.

| 구분 | 일반적인 대화 | 좋은 대화 |
|------|-------------|----------|
| 말하기 비율 | 70% 이상 | 20% |
| 듣기 비율 | 30% 이하 | 80% |
| 상대의 기분 | "내 말은 관심 없나 보네" | "이 사람은 내 말을 진심으로 들어주네" |
| 대화 후 느낌 | 피곤하다 | 기분 좋다 |

물론 상황에 따라 다릅니다. 프레젠테이션에서는 당연히 말하기 비율이 높아야 합니다. 하지만 **일상 대화, 상담, 갈등 해결**에서는 듣기 80%가 황금 비율입니다.

---

## 적극적 경청 (Active Listening) 5단계

경청은 그냥 조용히 있는 게 아닙니다. **적극적으로 듣는 것**입니다.

### 1단계: 집중하기 (Attending)

상대에게 온전히 집중합니다.

- 핸드폰을 뒤집어 놓거나 가방에 넣기
- 상대의 눈을 보기 (3초 보고 1초 쉬기)
- 몸을 살짝 상대 쪽으로 기울이기
- 팔짱 끼지 않기

**실수 예시:** 카페에서 친구 이야기를 들으면서 핸드폰 알림을 확인하는 것. 친구는 "내 이야기에 관심 없구나"라고 느낍니다.

### 2단계: 인정하기 (Acknowledging)

듣고 있다는 신호를 보냅니다.

- 고개 끄덕이기
- "응", "그래", "맞아" 등 짧은 추임새
- 표정으로 반응하기 (놀라움, 공감, 안타까움)

### 3단계: 반영하기 (Reflecting)

상대의 감정을 읽어서 되돌려 줍니다.

| 상대의 말 | 감정 반영 |
|----------|----------|
| "프로젝트가 너무 힘들어" | "정말 힘들겠다. 많이 지쳤구나." |
| "이번에 승진에서 떨어졌어" | "그동안 열심히 했는데 속상하겠다." |
| "아이가 학교에서 상 받았어!" | "와, 정말 자랑스럽겠다!" |
| "남자친구랑 또 싸웠어" | "마음이 많이 안 좋겠네." |

### 4단계: 확인하기 (Clarifying)

제대로 이해했는지 확인합니다.

- "그러니까 이런 뜻이야?"
- "내가 이해한 게 맞는지 확인해도 될까?"
- "정리하면, A 때문에 B가 힘든 거지?"

### 5단계: 요약하기 (Summarizing)

대화의 핵심을 정리해 줍니다.

- "그러니까 지금 가장 고민인 건 세 가지인 거네. 업무량, 상사와의 관계, 그리고 연봉."
- "들어보니까 핵심은 시간 부족 문제인 것 같아."

## 상대가 "이 사람은 다르다"고 느끼는 순간

사람들이 감동하는 경청의 순간들이 있습니다.

**순간 1: 지난 대화를 기억할 때**
"지난번에 어머니 건강이 안 좋다고 했었는데, 지금은 좀 괜찮으세요?"
이 한마디에 상대는 "이 사람이 내 말을 진심으로 들었구나"라고 느낍니다.

**순간 2: 말하지 않은 감정을 읽어줄 때**
"괜찮다고 하는데, 표정을 보니까 좀 힘든 것 같아. 괜찮아?"
사람들은 표면적인 말과 실제 감정이 다를 때가 많습니다.

**순간 3: 끝까지 들어줄 때**
중간에 끊지 않고, 상대가 하고 싶은 말을 다 할 때까지 기다려 주는 것. 이것만으로도 충분합니다.

**순간 4: 판단하지 않고 들어줄 때**
"그건 네가 잘못한 거 아니야?" 대신 "그때 마음이 어땠어?"
판단 없이 들어주는 것이 진정한 경청입니다.

## 맞장구의 기술

맞장구는 단순한 "응, 응"이 아닙니다. 수준이 있습니다.

### 맞장구 레벨

| 레벨 | 방법 | 예시 |
|------|------|------|
| Lv.1 | 단순 반응 | "응", "그래", "아~" |
| Lv.2 | 감탄 반응 | "진짜?", "대박", "헐" |
| Lv.3 | 감정 반영 | "그거 엄청 억울했겠다" |
| Lv.4 | 핵심어 반복 | "아, 3번이나 거절당한 거야?" |
| Lv.5 | 확장 질문 | "그래서 그 다음에는 어떻게 했어?" |

**Lv.4와 Lv.5를 자주 사용하면** 상대는 "이 사람은 정말 내 말을 듣고 있구나"라고 느낍니다.

### 핵심어 반복 예시

상대: "이번에 제주도 올레길을 혼자 걸었는데, 정말 힐링됐어."
나: "올레길을 혼자 걸었어? 완전 멋지다! 어느 코스 걸었어?"

상대의 말에서 **핵심 단어를 골라 반복**하면, 자연스럽게 대화가 이어집니다.

## "그럼 이런 거예요?" 확인 질문의 힘

확인 질문은 경청의 가장 강력한 도구입니다.

### 확인 질문 패턴

| 패턴 | 예시 |
|------|------|
| 내용 확인 | "그러니까 마감이 금요일에서 수요일로 당겨진 거죠?" |
| 감정 확인 | "지금 화가 나신 건 결과보다는 과정이 불공정하다고 느끼셔서인 거죠?" |
| 의도 확인 | "이 제안의 핵심은 비용 절감보다는 품질 향상에 있는 거죠?" |
| 요약 확인 | "정리하면 A, B, C 세 가지를 말씀하신 건가요?" |

확인 질문의 효과는 놀랍습니다. 상대는 "이 사람이 정확히 이해했구나"라고 느끼고, 오해로 인한 갈등을 미리 방지할 수 있습니다.

## 공감 vs 해결: 상대가 원하는 것을 구별하라

이것은 특히 남녀 간, 부모-자녀 간 대화에서 중요합니다.

### 상황: 친구가 직장 상사에 대해 불평할 때

| 반응 유형 | 답변 | 상대의 느낌 |
|----------|------|-----------|
| 해결형 | "그러면 인사팀에 정식으로 항의해봐" | "내 마음은 관심 없고 해결책만 주네" |
| 공감형 | "진짜 힘들겠다. 매일 그런 상사 밑에서 일하는 거 쉽지 않지" | "내 마음을 알아주는구나" |

### 구별하는 방법

상대가 원하는 것이 뭔지 모르겠으면, **직접 물어보세요.**

"지금 내가 같이 해결책을 찾아줄까, 아니면 그냥 들어줄까?"

이 한마디가 대화의 질을 완전히 바꿉니다.

### 공감 먼저, 해결은 나중에

대부분의 경우, 순서는 이렇습니다.

**공감하기** → **충분히 들어주기** → **상대가 준비됐을 때** → **조심스럽게 의견 제시**

"그건 정말 힘들었겠다" (공감) → "나도 비슷한 경험이 있어서 이해가 돼" (연결) → "혹시 내 생각도 말해도 될까?" (허락 구하기) → "이렇게 해보는 건 어때?" (제안)

## 경청을 방해하는 7가지 나쁜 습관

자신에게 해당하는 것이 있는지 체크해 보세요.

| 나쁜 습관 | 예시 | 해당 여부 |
|----------|------|----------|
| 끼어들기 | 상대 말 중간에 "아, 나도!" | |
| 선택적 듣기 | 관심 있는 부분만 듣기 | |
| 평가하기 | "그건 네가 잘못한 거지" | |
| 대기하기 | 내 말할 차례만 기다리기 | |
| 조언 강요 | "이렇게 해, 저렇게 해" | |
| 비교하기 | "나는 더 힘들었어" | |
| 딴짓하기 | 핸드폰 보면서 "응, 응" | |

3개 이상 해당된다면, 경청 연습이 필요합니다.

## 이 장의 핵심 정리

1. 말 잘하는 사람의 진짜 비밀은 **잘 듣는 것**이다
2. **80% 듣기, 20% 말하기**가 황금 비율이다
3. 적극적 경청 5단계: **집중 → 인정 → 반영 → 확인 → 요약**
4. 맞장구는 **핵심어 반복과 확장 질문**이 최고 레벨이다
5. **공감 먼저, 해결은 나중에** — 상대가 원하는 걸 먼저 파악하라
6. 경청만 잘해도 **"이 사람은 다르다"**는 평가를 받을 수 있다

> "들을 줄 아는 사람이 결국 말도 잘한다. 경청은 최고의 대화 기술이다."
