# 10장: 30일 말하기 업그레이드 플랜

## 30일이면 달라진다

"말하기를 어떻게 연습하죠? 학원을 다녀야 하나요?"

아닙니다. **일상 속에서 매일 조금씩 연습**하면 됩니다. 이 장에서 제시하는 30일 플랜을 따라 하면, 한 달 뒤에는 주변 사람들이 "요즘 뭔가 달라졌다"고 말할 것입니다.

이 플랜은 4주로 나뉩니다. 매주 하나의 핵심 스킬에 집중합니다.

---

## Week 1: 경청 훈련 (1~7일차)

첫 주는 **듣기**에 집중합니다. 말을 잘하기 위한 가장 좋은 출발점은 잘 듣는 것입니다.

### 일별 미션

| 일차 | 미션 | 실천 체크 |
|------|------|----------|
| Day 1 | 오늘 대화에서 **상대 말 끊지 않기** (하루 종일) | |
| Day 2 | 대화 중 **핵심어 반복** 3회 이상 하기 | |
| Day 3 | 누군가에게 **확인 질문** 2회 이상 하기 ("그러니까 이런 거야?") | |
| Day 4 | 대화 후 **상대가 한 말의 핵심** 메모하기 | |
| Day 5 | 공감 표현 5회 이상 하기 ("그거 힘들었겠다", "좋았겠다!") | |
| Day 6 | 하루 동안 의식적으로 **80% 듣기, 20% 말하기** 실천 | |
| Day 7 | 1주일 동안의 경청 경험 중 **가장 좋았던 순간** 기록하기 | |

## 매일 3분 스피치 연습법

매일 3분만 투자하면 말하기가 달라집니다.

### 3분 스피치 연습 방법

**시간:** 아침 출근 전, 점심 후, 자기 전 중 편한 시간

**장소:** 거울 앞, 운전 중, 샤워 중 어디든

**방법:**

**1분 - 주제 선택 후 바로 말하기 시작**
준비 시간 없이 바로 말하는 것이 핵심입니다. 두괄식으로 결론부터.

**2분 - 이유와 예시 전개**
PREP 구조로 이유와 구체적 사례를 말합니다.

**3분 - 마무리**
핵심을 다시 정리하며 깔끔하게 끝냅니다.

### 3분 스피치 주제 리스트

| 번호 | 주제 |
|------|------|
| 1 | 내가 좋아하는 음식과 그 이유 |
| 2 | 최근에 본 영화/드라마 추천 |
| 3 | 가장 기억에 남는 여행 |
| 4 | 내가 생각하는 좋은 리더의 조건 |
| 5 | 아침형 인간 vs 저녁형 인간 |
| 6 | 올해 가장 잘한 결정 |
| 7 | 10년 후의 나에게 하고 싶은 말 |
| 8 | 내가 추천하는 스트레스 해소법 |
| 9 | 재택근무의 장단점 |
| 10 | 나를 변화시킨 한 마디 |

녹음 후 들어보면서 체크해 보세요.

|----------|----------|----------|----------|----------|
| 결론 먼저 말했는가 | 결론이 어딘지 모르겠음 | 중간에 결론이 나옴 | 첫 문장이 결론 | |
| 논리 구조가 있는가 | 두서없음 | 대체로 흐름이 있음 | PREP 구조가 명확 | |
| 간투사 빈도 | 5회 이상 | 3회 이하 | 거의 없음 | |
| 목소리 크기·톤 | 작고 단조로움 | 적당함 | 크기와 톤 변화가 있음 | |
| 시간 관리 | 1분 미만 or 5분 초과 | 2~4분 | 정확히 3분 | |

## 마지막으로: 말하기는 평생의 기술

이 책에서 배운 모든 기술은 하나로 통합니다.

**상대를 존중하고, 명확하게 전달하고, 진심으로 연결하는 것.**

완벽한 말하기는 없습니다. 중요한 것은 **어제보다 나은 오늘의 대화**입니다.

30일 플랜을 마치고 나면, 이 책의 처음으로 돌아가서 한 번 더 읽어보세요. 처음 읽을 때와는 다른 것들이 보일 것입니다.

당신의 말하기 여정을 응원합니다.

## 이 장의 핵심 정리

1. **Week 1:** 경청 — 듣기 80%, 말하기 20%
2. **Week 2:** 두괄식 — 결론부터, PREP 구조로
3. **Week 3:** 질문 — 열린 질문으로 대화 확장
4. **Week 4:** 실전 — 배운 모든 기술 적용
5. **매일 3분 스피치**가 가장 효과적인 연습법
6. **30일 후에도 계속** — 말하기는 평생의 기술

> "30일이 인생을 바꾸는 것이 아니다. 30일의 습관이 평생을 바꾸는 것이다."
