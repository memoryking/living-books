# 복사해 쓰는 초집중 실행 키트

이 부록은 본문에서 배운 내용을 바로 실행할 수 있도록 정리한 템플릿과 체크리스트 모음입니다. 인쇄하거나 노션/메모 앱에 복사해서 매일 사용하세요.

---

## 1. 일일 집중 루틴 템플릿

### 아침 준비 (출근 전)
- [ ] 7시간 이상 수면 확인
- [ ] 물 한 잔 마시기
- [ ] 오늘의 개구리(가장 중요한 업무) 1가지 정하기
- [ ] 오늘의 SMART 목표 확인하기

### 오전 딥워크 (09:00~12:00)
- [ ] 디지털 셧다운 의식 실행 (알림 끄기, 메신저 상태 변경)
- [ ] 스마트폰 서랍/가방에 넣기
- [ ] 개구리 타임: 포모도로 1세트 (25분 집중 + 5분 휴식)
- [ ] 포모도로 2세트
- [ ] 포모도로 3세트
- [ ] 포모도로 4세트
- [ ] 15~30분 긴 휴식 (산책, 스트레칭)

### 점심 리차지 (12:00~13:00)
- [ ] 단백질+채소 중심 식사
- [ ] 10~15분 실외 산책
- [ ] 스마트폰 확인은 산책 후에

### 오후 업무 (13:00~18:00)
- [ ] 이메일/메신저 일괄 확인 및 처리 (30분)
- [ ] 회의/협업 시간
- [ ] 오후 딥워크 포모도로 1~2세트 (선택)
- [ ] 간식: 견과류/과일 (과자/음료 대신)

### 마무리 (퇴근 전)
- [ ] 오늘 완료한 일 3가지 적기
- [ ] 내일의 개구리 정하기
- [ ] 내일의 시간 블록 배치하기
- [ ] 디지털 종료 의식: "업무 끝. 내일 다시."

## 8. 자주 묻는 질문 (FAQ) 10선

**Q1. 오픈 오피스에서 어떻게 딥워크를 하나요?**
노이즈캔슬링 이어폰 착용, 모니터에 "집중 중" 메모 부착, 팀 내 "집중 시간" 합의가 3대 전략입니다. 불가능하면, 회의실이나 카페를 활용해 주 1~2회 장소를 바꿔 딥워크하세요.

**Q2. 포모도로 25분이 너무 짧아요.**
좋은 신호입니다. 50분 집중 + 10분 휴식으로 늘려보세요. 90분까지 확장할 수 있습니다. 핵심은 타이머를 사용한다는 것 자체입니다.

**Q3. 카카오톡을 완전히 끌 수 없는 직종이에요.**
모든 알림을 끌 필요 없습니다. 핵심 업무 단체방만 알림을 유지하고, 나머지는 끄세요. "방해금지" 대신 "알림 최소화"를 목표로 합니다.

**Q4. 아침에 회의가 잡혀서 개구리 먹기가 안 돼요.**
회의 후 첫 30분을 개구리 시간으로 확보하세요. 아침이 최적이지만, 회의 직후도 집중력이 비교적 높은 시간입니다. 유연하게 적용하세요.

**Q5. 습관이 자꾸 무너져요. 의지가 약한 건가요?**
의지의 문제가 아니라 시스템의 문제입니다. 목표를 더 작게 줄이고(25분→10분→5분), 환경을 더 단순하게 만들고, 기존 습관에 연결(습관 스태킹)하세요.

**Q6. 포모도로 중간에 상사가 부르면요?**
짧게 대응하고 돌아오세요. 그 포모도로는 무효 처리하고, 새 포모도로를 시작합니다. 자책하지 마세요. 완벽한 환경은 없습니다.

**Q7. 멀티태스킹이 필요한 업무도 있지 않나요?**
진짜 동시 처리가 필요한 업무는 극히 드뭅니다. 대부분은 빠른 순차 처리(배칭)로 대체할 수 있습니다. 이메일 10개를 하나씩 처리하는 것보다, 모아서 한 번에 30분간 처리하는 것이 더 빠릅니다.

**Q8. 주말에도 딥워크를 해야 하나요?**
반드시 그럴 필요 없습니다. 90일 챌린지는 주 5일 기준입니다. 주말은 충분히 쉬세요. 다만 자기 계발이나 사이드 프로젝트를 위해 주말에 1~2시간 딥워크를 하면 성장 속도가 빨라집니다.

**Q9. 카페인 없이 집중이 안 돼요.**
카페인 의존도가 높다면, 2주간 서서히 줄여보세요. 하루 3잔→2잔→1잔. 동시에 수면 시간을 늘리면, 카페인 없이도 자연스러운 각성이 가능해집니다. 물을 많이 마시는 것도 도움이 됩니다.

**Q10. 90일 후에도 계속해야 하나요?**
90일은 시스템을 구축하는 기간입니다. 이후에는 의식적 노력 없이도 딥워크가 자연스러운 일상이 됩니다. 다만 분기마다 한 번씩 루틴을 점검하고 개선하는 것을 추천합니다. 환경은 계속 변하니까요.
