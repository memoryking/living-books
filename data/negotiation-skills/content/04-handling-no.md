# Chapter 4. 상대의 "No"를 다루는 기술

## "No"는 끝이 아니라 시작이다

대부분의 사람은 상대가 "안 돼요"라고 말하는 순간 협상이 끝났다고 생각합니다. 체면이 구겨지고, 기분이 상하고, "더 이상 말해봤자 소용없어"라며 물러섭니다.

하지만 숙련된 협상가의 시각은 정반대입니다. **"No"는 진짜 협상이 시작되는 신호입니다.**

FBI 인질 협상관 출신 크리스 보스는 이렇게 말했습니다. "상대가 'No'라고 말할 때, 그것은 최종 답이 아니다. 그것은 '지금 이 조건으로는 안 된다'는 뜻이다."

**"No"의 진짜 의미를 분석해봅시다.**

| 상대가 말하는 "No" | 실제 의미 | 다음 행동 |
|-------------------|----------|----------|
| "안 됩니다" | 지금 조건은 안 됨 | 조건 변경 제안 |
| "그건 어렵습니다" | 내부 승인이 어려움 | 승인 가능한 조건 탐색 |
| "다시 생각해보겠습니다" | 관심은 있지만 확신이 없음 | 추가 근거 제시 |
| "좀 더 알아보고요" | 비교 검토하겠다는 뜻 | 차별화 포인트 강조 |
| "지금은 타이밍이 아닙니다" | 우선순위가 낮음 | 긴급성 부여 또는 타이밍 재조정 |
| "위에서 안 된다고 합니다" | 본인은 괜찮은데 결재가 안 됨 | 결재 가능한 대안 함께 모색 |

## 라벨링(Labeling): 상대의 감정에 이름을 붙여라

크리스 보스가 FBI에서 사용한 가장 효과적인 기법이 **라벨링**입니다. 상대의 감정이나 상황을 말로 짚어주는 것입니다.

**형식:** "~인 것 같습니다" / "~하신 것 같네요" / "~라고 느끼시는 것 같습니다"

**왜 효과적인가?** 사람은 자기 감정을 누군가 알아줄 때 방어벽을 낮춥니다. 공감받았다는 느낌이 협상의 문을 엽니다.

### 실전 라벨링 예시

| 상황 | 상대의 반응 | 라벨링 화법 |
|------|-----------|-----------|
| 연봉 협상 | "그 금액은 안 됩니다" | "예산에 대한 부담이 크신 것 같습니다" |
| 납기 협상 | "2주 안에는 절대 불가능해요" | "일정이 굉장히 빠듯하다고 느끼시는 것 같네요" |
| 클레임 대응 | "다시는 거래 안 합니다" | "이번 건으로 많이 실망하셨을 것 같습니다" |
| 가족 갈등 | "당신은 맨날 그래" | "내가 신경을 많이 못 써서 서운하셨나 봐요" |
| 상사 설득 | "지금 그런 거 할 때가 아니야" | "지금 팀 상황이 녹록지 않다고 판단하시는 것 같습니다" |

**라벨링의 핵심 규칙:**

1. "나는"으로 시작하지 마세요 — "나는 당신이 화났다고 생각합니다"는 판단입니다.
2. "~인 것 같습니다"로 시작하세요 — 부드러운 추측이 방어를 낮춥니다.
3. 라벨링 후 **침묵**하세요 — 상대가 반응할 시간을 주는 것이 핵심입니다.

## 미러링(Mirroring): 상대의 말을 반복하라

미러링은 놀랍도록 간단하지만 강력한 기법입니다. **상대가 말한 마지막 1~3개 단어를 그대로 반복**하는 것입니다.

**팀장:** "이번 프로젝트는 예산이 좀 빠듯해서 외주는 어려울 것 같아."

**미러링:** "외주가 어려울 것 같다고요?"

**팀장:** "응, 이번 분기 예산이 거의 소진됐거든. 근데 내부 인력으로 하면 시간이 좀..."

미러링만 했는데 상대가 추가 정보를 자발적으로 공개합니다. 왜 그럴까요?

**미러링이 작동하는 이유:**

| 원리 | 설명 |
|------|------|
| 경청 신호 | "이 사람이 내 말을 듣고 있구나" |
| 명확화 욕구 | 자기 말을 되돌아보며 보충 설명 |
| 심리적 유대 | 같은 말을 쓰면 동질감 형성 |
| 정보 획득 | 추가 설명 과정에서 핵심 정보 노출 |

### 미러링 실전 적용

**거래처 미팅:**

상대: "솔직히 가격이 좀 높아요."

나: "가격이 좀 높다고요?" (미러링 + 침묵)

상대: "네, 저번에 다른 업체에서 받은 견적이 20% 정도 낮았거든요. 근데 퀄리티는 좀..."

이 순간 핵심 정보를 얻었습니다. 상대에게 더 저렴한 대안이 있지만, 퀄리티에 대한 우려도 있다는 것을.

## "어떻게 하면 될까요?" — 질문의 전환

상대가 "안 돼요"라고 할 때, 가장 효과적인 대응 중 하나는 **열린 질문으로 전환**하는 것입니다.

| 닫힌 반응 (비효과적) | 열린 질문 (효과적) |
|---------------------|-------------------|
| "왜 안 되는데요?" (공격적) | "어떤 조건이면 가능할까요?" |
| "정말 안 되는 건가요?" (구걸) | "제가 어떻게 도우면 승인받으실 수 있을까요?" |
| "그러면 어쩌라고요" (감정적) | "서로 만족할 수 있는 방법이 있을까요?" |
| "다른 데는 해줬는데요" (비교) | "우리 상황에서 가능한 대안을 같이 찾아볼까요?" |

**"어떻게(How)"와 "무엇(What)"으로 시작하는 질문**이 핵심입니다.

- "어떻게 하면 이 문제를 해결할 수 있을까요?"
- "무엇이 가장 큰 걸림돌인가요?"
- "어떤 조건이 추가되면 가능해질까요?"

이런 질문의 마법은, **상대를 문제 해결의 파트너로 만든다**는 것입니다. "안 돼요"라고 말한 사람이 스스로 "이렇게 하면 될 수도 있어요"를 말하게 됩니다.

## 침묵의 힘: 전략적 포즈

한국 사람들은 대화에서 침묵을 매우 불편해합니다. 그래서 상대가 침묵하면 서둘러 양보하거나, 불필요한 말을 덧붙입니다.

**하지만 협상에서 침묵은 최고의 무기 중 하나입니다.**

### 침묵이 효과적인 순간

| 타이밍 | 침묵의 효과 |
|--------|-----------|
| 제안을 한 직후 | 상대가 먼저 반응하게 만듦 |
| 상대가 낮은 가격을 제시한 직후 | 불만을 표현하지 않아도 "그게 전부예요?"가 전달됨 |
| 라벨링 후 | 상대가 스스로 감정을 풀어놓음 |
| 상대가 감정적으로 나올 때 | 감정적 에너지를 스스로 소진하게 함 |

### 침묵 사용법

**1단계:** 핵심 발언을 합니다.

**2단계:** 입을 다뭅니다.

**3단계:** 눈을 부드럽게 마주칩니다(노려보지 마세요).

**4단계:** 최소 5초, 이상적으로는 7~10초를 기다립니다.

**5단계:** 상대가 먼저 말합니다. 거의 100% 확률로.

처음에는 5초가 5분처럼 느껴질 겁니다. 하지만 연습하면 자연스러워집니다.

## 감정적 반응 대처법

협상에서 상대가 화를 내거나, 목소리를 높이거나, 감정적으로 나올 때가 있습니다. 이때 절대 하면 안 되는 것과 해야 하는 것을 구분합시다.

| 하면 안 되는 것 | 해야 하는 것 |
|---------------|------------|
| 같이 화내기 | 톤을 낮추고 천천히 말하기 |
| "진정하세요"라고 말하기 | "충분히 그렇게 느끼실 수 있습니다" |
| 즉시 양보하기 | "잠시 정리할 시간을 갖겠습니다" |
| 논리로 반박하기 | 먼저 감정을 인정하고, 그 다음 논리 |
| 자리를 박차고 나가기 | "오늘은 여기까지 하고, 내일 다시 이야기할까요?" |

**감정 대응 3단계:**

**1단계 — 인정:** "이 부분이 정말 답답하실 거라고 생각합니다."

**2단계 — 공감:** "저라도 그런 상황이면 같은 마음일 겁니다."

**3단계 — 전환:** "그래서 서로 만족할 수 있는 방법을 찾고 싶습니다."

감정을 인정하는 것과 요구를 수용하는 것은 완전히 다릅니다. 감정은 인정하되, 조건은 별도로 협의하세요.

## 실전 시나리오: 프로젝트 마감일 협상

**상황:** 클라이언트가 2주 안에 완료를 요구하지만, 현실적으로 4주가 필요합니다.

| 단계 | 대화 |
|------|------|
| 클라이언트 요구 | "이번 달 말까지 끝내주셔야 합니다" |
| 라벨링 | "일정이 많이 촉박하신 것 같습니다" |
| 클라이언트 반응 | "네, 임원 보고가 있어서 어쩔 수 없어요" |
| 미러링 | "임원 보고가 있으시다고요?" |
| 클라이언트 보충 | "사실 핵심 데이터만 있으면 보고는 가능해요" |
| 열린 질문 | "핵심 데이터를 먼저 2주 안에 드리고, 최종본은 4주 후에 납품하는 건 어떨까요?" |
| 합의 | 핵심 중간 산출물 2주 + 최종본 4주 |

이것이 "No"를 "Yes"로 바꾸는 과정입니다. 상대의 진짜 이해(임원 보고)를 파악했기에 가능한 해결책이었습니다.

## 이 장의 핵심

1. **"No"는 끝이 아니라 협상의 시작이다** — 진짜 의미를 파악하고 대응하세요.
2. **라벨링으로 감정을 인정하라** — "~인 것 같습니다"가 방어벽을 허뭅니다.
3. **미러링으로 정보를 얻어라** — 마지막 1~3단어를 반복하면 상대가 스스로 풀어놓습니다.
4. **"어떻게"와 "무엇"으로 질문하라** — 상대를 문제 해결의 파트너로 만드세요.
5. **침묵을 두려워하지 마라** — 5초의 침묵이 5%의 추가 양보를 만듭니다.
6. **감정에는 감정으로, 조건에는 논리로** — 감정 인정과 조건 수용은 별개입니다.

다음 장에서는 이 모든 기술을 종합해서, 한국 직장인의 최대 관심사인 연봉 협상에 적용합니다.
