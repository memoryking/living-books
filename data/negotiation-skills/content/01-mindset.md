# Chapter 1. 협상은 싸움이 아니다: 마인드셋 전환

## 왜 우리는 협상을 두려워할까

"협상"이라는 단어만 들어도 몸이 긴장되는 분이 있을 겁니다. 한국직업능력연구원의 2025년 조사에 따르면, 한국 직장인의 68%가 "협상 상황이 불편하다"고 답했습니다. 그 이유를 분석하면 명확한 패턴이 보입니다.

| 두려움 | 실제 내면의 생각 | 현실 |
|--------|-----------------|------|
| 거절 공포 | "안 된다고 하면 어쩌지" | 거절은 대화의 시작점일 뿐 |
| 관계 훼손 | "이걸 말하면 사이가 나빠질까" | 오히려 명확한 소통이 관계를 강화 |
| 갈등 회피 | "그냥 참는 게 편해" | 참는 것이 쌓이면 폭발한다 |
| 체면 의식 | "돈 얘기하면 격이 떨어져" | 합리적 요구는 프로페셔널의 기본 |
| 능력 부족감 | "나는 말재주가 없어서" | 협상은 말재주가 아니라 준비의 기술 |

핵심을 짚겠습니다. **협상을 피하는 것 자체가 이미 협상에서 진 것입니다.** 여러분이 "괜찮아요"라고 말할 때, 상대방은 자기가 원하는 것을 이미 얻었습니다.

## 협상 = 싸움? 완전히 잘못된 프레임

가장 먼저 버려야 할 생각이 있습니다. **"협상은 이기고 지는 게임"**이라는 믿음입니다.

많은 사람이 협상을 제로섬 게임으로 봅니다. 내가 1만 원 깎으면 상대가 1만 원 손해본다. 내 연봉이 500만 원 오르면 회사가 500만 원 손해본다. 이런 사고방식은 협상을 전쟁터로 만듭니다.

현실은 다릅니다.

**분배적 협상(Distributive):** 파이의 크기가 정해져 있고, 누가 더 가져가느냐를 다툼 — 이것만 협상이라고 생각하면 안 됩니다.

**통합적 협상(Integrative):** 파이 자체를 키워서 양쪽 모두 더 가져가는 구조 — 진짜 고수의 협상입니다.

예를 들어보겠습니다.

| 상황 | 분배적 접근 | 통합적 접근 |
|------|-----------|-----------|
| 연봉 협상 | "500만 원 올려주세요" vs "안 돼요" | "재택근무 2일 + 교육비 지원이면 현 연봉 수용 가능" |
| 납기 협상 | "2주 안에 해주세요" vs "3주 필요해요" | "핵심 기능만 2주에 납품, 나머지는 3주 후 추가" |
| 가사 분담 | "당신이 설거지해" vs "나는 피곤해" | "평일은 각자, 주말은 함께 + 한 달에 한 번 외식" |

## 일상이 협상이다

"나는 협상할 일이 없는데요?" 이렇게 생각하는 분이 많습니다. 하지만 하루를 돌아보면 협상 아닌 순간을 찾기가 더 어렵습니다.

**아침:** 알람을 끄고 5분만 더 자겠다고 자신과 협상합니다.

**출근길:** 택시 기사에게 "이 길로 가주세요"라고 경로를 제안합니다.

**오전 회의:** 팀장이 추가 업무를 요청하면, 기존 업무 우선순위와 조율합니다.

**점심:** 동료 5명이 각각 다른 음식을 먹고 싶어 합니다.

**오후:** 거래처에서 납기를 앞당겨 달라고 합니다.

**저녁:** 배우자와 주말 계획을 조율합니다.

이 모든 순간에 여러분의 협상 능력이 작동합니다. 잘하면 원하는 것을 얻고, 못하면 원하지 않는 결과를 받아들입니다.

## 기본 원칙: "상대도 원하는 게 있다"

모든 협상의 출발점은 이것입니다. **상대방도 무언가를 원한다.** 당연한 말 같지만, 실제 협상에 들어가면 대부분 자기가 원하는 것만 생각합니다.

상대가 원하는 것을 파악하는 순간, 게임이 바뀝니다.

| 나의 상황 | 내가 원하는 것 | 상대가 원하는 것 | 가능한 합의 |
|----------|--------------|----------------|-----------|
| 연봉 협상 | 연봉 인상 | 인재 유지, 예산 관리 | 연봉 + 스톡옵션 조합 |
| 거래처 협상 | 낮은 단가 | 안정적 물량 확보 | 장기 계약 조건으로 단가 할인 |
| 배우자 설득 | 새 차 구매 | 저축 목표 달성 | 중고차로 절충 + 적금 유지 |

## 입장(Position) vs 이해(Interest)

하버드 협상 프로젝트에서 나온 가장 중요한 개념입니다.

**입장(Position):** 상대가 겉으로 말하는 것 — "연봉 6,000만 원이 아니면 안 갑니다"

**이해(Interest):** 그 입장 뒤에 숨은 진짜 욕구 — "가족을 부양할 수 있는 안정적 수입이 필요합니다"

유명한 오렌지 사례를 봅시다. 두 자매가 오렌지 하나를 두고 싸웁니다. 입장만 보면 둘 다 "오렌지를 원한다"입니다. 하지만 이해를 파보면, 언니는 오렌지 즙으로 주스를 만들고 싶고, 동생은 오렌지 껍질로 케이크를 만들고 싶습니다. 입장은 충돌하지만, 이해는 양립 가능합니다.

**직장에서의 적용:**

| 상대의 입장 | 숨겨진 이해 | 대응 전략 |
|-----------|-----------|----------|
| "야근 좀 해줘" | 마감 압박, 상사 눈치 | "내일 오전에 일찍 와서 마무리하겠습니다" |
| "이 가격은 안 돼요" | 예산 한도, 결재 라인 | "분할 결제나 패키지 조정은 가능한가요?" |
| "다른 곳도 알아보고 있어요" | 더 나은 조건 확보 | "저희만의 차별 포인트를 말씀드릴게요" |

## BATNA: 최선의 대안

BATNA(Best Alternative To a Negotiated Agreement)는 협상학에서 가장 중요한 개념입니다. 한마디로 **"이 협상이 결렬되면 나의 플랜 B는 무엇인가?"**입니다.

BATNA가 강할수록 협상력이 올라갑니다. BATNA가 없으면 어떤 조건이든 받아들일 수밖에 없습니다.

**BATNA 강도에 따른 협상력 변화:**

| BATNA 수준 | 예시 | 협상 자세 |
|-----------|------|----------|
| 강력한 BATNA | 다른 회사 오퍼가 있는 상태 | 여유 있게 최적 조건 요구 |
| 보통 BATNA | 현 직장을 유지할 수 있는 상태 | 합리적 범위 내 협상 |
| 약한 BATNA | 당장 이 일자리가 필요한 상태 | 최소 조건이라도 수용 |
| BATNA 없음 | 대안이 전혀 없는 상태 | 상대 조건 무조건 수용 |

중요한 것은 **BATNA는 만드는 것**이라는 점입니다. 자연적으로 생기는 것이 아닙니다. 연봉 협상 전에 다른 회사에 이력서를 넣어두는 것, 거래처 협상 전에 대체 공급업체를 확보해두는 것, 이것이 BATNA를 만드는 행위입니다.

## 실전 연습: 마인드셋 점검

지금 바로 자가 진단을 해봅시다.

| 질문 | 그렇다 | 아니다 |
|------|--------|--------|
| 가격 흥정이 불편하다 | | |
| 부당한 요구를 받아도 참는 편이다 | | |
| "안 돼요"라는 말이 무섭다 | | |
| 협상은 말 잘하는 사람이 이긴다고 생각한다 | | |
| 상대가 화내면 양보하는 편이다 | | |
| 연봉 협상을 해본 적이 없다 | | |

"그렇다"가 3개 이상이면, 이 책이 여러분의 인생을 바꿀 수 있습니다. 문제는 능력이 아니라 마인드셋이었으니까요.

## 이 장의 핵심

1. **협상은 싸움이 아니라 문제 해결이다** — 양쪽 모두 원하는 것을 얻는 방법을 찾는 과정입니다.
2. **일상의 모든 대화가 협상이다** — 인식하는 순간 연습 기회가 무한히 생깁니다.
3. **입장이 아니라 이해를 파악하라** — 겉으로 드러난 요구 뒤의 진짜 욕구를 찾으세요.
4. **BATNA를 만들어라** — 대안이 없으면 협상력도 없습니다. 항상 플랜 B를 준비하세요.
5. **협상을 피하는 것이 가장 나쁜 협상이다** — 침묵은 상대에게 동의로 해석됩니다.

다음 장에서는 실전 협상에 들어가기 전에 반드시 해야 하는 준비 작업을 다룹니다. 준비가 90%라는 말, 과장이 아닙니다.
