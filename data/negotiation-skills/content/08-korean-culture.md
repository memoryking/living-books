# Chapter 8. 문화와 협상: 한국적 상황에서의 전략

## 한국에서 협상이 특별히 어려운 이유

미국 협상 교과서에서는 "자신감 있게 요구하라", "직접적으로 말하라", "감정을 빼라"고 가르칩니다. 하지만 이 조언을 한국 직장에서 그대로 적용하면 "건방지다", "예의가 없다", "분위기 파악 못 한다"는 평가를 받습니다.

한국의 협상 환경에는 고유한 변수가 있습니다.

| 문화적 요소 | 협상에 미치는 영향 |
|-----------|-----------------|
| 위계질서 | 상급자에게 반박이 어려움 |
| 체면 문화 | 상대를 공개적으로 궁지에 몰면 관계 파탄 |
| 관계 중심 | 이해관계보다 인간관계가 먼저 |
| 간접적 소통 | 직접적 거절 대신 "생각해볼게요" |
| 집단주의 | 개인 의견보다 팀·조직 논리가 우선 |
| 정(情) 문화 | 오래 알면 깎아줘야 한다는 기대 |
| 빨리빨리 | 충분한 협상 과정 없이 빨리 결론 |

이 문화적 변수를 이해하고 활용하는 것이 한국에서의 협상 능력입니다.

## "분위기"와 "눈치"를 활용하는 법

눈치는 한국 문화의 핵심 코드입니다. 협상에서 눈치를 잘 활용하면 강력한 무기가 됩니다.

### 눈치로 읽는 협상 신호

| 상대의 행동 | 해석 | 대응 |
|-----------|------|------|
| 시계를 자주 본다 | 시간 압박, 빨리 끝내고 싶음 | 핵심 조건만 집중 제시 |
| 펜을 돌린다 | 불안하거나 고민 중 | 추가 정보로 확신 제공 |
| 동료와 눈빛 교환 | 내부 소통 중, 의견 조율 | 잠시 기다리며 관찰 |
| 앞으로 몸을 기울인다 | 관심 있음, 긍정적 | 구체적 조건 제시 타이밍 |
| 팔짱을 낀다 | 방어적, 부정적 | 압박 줄이고 공감 표현 |
| "네, 네" 연발 | 경청이 아니라 끝내고 싶음 | 핵심만 간결하게 전달 |
| "검토해보겠습니다" | 대부분 거절의 완곡한 표현 | "언제까지 답변 주실 수 있나요?"로 확인 |

### 분위기를 만드는 기술

한국 협상에서는 **본론에 들어가기 전의 분위기 조성**이 중요합니다.

| 분위기 조성법 | 예시 |
|-------------|------|
| 공통 관심사 대화 | 골프, 야구, 맛집, 날씨 |
| 상대 칭찬 | "이번 프로젝트 성과가 정말 인상적이었습니다" |
| 관계 언급 | "저번에 도움 주셔서 정말 감사했습니다" |
| 겸손한 시작 | "부족한 점이 있겠지만 잘 부탁드립니다" |
| 적절한 유머 | 긴장을 풀되, 상대를 깎아내리지 않는 유머 |

서양에서는 "시간 낭비"로 보일 수 있지만, 한국에서는 이 시간이 합의율을 높이는 투자입니다.

## 상사에게 제안하기

한국 직장에서 가장 어려운 협상입니다. "말하지 않으면 아무것도 안 바뀐다" vs "말하면 찍힌다"의 딜레마.

### 상사 유형별 전략

| 상사 유형 | 특징 | 접근법 |
|----------|------|--------|
| 권위적 상사 | 결정은 내가 한다 | 선택지를 주되, 최종 결정은 상사가 하는 구조로 |
| 합리적 상사 | 데이터를 중시 | 숫자와 근거를 준비해서 보고 형식으로 |
| 관계형 상사 | 사람을 중시 | 1:1 비공식 자리에서 부드럽게 |
| 변화 거부형 상사 | "원래 이렇게 해왔어" | 작은 파일럿부터 제안, 성과로 증명 |

### 상사에게 연봉 인상을 요청하는 화법

**하면 안 되는 말:**

"다른 팀 김대리는 얼마 받던데요." (비교는 역효과)

"저 안 올려주면 나갈 겁니다." (협박은 관계를 파괴)

"원래 이 정도면 더 받아야 하는 거 아닌가요?" (모호한 근거)

**효과적인 화법:**

"팀장님, 5분만 시간 괜찮으시면 한 가지 상의드리고 싶습니다. 올해 성과에 대해 제 생각을 말씀드리고, 연봉 부분에서 의견을 여쭙고 싶습니다."

"올해 맡았던 A, B, C 프로젝트에서 이런 성과가 있었습니다. (구체적 수치) 이 점을 고려해서 연봉 조정이 가능한지 검토 부탁드려도 될까요?"

"팀장님 판단이 가장 중요하다고 생각합니다. 방향을 말씀해주시면 거기에 맞춰 더 열심히 하겠습니다."

**핵심:** 상사가 결정권자라는 것을 존중하면서, 근거 있는 요청을 하는 것입니다.

## 한국식 식사 자리 협상

한국 비즈니스에서 식사 자리는 단순한 식사가 아닙니다. **비공식 협상 채널**입니다.

### 식사 자리 협상의 규칙

| 규칙 | 설명 |
|------|------|
| 바로 본론 꺼내지 않기 | 음식 주문 후, 가벼운 대화로 시작 |
| 술자리에서 합의한 것은 다음 날 확인 | "어제 말씀하신 내용 메모해왔습니다" |
| 상석 배치에 신경 쓰기 | 상급자가 안쪽 자리, 문에서 먼 곳 |
| 계산은 초대한 쪽이 | 가격이 아니라 관계의 투자 |
| 과음하지 않기 | 협상력은 술잔이 비워질수록 떨어짐 |

### 식사 자리에서 본론을 꺼내는 타이밍

**1단계 (음식 도착 전):** 가벼운 대화, 안부, 업계 뉴스

**2단계 (식사 중반):** "아, 그러고 보니 한 가지 여쭤볼 게 있는데요" — 자연스럽게 연결

**3단계 (디저트/커피):** 구체적 조건 논의 — 가장 이상적인 타이밍

**4단계 (식사 후):** "오늘 좋은 말씀 감사합니다" — 서면 후속 연락 예고

## 계약서 없는 구두 합의의 위험

한국 비즈니스에서 여전히 흔한 관행입니다. "우리 사이에 계약서가 무슨 필요가 있어" 혹은 "일단 시작하고, 계약서는 나중에."

**구두 합의가 위험한 이유:**

| 상황 | 구두 합의 결과 | 서면 계약 결과 |
|------|-------------|-------------|
| 범위 변경 | "처음부터 포함이었잖아요" | 계약서 범위를 확인하면 명확 |
| 대금 미지급 | "그 금액 아니었는데요" | 계약서에 명시된 금액대로 |
| 일정 지연 | "언제 한다고 한 적 없어요" | 납기일 명시, 지연 패널티 |
| 분쟁 발생 | 증거 없음, 말 대 말 | 법적 보호 가능 |

**"관계가 좋아서 계약서를 안 쓰는 게 아닙니다. 관계가 좋기에 계약서를 쓰는 것입니다."** 계약서는 양쪽을 보호합니다.

### 구두 합의를 서면화하는 스크립트

"오늘 대화 내용을 정리해서 이메일로 보내드리겠습니다. 빠진 것이나 수정할 것 있으시면 말씀해주세요."

이것만 해도 분쟁의 90%를 예방합니다.

## 동아시아 협상 스타일 vs 서양 스타일

외국 기업과 거래하거나 다문화 환경에서 일하는 분들을 위한 비교입니다.

| 요소 | 한국/동아시아 | 서양(미국/유럽) |
|------|-------------|---------------|
| 관계 우선 vs 거래 우선 | 관계를 먼저 쌓고 거래 | 거래 조건부터 논의 |
| 소통 방식 | 간접적, 맥락 의존적 | 직접적, 명시적 |
| 의사결정 | 합의 기반, 시간 필요 | 개인 결정권자 중심 |
| 계약서 역할 | 관계의 부속, 유연하게 변경 가능 | 법적 구속력, 엄격 준수 |
| 시간 개념 | 유연함, 다회 미팅 선호 | 효율 중시, 한 번에 결정 |
| 갈등 대응 | 회피 또는 중재자 활용 | 직접 대면 |
| 체면 | 매우 중요 | 상대적으로 덜 중요 |

### 외국 기업과 협상할 때 주의점

**서양 상대와 협상 시:**

- "검토해보겠습니다"를 "No"로 해석하지 않습니다 — 직접 물어보세요.
- 그들의 직접적인 화법을 무례하다고 느끼지 마세요 — 문화적 차이입니다.
- 서면 계약을 매우 중시합니다 — 구두 합의에 의존하면 안 됩니다.
- 식사보다 미팅룸에서의 논의를 선호합니다.

**한국 상대와 협상하는 외국인에게 알려줄 것:**

- 첫 미팅에서 바로 본론으로 들어가지 마세요.
- 공개적으로 상대를 반박하면 체면이 훼손됩니다.
- "네"가 항상 동의를 의미하지는 않습니다.
- 회식 문화를 이해하고 참여하면 관계가 깊어집니다.

## 한국적 협상에서 통하는 화법 패턴

| 상황 | 직접적 표현 (역효과) | 한국적 표현 (효과적) |
|------|-------------------|-------------------|
| 거절할 때 | "안 됩니다" | "좀 더 생각해보겠습니다" |
| 이의 제기 | "그건 틀렸습니다" | "혹시 이런 관점은 어떠실까요?" |
| 조건 변경 요청 | "이 조건을 바꿔주세요" | "이 부분에서 조율이 가능할까요?" |
| 불만 표현 | "이건 문제가 있어요" | "이 부분이 좀 아쉽습니다" |
| 가격 제안 | "100만 원입니다" | "시장 상황을 고려했을 때 100만 원 선이 적정하다고 봅니다" |

## 이 장의 핵심

1. **한국 문화를 무시하면 협상이 실패한다** — 위계, 체면, 관계를 이해하고 활용하세요.
2. **눈치는 정보 수집 도구다** — 상대의 비언어적 신호를 읽으세요.
3. **상사에게는 존중+근거로 접근하라** — 결정권을 인정하면서 데이터를 제시하세요.
4. **구두 합의를 반드시 서면화하라** — "관계가 좋아서"가 아니라 "관계를 지키기 위해" 계약서를 씁니다.
5. **문화 차이를 이해하면 글로벌 협상력이 올라간다** — 동서양의 차이를 아는 것이 경쟁력입니다.
