# Chapter 10. 30일 협상 능력 업그레이드 플랜

## 읽기만 하면 아무것도 바뀌지 않는다

여기까지 읽으셨다면, 협상에 대한 지식은 충분히 갖추셨습니다. 하지만 한 가지 불편한 진실이 있습니다. **책을 읽는 것과 실제로 협상을 잘하는 것은 완전히 다릅니다.**

수영 교본을 100번 읽어도 물에 들어가지 않으면 수영을 못 합니다. 협상도 마찬가지입니다. 이번 장에서는 30일 안에 배운 것을 실전에 적용하고 체화하는 구체적 플랜을 제공합니다.

## Week 1: 마인드셋 전환 (Day 1~7)

첫 주의 목표는 **"나는 매일 협상하고 있다"는 인식을 심는 것**입니다.

### Day 1~2: 협상 인식 훈련

하루 동안 겪는 모든 협상 상황을 기록하세요. 대부분 인식하지 못하고 지나치던 것들입니다.

| 시간 | 상황 | 협상 여부 | 결과 |
|------|------|----------|------|
| 오전 | 팀 회의에서 업무 배분 | | |
| 점심 | 동료와 식당 선택 | | |
| 오후 | 클라이언트 일정 조율 | | |
| 저녁 | 가족과 저녁 메뉴 결정 | | |
| 밤 | 자녀 취침 시간 조율 | | |

이틀만 기록해보면 "나는 하루에 10번 이상 협상한다"는 것을 체감하게 됩니다.

### Day 3~4: 작은 협상 시도

**미션 1:** 카페에서 "아이스 아메리카노 한 잔이요" 대신 "아이스 아메리카노 한 잔인데, 얼음 적게 해주실 수 있나요?" — 요청하는 연습입니다.

**미션 2:** 점심 식사 때 동료에게 "오늘 제가 먹고 싶은 데가 있는데, 어떠세요?" — 제안하는 연습입니다.

**미션 3:** 온라인 쇼핑에서 "쿠폰 있나요?"라고 채팅 문의하기 — 할인을 요청하는 연습입니다.

### Day 5~7: 마인드셋 일지

매일 저녁 5분, 다음 질문에 답하세요.

| 질문 | 오늘의 답변 |
|------|-----------|
| 오늘 협상 상황이 있었나? | |
| 내가 원하는 것을 말했나? | |
| 상대가 원하는 것은 무엇이었나? | |
| 결과에 만족하나? | |
| 다르게 했다면 어떻게 했을까? | |

## Week 2: 앵커링 + BATNA 연습 (Day 8~14)

두 번째 주의 목표는 **핵심 기술인 앵커링과 BATNA를 실전에서 연습하는 것**입니다.

### Day 8~9: 앵커링 연습

**미션 1 — 중고 거래:** 당근마켓에서 관심 있는 물건에 가격 제안을 해보세요. 시세를 조사하고, 근거를 대며 제안합니다.

**미션 2 — 서비스 할인:** 통신사, 보험사, 구독 서비스에 전화해서 할인이나 요금제 변경을 요청해보세요.

### Day 10~11: BATNA 만들기 연습

현재 여러분의 상황에서 BATNA를 구체적으로 작성해보세요.

| 항목 | 나의 현재 BATNA |
|------|---------------|
| 연봉 협상 시 나의 대안 | |
| 현재 거래처가 조건을 바꿀 때 대안 | |
| 현재 집 계약 갱신 시 대안 | |
| 현재 프로젝트가 무산될 때 대안 | |

BATNA가 비어 있는 항목이 있다면, 이번 주에 하나라도 채워보세요. 이력서 업데이트, 다른 거래처 미팅 잡기, 부동산 시세 확인 등 **구체적 행동**으로.

### Day 12~14: 라벨링·미러링 실전

**미션:** 일상 대화에서 라벨링과 미러링을 의식적으로 사용해보세요.

| 기법 | 연습 상황 | 예시 |
|------|----------|------|
| 라벨링 | 동료가 업무 불만을 말할 때 | "요즘 업무량 때문에 많이 지치신 것 같네요" |
| 미러링 | 상사가 지시할 때 | "금요일까지요?" (마지막 단어 반복) |
| 라벨링 | 배우자가 짜증을 낼 때 | "오늘 피곤하셨나 봐요" |
| 미러링 | 거래처가 조건을 말할 때 | "납기가 2주라고요?" |

**주의:** 너무 기계적으로 하면 오히려 어색합니다. 자연스러운 대화 속에 녹여넣으세요.

## Week 3: 실전 시뮬레이션 (Day 15~21)

세 번째 주의 목표는 **실제 크기의 협상을 시뮬레이션하고, 가능하면 실전에 적용하는 것**입니다.

### Day 15~17: 연봉 협상 시뮬레이션

신뢰할 수 있는 친구나 동료와 역할극을 해보세요.

| 역할 | 시나리오 |
|------|---------|
| 나: 직원 | 연봉 15% 인상 요청, 성과 자료 준비 |
| 상대: HR/팀장 | 예산 한도로 5%만 가능하다고 반박 |
| 목표 | 10% + 추가 복리후생으로 합의 |

**시뮬레이션 후 복기 질문:**

| 질문 | 답변 |
|------|------|

| 감정적으로 반응한 순간이 있었는가? | |

### Day 18~19: 비즈니스 협상 시뮬레이션

| 시나리오 | 역할 |
|---------|------|
| 프리랜서 단가 협상 | 나: 프리랜서, 상대: 클라이언트 |

| 파트너십 조건 협상 | 나: 제안자, 상대: 파트너사 |

### Day 20~21: 실전 적용

이번 주 안에 실제 협상을 하나 실행하세요. 크지 않아도 됩니다.

**실전 적용 후보:**

- 통신비 할인 요청 전화
- 구독 서비스 가격 네고
- 가전제품 매장에서 추가 할인 요청
- 자동차 정비소에서 수리 견적 조율
- 상사에게 업무 조건(재택근무 등) 요청

## 매일 협상 일지 작성법

30일 플랜이 끝난 후에도 협상력을 지속적으로 키우려면, **협상 일지**를 쓰는 습관이 가장 효과적입니다.

매일 5분, 다음 형식으로 기록하세요.

| 항목 | 오늘의 기록 |
|------|-----------|
| 날짜 | |
| 협상 상황 | |
| 내가 원했던 것 | |
| 상대가 원했던 것 | |
| 사용한 기법 | |
| 결과 | |
| 잘한 점 | |

한 달만 기록해보면, 자신의 패턴이 보입니다. 어떤 상황에서 잘하고, 어떤 상황에서 약한지. 그 패턴을 아는 것이 성장의 시작입니다.

## 30일 후 달라지는 것들

이 플랜을 성실히 실행하면 30일 후 이런 변화를 체감하게 됩니다.

| 변화 | 구체적 모습 |
|------|-----------|
| 요청에 대한 두려움 감소 | "안 될 게 뭐가 있어?"라는 마음 |
| 준비 습관 형성 | 중요한 대화 전에 자동으로 준비 |
| "No" 내성 증가 | 거절을 개인적으로 받아들이지 않음 |
| 상대 관점 이해력 향상 | "저 사람은 왜 저렇게 말하지?" 분석 가능 |
| 자기 가치 인식 | 과소평가하지 않고 합리적으로 요구 |
| 관계 개선 | 원하는 것을 말하면 오히려 소통이 좋아짐 |

## 이 장의 핵심

1. **지식을 행동으로 바꿔야 한다** — 읽기만 하면 아무것도 바뀌지 않습니다.
2. **작은 것부터 시작하라** — 카페 주문 변경, 온라인 할인 문의부터.
3. **시뮬레이션이 실전을 만든다** — 역할극 연습이 실전 자신감을 키웁니다.
4. **피해왔던 것에 도전하라** — 가장 어렵다고 느끼는 협상이 가장 큰 성장을 줍니다.
5. **일지를 쓰라** — 기록하면 패턴이 보이고, 패턴을 알면 개선할 수 있습니다.

부록에서는 바로 인쇄해서 쓸 수 있는 체크리스트, 스크립트, 템플릿을 제공합니다. 이 책의 내용을 실전에서 바로 활용하세요.
