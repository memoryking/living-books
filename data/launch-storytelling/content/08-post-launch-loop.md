# 런칭 이후: 수익화 루프 시스템 만들기

## 런칭이 끝나면 진짜가 시작된다

축하합니다. 런칭 D-Day를 무사히 넘기셨습니다. 하지만 여기서 멈추면 안 됩니다. 많은 사업자가 런칭 당일 매출에만 집중하고, 그 이후를 방치합니다. 결과는? 한 번 반짝하고 사라지는 "원히트원더"가 됩니다.

진짜 사업은 **런칭 이후에 만들어집니다**. 이 장에서는 런칭 에너지를 **지속 가능한 수익 시스템**으로 전환하는 방법을 다룹니다.

## 콘텐츠 재활용: 3-R 기준

런칭 과정에서 만든 콘텐츠는 **새로운 형태로 재활용**할 수 있습니다. 모든 콘텐츠를 처음부터 다시 만들 필요가 없습니다. 재활용 여부를 판단하는 기준이 **3-R**입니다.

### Results (결과)
이 콘텐츠가 실제로 성과를 냈는가?
- 높은 인게이지먼트를 받은 인스타 포스트
- 오픈율/클릭률이 높았던 이메일
- 공유가 많이 된 블로그 글

### Relevance (관련성)
이 콘텐츠가 현재 고객에게 여전히 유효한가?
- 시의성이 지난 내용은 업데이트
- 핵심 원리를 다루는 콘텐츠는 "에버그린"으로 활용
- 계절/트렌드에 맞게 앵글만 변경

### Refresh (리프레시)
새로운 형태로 변환할 수 있는가?
- 블로그 글 → 카드뉴스 (인스타그램)
- 이메일 시퀀스 → 뉴스레터 시리즈
- 라이브 세션 → 유튜브 클립 → 릴스
- FAQ 답변 → 블로그 포스트

**재활용 흐름 예시:**

```
런칭 프리런칭 콘텐츠 (원본)
  → 블로그 시리즈 (3-R 통과 콘텐츠 선별)
    → 카드뉴스 시리즈 (핵심 요약)
      → 숏폼 영상 (시각적 변환)
        → 이메일 뉴스레터 (구독자 전용 심화)
```

## 웨비나에서 상시 퍼널로 전환

런칭 때 진행한 라이브 세션이나 웨비나가 있다면, 이것을 **상시 판매 퍼널(Evergreen Funnel)**로 전환할 수 있습니다.

### 상시 퍼널 구조

1. **리드마그넷** → 이메일 수집 (4장에서 만든 것 그대로 활용)
2. **자동 웨비나** → 녹화본을 "주문형 세미나"로 제공
3. **자동 이메일 시퀀스** → 웨비나 시청 후 3통의 후속 이메일
4. **판매 페이지** → 런칭 때 사용한 상세페이지를 상시용으로 수정
5. **결제** → 얼리버드 대신 "지금 등록 시 보너스" 형태로 변경

핵심: 런칭의 긴급성은 사라지지만, **가치 전달 구조**는 그대로 유지됩니다.

## 고객 관리 시퀀스: 0/3/7/14/30일

구매 이후 고객을 방치하면 환불과 부정적 후기가 늘어납니다. 반대로, 적절한 타이밍에 관리하면 **재구매와 추천**이 발생합니다.

| 시점 | 목적 | 메시지 예시 |
|------|------|------------|
| **D+0** | 환영, 시작 가이드 | "구매 감사합니다! 먼저 이것부터 해보세요" |
| **D+3** | 진행 확인, 응원 | "3일째인데요, 어떠세요? 막히는 부분 있으시면 알려주세요" |
| **D+7** | 중간 점검, 성과 공유 | "1주일 되셨네요! 다른 분들은 이렇게 활용하고 계세요" |
| **D+14** | 심화 활용 안내 | "여기까지 오셨으면, 이 기능도 활용해 보세요" |
| **D+30** | 후기 요청, 추천 유도 | "한 달이 되었습니다. 솔직한 후기를 남겨주시면 ___을 드립니다" |

## 커뮤니티 선순환 만들기

구매 고객 커뮤니티는 **고객 유지와 신규 고객 획득**을 동시에 만드는 엔진입니다.

### 커뮤니티 플랫폼 선택 (한국)

| 플랫폼 | 장점 | 단점 |
|--------|------|------|
| 카카오 오픈채팅 | 접근성 최고, 즉시 소통 | 콘텐츠 정리 어려움 |
| 네이버 카페 | 콘텐츠 축적 가능, 검색 유입 | 관리 공수 높음 |
| 디스코드/슬랙 | 채널 분리, 구조화 | 한국 사용자 진입 장벽 |
| 노션 | 자료 정리 우수 | 실시간 소통 어려움 |

**추천 조합**: 카카오 오픈채팅(일상 소통) + 노션(자료 저장소)

### 커뮤니티 활성화 3단계

1. **Seed (씨앗)**: 초기 20-30명의 활발한 멤버 확보. 직접 질문을 던지고 대화를 이끕니다.
2. **Growth (성장)**: 멤버 간 자발적 대화가 시작되면, 주간 주제를 제공하고 우수 사례를 소개합니다.
3. **Self-sustain (자립)**: 멤버가 서로 질문하고 답하는 단계. 운영자는 방향 설정과 품질 관리에 집중합니다.

## 추천 프로그램 설계

만족한 고객이 새로운 고객을 데려오는 **추천 루프**는 가장 비용 효율적인 성장 방법입니다.

### 추천 프로그램 설계 원칙

1. **양쪽 보상**: 추천인과 피추천인 모두에게 혜택 (한쪽만 보상하면 동기 부족)
2. **간단한 프로세스**: 링크 하나로 추천 가능해야 합니다 (복잡하면 안 합니다)
3. **즉시 보상**: 추천 확인 즉시 보상이 전달되어야 합니다

**보상 유형 예시:**
- 추천인: 다음 구매 20% 할인 쿠폰
- 피추천인: 첫 구매 10% 할인
- 누적 추천 3건 이상: VIP 보너스 콘텐츠 제공

### 한국에서 활용 가능한 추천 도구

- **스마트스토어**: 친구 초대 쿠폰 기능
- **아임웹**: 쿠폰 코드 생성 후 수동 관리
- **채널톡**: 추천인 코드 추적
- **자체 구글 폼**: 추천인 이름 입력 → 수동 보상 (초기 단계 추천)
