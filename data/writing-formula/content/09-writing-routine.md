# Chapter 9. 글쓰기 루틴 시스템: 매일 쓰는 사람이 되는 법

## 영감을 기다리면 영원히 못 쓴다

"오늘은 영감이 안 와서 못 쓰겠어."

이 말을 하는 순간, 당신은 아마추어입니다. 프로는 영감을 기다리지 않아요. **시스템을 만들고 그 안에서 씁니다.**

작가 무라카미 하루키는 매일 새벽 4시에 일어나 5~6시간 글을 씁니다. 스티븐 킹은 하루 2,000단어를 쓰는 루틴을 40년간 지켰습니다. 매일 인스타에 글을 올리는 인플루언서들도 감이 아니라 **시스템**으로 운영합니다.

이 챕터에서는 아무리 바쁜 사람도 매일 글을 쓸 수 있는 루틴 시스템을 설계합니다.

## 글쓰기 루틴의 과학

### 습관 루프 (The Habit Loop)

찰스 두히그의 습관 루프 이론에 따르면, 모든 습관은 3단계로 작동합니다.

```
신호(Cue) → 루틴(Routine) → 보상(Reward)
```

**글쓰기 습관 루프 설계:**

| 요소 | 설계 예시 |
|---|---|
| **신호** | 아침 커피를 마실 때 / 퇴근 후 책상에 앉을 때 / 알람 |
| **루틴** | 15분 글쓰기 (타이머 세팅) |
| **보상** | 체크리스트에 체크 / 좋아하는 간식 / SNS에 인증 |

### 66일의 법칙

런던대학교 연구에 따르면, 새로운 습관이 자동화되는 데 평균 **66일**이 걸립니다. 처음 2주가 가장 힘들고, 4주가 지나면 점점 자연스러워지고, 66일이 지나면 "안 하면 불편한" 상태가 됩니다.

**핵심**: 처음 2주를 버티는 것이 전부입니다. 그래서 **시작 장벽을 극단적으로 낮추는** 전략이 필요합니다.

## 5단계 글쓰기 루틴 시스템

### Step 1: 시간 확보 — "15분의 기적"

"시간이 없어서 못 쓴다"는 핑계입니다. 하루 15분은 누구에게나 있어요.

**15분 확보 전략:**

| 상황 | 15분 확보법 |
|---|---|
| 직장인 | 출근 전 15분 일찍 일어나기 |
| 육아맘 | 아이 낮잠 시간 첫 15분 |
| 자영업자 | 오픈 전 15분 or 마감 후 15분 |
| 학생 | 점심시간 or 자기 전 15분 |
| 프리랜서 | 업무 시작 전 워밍업 15분 |

**중요**: 15분은 "최소량"입니다. 더 쓸 수 있으면 쓰되, **15분이 넘으면 보너스**라는 마인드셋.

### Step 2: 환경 설계 — "글쓰기 트리거"

환경이 행동을 만듭니다. 글을 쓰고 싶어지는 환경을 의도적으로 설계하세요.

**물리적 환경:**
- 글쓰기 전용 공간 or 자리 지정 (카페 한 곳, 책상 한쪽)
- 스마트폰 다른 방에 두기 (or 비행기 모드)
- 글쓰기용 앱만 열어두기 (노션, 워드프레스, 메모장)

**디지털 환경:**
- 글쓰기 시작 전 브라우저 탭 모두 닫기
- 알림 끄기 (카카오톡, 이메일, SNS)
- 글쓰기 타이머 앱 활용 (뽀모도로 25분 or 15분)

**의식(Ritual):**
- 글쓰기 전 커피 한 잔 마시기 → 커피 = 글쓰기 시작 신호
- 특정 음악 틀기 → 음악 = 집중 모드 전환
- 3줄 자유 글쓰기로 워밍업 → 뇌 활성화

### Step 3: 주간 콘텐츠 캘린더

매일 "무슨 글 쓰지?"를 고민하면 에너지가 낭비됩니다. **주간 캘린더를 미리 짜두세요.**

### 주간 캘린더 템플릿

| 요일 | 활동 | 예시 (블로그 운영자) |
|---|---|---|
| **월** | 주제 선정 + 키워드 리서치 | 이번 주 발행할 2편의 주제 확정 |
| **화** | 1편 아웃라인 작성 | PSEA 구조로 뼈대 잡기 |
| **수** | 1편 초고 작성 | 완벽하지 않아도 OK, 일단 쓰기 |
| **목** | 1편 편집 + 발행 | 24시간 숙성 후 퇴고 → 발행 |
| **금** | 2편 아웃라인 + 초고 | 금요일에 한 번 더 |
| **토** | 2편 편집 + 발행 | 토요일 발행 → 주말 트래픽 |
| **일** | 스와이프 파일 정리 + 다음 주 계획 | 영감 수집 + 다음 주 주제 예약 |

### Step 4: 편집은 내일의 나에게

**초고 쓰기와 편집을 같은 시간에 하지 마세요.** 이것이 글쓰기를 망치는 가장 큰 실수입니다.

### 초고 쓰기 규칙

1. **한 번에 끝까지 쓴다** — 중간에 수정하지 않기
2. **완벽하지 않아도 된다** — "쓰레기 같은 초고도 초고다" (Shitty First Drafts)
3. **타이머를 켜놓는다** — 시간 압박이 완벽주의를 억제
4. **오타, 문법 무시** — 내용 흐름에만 집중

### 편집 체크리스트

초고를 쓴 후 **최소 몇 시간~하루** 후에 편집합니다.

| 단계 | 체크 포인트 |
|---|---|
| **1차: 구조** | PSEA/AIDA 등 구조가 맞는가? 논리 흐름이 자연스러운가? |
| **2차: 문장** | 능동태인가? 불필요한 단어는 없는가? 문장이 너무 길지 않은가? |
| **3차: 톤** | 대화체인가? 타겟 독자에 맞는 톤인가? |
| **4차: 시각** | 소제목, 볼드, 리스트, 이미지가 적절한가? |
| **5차: CTA** | 행동 유도가 명확한가? |

### Step 5: 피드백 루프 — "숫자를 읽는 법"

글을 발행한 후에는 반드시 **데이터를 확인**하고 다음 글에 반영하세요.

### 플랫폼별 핵심 지표

| 플랫폼 | 핵심 지표 | 확인 주기 |
|---|---|---|
| 네이버 블로그 | 일방문자, 검색 유입 키워드, 평균 체류시간 | 주 1회 |
| 인스타그램 | 저장 수, 도달, 팔로워 증가율 | 게시물당 |
| 브런치 | 조회수, 좋아요, 구독자 수 | 글당 |
| 뉴스레터 | 오픈율, 클릭률, 구독 취소율 | 발행 때마다 |
| 상세페이지 | 전환율, 이탈률, 체류시간 | 주 1회 |

### 데이터 기반 개선 사이클

```
발행 → 데이터 확인 (48시간 후)
  → 잘된 점 1가지 기록
  → 개선할 점 1가지 기록
  → 다음 글에 반영
```

## 글쓰기 슬럼프 탈출법

매일 쓰다 보면 반드시 슬럼프가 옵니다. 이건 정상입니다.

### 슬럼프 유형별 처방

| 유형 | 증상 | 처방 |
|---|---|---|
| **빈 화면 공포증** | 첫 줄을 못 시작함 | 아무 말이나 쓰기. "오늘 뭘 쓸지 모르겠다"부터 시작 |
| **완벽주의 마비** | 쓰다가 계속 지움 | 타이머 15분 + 지우기 금지 규칙 |
| **소재 고갈** | 쓸 게 없다고 느낌 | 스와이프 파일 훑기 + 댓글/질문에서 소재 발굴 |
| **동기 상실** | 왜 쓰는지 모르겠음 | 서문의 목표 다시 읽기 + 초기 비전 상기 |
| **비교 함정** | 남의 글과 비교하며 위축 | "1년 전의 나 vs 지금의 나" 비교로 전환 |

### 슬럼프 긴급 처방 5분 루틴

1. **1분**: 좋아하는 글 1편을 소리 내어 읽기
2. **1분**: 그 글에서 인상적인 문장 1개 필사하기
3. **3분**: 그 문장을 내 스타일로 변형해서 쓰기

이 5분 루틴만으로도 뇌의 글쓰기 모드가 재활성화됩니다.

## 글쓰기 도구 추천

### 글쓰기 앱

| 도구 | 특징 | 추천 용도 |
|---|---|---|
| **노션 (Notion)** | 구조화 + 데이터베이스 | 콘텐츠 관리 + 캘린더 |
| **옵시디언 (Obsidian)** | 마크다운 + 로컬 저장 | 아이디어 연결 + 메모 |
| **베어 (Bear)** | 심플 + 마크다운 | 빠른 초고 작성 (Mac) |
| **구글 독스** | 협업 + 접근성 | 팀 작업 + 피드백 |
| **메모장** | 제로 방해 | 순수 집중 글쓰기 |

### 보조 도구

| 도구 | 용도 |
|---|---|
| **뽀모도로 타이머** | 집중 시간 관리 (25분/5분) |
| **그래머리 (한국어: 맞춤법 검사기)** | 오타/문법 교정 |
| **캔바 (Canva)** | 인스타 카드뉴스/썸네일 제작 |
| **서베이몽키/타입폼** | 독자 피드백 수집 |
