# Chapter 2. 뇌에 박히는 첫 문장: 호기심 갭과 6가지 훅 공식

## 3초 안에 잡지 못하면 끝이다

네이버 블로그에서 사람들은 제목을 보고 0.3초 만에 클릭 여부를 결정합니다. 인스타 피드에서는 첫 줄을 보고 "더 보기"를 누를지 말지 결정합니다. 이메일 제목을 보고 열지 삭제할지 판단하는 데 걸리는 시간은 단 2초.

**첫 문장이 곧 생존입니다.**

아무리 본문이 훌륭해도, 첫 문장이 약하면 아무도 읽지 않습니다. 반대로 첫 문장이 강하면, 본문이 조금 부족해도 끝까지 읽히는 힘이 생깁니다.

## 호기심 갭(Curiosity Gap): 뇌가 거부할 수 없는 트리거

**호기심 갭**은 "독자가 아는 것"과 "알고 싶은 것" 사이의 간극을 만드는 기법입니다. 인간의 뇌는 미완성된 정보를 견디지 못합니다. 열린 루프(Open Loop)를 닫고 싶은 본능이 있어요.

### 호기심 갭의 3가지 유형

| 유형 | 설명 | 예시 |
|---|---|---|
| **정보 갭** | 모르는 정보가 있다는 걸 알려줌 | "대부분의 블로거가 모르는 SEO 비밀 하나" |
| **결과 갭** | 결과가 궁금하게 만듦 | "이 방법을 쓴 후 매출이 300% 올랐습니다" |
| **반직관 갭** | 상식과 반대되는 정보 제시 | "글을 많이 쓸수록 글쓰기 실력이 떨어지는 이유" |

### 호기심 갭 작성 공식

```
[대상]이 [반직관적 결과]한 [구체적 방법]
```

**예시:**
- "글쓰기 초보자가 한 달 만에 브런치 메인에 실린 공식"
- "좋아요 0이던 인스타 계정이 릴스 하나로 1만 팔로워를 만든 비결"
- "네이버 블로그 상위노출, 글 잘 쓰는 것보다 중요한 한 가지"

## 6가지 헤드라인 공식

수천 개의 바이럴 헤드라인을 분석하면 **6가지 패턴**으로 수렴합니다. 이 공식을 외우면 제목 짓는 데 걸리는 시간이 1/3로 줄어듭니다.

### 1. How-To (방법형)

> **"~하는 방법" / "~하는 N가지 비결"**

**특징**: 가장 보편적이고 안전한 형태. 독자에게 실용적 가치를 약속합니다.

**예시:**
- "네이버 블로그 상위노출하는 7가지 방법"
- "인스타 팔로워 없이 매출 올리는 3단계 전략"
- "브런치 글쓰기로 출판 계약받는 방법"

### 2. List (리스트형)

> **"N가지 ~" / "Top N ~"**

**특징**: 숫자가 주는 구체성과 예측 가능성. 스캔 독서에 최적화.

**예시:**
- "상세페이지 전환율을 높이는 5가지 문장 패턴"
- "직장인이 퇴근 후 글쓰기를 시작하는 10가지 방법"
- "블로그 글쓰기를 망치는 3가지 실수"

### 3. Question (질문형)

> **"왜 ~할까?" / "~하고 있나요?"**

**특징**: 독자의 머릿속에 질문을 심어서 답을 찾으려는 본능을 자극.

**예시:**
- "왜 당신의 블로그 글은 검색되지 않을까?"
- "매일 글을 쓰는데 왜 실력이 안 느는 걸까?"
- "당신의 상세페이지, 첫 3초에서 이탈하고 있진 않나요?"

### 4. Secret (비밀형)

> **"~의 비밀" / "아무도 알려주지 않는 ~"**

**특징**: 독점 정보라는 느낌. 인간은 숨겨진 정보에 더 높은 가치를 부여합니다.

**예시:**
- "월 매출 1억 셀러가 절대 공개하지 않는 상세페이지 비밀"
- "인스타 알고리즘이 밀어주는 글의 비밀 공식"
- "에디터가 말하는, 브런치 메인에 뽑히는 글의 숨은 기준"

### 5. Negative (부정형)

> **"~하지 마세요" / "~하면 망합니다" / "~의 실수"**

**특징**: 손실 회피(Loss Aversion) 심리 활용. 얻는 것보다 잃는 것에 2배 강하게 반응합니다.

**예시:**
- "이 3가지를 모르면 네이버 블로그는 시작도 하지 마세요"
- "인스타 글쓰기에서 90%가 저지르는 치명적 실수"
- "상세페이지에 절대 넣으면 안 되는 단어 5가지"

### 6. Challenge (도전형)

> **"~할 수 있나요?" / "N일 안에 ~하기"**

**특징**: 경쟁심과 성취 욕구를 자극. 행동을 유도하는 힘이 강합니다.

**예시:**
- "7일 안에 네이버 블로그 일방문자 1,000명 만들기"
- "이 글쓰기 테스트, 당신은 몇 점일까요?"
- "30일 글쓰기 챌린지로 인생이 바뀐 사람들"

## 리드 문장: 첫 3줄의 마법

제목으로 클릭을 유도했다면, **리드 문장**(본문 첫 3~5줄)으로 스크롤을 멈추게 해야 합니다.

### 리드 문장 5가지 패턴

**1. 충격 통계형**
> "한국인의 87%는 자신이 쓴 글에 자신이 없다고 답했습니다."

**2. 공감 질문형**
> "블로그 글을 발행하고 나서, 조회수가 10을 넘기지 못할 때의 그 허무함. 아시죠?"

**3. 반직관 선언형**
> "글쓰기를 잘하려면, 글을 쓰지 마세요. 먼저 읽어야 합니다."

**4. 스토리 시작형**
> "2019년, 나는 하루 방문자 3명짜리 블로그를 운영하고 있었습니다."

**5. 약속 제시형**
> "이 글을 끝까지 읽으면, 당신은 오늘부터 헤드라인 짓는 데 5분 이상 고민하지 않게 됩니다."

## 헤드라인 점검 체크리스트

좋은 헤드라인인지 확인하는 자가 진단표입니다.

| 체크 항목 | Y/N |
|---|---|
| 독자의 이익이 명확한가? | |
| 구체적인 숫자나 기간이 있는가? | |
| 호기심 갭이 존재하는가? | |
| 10단어 이내인가? (한국어 기준 20자 내외) | |
| 타겟 독자가 "이건 내 얘기다"라고 느낄 수 있는가? | |
| 네이버 검색 시 경쟁 가능한 키워드가 포함되어 있는가? | |
| 감정을 건드리는 단어가 있는가? | |

**5개 이상 Y**: 좋은 헤드라인입니다. 바로 쓰세요.
**3~4개 Y**: 조금 더 다듬어보세요.
**2개 이하 Y**: 처음부터 다시 쓰는 게 낫습니다.
