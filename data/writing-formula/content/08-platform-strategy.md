# Chapter 8. 플랫폼별 글쓰기 전략: 블로그·SNS·뉴스레터·상세페이지

## 같은 이야기, 다른 옷을 입혀라

인스타에서 먹히는 글이 네이버 블로그에서 먹히지 않습니다. 브런치에서 호평받는 글이 스레드에서는 스크롤당합니다. **플랫폼마다 독자의 기대, 알고리즘, 소비 방식이 다르기 때문**입니다.

하나의 메시지를 플랫폼에 맞게 변환하는 것. 이것을 **콘텐츠 리퍼포징(Content Repurposing)**이라고 합니다. 글 하나를 5~6개 플랫폼용으로 재가공하면, 투입 시간 대비 도달률이 폭발적으로 올라갑니다.

## 플랫폼별 특성 비교표

| 항목 | 네이버 블로그 | 인스타그램 | 브런치 | 스레드 | 뉴스레터 | 상세페이지 |
|---|---|---|---|---|---|---|
| **글 길이** | 1,500~3,000자 | 300~500자 | 2,000~5,000자 | 100~300자 | 800~1,500자 | 1,000~3,000자 |
| **목적** | 검색 유입 | 브랜딩+소통 | 콘텐츠 깊이 | 빠른 소통 | 관계 유지 | 구매 전환 |
| **독자 상태** | 정보 탐색 중 | 스크롤 중 | 읽기 모드 | 빠른 소비 | 의도적 읽기 | 구매 고민 중 |
| **핵심 기술** | SEO+구조화 | 첫 줄 훅+비주얼 | 스토리텔링 | 임팩트+대화 | 개인적 톤 | 설득 구조 |
| **알고리즘** | 키워드 중심 | 저장/공유 중심 | 에디터 큐레이션 | 답글/리포스트 | 오픈율/클릭률 | N/A |

## 1. 네이버 블로그 전략

### SEO 글쓰기 핵심

네이버 블로그는 **검색으로 독자가 들어오는** 플랫폼입니다. 따라서 SEO(검색엔진 최적화)가 생명입니다.

**키워드 리서치 3단계:**

1. **메인 키워드 선정**: 네이버 키워드 도구, 연관 검색어 확인
2. **롱테일 키워드 발굴**: "영양제 추천"보다 "30대 직장인 피로 회복 영양제 추천"
3. **키워드 배치**: 제목, 본문 서두, 소제목, 결론에 자연스럽게 삽입

### 네이버 블로그 글 구조 템플릿

```
[제목] 메인 키워드 + 숫자 or 구체적 혜택
  예: "네이버 블로그 상위노출 7가지 비결 (2024년 최신)"

[서두 — 200자]
공감형 오프닝 + 이 글에서 얻을 것 예고

[본문 — 1,000~1,500자]
핵심 정보를 H2/H3 소제목으로 구조화
각 섹션마다 이미지 1장 이상
리스트, 표, 볼드 적극 활용

[결론 — 200~300자]
핵심 요약 + CTA (이웃 추가, 댓글 유도)
다음 글 예고 (시리즈라면)
```

### 네이버 블로그 체크리스트

- [ ] 제목에 메인 키워드가 들어가 있는가?
- [ ] 본문 서두 2줄 안에 키워드가 있는가?
- [ ] 소제목(H2)을 3개 이상 사용했는가?
- [ ] 이미지를 5장 이상 삽입했는가?
- [ ] 글자 수가 1,500자 이상인가?
- [ ] CTA가 명확한가?

## 2. 인스타그램 전략

### 인스타 캡션 = 첫 줄이 전부

인스타 피드에서는 캡션의 **첫 1~2줄만** 보입니다. "더 보기"를 누르게 만드는 것이 승부처.

### 인스타 캡션 구조

```
[훅 — 첫 줄] 강력한 한 줄 (호기심 갭, 반직관, 질문)
[공백]
[본문 — 3~5줄] 핵심 메시지 (리스트 or 미니 스토리)
[공백]
[CTA] 저장/댓글/공유 유도
[해시태그] 관련 해시태그 10~15개
```

### 인스타 첫 줄 공식 5가지

1. **"~하지 마세요" (금지형)**: "인스타 글 쓸 때 이것만은 하지 마세요"
2. **"~하는 사람 특징" (정체성형)**: "글 잘 쓰는 사람의 3가지 습관"
3. **"솔직히 ~" (고백형)**: "솔직히 말하면, 저도 이게 제일 어려웠어요"
4. **"이거 모르면 ~" (경고형)**: "이거 모르면 인스타 해도 소용없어요"
5. **"~했더니 ~됐다" (결과형)**: "캡션 첫 줄만 바꿨더니 저장 수가 10배"

### 인스타 해시태그 전략

| 유형 | 개수 | 예시 |
|---|---|---|
| 대형 (100만+) | 2~3개 | #글쓰기 #마케팅 #자기계발 |
| 중형 (1만~100만) | 5~7개 | #블로그글쓰기 #카피라이팅 #콘텐츠마케팅 |
| 소형 (1만 미만) | 3~5개 | #글쓰기공식 #헤드라인공식 #인스타글쓰기팁 |

## 3. 브런치 전략

### 브런치 = 읽기 플랫폼

브런치 독자는 **긴 글을 읽을 준비가 된 사람들**입니다. 깊이 있는 스토리텔링과 개인적 에세이가 잘 먹히는 플랫폼이에요.

### 브런치 에디터 추천 기준 (비공식)

- 독창적인 관점과 깊이 있는 내용
- 완성도 높은 문장과 구조
- 독자에게 가치를 주는 콘텐츠
- 꾸준한 발행 (주 1~2회)

### 브런치 글 구조 팁

```
[제목] 문학적 감성 + 핵심 키워드
  예: "퇴사 후 365일, 글 하나로 먹고사는 법"

[서두] 개인적 에피소드로 시작 (장면 묘사)
[본문] 인사이트 + 에피소드 교차 배치
[결론] 여운 있는 마무리 + 독자에게 질문

[매거진 분류] 관련 매거진에 연재 형태로 묶기
```

## 4. 스레드(Threads) 전략

### 스레드 = 속도와 임팩트

스레드는 텍스트 중심의 빠른 소통 플랫폼. **짧고 강한 글**이 승부수입니다.

### 스레드 글쓰기 공식

**단문 임팩트형:**
> "글쓰기에서 가장 쓸데없는 조언:
> '그냥 많이 써보세요'
>
> 방향 없이 많이 쓰면 나쁜 습관만 늘어남.
> 제대로 된 공식 하나를 배우고 쓰세요."

**리스트 나열형:**
> "매일 글쓰는 사람들의 5가지 공통점:
> 1. 완벽을 추구하지 않는다
> 2. 루틴이 정해져 있다
> 3. 읽는 양이 쓰는 양보다 많다
> 4. 스와이프 파일이 있다
> 5. 피드백을 두려워하지 않는다"

**반전형:**
> "글을 잘 쓰고 싶으면 글을 쓰지 마세요.
>
> 먼저 잘 쓴 글 100개를 읽으세요.
> 패턴이 보이기 시작하면 그때 쓰세요."

## 5. 뉴스레터 전략

### 뉴스레터 = 가장 개인적인 채널

뉴스레터는 독자가 **자발적으로 이메일을 열어보는** 채널입니다. 가장 높은 전환율을 만들 수 있는 매체.

### 뉴스레터 핵심 지표

| 지표 | 목표 수치 | 개선 방법 |
|---|---|---|
| **오픈율** | 30% 이상 | 제목 최적화 (6가지 헤드라인 공식) |
| **클릭률** | 5% 이상 | CTA 위치/문구 최적화 |
| **구독 유지율** | 90% 이상 | 일관된 가치 제공 |

### 뉴스레터 제목 공식

- **[숫자] + [구체적 혜택]**: "글쓰기 실력을 올리는 3가지 주간 루틴"
- **[개인적 톤] + [호기심]**: "저번 주에 발견한 글쓰기 비밀 하나"
- **[긴급성] + [가치]**: "오늘까지만 공개: 제가 쓰는 헤드라인 템플릿 30개"

### 뉴스레터 본문 구조

```
[인사] 개인적 안부 (1~2줄)
[본문] 하나의 핵심 인사이트 (PSEA 구조)
[실전 팁] 바로 적용 가능한 것 1개
[CTA] 회신/링크 클릭/공유 유도
[PS] 추가 정보 or 다음 주 예고
```

## 6. 상세페이지 전략

### 상세페이지 = 매출의 최전선

상세페이지는 **돈이 오가는 글**입니다. 여기서의 글쓰기는 매출에 직결됩니다.

### 상세페이지 구조 (스마트스토어 기준)

```
[영역 1: 후킹] — 스크롤 멈추기
  고객의 고통 3줄 (공감)
  "이런 경험 있으시죠?"

[영역 2: 해결] — 이 상품이 답인 이유
  기능이 아닌 혜택 중심 설명
  Feature → Benefit 변환

[영역 3: 증거] — 신뢰 구축
  후기 캡처 / 인증 / 수상 / 데이터
  Before & After 비주얼

[영역 4: 상세 정보] — 궁금증 해소
  성분, 사용법, 주의사항
  자주 묻는 질문 (FAQ)

[영역 5: CTA] — 구매 전환
  구매 버튼 + 한정 혜택 + 보장 정책
```

### 상세페이지 글쓰기 핵심

**Feature → Benefit 변환 연습:**

| Feature (기능) | Benefit (혜택) |
|---|---|
| 비타민C 1,000mg 함유 | 하루 한 알로 지친 피부에 활력을 |
| 100% 오가닉 소재 | 아기 피부에도 안심하고 사용 |
| 48시간 저온 숙성 | 입에 넣는 순간 퍼지는 깊은 풍미 |
| AI 자동 분석 기능 | 매일 10분 아끼는 스마트한 일상 |

## 콘텐츠 리퍼포징 실전 가이드

### 1편의 블로그 글 → 6개 콘텐츠

```
[원본] 네이버 블로그 글 (2,000자)
  ↓
[인스타 캐러셀] 핵심 포인트 5장 카드뉴스
[인스타 캡션] 핵심 메시지 300자로 압축
[스레드] 핵심 한 줄 + 리스트 3개
[뉴스레터] 개인적 톤으로 재구성
[브런치] 스토리를 덧입혀 에세이로 확장
[상세페이지] 제품 연결하여 설득 글로 변환
```

### 리퍼포징 워크플로우

| 단계 | 작업 | 소요 시간 |
|---|---|---|
| 1 | 원본 블로그 글 작성 | 60분 |
| 2 | 인스타 캡션 변환 | 10분 |
| 3 | 스레드 변환 | 5분 |
| 4 | 뉴스레터 변환 | 15분 |
| 5 | 브런치 변환 | 20분 |
| **합계** | 1편 → 5편 | **110분** |

## 실전 과제: 플랫폼 최적화 연습

### 과제 1: 하나의 주제, 3개 플랫폼
하나의 주제를 정하고, 네이버 블로그 / 인스타 캡션 / 스레드 각각에 맞는 글을 써보세요.

### 과제 2: 상세페이지 Feature → Benefit
내 제품(또는 관심 제품)의 Feature 5개를 Benefit으로 변환해보세요.

### 과제 3: 리퍼포징 실전
이번 주에 쓴 글 1편을 골라 다른 2개 플랫폼용으로 리퍼포징해보세요.

---

> **핵심 정리**: 플랫폼마다 글의 옷을 갈아입히세요. 네이버는 SEO, 인스타는 첫 줄 훅, 브런치는 스토리, 스레드는 임팩트, 뉴스레터는 개인적 톤, 상세페이지는 설득 구조. 1편의 글을 6개로 리퍼포징하면 효율이 극대화됩니다.
