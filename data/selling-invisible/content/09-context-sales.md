# 9장. 맥락 세일즈: 상황 · 타이밍 · 메시지를 일치시키는 조건부 타겟팅

---

## 같은 말도 '언제' 하느냐에 따라 다르다

카카오톡 채널에서 다이어트 식단 전자책을 판매하는 지은 씨의 이야기입니다.

1월에 보낸 메시지: "신년 다이어트 프로젝트, 지금 시작하세요!" → 전환율 **4.8%**
3월에 같은 메시지: "다이어트 프로젝트, 지금 시작하세요!" → 전환율 **0.9%**

같은 상품, 같은 메시지, 같은 고객. **달라진 건 '맥락'뿐이었습니다.**

1월은 "새해 결심"이라는 맥락이 있었고, 3월은 그 맥락이 사라진 후였습니다.

**맥락 세일즈(Context-Based Selling)**란, 고객의 상황 · 타이밍 · 심리 상태에 맞춰 메시지를 조율하는 것입니다.

---

## 맥락의 3가지 축

### 축 1: 상황 (Situation)

고객이 **지금 처한 환경**이 무엇인가?

| 상황 | 예시 | 맞춤 메시지 |
|---|---|---|
| 문제 인식 직후 | 세금 폭탄 맞은 직후 | "종합소득세, 이번엔 제대로 절세하세요" |
| 변화 시점 | 퇴사 직후 | "퇴사 후 첫 달, 이것부터 하세요" |
| 성장 정체 | 매출 정체 3개월째 | "정체기를 돌파하는 3가지 전략" |
| 경쟁 위협 | 경쟁자 급증 | "레드오션에서 살아남는 차별화 공식" |

### 축 2: 타이밍 (Timing)

고객에게 **지금이 적절한 순간**인가?

| 타이밍 | 카테고리 | 활용 예시 |
|---|---|---|
| **시즌** | 1월 신년, 3월 개학, 5월 종소세 | 시즌 키워드 + 상품 연결 |
| **요일/시간** | 월요일 아침, 금요일 저녁 | 발송 시간 최적화 |
| **인생 이벤트** | 결혼, 출산, 이직, 창업 | 이벤트 맞춤 메시지 |
| **구매 주기** | 첫 구매 후 30일, 90일 | 재구매 유도 타이밍 |

### 축 3: 메시지 (Message)

**상황과 타이밍에 맞는 말**을 하고 있는가?

같은 상품이라도 맥락에 따라 메시지가 달라져야 합니다:

**스마트스토어 운영 강의:**
- 1월 (새해): "올해는 진짜로 부업 수입을 만들어보세요"
- 5월 (종소세): "스마트스토어 종소세 신고, 이거 모르면 세금 더 냅니다"
- 9월 (추석): "추석 선물세트 특수 시즌, 3주 안에 준비하는 법"
- 11월 (블프): "블랙프라이데이 매출 3배 만드는 상세페이지 전략"

## 조건부 타겟팅 실전 가이드

### 조건부 타겟팅이란?

**"만약 [조건]이라면, [이 메시지]를 보낸다"**는 규칙 기반 마케팅입니다.

### 조건 설계 프레임워크

```
IF [고객 상태] + [타이밍] THEN [메시지] + [오퍼]
```

### 실전 적용 예시

**예시 1: 크몽 프리랜서의 조건부 타겟팅**

```
IF 프로필 조회 후 미구매 (3일 경과)
THEN "아직 고민 중이시라면, 무료 포트폴리오 리뷰를 먼저 받아보세요"
```

**예시 2: 아임웹 전자책 판매자의 조건부 타겟팅**

```
IF 구매 후 7일 경과 + 후기 미작성
THEN "OOO 님, 읽어보셨나요? 후기 남겨주시면 다음 전자책 30% 할인 쿠폰을 드려요"
```

**예시 3: 카카오톡 채널 코칭 판매**

```
IF 무료 상담 완료 + 미구매 (2일 경과)
THEN "상담에서 말씀드린 3가지 실천법, 잘 적용되고 계신가요?
      더 체계적으로 하고 싶으시면 4주 코칭 프로그램도 있습니다 →"
```

## 시즌별 맥락 마케팅 캘린더

### 한국 시장 맥락 캘린더 (무형 상품 기준)

| 월 | 시즌 키워드 | 맥락 | 적용 상품 예시 |
|:---:|---|---|---|
| 1월 | 새해 결심 | 변화 욕구 최고 | 자기계발, 습관, 부업 |
| 2월 | 졸업/취업 준비 | 불안감 높음 | 포트폴리오, 면접, 스펙 |
| 3월 | 새 학기/새 분기 | 새 출발 에너지 | 생산성, 업무 스킬 |
| 4월 | 봄 환절기 | 건강 관심 증가 | 건강, 다이어트, 운동 |
| 5월 | 종합소득세 | 세금 공포 | 세무, 절세, 사업자 관리 |
| 6월 | 상반기 마감 | 성과 점검 | 비즈니스 전략, 리뷰 |
| 7월 | 여름 휴가 | 자기 투자 시간 확보 | 자기계발, 사이드 프로젝트 |
| 8월 | 하반기 준비 | 계획 수립 | 마케팅, 브랜딩, 기획 |
| 9월 | 추석 시즌 | 특수 판매 기회 | 시즌 마케팅, 특수 전략 |
| 10월 | 독서의 달 | 학습 욕구 | 전자책, 강의, 지식 상품 |
| 11월 | 블프/쇼핑 시즌 | 할인 기대 심리 | 번들, 패키지, 연간 플랜 |
| 12월 | 연말 정산/회고 | 정리 욕구 | 재테크, 회고, 플래너 |

### 시즌 마케팅 3원칙

**원칙 1: 2주 전에 준비**
시즌 시작 2주 전부터 인지 단계 콘텐츠 발행

**원칙 2: 시즌 키워드 + 상품 자연스럽게 연결**
- 나쁜 예: "새해 기념 할인합니다!"
- 좋은 예: "새해 결심 1위는 '부업'. 그런데 95%는 2월에 포기합니다. 포기하지 않는 3가지 방법은..."

**원칙 3: 시즌이 끝나면 메시지도 바꾸기**
지난 시즌 메시지를 계속 쓰면 "이 사람 관리 안 하는구나" 인상

## 채널별 맥락 최적화

### 인스타그램

**맥락 포인트:** 스크롤 중 3초 안에 멈추게 해야 함
- 첫 줄에 맥락 키워드: "5월 종소세 시즌..."
- 릴스: 처음 2초에 충격적 맥락 제시
- 스토리: 실시간 맥락 (오늘, 지금, 방금)

### 카카오톡 채널

**맥락 포인트:** 1:1 대화의 친밀감 활용
- 발송 시간 최적화: 점심 12~1시, 퇴근 후 7~9시
- 요일 최적화: 화~목 발송률이 가장 높음
- 개인화: "OOO 님" 이름 포함 시 열람률 23% 상승

### 네이버 블로그

**맥락 포인트:** 검색 의도에 맞는 콘텐츠
- 시즌 검색어 분석: 네이버 데이터랩 활용
- 검색 의도 파악: 정보 탐색 vs 구매 의도 구분
- 맥락 맞춤 제목: "2026년 9월 스마트스토어 추석 특수 공략법"

### 이메일/뉴스레터

**맥락 포인트:** 정기 발송의 기대감 활용
- 고정 발송일: 매주 화요일 아침 8시 (예시)
- 시즌 특별 호: 월 1회 시즌 맞춤 콘텐츠
- 구매 후 시퀀스: 구매 직후 → 3일 후 → 7일 후 → 30일 후

## 메시지 일치도 진단: 불일치가 매출을 죽인다

### 메시지 불일치의 3가지 유형

**유형 1: 채널 불일치**
- 인스타 릴스(가벼운 톤)의 CTA → 판매 페이지(격식 톤)
- 고객이 "다른 곳에 온 것 같다"고 느끼면 이탈

**유형 2: 시점 불일치**
- 인지 단계 고객에게 바로 구매 CTA
- 관심 단계인데 기초 정보 반복

**유형 3: 감정 불일치**
- Before(공감)에서 갑자기 After(과장)으로 점프
- 고객의 감정 흐름과 어긋남

### 메시지 일치도 체크리스트

- [ ] 광고/콘텐츠의 톤 = 판매 페이지의 톤
- [ ] 약속한 내용 = 실제 제공하는 내용
- [ ] 고객의 현재 단계 = 메시지의 수준
- [ ] 시즌/상황 = 메시지의 키워드
- [ ] 채널의 특성 = 콘텐츠 형태

## 맥락 기반 A/B 테스트 방법

### 무엇을 테스트할 것인가

| 테스트 대상 | A 버전 | B 버전 | 측정 지표 |
|---|---|---|---|
| 발송 시간 | 아침 8시 | 저녁 8시 | 열람률 |
| 헤드라인 맥락 | 시즌 키워드 포함 | 시즌 키워드 미포함 | 클릭률 |
| CTA 문구 | "지금 시작하기" | "무료 체험해보기" | 전환율 |
| 감정 강도 | 손실회피형 | 이득형 | 전환율 |

### A/B 테스트 규칙

1. **한 번에 하나만** 바꾸세요 (둘 이상 바꾸면 뭐가 효과인지 모름)
2. **최소 100명** 이상에게 테스트 (표본이 적으면 우연일 수 있음)
3. **1주일** 이상 운영 (요일별 차이 반영)
4. **결과를 기록**하세요 (다음 시즌에 재활용)
