## 부록 A: 판매 페이지 체크리스트

판매 페이지를 공개하기 전, 아래 항목을 하나씩 확인하세요.

### 구조 점검

- [ ] 헤드라인이 고객의 Pain을 정확히 짚고 있는가?
- [ ] 첫 3줄 안에 "이건 내 이야기다"라는 공감이 발생하는가?
- [ ] Pain → 공감 → Solution → Evidence → CTA 순서를 따르고 있는가?
- [ ] Feature뿐 아니라 Benefit과 Emotion이 충분히 포함되어 있는가?
- [ ] Who/What/How 가치 한 문장이 명확한가?

### 신뢰 장치 점검

- [ ] 사회적 증거가 2개 이상 포함되어 있는가? (숫자, 후기, 권위 등)
- [ ] 고객 후기에 Before → After 변화가 구체적으로 드러나는가?
- [ ] 판매자의 권위/전문성이 근거와 함께 제시되어 있는가?
- [ ] 환불 보증 또는 리스크 제거 장치가 명시되어 있는가?
- [ ] 과정 공개(타임라인, 단계별 결과)가 포함되어 있는가?

### 가격 프레이밍 점검

- [ ] 앵커링(상위 가격 또는 외부 비교)이 적용되어 있는가?
- [ ] 가격이 세분화(일 단위, 건 단위)되어 있는가?
- [ ] ROI가 구체적 숫자로 제시되어 있는가?
- [ ] 대안 비용과의 비교가 포함되어 있는가?

### CTA 점검

- [ ] CTA 버튼이 동사로 시작하는가?
- [ ] CTA에 "얻게 되는 것"이 포함되어 있는가?
- [ ] CTA 주변에 리스크 제거 문구가 있는가?
- [ ] CTA가 최소 3곳에 배치되어 있는가? (상단, 중단, 하단)
- [ ] 긴급성/희소성 요소가 CTA 근처에 있는가?

### 톤앤매너 점검

- [ ] 전체 톤이 일관성 있는가? (시작~끝까지)
- [ ] 감각적 언어가 3개 이상 사용되었는가?
- [ ] 전문 용어에 즉시 풀이가 달려 있는가?
- [ ] FAQ가 고객의 말투로 작성되어 있는가?
- [ ] 모바일에서 읽기 편한 줄 길이인가?

### 최종 점검

- [ ] 오탈자 확인 완료
- [ ] 링크 정상 작동 확인
- [ ] 결제 프로세스 테스트 완료
- [ ] 모바일 화면 레이아웃 확인
- [ ] 주변 3명에게 피드백 받기 완료

## 부록 D: CTA 템플릿 10개

상품 유형에 맞는 CTA를 골라 사용하세요. 괄호 안을 자신의 상품에 맞게 수정합니다.

### 1. 직접 구매형
> **지금 [상품명] 시작하기 →**
> 7일 무조건 환불 보증

### 2. 무료 체험형
> **무료로 [1장/1강] 먼저 확인하기**
> 결제 정보 없이 바로 열람 가능

### 3. 상담 연결형
> **카카오톡으로 1분 상담받기 →**
> 평균 응답 시간: 2시간 이내

### 4. 얼리버드형
> **얼리버드 가격으로 시작하기 (D-[숫자])**
> [날짜]부터 정가 [금액]원으로 올라갑니다

### 5. 번들형
> **[상품 A + B + C] 세트로 한 번에 받기**
> 개별 구매 대비 [숫자]% 절약

### 6. 한정 수량형
> **지금 신청하기 ([숫자]명 중 [숫자]자리 남음)**
> 1:1 맞춤 서비스를 위해 인원을 제한합니다

### 7. 리스크 제거 강조형
> **부담 없이 시작하기**
> 만족하지 않으시면 100% 환불 (질문 없이)

### 8. 결과 약속형
> **[기간] 안에 [결과]를 만들어 보세요 →**
> [숫자]명이 이미 [결과]를 달성했습니다

### 9. 업그레이드형
> **[기본 플랜] 대신 [프리미엄 플랜] 선택하기**
> +[금액]원으로 [추가 혜택]까지 포함

### 10. 뉴스레터 전환형
> **매주 [요일], 무료 인사이트 받아보기**
> 이메일 주소만 입력하면 바로 시작됩니다
> [숫자]명의 [타겟]이 함께 읽고 있습니다
