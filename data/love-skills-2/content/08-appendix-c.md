## 복사해서 쓰는 실행표

| 날 | 실제로 한 일 | 알게 된 점·다음 선택 |
|---|---|---|
| 1일 — 사실과 해석 | [ ] | [ ] |
| 2일 — 요청 한 문장 | [ ] | [ ] |
| 3일 — 제안하고 답 듣기 | [ ] | [ ] |
| 4일 — 합의한 행동 실행 | [ ] | [ ] |
| 5일 — 도움·부담 기록 | [ ] | [ ] |
| 6일 — 필요한 조정 | [ ] | [ ] |

**기록 규칙:** 쉬었다면 ‘쉬었음’, 대화하지 못했다면 ‘대화 못 함’, 합의가 없다면 ‘합의 없음’이라고 씁니다. 빈칸을 성공한 것처럼 채우지 않습니다. 일주일은 편의를 위한 묶음이며 관계 판단의 의무 대기 기간이 아닙니다.

## 완성 예시 — 휴일 약속을 미리 정하고 싶은 경우

| 날 | 실제 기록 | 알게 된 점 |
|---|---|---|
| 1일 | 토요일 오전까지 만남 시간이 정해지지 않았던 일을 적었다 | 관심이 없다는 해석과 일정 미정이라는 사실은 다르다 |
| 2일 | “목요일까지 가능 여부를 알고 싶어”라고 썼다 | 내가 원하는 것은 매주 만남보다 예측 가능한 일정이다 |
| 3일 | 제안했고 상대는 금요일 오전이라면 가능하다고 했다 | 목요일은 업무가 정해지지 않는다고 들었다 |
| 4일 | 금요일 오전까지 알려주기로 둘이 동의했다 | 아직 행동 확인 전이다 |
| 5일 | 약속한 때 연락이 와서 토요일 저녁으로 정했다 | 내 다른 일정도 정할 수 있었다 |
| 6일 | 급한 변경은 알게 된 쪽이 먼저 알리기로 덧붙였다 | 확정 뒤의 변경도 따로 정할 필요가 있었다 |
| 7일 | 다음 주에도 이 방식을 써보기로 했다 | 이번 약속은 실행됐지만 모든 문제가 해결된 것은 아니다 |

이 예시는 가상의 성공 사례입니다. 상대가 제안을 원치 않거나 약속이 지켜지지 않은 경우도 실제 결과로 기록합니다. 상대의 답을 바꾸기 위해 같은 제안을 계속 반복해야 하는 것은 아닙니다.

## 막혔을 때 돌아갈 절

**“내가 너무 예민한 걸까?”** 감정의 크기를 평가하기 전에 01절에서 사실과 해석을 나누고, 04절에서 원하는 행동과 경계를 적습니다. 불편하다는 말을 하기 위해 먼저 내가 정상이라는 판정을 받을 필요는 없습니다.

**“말은 잘했는데 상대가 화를 내요.”** 06절의 문장만 계속 다듬지 마세요. 상대가 구체적으로 어떤 요청을 거절하는지, 조롱이나 위협이 있는지 구분합니다. 15·16절로 넘어갈 수 있습니다.

**“내가 참으면 싸움이 줄어요.”** 싸움 횟수만 보지 말고 내 의견을 말할 수 있는지도 확인합니다. 불만을 말하지 않아 조용한 것과 서로 조정해 편안한 것은 다릅니다.

**“쉬자고 하면 더 불안해져요.”** 09절에서 재개 시점과 변경 연락을 정합니다. 약속한 재개가 반복해서 사라진다면 기다리는 연습만 할 문제가 아닙니다.

**“사과는 정말 잘해요.”** 11절에서 책임지는 행동이 있는지 보고 12절에서 실제 실행을 기록합니다. 말의 감동과 다음 장면을 구분합니다.

**“혼자 읽어도 쓸모가 있나요?”** 사실·해석 메모, 요청 초안, 경계와 판단 기록은 혼자 쓸 수 있습니다. 둘의 연락 약속이나 공동 행동은 상대의 동의 없이 합의로 만들 수 없습니다.

**“헤어지는 게 정답인가요?”** 이 책은 한쪽 기록만으로 답을 내려주는 검사가 아닙니다. 15절의 내 기준과 확인한 행동을 살피세요. 계속 만나야 할 의무는 없으며, 위험이 있으면 16절의 안전과 지원을 먼저 선택합니다.
