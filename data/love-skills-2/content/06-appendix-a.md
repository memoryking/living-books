# 부록 A. 보내기 전 점검표와 빈 양식

이 부록은 본문을 읽은 뒤 메모장에 복사해서 쓰는 도구입니다. 입력 내용이 이 전자책에 자동 저장되는 양식은 아닙니다. 민감한 기록은 자신이 안전하게 관리할 수 있는 곳에 보관하세요. 상대의 계정이나 기기에 접근해 기록을 수집하지 않습니다.

## 한 장 점검표 — 이 말을 지금 보내도 될까?

답은 ‘예 / 아니요 / 아직 모름’으로 적습니다. 개수를 합산해 연애 실력을 평가하지 않습니다. ‘아니요’인 항목이 지금 다룰 작업입니다.

| 점검할 것 | 아니라면 할 일 |
|---|---|
| 내가 본 사실과 추측을 나눴다 | 01절의 네 칸을 쓴다 |
| 이번 메시지의 목적이 하나다 | 확인·위로·요청 중 하나를 고른다 |
| ‘항상·절대·원래 그런 사람’으로 인격을 판정하지 않았다 | 실제 사건과 시점으로 바꾼다 |
| 상대가 실행할 수 있는 요청이 있다 | 행동과 시점을 붙인다 |
| 상대가 거절하거나 대안을 제시할 수 있다 | 사랑을 증명하라는 조건을 뺀다 |
| 지금 대화할 수 있는 상황인지 확인했다 | 가능할 때를 묻는다 |
| 내 경계와 상대를 통제하려는 요구를 구분했다 | 내가 허용할 범위를 쓴다 |
| 상대의 답이 내 기대와 달라도 들을 준비가 있다 | 설득 전에 내 선택지를 적는다 |
| 대화가 위험하지 않다 | 위협이 있으면 대화보다 도움을 먼저 구한다 |

**작성 예시:** “넌 왜 늘 친구부터야?”를 보내려 했다면 목적은 ‘이번 주말 함께할 시간 정하기’로 좁힙니다. “이번 주말에 함께 시간을 보내고 싶어. 토요일 저녁 가능해? 어렵다면 다른 날을 정하자.” 이 요청이 모든 서운함을 해결하지는 않습니다. 반복되는 우선순위 문제는 별도의 대화로 남깁니다.

## 빈 양식 1 — 사실에서 요청까지

> 날짜와 상황: [ ]  
> 직접 확인한 사실: [ ]  
> 내가 붙인 해석: [ ]  
> 아직 모르는 점: [ ]  
> 내 감정·생활에 준 영향: [ ]  
> 이번에 원하는 행동 하나: [ ]  
> 보낼 문장: [ ]  
> 상대가 어렵다고 하면 제안할 대안 또는 내 선택: [ ]

**사용 시점:** 답장이 늦거나 약속이 바뀌어 바로 반응하고 싶을 때. 사실 칸에 ‘날 무시했다’가 있다면 어떤 행동을 보고 그렇게 느꼈는지 다시 씁니다.

**작성 예시:** 토요일 약속 변경을 출발한 뒤 알았다 / 나를 가볍게 여긴다고 생각했다 / 변경 가능성을 언제 알았는지 모른다 / 이동 시간을 잃어 속상했다 / 다음에는 가능성을 알게 되면 알려주길 바란다.

> 상태: [내 제안 / 상대 제안 / 둘이 동의한 합의]  
> 각자 연락하기 어려운 상황: [ ]

**사용 시점:** 연락 빈도나 답장 기대가 다를 때. ‘사랑하면 즉시 답장’ 같은 시험 문장을 합의에 넣지 않습니다.

**작성 예시:** 둘이 동의함 / 근무·수업 중 답하기 어려움 / 저녁에 짧은 안부 / 약속 변경은 알게 된 쪽이 먼저 메시지 / 급한 용건은 전화 / 놓쳤다면 확인 후 사정과 가능한 시간 알리기 / 주말에 부담된 점 확인.

## 빈 양식 3 — 중단과 재개

> 대화를 멈춰야겠다고 느끼는 신호: [ ]  
> 그때 쓸 말: [ ]  
> 다시 이야기할 제안 시점: [ ]  
> 그때도 어려우면 알릴 방법: [ ]  
> 재개할 때 다룰 사건 하나: [ ]  
> 각자 들은 요점: [ ]  
> 정한 행동과 남은 차이: [ ]

**사용 시점:** 안전한 관계에서 말이 거칠어지거나 대화가 반복될 때. 상대의 이동을 막거나 대화를 강제로 계속시키는 용도로 쓰지 않습니다.

**작성 예시:** 목소리가 커지고 같은 말을 반복함 / “쉬었다가 오늘 아홉 시에 이 문제만 이야기하자” / 아홉 시 / 어려우면 그전에 연락 / 약속 변경 통보 / 늦게 알아 기다리는 시간이 힘들었음 / 변경 가능성 먼저 알리기, 만남 횟수는 다음에 논의.

> 원하지 않는 일: [ ]  
> 전달할 문장: [ ]  
> 존중되지 않을 때 내가 취할 수 있는 안전한 행동: [ ]

**사용 시점:** 기기 열람, 사진 게시, 비용, 시간, 신체 접촉에 불편함이 있을 때. 경계는 상대를 벌주겠다는 협박이 아닙니다.

**작성 예시:** 허락 없이 사진을 올림 / 함께 찍는 것은 괜찮음 / 게시 전 사진과 공개 범위 확인 / 허락 없는 게시 원치 않음 / “올리기 전에 나에게 물어봐줘. 이번 사진은 내려줬으면 해” / 반복된다면 함께 찍는 일을 중단하고 관계를 다시 판단.

**사용 시점:** 사과나 약속이 반복되어 판단이 흐려질 때. ‘나쁜 사람’ 같은 평가 대신 확인한 행동을 씁니다.

**작성 예시:** 다른 사람 앞에서 개인 고민 말하지 않기 / 다음 모임에서 이야기를 꺼내지 않음 / 이번에는 어긋남 없음 / 덜 긴장하고 이야기할 수 있었음 / 같은 경계 유지 / 관계를 이어가며 내 불편도 계속 살피기.

**작성 예시:** 밤에 답이 늦음 / 관계가 끝난 것 같음 / 오늘 통화 약속이 있었는지 확인 / “가능할 때 오늘 통화할 수 있는지 알려줘” / 식사하고 내 일정 마무리 / 신뢰하는 친구에게 지금 힘든 점을 이야기하기.
